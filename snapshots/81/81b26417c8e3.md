# 国产大型邮轮“爱达·花城号”出坞

发布时间：2026-03-23 16:24文章来源：海关总署【字体：小中大】

3月20日，第二艘国产大型邮轮“爱达·花城号”出坞，转入码头系泊调试，并计划于2026年10月交船。“爱达·花城号”总吨位达14.19万吨，总长341米，规模较首艘国产邮轮——“爱达·魔都号”进一步扩大，全船零部件数量达2500万个。

邮轮建造过程中需要引进大量关键性生产设备，这些设备具有体积大、精度高、加工覆盖范围广的特点，对加工贸易备案、核销等全流程监管提出了更高的要求。上海海关所属上海浦东海关建立高效响应机制，及时解答企业在建造过程中的各类疑难问题。自2022年8月“爱达·花城号”开工建造以来截至2026年2月底，上海浦东海关共监管邮轮项目保税物资1651批次，货值约3.78亿美元。

“爱达·花城号”在建造过程中，上海外高桥造船有限公司创新采用自研智能平台，在项目的设计、采购、物流、加工、财务结算等各个方面实现扁平化管理，有效提升资源效率和成本控制水平。

“针对船舶全流程智能化建造的革新需求，海关依托加工贸易‘政策包’开展顺势监管，通过制度创新、流程再造与精准服务，为‘大国重器’建造提速赋能。以‘一船一册’为核心设立加工贸易专用账册、支持企业报核前申报单耗，并借助企业智能平台上提供的海关通道，实现邮轮项目料件的精细化管理和全流程追溯。同时，将企业纳入企业集团加工贸易监管模式，充分利用保税料件等政策优势，降低企业资金占用和运营成本，助力邮轮建造高效推进。”上海海关稽查处保税监管科科长王尧介绍。

2026年前两个月，上海海关加工贸易海工船舶进出口值达203.96亿元，同比增加154.38%。（陈如意/文）
