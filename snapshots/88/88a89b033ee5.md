# 美股道指首次突破50000点

2026-02-07 08:58:11 来源：[中国新闻网](http://www.chinanews.com.cn/gj/2026/02-07/10567726.shtml) 作者：叶攀 责任编辑：叶攀

[中新社](/)纽约2月6日电(记者 王帆)美国股市三大指数6日全线收高，其中道琼斯工业平均指数大涨逾1200点，收盘时首次突破50000点大关。

　　截至收盘，道指上涨1206.95点，收于50115.67点，涨幅为2.47%；纳斯达克综合指数上涨490.63点，收于23031.21点，涨幅为2.18%；标准普尔500种股票指数上涨133.90点，收于6932.30点，涨幅为1.97%。

　　当天，不少科技股在经历连续数日的大规模抛售后反弹。热门股中，英伟达涨7.87%，特斯拉涨3.50%，微软涨1.90%。不过，亚马逊、谷歌等公司股价继续走低，市场对科技巨头在人工智能(AI)领域的巨额投入仍感担忧。

　　《华尔街日报》说，道指突破50000点的道路“充满荆棘”，接下来的道路可能“更加崎岖”。曾推动美股上涨的AI热潮，正逐步转化为市场压力点。叠加美联储货币政策与美国贸易政策的不确定性，市场情绪在发生转变。

|  |
| --- |
|  |

　　报道说，本周多家科技巨头公布了季度财报，其中部分公司今年在AI领域的数千亿美元资本支出计划，引发了整个行业的股价波动。市场对尚未盈利的投机性投资开始失去信心，预计对AI热潮的审视仍将持续。

　　彭博社援引分析人士观点说，本周前几日，美股的调整可视为“挤泡沫”。道指达到新的里程碑，与其说是“庆祝”，不如说是“确认”，因为市场已经适应了更高的利率、更慢的经济增长以及全球多重因素的不确定性。2026年的美股走势将更依赖基本面。如果科技股在未来几周再出现大幅回调，投资者需关注风险。(完)
