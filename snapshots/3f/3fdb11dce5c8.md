| 新任证监会主席易会满： 一位浙江籍“草根银行家” |
| --- |
|  |

| 2019-01-27 09:55:25 [杭州网](http://www.hangzhou.com.cn/) |
| --- |
|  |

| **中专学历出身 从最基层干到国有大行董事长**<br>**出生在温州苍南，从杭州起步进入金融业**<br>都市快报 记者 林司楠<br>据新华社消息，日前，中共中央决定，任命易会满同志为中国证监会党委书记，免去刘士余同志的中国证监会党委书记职务。国务院决定，任命易会满同志为中国证监会主席，免去刘士余同志的中国证监会主席职务。刘士余同志另有任用。<br>**逆袭的浙江籍“草根银行家”**<br>现年55岁的易会满，1964年出生于温州市苍南县。1984年，易会满从当时的国家级重点中专浙江银行学校（现已升格为浙江金融职业学院）城市金融专业毕业，进入中国人民银行杭州市分行，担任计划处计划员。工商银行公告显示，易会满1985年加入中国工商银行。从1985年开始，他先后任工行杭州分行西湖办事处计划股科员、办事处主任、杭州市分行行长、浙江省分行副行长、江苏省分行行长、北京市分行行长等职。可以说，易会满职业生涯的前半程与杭州密不可分。<br>2013年5月，中国工商银行正式宣布，由易会满接替超期服役的杨凯生，担任行长一职，同时提名易会满为工商银行执行董事，并选举其为副董事长。但这显然不是易会满职业生涯的顶点。<br>2016年5月，易会满被正式选举为工商银行董事长。在他的带领下，2016-2017年，工商银行的净利润总量保持着全球银行业最好水平。<br>一名央行官员曾这样评价易会满：“国有大行中，由行长直接接任董事长职位的做法几乎没有先例。国有大行董事长的人选一般由央行或者其他副部级单位一把手来接任，易会满的能力可见一斑。”<br>事实上，作为一名毫无背景、毕业于中专院校的“草根银行家”，易会满的脱颖而出时常被金融业界视为职业标杆。<br>浙江金融业资深人士说起易会满，最深的印象就是务实。当时当过工行浙江省分行行长、工行副行长的张衢，很快发现易会满具有很强的业务能力、灵活的思维、扎实的工作作风，便着力培养。现在的浙江工行有不少老员工曾是易会满的下属，他给他们最直观的感受就是专业强、人随和。“他业务能力强，口才超好，很多时候都是脱稿演讲”“没什么领导架子，为人非常随和”。<br>- 1<br>- [2](http://hznews.hangzhou.com.cn/jingji/content/2019-01/27/content_7139686_2.htm)<br>- [3](http://hznews.hangzhou.com.cn/jingji/content/2019-01/27/content_7139686_3.htm)<br>- [下一页](http://hznews.hangzhou.com.cn/jingji/content/2019-01/27/content_7139686_2.htm)<br>- [全文阅读](http://hznews.hangzhou.com.cn/jingji/content/2019-01/27/content_7139686_0.htm) |
