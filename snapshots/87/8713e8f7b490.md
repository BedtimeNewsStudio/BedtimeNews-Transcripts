| 亚泰状告足协　法院不予受理 |  |  |  |  |  |  |  |  |
|  |  |  |  |  |  |  |  |  |
| 据新华社北京1月24日电（记者李煦 <br>牛爱民）记者今晚从北京市第二中级人民法院获悉，长春亚泰足球俱乐部及其教练员殷铁生状告中国足球协会案终于有了结果。1月23日，法院对上述两案作出不予受理的裁定，并将裁定书送达了起诉人。<br> <br>　 <br>据了解，今年1月7日，长春亚泰足球俱乐部及其教练员殷铁生，携球员李洪政、姜鹏翔等10人委托代理人———北京友邦律师事物所律师周卫平、蔡宝川到北京市第二中级人民法院分别状告中国足球协会，请求法院判令中国足球协会撤消其作出的足纪字（2001）14号处理决定；中国足球协会赔偿因上述处罚而给原告造成的直接经济损失300万元；诉讼费由中国足球协会承担。<br> <br>原告在起诉书中称：“2001年，中国足球协会组织全国足球甲级联赛并实施管理，原告依据有关规则参加了全国足球甲级 <br>B组联赛。在联赛中，原告发扬体育拼搏精神，终于在2001年10月6日的第二十二轮与浙江绿城足球队比赛中，净胜6球，在整个赛季中排名甲 <br>B第二。按照中国足球协会发布的《全国足球队甲级联赛规则》第九条的有关规定，长春亚泰足球队应升入甲 <br>A足球队之列。但是，中国足球协会在联赛后的2001年10月16日，突然作出足纪字（2001）14号‘关于对四川绵阳、成都五牛、长春亚泰、江苏舜天和浙江绿城俱乐部足球队处理的决定’，该决定第一项处罚是取消原告升入甲 <br>A资格，第四项处罚是取消原告足球队2002年、2003年甲乙级足球联赛引进国内球员的资格，第七项是限原告3个月期限的内部整顿。原告不服中国足球协会的14号处理决定，于2001年10月19日和11月10日两次向中国足球协会提出申诉状，但中国足球协会未能在法定的时间内答复，原告认为该决定为法律授权的组织作出的行政处罚行为，该行为没有事实依据，也无法律依据，依据《行政诉讼法》应予撤消。”<br> <br>　 <br>北京市第二中级人民法院对上述两案进行审查后，认为两案的起诉不符合《中华人民共和国行政诉讼法》有关规定的受理条件。据此，作出不予受理的裁定。 |  |  |  |  |  |  |  |  |
