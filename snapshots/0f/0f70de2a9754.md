# 复旦大学2020年强基计划补充遴选通知

发布时间：2020-09-11

为培养更多为国担当、能承担科技创新和科教兴国重任的掌握未来的复旦人，进一步夯实强基计划生源基础，经学校研究决定，在2020级本科新生中开展强基计划补充遴选工作。

**一、补充遴选计划数**

| **专业** | **计划上限（人）** |
| --- | --- |
| 汉语言（古文字学方向） | 13 |
| 历史学 | 6 |
| 哲学 | 7 |
| 数学与应用数学 | 12 |
| 物理学 | 20 |
| 化学 | 23 |
| 生物科学 | 23 |
| 基础医学 | 20 |

每人限报一个专业。

**二、遴选对象及报名条件**

参加2020年普通高等学校招生全国统一考试报名、有志于服务国家重大战略需求的复旦大学2020级本科新生，除以下几类学生外，均可报名：

（一）已经入选强基计划的新生；

（二）通过外语类保送生体验营录取的新生；

（三）通过高考统招批次（含国家专项和高校专项批次）录取至俄语、朝鲜语、马克思主义理论、法医学、护理学（含助产士方向）专业的新生。

此外，复旦大学上海医学院录取的新生只可填报基础医学专业，数学与应用数学专业补充遴选范围限于“2020数学英才试验班”新生。

不符合报名条件的，视为无效报名。

**三、报名方式与选拔程序**

（一）9月14日9:00至9月20日17:00，符合报名条件的学生可登录[复旦大学网上办事服务大厅](http://ehall.fudan.edu.cn/)，搜索“转专业”，进入服务后，选择“2020年强基计划补充遴选”批次，填写报名信息。医学院学生只能填报“基础医学”专业，否则作无效报名处理。

（二）9月24日前，在复旦大学本科教学信息网公布通过报名资格审核的学生名单。

（三）10月1日前，完成遴选考核（具体安排另行通知），各专业考核方式如下：

1.数学与应用数学专业：在“2020数学英才试验班”中根据选拔成绩择优征询录取；

2.其他专业：专家组面试。

（四）10月10日前，依据考核结果和专业计划数择优确定强基计划补充入选名单，并在复旦大学本科教学信息网公示。

强基计划补充入选名单确定并公示后，入选学生的学籍及相关信息将由学校统一予以变更，学校不再接受学生退回原专业（类）的申请。

**四、培养方案**

本次补充入选的学生，后续的培养措施等与前期直接通过强基计划录取的学生完全相同。学校对强基计划学生制定单独人才培养方案和激励机制，增强学生的荣誉感和使命感。学校将为强基计划学生配备一流的师资，提供一流的学习条件，创造一流的学术环境和氛围，实行导师制、小班化等培养模式。对于学业优秀的学生，将在本硕博衔接培养、公派留学、奖学金等方面予以优先安排。同时，建立阶段性考核和动态进出机制。

**五、其他说明**

（一）学生报名时填写的信息将作为考核参考材料，无需递送纸质材料。

（二）对于报名材料造假或在考核中舞弊的学生，将取消强基计划补充遴选的报名、考核和入选资格，并按照教育部和我校有关规定进行处理。

（三）视疫情防控情况，考核方案或作相应调整，另行通知。

（四）基础医学专业的强基计划学生原则上本科阶段不得转专业；其他专业的强基学生原则上本科阶段不得转到强基计划招生之外的专业就读。

（五）学校未委托任何个人或中介机构组织开展包括强基计划在内的各项考试招生，不举办任何形式的培训活动。

**六、领导与监督保障机制**

（一）复旦大学强基计划补充遴选工作由学校强基计划专项工作领导小组统筹管理有关工作。

（二）复旦大学在强基计划补充遴选的过程中做到机会公平、程序公开、结果公正。

（三）复旦大学强基计划补充遴选工作全程接受复旦大学监察处监督。
