# 虎头局，狂飙失速

###### 2023年04月03日 15:54   猎云网

![](https://img.21jingji.com/uploadfile/cover/20230403/1680486477861664.png)

加速拓店，成了“阿喀琉斯之踵”。

**来自：猎云精选；文/孙媛**

最新一轮融资过去仅2个月，虎头局资金链风波又起。

3月30日，小红书账号“疯狂产品Jason”发布了一篇文章，标题直指“虎头局倒闭”，并阐述其亲身经历，认为公司在融资3亿、疯狂开店、网红营销、资金断裂、关店撤城后，欠薪2亿、拖欠工资、安抚欺骗、破产清算。

他在内容中表示，大概去年4月开始，裁员1000多人，11月至今，拖欠员工工资累计4个半月。此外，他还指出，拖欠的供应商货款、房租、贷款、工资，累计可能达2亿元。

![](https://img.21jingji.com/uploadfile/cover/20230403/1680486476756650.jpg)

来源：“疯狂产品Jason”小红书截图

为此，猎云网找虎头局相关工作人员核实，对方表示“疯狂产品Jason”是信息化部门前员工，目前线下运营团队解散，线上电商团队仍在，门店也有部分在开。

此外，虎头局位于上海绿谷广场的总部目前已人去楼空，据一位供应商透露，跟他对接的虎头局工作人员表示这次解散实属突然，昨天去上海办公室时，就发现公司人员正在进行离职清算。

3月31日下午，对于近日网传的新中式点心品牌虎头局渣打饼行倒闭的消息，虎头局在天猫店发布公告回应称，倒闭信息不实，线上所有的店铺正常运营，订单将有序发货，无任何延迟。

在对界面新闻的回复中，虎头局渣打饼行创始人胡亭否认欠款2个亿、转移资产等说法，并称“之后会有对外沟通，给我们一些时间努力。”

![](https://img.21jingji.com/uploadfile/cover/20230403/1680486482304390.png)

来源：虎头局天猫店截图

从背靠红杉纪源IDG等明星机构的风投宠儿，到如今陷入资金链困境，虎头局作为新中式烘焙的头部品牌，在这两年多的时间里到底经历了什么，或许我们可以从不同视角的部分回复中得到一些答案。

# 被资本偏爱，A轮估值15亿元

在2019年5月长沙开设首店后，虎头局迎着新中式烘焙的风口而生。

“国潮+烘焙”的流量密码，以及“玩转营销组合拳”的商业范式，让虎头局在诞生初，就快速在餐饮赛道、快消赛道制造了足够的差异感，成为了第一批在小红书获得“绝绝子”评价的品牌，线下门店更是排长队购买。

2021年1月，虎头局完成了Pre-A轮融资，红杉中国领投，IDG资本、唐彬森的挑战者创投跟投；又过了6个月，红杉再次出手，拉上IDG、老虎、GGV和天使投资人宋欢平，投出了5000万美元，估值升至15亿元。

有媒体统计，虎头局的单店估值最高时期达到了3.75亿元，而同期喜茶的单店估值“仅为”7151万元、奈雪的单店估值仅为2509元。

对此，有同样投烘焙品牌的投资人直呼，“一个烘焙品牌能融这么多钱，推这么高估值真是让人看不懂。”

那一年，虎头局渣打饼行在五棵松的首店开业，有人从五环外花两个小时“风尘赴会”。虎头局以超高流量持续刷屏各大社交平台，其首家门店单月营业额最多曾高达127万元。

资本和消费领域两头“吃”，给虎头局带来了极大的自信。

2021年12月，一位踏入虎头局上海办公室合作的供应商被当时密密麻麻都是人的情形看呆了。“他们刚融资完，办公室大概200多人，准备快速扩店。”也就是那时，虎头局对外放出豪言壮语：“到2022年底将会在全国开出150家门店。”

当时对于虎头局来说，拓店是跑马圈地的最佳路径，然而2022年，在资本投不动“中式烘焙”头部后，亦成为了资金链上的最大压力。

# 拓店埋雷，风波2022

从2022年开始，虎头局的故事便迎来了转折。

先是4月，虎头局在创纪录的单月开店14家后，在大众点评、小红书上开始收获大量差评，内容直指“网红营销感过浓影响了消费体验+商品实际使用后的体验远低于预期”。

再到下半年，虎头局收缩关店、开放加盟、裁员欠薪的传闻一时间将其线下的经营困境展露无遗。

在此前媒体报道中，爆料显示虎头局的裁员风波从年中就有所开启，客服团队、会员中心、信息化中心相继解散。当时还有内部消息表示，除欠薪外，在去年三季度，由于拖欠了供应商货款，导致一些供应商开始断供原材料，部分地区门店的招牌麻薯卷、米蛋糕及新品奶砖，均无法正常销售。

到了去年年底，虎头局位于广州珠江新城的办公室门口还被贴上了拖欠装修款的大字报。

到2022年11月底，在虎头局订阅号推文《想和你聊聊虎头局的一些变化》中，官方表示公司面临巨大的资金压力，决定暂时退出部分区域市场，并随即退出了成都、重庆、北京等多个城市。当时据品牌公布的信息，虎头局在全国10座城市开出了超80家自营门店。之后的一个月间，虎头局的门店数量持续缩减。

从虎头局官方披露的门店信息来看，目前其长沙、杭州、南京、武汉、广州、深圳、上海在营门店数量分别为1家、3家、1家、7家、2家、2家、7家。23家的总店数量距离高峰时期的80多家，等于缩减了3/4。

对于这些表现，前员工小王表示自己也很“无语”。“感觉现在线下是做不下去了，有些门店还开着。”

小王表示，自去年开始，线上线下团队便开始单独运营。拖欠薪资的确存在，目前线下团队是4、5个月未发工资。但对于“疯狂产品Jason“所言，小王觉得也有失偏颇。

“他在视频中说自己毫无准备，但去年线下，就已经开始了职能部门排班制度，当日可以上班的员工工作量大打折扣，被排班休息时段的薪资也是对应上海最低工资拿。当时公司线下情况有多严重，我觉得他应该多少是知情的。”

而电商开启单独运作，在小王看来，是因为当时创始团队也觉得线下过于“重”。据其透露，对于虎头局线下门店来说，主要是业务调整不够及时。而虎头局的线下模型到底有多重呢？其透露，以北京上海深圳的门店为例，虎头局选址多为商场内，每家门店成本需要投入200万-300万区间。

对线下的重模型投入，有业内人士表示，毕竟虎头局拿的位置都是商场中相对不错的，包含装修、员工工资、物料等所有开店成本而言，对新中式烘焙品牌来说实属正常。

同时，据猎云网查询，虎头局天猫店“虎头局渣打饼行旗舰店”隶属于上海万物有样食品有限公司，由上海万物有样餐饮管理有限公司100%持股，粉丝数为10.2万，热销商品月销量超1万+。

对此，业内人士表示，即便虎头局在内部单独运营，但一旦母公司资金链断裂，子公司很难不受影响，想要实现资金独立运作，更像是一种幻想。

# 狂飙，虎头局们的“阿喀琉斯之踵”

事实上，虎头局走到今天这一步，也并非完全没有挣扎过。

2022年12月12日，虎头局曾表示开启加盟，转向直营与“事业合伙人”并行，在部分城市招募“事业合伙人”，开启合伙制门店业务。当时，虎头局创始人胡亭认为，从盈利效率、管理分工和利益分配角度考虑，变动的大环境下，合伙人制度更利于规模化成长。

虽然加盟模式会缓解虎头局的资金压力，帮助其抢占市场份额，但一边裁员欠薪关店，一边又开放加盟，难免让人感觉像割韭菜。

据虎头局小程序的事业合伙人申请表显示，要求加盟商独立申请，不能再找合伙人，且须全职参与店铺日常经营并亲自管理。关于“可投入加盟的自有资金”的选项则涉及“100万以下”到“200至300万”的投资区间。

与此同时，烘培因为其自身商品的复杂交付、门店管理上有一定标准，又让虎头局的新中式烘焙走加盟模式在实操中有更多难度。

有业内人士指出，烘焙需要面团运到门店进行现场制作，譬如可颂就是要当天现烤的，不可能中央厨房烤好拉过来，如果那样，就不是烘焙而是便利店。如此一来，对于门店烘焙师以及人员管理、品控就有更高的要求，需要在门店完成产品的加工到交付。

在高门槛和自身风波甚起的背景下，加盟的成绩可想而知。

随后，1月红杉资本、GGV纪源资本跟嘉兴水滴资产又相继给虎头局输入数千万元的资金。据知情人士对媒体表示，资方已经完成打款。但即便如此，这几千万元对于虎头局的现金流困局来说，依然难解。

而虎头局之所以会陷入当前处境，问题的关键或许在于“狂飙”。在天使湾创投投资总监顾隽华看来，这属于头部企业拿钱后的通病。

“有时候拿钱越多，越容易出问题。因为一旦拿了资本的钱，投资方也会对企业提增长的目标，企业就会想要扩张、招人。但是扩张会摊薄企业的盈利或管理能力。同时一款产品能否打不同地域，还是要进行适当调整，对企业都会提出更多挑战。”

在他看来，虎头局在新中式烘焙赛道是一个不错的投资标的，值得头部资本押注。但是，过去一年的“狂飙”成为了虎头局的“阿喀琉斯之踵”。

“餐饮跟零售的打法都是要先慢后快，对市场有敬畏之心。所以虎头局如果当时选择slow down，放慢扩张的速度，我相信现在这个品牌依然会非常有前景。一味追逐资本和效率，会适得其反。”

值得注意的是，在新中式烘焙赛道，缩店的并不只有虎头局。

一样诞生于长沙的墨茉点心局，在近日也被爆出暂时退出浙江市场。其杭州湖滨银泰店自去年6月1日营业至今，也就不到10个月。其小程序显示，目前门店分布情况为北京、长沙、常德、衡阳、武汉和株洲，门店数分别为6家、33家、1家、2家、4家和1家，共计47家门店。该数据距离此前2月有媒体统计的7座城市共50余家门店的数据，又有所缩减。

据企查查数据显示，墨茉点心局在2021年连续完成A、B轮融资，均获得数亿元人民币投资，背后资方更是不乏美团龙珠、今日资本等明星机构。

![](https://img.21jingji.com/uploadfile/cover/20230403/1680486476907933.png)

来源：猎云网

与这两位“新中式烘焙”前辈融资暂停、缩店相比，赛道里新玩家却更热闹一些，龙门局渣打点心、KUMO KUMO、鹤所等，皆在2022年首次获得融资。值得注意的是，就在今年年初虎头局融资宣布期间，泸溪河也宣布获得了其首轮融资——百联挚高资本、龙柏资本在A轮投资了数亿元，且在40多个城市有超360家直营门店，直接超车。

据企查查数据显示，2020年以来，我国合计有14个新中式烘焙品牌产品完成32次融资，总披露吸金超十亿元。以轮次来看，新中式烘焙赛道依然处于早期阶段，A轮前融资占比达65.7%。

就新中式烘焙赛道而言，其小而美的魅力依然吸引着新玩家和资本的陆续涌入，但随着企业融入后期，如何自我造血撑起数亿元融资后的估值，疯狂拓店显然不是最优解。

对于虎头局们来说，挑战或许更多来源自身。

（小王为化名）
