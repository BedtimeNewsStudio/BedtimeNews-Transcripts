# 云南因杞麓湖污染治理弄虚作假对29名干部追责问责

2021-07-08 22:25:10 来源：[中国新闻网](http://www.chinanews.com./gn/2021/07-08/9515732.shtml) 作者：田博群 责任编辑：田博群

2021年07月08日 22:25　来源：[中国新闻网](http://www.chinanews.com/)[![参与互动](http://www.chinanews.com/fileftp/2019/08/2019-08-19/U719P4T47D44991F24534DT20190819170959.jpg)参与互动](#zw_cyhd)

[中新社](http://www.chinanews.com/)昆明7月8日电 (何淑亭)据云南省纪委监委8日通报，5月17日，生态环境部公布“云南玉溪杞麓湖污染治理治标不治本水质长期得不到改善”典型案例后，省纪委省监委对杞麓湖污染治理弄虚作假等有关问题以事立案，经过全面深入调查核实后，决定对6个责任单位，29名责任人追责问责。

|  |
| --- |
|  |

　　经查，玉溪市委、市政府，通海县委、县政府学习贯彻习近平生态文明思想不深不透，贯彻落实党中央重大决策部署不力；形式主义、官僚主义愈演愈烈，从不作为乱作为发展到公然造假；政绩观扭曲、错位，动歪心思，斥资数千万元弄虚作假；决策任性，不讲程序和规矩，监督缺失催生造假工程；自然生态污染背后，潜藏着政治生态污染，存在官商勾结、利益输送的贪腐问题。

　　根据有关党纪法规，经云南省委批准，云南省纪委监委决定给予玉溪市委、市政府，通海县委、县政府通报问责，责令作出深刻书面检查；给予玉溪市生态环境局通海分局、通海县水利局通报问责。

　　对玉溪市人民政府副市长贺彬等5名涉嫌严重违纪违法公职人员立案审查调查，采取留置措施；给予玉溪技师学院党委书记，时任通海县委书记、杞麓湖县级湖长卢维江党纪政务立案、停职检查；给予玉溪市委原书记、市级总河长罗应光党内严重警告处分，因其严重违纪违法已被开除党籍、开除公职，存在问题并案处理；给予通海县政协党组副书记、副主席，时任通海县副县长常伟等4名责任人党纪政务处分、职务调整；给予云南省政府副秘书长，时任玉溪市委副书记、市长、市级副河长张德华等7名责任人党纪政务处分；给予德宏傣族景颇族自治州委常委、统战部部长，时任玉溪市委副书记、杞麓湖市级湖长保明顺等11名责任人诫勉、通报、批评教育。

　　杞麓湖是云南九大高原湖泊之一，也是通海县“母亲湖”。由于流域内蔬菜种植面积居高不下，农业面源污染严重，杞麓湖水质长期为劣V类。2016年第一轮中央生态环境保护督察及2018年“回头看”均严肃指出该问题。(完)
