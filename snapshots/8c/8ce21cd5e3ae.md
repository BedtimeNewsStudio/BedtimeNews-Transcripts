| 广电总局取消"真人动画"动画资格 动画频道禁播"真人动画" |  |

|  |
| --- |
| ![广电总局：取消“真人动画”的动画资格[图]](http://image2.sina.com.cn/dy/o/2006-02-20/14ea9d63d9a07d1e30a345bceb45ee04.jpg) |
|  |

正在北京台播出的《变身战士阿龙》被称为中国第一部“特摄”作品。

日前，国家广电总局下发了《关于进一步加强动画片审查和播出管理的通知》，在《通知》中首次对真人演出的所谓动画片进行了详细的界定和严格的规定。

《通知》指出，近期一些电视台在播出动画片的频道、时段或栏目中播出了以真人演出的所谓动画片。这些所谓的动画片绝大部分内容均以真人演出，仅有极少量的电脑特技内容作为点缀。以动画片的名义播出这些剧目，将会扰乱国产动画片的播出秩序，误导国产动画片的创作方向。

《通知》特别强调，对以真人演出的所谓动画片一般不得作为动画片受理审查并发放国产动画片发行许可证。片中部分内容涉及真人演出或实景拍摄的动画片，如拟在动画频道、时段或栏目中播出的，剧本大纲须提前报总局审查，制作完成后报总局审批。禁止在播出动画片的频道、时段或栏目中播出以真人演出的所谓动画片。(雷丹/中新网)

**广电总局取消"真人动画"动画资格**

国家广播电影电视总局日前下发通知，停止以动画片名义受理审查以真人演出的所谓动画片，从而在分类上取消了“真人动画”的动画资格。

广电总局在《广电总局关于进一步加强动画片审查和播出管理的通知》中说，对以真人演出的所谓动画片一般不得作为动画片受理审查并发放国产动画片发行许可证。片中部分内容涉及真人演出或实景拍摄的动画片，剧本大纲须提前报广电总局审查，制作完成后报广电总局审批。禁止在动画频道、时段或栏目中播出以真人演出的所谓动画片。

“近期在一些电视台的动画频道播出的所谓动画片，绝大部分内容均以真人演出，仅有极少量的电脑特技内容作为点缀，根本不能称作动画片。”广电总局的相关负责人告诉记者。

广电总局在通知中同时指出，以动画片的名义播出这些所谓的“真人动画”，将会“扰乱国产动画片的播出秩序，误导国产动画片的创作方向”。(据新华社消息/京华时报)

**“特摄”“真人动画”**

“真人动画”也被称为“特摄”，特摄是特摄电影的简称，本意是运用了特殊摄影技术而拍成的影片。但其实，特摄片可以说是只有在日本这样一个特殊的国家，特殊的民族，特殊的时期才会发展壮大的一类特殊影片。二战以后，作为战败国的日本，承受了政治、经济等各方面的制裁，当然，其中也包括文化娱乐。日本宪法第九条规定，不能制作表现激烈战争场面的娱乐影视作品，这就使得日本不可能推出类似《珍珠港》或《大决战》之类的影片来满足观众这方面的需求。因此，日本人只能通过一些架空的背景和人物，来使观众得到看“战争题材”影片的需要。美国可以选择二战、越战来作为战争的背景，而日本只有“来自宇宙的侵略者”，“想要统治世界的XX组织”，这样特摄在日本诞生了，并逐渐壮大起来……

随着特摄的形成与发展，也逐渐形成了自己的特点。一般的特摄片，都有着以下几个特点：1.“变身”。主角必须通过特定的方法或道具才能通过“变身”这一手段变成正义的英雄。2.“怪兽”。在特摄片中，作为英雄对手的，都是一些“怪兽”或“怪人”尤其是怪兽，甚至有喧宾夺主之势，成为特摄片的一大卖点。3.华丽的必杀技。在特摄片的最后，也就是英雄们必杀技演出时间。而主角那时所摆的POSE，也成了第二天孩子们竞相学习的对象。

“特摄”代表作品：《恐龙特级克塞号》、《奥特曼》、《哥斯拉》(中新网)
