| 18日,国资委党委书记、副主任李毅中在由国务院国资委研究中心和国务院发展研究中心企业所主办、上证报协办的"中国国企改制与产权交易高峰论坛"上表示,2004年国企改制已经取得显著成效,规范国企改制和国有产权转让工作也已取得积极进展,但是国企改制和国有产权交易仍然存在四个方面的问题,主要表现在:在部分国企改制的程序中存在不规范；管理层收购(MBO)不规范；国有产权进场交易存在不规范；对改制后的企业跟踪指导监督不够。

|  |
| --- |
|  |

    李毅中表示,采取多种形式加快推进国有企业改制,已经取得了显著成效。国有大企业改制工作取得明显进展。国有企业股份制改制进展较快,在净资产占全国国有企业66.9%的2903家国有及国有控股大型骨干企业中已有1464家改制为多元股东的公司制企业,改制面达到50.4%。目前国有控股的境内外上市公司1000余家,其国有权益约占全国国有及国有控股企业的17%,实现利润占46%,累计筹集资金超过1万亿元。李毅中表示国有控股的上市公司已经成为国有经济的骨干力量和国有资产的富集区。

    对于外界关注的管理层收购,李毅中认为目前管理层收购(MBO)存在大量不规范情况,如管理者本人参与甚至主持收购活动；经营者虚构、虚增成本和债务；管理层与中介机构串通低估、隐匿资产；管理层将职工经济补偿金从转让前的净资产扣掉,降低了出让价格,又无偿占用了这部分净资产；管理层让客户向改制企业预付款,再由管理层借用与收购等。

    李毅中表示,管理层收购使所有权和经营权趋于合一,不符合建立现代企业制度的方向,而且现有法规制度还不健全。因此大型企业一定不能搞,一些中小企业的探索要区别情况,在规范以后可以进行试点。
