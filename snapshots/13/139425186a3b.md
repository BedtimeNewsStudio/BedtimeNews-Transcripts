## 十一、旅游、文化、体育和卫生健康

恩施州被纳入全省重点支持建设的世界级旅游目的地和国

际特色旅游城市，武陵山区（鄂西南）土家族苗族文化生态保护区正式命名为国家级文化生态保护区，恩施大峡谷山地户外运动目的地上榜全国首批高质量户外运动目的地建设名单。全州A级景区达到50个，其中5A景区3个，4A景区27个。宣恩县兴隆老街获评国家级夜间文化和旅游消费集聚区，新增2个4A级景区，5A级旅行社、国家甲级旅游民宿实现零的突破。全年接待游客11037.16万人次，同比增长10.0%，实现旅游综合收入920.06亿元，同比增长23.0%。境外游客住宿达到7.34万人次，同比增长105.9%。

全州共有公共图书馆9个，书刊文献外借79.86万人次，图书流通188.02万册次；文化馆9个；博物馆8个，参观人数175.89万人次。年末全州文化和旅游系统有艺术表演场馆6个，艺术表演团体9个。年末广播节目综合人口覆盖率为99.95%；电视节目综合人口覆盖率为99.96%。全年规模以上文化产业企业137家，实现营业收入74.56亿元，同比增长10.1%。

成功举办中国公路自行车公开赛（湖北恩施站）、“村 BA”中部赛区决赛等国家级赛事。“恩 BA”、四季村晚等群众性文体活动持续火爆。成功落地群众身边体育场所 33 个，新增巴东体育馆等 5 个免费或低收费公共体育场馆。咸丰白茶队获全国“村 BA”总决赛亚军。

## 十二、资源、环境和应急管理

全州县市城区空气质量平均优良率为 97.2%。州城恩施市空气质量优良天数为 335 天，优良率为 92.6%。县市城区可吸入颗粒物（PM10）浓度均值为 ( 36\\mu g/m^{3} ) 。县市城区细颗粒物（PM2.5）浓度均值为 ( 23\\mu g/m^{3} ) 。州城恩施市细颗粒物（PM2.5）浓度均值为 ( 29\\mu g/m^{3} ) 。

全社会用电量 84.61 亿千瓦时，增长 6.8%。其中，工业用电量 22.25 亿千瓦时，增长 7.6%。

全年平均气温 ( 17.1^{\\circ}C ) ，比常年同期偏高 ( 1.4^{\\circ}C ) 。平均累计降水量 1564.3 毫米，平均雨日为 165.1 天，偏多 1.6 天。平均日照时数 1341.1 小时，比常年同期偏多 163.4 小时。

全州共有国家级自然保护区5个，保护区面积14.68万公顷。

全年发生一般生产安全事故4起，死亡8人。其中，工矿商贸企业事故2起，死亡6人；道路交通事故2起，死亡2人。全年未发生重特大生产安全事故。
