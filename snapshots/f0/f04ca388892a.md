# “全国优秀县委书记”陶永欣，履新副市长

![](https://images.shobserver.cn/img/2020/2/18/sub_82.png)纵览2023-11-30 10:53

来源：上观新闻作者：观八闽

![](https://images.shobserver.cn/news/690_390/2021/09/02/l_2607.jpg)

11月29日，深圳市人大常委会第二十二次会议表决通过系列法规和人事任免事项。会议任命 **陶永欣** 为深圳市人民政府副市长；免去黄敏的深圳市人民政府副市长职务。

![](https://images.shobserver.com/img/2023/11/30/CB20231130104338701088.jpg)陶永欣（资料图）

据公开资料，陶永欣出生于1972年2月，吉林柳河人，1996年7月参加工作，1992年6月加入中国共产党，东北师范大学教育科学学院教育学原理专业毕业，研究生学历，教育学硕士学位，讲师。

他早期任职深圳市委党校，2008年调任中国国际贸易促进委员会深圳分会副会长，后任中国国际贸易促进委员会深圳委员会副主任、主任。2015年，陶永欣调任坪山新区党工委副书记，管委会主任，2017年任坪山区区长，2018年任坪山区委书记。

2021年5月，在深圳市政府换届中，陶永欣当选深圳市副市长， **6月获“全国优秀县委书记”称号**，同年8月卸任坪山区委书记。

2021年10月，陶永欣任深圳市委常委、秘书长，同月卸任深圳市副市长。近期报道显示，他已卸任市委秘书长。

“1996年刚来深圳时，我就被特区因改革创新所释放出的活力所深深吸引，也被敢闯敢试、敢为人先、埋头苦干的特区精神所打动。”据《南方日报》报道，陶永欣对初来深圳时的情景记忆犹新。后来，他也推动改革的活力、创新的动力注入坪山发展的方方面面。

在认真调研世界知名创新之都成功经验之后，陶永欣得出一个结论： **一座创新城市的“磁力”，在于科技、教育、文化、社会等方面的创新。**

陶永欣担任坪山区委书记后，坪山逐步构建起了“立足产业、聚焦转化、面向国际、全域创新”的创新生态体系，教育链、人才链、创新链、产业链“四链融合”的创新格局初步形成。创新药、中国芯、智能车已经成为坪山的三张名片，其中生物医药企业年均新增100家以上、产值年均增长30%以上，坪山也成为深圳市生物医药产业发展核心区和粤港澳大湾区生命健康创新示范区。

“创新的城区需要创新的人才，而要吸引创新的人才，就必须营造适合创新的土壤。”陶永欣说。

此番卸任深圳市副市长的黄敏，出生于1963年8月。调整前，他任深圳市委常委，市人民政府副市长、党组副书记。
