# 黑龙江医药类大学排名一览表

更新：2026-5-26 11:59:47    发布：大学生必备网

[黑龙江](/news/list_113.html)[医药](/news/list_198.html)类[大学排名](/news/list_75.html)第一的是哈尔滨医科大学，排名第二的是黑龙江中医药大学，排名第三的是牡丹江医学院，以下是具体榜单一览表，希望对大家有所帮助。如有异议，还请以教育部、考试院等权威部门公布的信息为准。

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 序号 | 学校名称 | 省份 | 城市 | [双一流](/news/list_178.html) |
| 1 | 哈尔滨医科大学 | 黑龙江 | 哈尔滨 | 否 |
| 2 | 黑龙江中医药大学 | 黑龙江 | 哈尔滨 | 否 |
| 3 | 牡丹江医学院 | 黑龙江 | 牡丹江 | 否 |
| 4 | 齐齐哈尔医学院 | 黑龙江 | 齐齐哈尔 | 否 |

哈尔滨医科大学（Harbin Medical University），简称“哈医大”，位于黑龙江省哈尔滨市，为国家教育部首批试办七年制高等医学教育的院校，是省部共建大学、黑龙江省高水平大学和优势特色学科建设高校、国家“中西部高校基础能力建设工程”建设高校、教育部“卓越医生教育培养计划”试点高校、国家建设高水平大学公派[研究生](/news/list_41.html)项目实施高校、国家“特色重点学科项目”建设高校、国家理科基础科学研究与教学人才培养基地、国家级[大学生](/)创新[创业](/news/list_36.html)训练计划实施高校、临床医学硕士专业学位研究生培养模式改革试点高校、黑龙江省高等医学教育研究基地、中俄医科大学联盟中方牵头单位。

学校前身是哈尔滨医学专门学校和1931年11月在[江西](/news/list_111.html)瑞金创建的中国工农红军卫生学校，1949年4月由原哈尔滨医科大学和原兴山（现鹤岗市）中国医科大学第一、二分校组建而成。2000年5月，鸡西煤炭医学高等[专科学校](/news/list_134.html)并入。2015年10月24日，哈尔滨医科大学正式被教育部、国家卫生和计划生育委员会、黑龙江省人民政府批准为部委省共建大学。
