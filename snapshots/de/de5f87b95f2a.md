# 发布L2城区辅助驾驶系统HSD，地平线携手奇瑞等车企共赴智能化新征程

2025/04/18

- 品牌事件

- 产品发布

- 产品介绍

- 解决方案

2025 地平线年度产品发布会精彩直播回放

4月18日，以“征程所向，远超想象”为主题的2025地平线年度产品发布会在上海滴水湖举行。地平线重磅推出L2城区辅助驾驶系统——地平线HSD，构建体验“类人”、用户“信任”的城区辅助驾驶新解。同时，地平线与奇瑞达成 [HSD](https://www.horizon.auto/) 首个量产合作，以全栈实力助力智能化量产迈向新征程。

![地平线HSD_HSD](https://www.horizon.auto/Public/Uploads/ueditor/upload/image/wechat/20250421/68059ebed80ba.jpeg)

地平线重磅推出L2城区辅助驾驶系统——地平线HSD

作为业内率先提出并持续践行软硬结合技术路径的智驾科技公司，地平线始终坚持软硬一体的技术信仰，这是地平线能够超越摩尔定律、引领汽车智能化升级的根源所在。而地平线HSD的推出与量产，是软硬结合技术路径的重要成果，也是地平线在智驾普及课题上的关键锚点。

**地平线创始人兼CEO余凯博士表示：**

|  |
| --- |
| “回顾过去计算平台的发展，每一次软硬件的深度耦合都在重构人类的底层逻辑，推动了人类科技文明的进步。地平线坚定地与推动人类科技文明进步的先行者相向而行，以「软硬一体的技术信仰」贯穿始终。” |

**打造人人爱用的智驾产品**

**HSD推进L2城区辅助驾驶高效量产**

发布会上，余凯博士宣布了地平线的最新愿景——“打造人人爱用的智能驾驶产品”。站在现在看未来，地平线以全新愿景为指引，打造高信任度的智驾产品；站在未来看现在，地平线遵循AI时代产品逻辑，不断“逼近世界的真相”。

以技术为基石，让愿景加速落地。站在成立十周年的重要节点，地平线正式发布L2城区辅助驾驶系统——地平线HSD。HSD搭载当前最强性能的国产智驾计算方案征程6P，采用一段式端到端技术架构，是国内首个软硬结合全栈开发的L2城区辅助驾驶系统。HSD能够全方位提升系统安全性、稳定性和通行效率，为用户带来信任度高、体验类人的智慧出行。

![智驾技术_软硬结合](https://www.horizon.auto/Public/Uploads/ueditor/upload/image/wechat/20250421/68059ebf0ec78.jpeg)

基于软硬结合全栈技术，地平线推进智驾技术高效量产。地平线创新推出Horizon Cell“弹夹系统”，实现硬件可插拔、软件可升级，为车企合作伙伴提供“软硬件皆可升级”的方案选择，支持车载计算平台快速升级，实现车企与用户的共赢。基于弹夹系统，依托于“技术同源、架构统一”的特点，软硬一体全栈方案HSD推出HSD 300/HSD 600/HSD 1200三个版本，提供从普惠级到高性能再到全场景的全价格段、全性能段解决方案，打造L2城区辅助驾驶全家桶。

![弹夹系统_软硬结合](https://www.horizon.auto/Public/Uploads/ueditor/upload/image/wechat/20250421/68059ebf31d61.jpeg)

地平线推出Horizon Cell“弹夹系统”，为车企提供“软硬件皆可升级”的方案选择

**软硬全栈量产交付**

**携手奇瑞打造智能化新答案**

在智能驾驶迈向大规模量产的关键阶段，地平线与奇瑞集团就HSD量产展开全面合作。奇瑞基于开放创新的联合生态打造“猎鹰方案”，地平线HSD将作为奇瑞“猎鹰”的一款先进方案，与征程6P计算方案一同在星途品牌上全球首发，并于2025年9月正式量产。后续奇瑞还会有更多采用HSD方案的“猎鹰方案”车型上市亮相。双方将共同为中国汽车产业智能化转型注入强劲动能，加速智能驾驶技术的创新突破和普及应用。

![奇瑞_智驾量产](https://www.horizon.auto/Public/Uploads/ueditor/upload/image/wechat/20250421/68059ebf54f70.jpeg)

奇瑞控股集团董事长尹同跃出席地平线发布会，宣布与地平线达成HSD全球首发量产合作

**奇瑞控股集团董事长尹同跃出席发布会并表示：**

|  |
| --- |
| “地平线是我们在智能化领域最重要的合作伙伴之一，HSD是行业一流的城区辅助驾驶方案。奇瑞与地平线都希望在技术、安全、品质上追求极致，让‘中国智能’成为全球信赖的代名词，让更多用户喜欢中国智能化解决方案！” |

![奇瑞控股集团_地平线公司](https://www.horizon.auto/Public/Uploads/ueditor/upload/image/wechat/20250421/68059ebf832a5.jpeg)

奇瑞控股集团董事长尹同跃与地平线创始人兼CEO余凯

在与奇瑞深化合作的同时，地平线的生态布局也取得突破。大众汽车集团已于近日宣布与地平线基于HSD深化合作，通过双方合资公司酷睿程 (CARIZON) 加速全场景辅助驾驶全栈方案的研发，并于2026年起落地在大众汽车集团旗下的多款车型上。

**新十年新开端**

**亮出“中国智驾科技第一名片”**

2025年是过去十年的尾声，也是全新十年的开端。回望十年历程，地平线走出了一条独具特色的智能驾驶向高而行之路。正如创始人余凯博士所言： **“我们的事业不是一场热闹的party，而是长期跋涉的journey。”**

**“过去十年，我们坚持软硬一体，不断地引领行业创新。”** 2015年成立伊始，地平线率先聚焦深度神经网络计算方向，并在技术研发上不断突破。十年推出三代BPU智能计算架构，不断追求计算性能最优解，超越摩尔定律，实现了计算性能十年超1000倍的提升，支持超10款计算方案规模化量产。基于纳什架构开发的征程6系列，覆盖10-560TOPS算力，是目前国内唯一满足从L2辅助驾驶到全场景城区辅助驾驶需求的智驾计算方案，适合各种智能车型的需求。

![BPU_辅助驾驶](https://www.horizon.auto/Public/Uploads/ueditor/upload/image/wechat/20250421/68059ebfb4ef1.jpeg)

超越摩尔定律，BPU十年提升计算性能超1000倍

在最核心的算法层面，地平线始终走在前沿，持续推动智驾算法创新，近3年国际顶会收录文章超过40篇，学术成果引用量超过10万次，全球专利申请达到2000件。其中，2023年，地平线在业界首次公开发表端到端自动驾驶大模型UniAD，荣获当年CVPR最佳论文；2024年，地平线推出下一代通用视觉主干模型Vision Mamba，性能超越Vision Transformer，与Deepseek共同登榜2024全球最高引用量AI论文，地平线位列全球第三、国内第一，为智驾理论创新与技术实践提供了有力支撑。
