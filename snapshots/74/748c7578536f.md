| 王细牛因涉嫌非法吸收公众存款上亿元被批捕 |  |  |  |
|  |  |  |  |
|  |  |  |  |
|  |  |  |  |
|  |  |  |  |
|  |  |  |  |
|  |  |  |  |
| 2007-03-13    记者：汤计    来源:经济参考报 |  |  |  |
|  |  |  |  |
|  |  |  |  |
| 据新华社呼和浩特3月12日电 <br>记者12日从内蒙古自治区公安厅了解到，被呼和浩特市民戏称为“王木匠”的呼和浩特市“金鹰国际CBD(中心商务区)项目”原业主、金鹰国际集团有限责任公司董事长王细牛，因涉嫌非法吸收公众存款等罪名，3月9日被内蒙古自治区人民检察院依法批准逮捕。王细牛捕前系呼和浩特市“金鹰国际CBD(中心商务区)项目”原业主、金鹰国际集团有限责任公司董事长，2005年冒充港商“忽悠”呼和浩特市政府炸掉了位于市中心、刚建成投入使用两年多的市公安局指挥中心大楼等建筑。随后，于2005年6月16日开工建设所谓“计划投资53亿元”、169米高的西北地区第一高楼——金鹰国际CBD工程。<br>　　但是，王细牛的金鹰国际集团没有资金履行合同，各大银行通过贷前调查，发现了王细牛的所谓“香港金鹰国际集团股份有限公司”实际上只是一个无地址、无人员、无实业的“三无”皮包公司，纷纷拒绝贷款。将近两年时间里，王细牛一方面依靠收缴施工企业的保证金、垫付款和呼和浩特市政府的“退税”款运作“西北第一高楼”项目，另一方面公开在呼和浩特市非法吸收公众存款。 |  |  |  |
