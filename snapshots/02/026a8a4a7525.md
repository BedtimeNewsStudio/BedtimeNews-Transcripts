| 中俄2020年或提前实现双边贸易额达2000亿美元目标 |  |  |  |
|  |  |  |  |
|  |  |  |  |
| 2012-09-05 　　作者：刘维靖　　来源：国际在线 |  |  |  |
|  |  |  |  |
| 【字号 <br> 大中小】 |  |  |  |
| 第二届中国－亚欧博览会正在位于中国西北部的乌鲁木齐市举行。前来参会的中国商务部欧洲司副司长张地先生接受记者采访时表示，中俄两国贸易发展势头良好，双边贸易额或将提前实现2020年达到2000亿美元的目标。<br>采访中，张地先生首先对当前中俄合作的现状进行了分析，回顾了这十年间中俄贸易发展的变化。<br>“这十年来，（两国贸易）发展很大，目前还有很多事情在做。十年前，两国的贸易层次相对来说比现在低，比如说，中国对俄罗斯的出口，大约10年前，基本都是一些轻工产品、纺织品、食品。就是说高附加值的产品占的比例比较低，而现在中国对俄罗斯出口的工业制成品，机电产品，已经是大幅度的提高了，已经占到45％－50％左右，这是一个非常大的进步。”<br>近十年来，中国经济发展取得了举世瞩目的成就，这也为中俄全面战略协作伙伴关系的发展注入了强劲动力。在国际金融危机的背景下，2010和2011两年间两国双边贸易年均增速仍达40％以上，这些都充分表明了两国经贸合作的活力。<br>“中俄经贸合作现在发展非常好，我们已经连续两年是俄罗斯最大的贸易伙伴，去年中俄贸易额已经达到800亿美元。”<br>张地指出，目前俄中经贸合作总体呈现好的发展态势，但贸易结构还需要进一步改善。当前中俄贸易结构的特点是中方的劳动密集型商品与俄方的资源密集型原材料商品的贸易，机电产品和高科技产品等高附加值商品在双边贸易中的比重较低。<br>“这是一个客观存在的问题，就是贸易结构不是很平衡。需要双方的努力，比如，俄罗斯要加大推介产品的力度。还有增强自己向出口中国产品的竞争力，这是他们面临的问题。再有一个，机电产品出口比例小，是因为整个工业结构调整的问题，并不是说中国主观上的问题，是一个客观存在的事实。”<br>今年6月份，中国国家主席胡锦涛在会见俄罗斯总统普京时指出，两国应该根据各自国内发展和世界经济形势新特点，发挥经济互补性强的优势，改善经贸合作结构，提高经贸合作质量。对此，张地先生表示，目前中国正在积极采取措施改善中国的贸易结构。<br>“解决这个问题需要一定的时间。但是我们已经注意到这个问题，我们在不断地改善。现在我们开始加大了相互投资合作的力度。因为两国经济上互补性很大，都有很多基础，人员交往和共同边界都有很多便利条件，需要逐步扎实推进，前景非常好。”<br>2011年6月中国国家主席胡锦涛和时任俄罗斯总统梅德韦杰夫共同发表了关于《中俄睦邻友好合作条约》签署10周年联合声明。双方决定，将双边贸易额在2015年前提升至1000亿美元，在2020年前提升至2000亿美元。张地对中俄贸易发展前景十分乐观，认为目标有可能提前实现。<br>“目前中俄两国贸易发展势头非常好，俄罗斯政府、领导人都非常重视，企业也非常的积极。按照目前的增长速度来推算，到2015年将两国贸易额达到1500亿美元，2020年达到2000亿美元。我们完全有能力达到这个目标，甚至有可能提前实现。” |  |  |  |
