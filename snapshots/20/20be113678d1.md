# 河北高考报名人数统计表（含2015-2025历年）

更新：2025-6-11 9:45:07    发布：大学生必备网

![河北高考报名人数统计表（含2015-2025历年）](https://img.dxsbb.com/upFiles/infoImg/2021060336862345.jpg)

2025年 [河北](https://www.dxsbb.com/news/list_105.html) [高考](https://www.dxsbb.com/) 报 [名人](https://www.dxsbb.com/news/list_30.html) 数为64万（统考），2024年河北高考报名人数为67.4万（统考），2023年河北高考报名人数为86.2万（参加统考61.54万），2022年河北高考报名人数为75.32万（统考52.74万）。本文整理了河北2015-2025年高考报名人数，供大家参考。

## 一、历年河北高考报名人数统计表

|  |  |  |
| --- | --- | --- |
| 年份/人数 | 报名人数 |  |
| 全国 | 河北 |  |
| 2025年 | 1335万 | 统考64万 |
| 2024年 | 1342万 | 统考67.4万 |
| 2023年 | 1291万 | 86.2万（统考61.54万） |
| 2022年 | 1193万 | 75.32万（统考52.74万） |
| 2021年 | 1078万↑ | 63.4万 |
| 2020年 | 1071万↑ | 62.48万 |
| 2019年 | 1031万↑ | 55.96万 |
| 2018年 | 975万↑ | 48.6万 |
| 2017年 | 940万 | 43.6万 |
| 2016年 | 940万↓ | 42.31万 |
| 2015年 | 942万↑ | 40.48万 |

## 二、2025年河北高考报名人数

2025年高考将于6月7日至9日举行。今年河北省有64万考生参加考试，全省共设置420个标准化考点，2.2万个考场，安排考务 [工作](https://www.dxsbb.com/news/list_37.html) 人员10万多人，目前各个考场已经全部准备就绪。

为确保考试安全有序进行，各级教育、公安、工信、通信、市场监管等部门，持续开展“净化涉考网络环境”“打击替考作弊”“净化考点周边环境”等专项行动，加强治安、交通、食宿、卫生、噪音等治理和管控，及时消除考点及周边安全隐患，营造公平公正、安心舒适的考试环境。
