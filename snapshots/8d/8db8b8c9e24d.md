中国首家花炮海外上市企业华盛烟花北美上市

2009年05月25日 14:28　来源：中国广播网　![](http://i2.chinanews.com/zwimg/01.jpg)[发表评论](http://comment.chinanews.com.cn/comments/comments.php?newsid=1706561)　　【字体：↑大↓小】

据中国之声《央广新闻》8时18分报道，日前召开的全球花炮产业投融资国际峰会透露，湖南华盛烟花有限公司将以“浏阳花炮”的名称，在加拿大多伦多证券交易所创业板上市，成为中国首家在北美上市的烟花企业。详细情况连线湖南电台新闻频道记者杨华： 中国之声：能给我们介绍一下“浏阳花炮”将在北美上市的具体情况吗？

|  |
| --- |
|  |

记者：湖南华盛烟花有限公司是浏阳著名花炮企业，也是国内花炮行业的领军企业，从2007年起，华盛烟花开始运作海外上市。由于该公司高端产品长期出口到全球14个国家和地区，高品质、国际化的企业形象赢得了国际投融资界的青睐，一批欧美顶级投资银行、审计师事务所、律师事务所多次来到浏阳，对公司进行辅导，商讨上市方案，并在5月中旬全部完成了加拿大证券监管机构要求的上市程序。华盛烟花的产品将以“浏阳花炮”为名登陆加拿大多伦多股票交易市场创业板，股票代码为FWK。具体上市时间将在本月27号中国证监会审议后确定，预计为5月底至6月初。华盛烟花有限公司因此成为中国花炮行业首家海外上市的企业，也是湖南省第一个在加拿大上市的企业。

华盛烟花相关负责人介绍说，相对于其他制造业，烟花产业受世界金融危机的影响较小，具备吸引投资者的潜力。

另外，华盛烟花此次登陆国际融资市场受到投资者的热情追捧，加拿大多伦多证券交易所亚洲部负责人告诉记者，在加拿大首次融资市场上，发行市盈率一般不超过10倍，而来自中国的“浏阳花炮”却获得了近20倍的发行市盈率，受到了投资者的热烈追捧。据了解，加拿大多伦多证券交易所的交易量排名世界第五。
