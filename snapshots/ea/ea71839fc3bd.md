## 产品形态

### CodeBuddy IDE

适用：产品 / 设计师 / 全栈开发 / 编程初学者。支持可视化调试，主打"对话即编程"。通过将 AI 深度融入从需求规划、产品设计、代码研发、产品部署的全流程，实现从产品构想到产品发布的一站式高效交付平台。

![](https://qcloudimg.tencent-cloud.cn/trisys/assets/product/images/yBcYg6zKW9reZnc6LMxHH.png)

### CodeBuddy 插件

适用：日常编码开发者 / 特定 IDE 使用者。以插件形式安装到编辑器（VS Code 或 JetBrains 系列等 IDE）中，AI辅助编程。即插即用、融入现有工作流。

![](https://qcloudimg.tencent-cloud.cn/trisys/assets/product/images/WfC0fRfNjpd2hHJRny3-T.png)

### CodeBuddy Code（CLI）

适用：DevOps / 运维 / SRE / 资深开发者。面向专业工程师的 AI CLI 工具，能无缝融入现有开发流程。支持在命令行中用自然语言驱动开发全流程，实现高度自动化。
