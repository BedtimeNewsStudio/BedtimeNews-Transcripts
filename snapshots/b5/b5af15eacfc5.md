## 西安开往乌鲁木齐列车隧道中起火 千余乘客逃生

昨日上午8时15分，由西安开往乌鲁木齐的1043次旅客列车，运行至中国最长的铁路隧道——兰新线乌鞘岭隧道左线时机车突然着火，经铁路、消防等部门紧急处置，千余旅客徒步逃生，大火被扑灭，未造成人员伤亡。事故原因有关方面正在调查。

**车头起火停在隧道**

昨日中午12时许，记者抵达兰新线乌鞘岭隧道西出口龙沟段时，发生火灾的机车已经被拖走，现场乘客已经被铁路方面妥善处置，隧道右线也已恢复正常通车。

|  |
| --- |
|  |

在隧道西出口的左线上，记者看到有一些铁路工人仍在紧张地抢修电路设施。出口约300米处的铁轨上，留下焦黑的一团印迹，现场散落着一些被烧坏了的机车零部件。铁轨隔离网之外的空地一片泥泞，车痕杂乱。据现场一位抢修工人讲，消防车在这里将列车机车的大火扑灭。

据了解，起火部位是牵引列车的电力机车。起火时车头距隧道洞口2公里左右，被强行制动后停在了隧道里。

**千余乘客徒步逃生**

据介绍，发生险情的1043次列车上有旅客1700多人。事发后，所有人员被紧急疏散，徒步走出漆黑的隧道。

乘客梁女士称，当日上午8时15分左右，火车正在乌鞘岭隧道中前行，车厢内外突然飘来大量的烟雾，空气中弥漫着一股焦煳味，火车随即停了下来，乘务员拿着毛巾给乘客分发，让大家捂住嘴巴，车上乘客顿时慌乱起来。过了一段时间，车门打开了，在武警和铁路工作人员的带领下，乘客们在漆黑一团的隧道中步行前进。“我们在隧道中走了很长时间，许多人出隧道后已被烟熏黑了。出了隧道，我的腿软得抬不起来了。”梁女士说。

记者了解到，事故中，一名女列车员出现险情。这名女列车员所在的车厢离发生火灾的机车最近，起火后，她提着灭火器想帮司机灭火，但因为隧道里能见度不足一米，加之火情愈来愈严重，一时间浓烟滚滚。最终她因缺氧加之疲劳过度而晕倒在车厢。经过紧急救治，该女列车员现已脱离危险。

**事故原因尚在调查**

乘客从隧道脱险后，铁路部门立即清点人数，确认无人员伤亡。对部分距离目的地不远的乘客，铁路警方安排班车回家，大部分乘客等待救援的机车抵达后，被安全带离现场。

当日中午12时14分许，在新机车的牵引下，1043次旅客列车从龙沟车站开出，运输秩序恢复正常。目前，机车起火具体原因正在调查当中。综合兰州晨报、兰州晚报
