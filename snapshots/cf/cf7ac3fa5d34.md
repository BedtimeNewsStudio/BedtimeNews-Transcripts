# 台湾歌手郑智化吐槽轮椅登机不便 深圳机场回应：立即启动整改

[中新网](https://www.chinanews.com/) 深圳10月26日电 (记者 索有为)台湾知名歌手郑智化25日在微博发文，反映其在深圳宝安国际机场乘机时遭遇登机困难，引发广泛关注。深圳机场当日深夜发布情况说明称服务存在不足，并宣布多项整改措施。

据郑智化当日14时59分左右发布的微博称，当日乘轮椅至远机位登机时，升降车停至机门前有25厘米高差。“我轮椅推不进飞机，腿也没办法跨进机门。”

深圳机场在当日傍晚回应“已第一时间启动核查”后，又在深夜作出详细的情况说明。

深圳机场称，郑智化当日乘坐深圳航空ZH9073航班从深圳前往台北，因前序国际及地区航班密集，近机位资源饱和，航班被安排在远机位停靠。机场已按流程调派行动不便旅客专用登机车。但由于飞机在旅客登机及货物装载过程中存在上下浮动，为防止设备刮碰飞机，依据安全操作规范，登机车与舱门需保持约20厘米高度差，导致轮椅无法直接对接舱门。最终，在1名地服人员与1名机组人员协助下，郑先生安全登机。

|  |

深圳机场在说明中对此次服务保障带来的不便“深表歉意”，并表示“深知机场服务与旅客预期还有差距”。对此，机场方面联合航空公司立即启动整改，表示自10月25日晚起，对搭载轮椅旅客的航班优先安排廊桥靠接；确需使用远机位时，现场保障人员由1名增至2名；同时试点启用已研发测试的带坡度登机连接装置，以解决高度差问题，提升登机安全性与便利性。(完)
