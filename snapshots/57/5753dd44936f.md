| | 足协减轻对长春亚泰队、原成都五牛队的处罚 |
| --- |
| * * * |
| http://sports.sina.com.cn <br> 2002年05月08日15:30 新浪体育 |
|  |
| 5月8日下午，中国足协公布了关于对长春亚泰队、原成都五牛队及相关人员减轻处罚的决定。

具体决定如下：

各会员协会、甲乙级队足球俱乐部：

|     |
| --- |
|  |

针对2001年全国足球甲B联赛最后两轮三场比赛中的严重违纪行为，本会于2001年10月16日做出了足纪字(2001)14号处罚决定。该处罚决定公布后，长春亚泰队和原成都五牛队及所属俱乐部进行了内部整顿。根据俱乐部提交的整顿报告和本会调查组的调查结果显示，长春亚泰和成都足球俱乐部整顿态度有了较大的转变，整顿比较认真，整顿效果较好。为此，依据《中国足球协会纪律处罚办法》第三条、第二十九条第二项之规定，本会决定对长春亚泰队和原成都五牛队及相关人员减轻处罚：

一、对下列运动员：

长春亚泰队：郭昊、魏东、李斌、姜鹏翔、杜震宇

王栋、礼彬、杨海波

成都五牛队：刘建军、黎榕、方立军、陈元昆、黄钜华

李红军、龙志伟、彭晓方

1、由取消2002年注册资格减为取消2002年上半年注册资格；允许其于2002年7月1日后申请注册，并可参加各自所属球队相应级别的比赛。

2、由取消2002年和2003年转会资格减为取消2002年转会资格。

二、对长春亚泰队、原成都五牛队主教练：由停止2002年赛季工作一年减为停止2002年赛季从事主教练工作一年。

三、对长春亚泰俱乐部、成都足球俱乐部：由取消2002年、2003年甲级联赛引进国内球员的资格，减为取消2002年甲级联赛引进国内球员的资格。

除上述处罚外，其它处罚不变。

上述决定自公布之日起实施。

中国足球协会纪律委员会

二〇〇二年五月八日
