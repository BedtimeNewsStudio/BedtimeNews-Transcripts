| **抽签竟出如此“绝招”：抽扑克牌来决定甲A亚军** |  |  |
|  |  |  |
|  |  |  |
| 2002年12月3日04:11   [新闻晨报](https://www.jfdaily.com/epublish/gb/paper28/index.htm) |  |  |
|  |  |  |
|  |  |  |

晨报香河12月2日电“足球不用脚踢，改用手了。”这是某相关人士的牢骚话，但其实抽签定名次并不是足协首创，大家应该还记得1999年乙级联赛的“69风波”。而这一次足协再出“绝招”———通过抽扑克牌大小来决定今年甲A的亚军得主。

从北京方面传来消息，明天上午在中国足协会议室举行的抽签仪式将由北京、深圳两家俱乐部代表从一副扑克牌中分别抽出一张牌，谁的点数大谁的名次就靠前。天津泰达与沈阳金德也同样通过这一方式来决定最终由谁获得了第十名。

其实早在1999年乙级联赛结束之时，四川绵阳队与大连铁路队就是通过抽签方式决定谁冲入甲B的。当时足协联赛部官员郎效农想到的办法是：让两队代表分选“单”、“双”，然后各从0至9的数字中抽出一数相加，如果和是单数，那选“单”者获胜，如果和是双数，那选“双”者获胜。结果绵阳代表写下似是而非的9（或者是6），取得了最终胜利。这一“经典”至今成为足坛笑话，不知道明天的抽签还会有什么怪事情发生。

（袁崴） |
