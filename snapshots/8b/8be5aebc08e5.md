# 从服务员到年入千万的老板，网红景点推手到底有多赚钱

![头像](http://inews.gtimg.com/newsapp_ls/0/12856305545_200200/0)![](http://inews.gtimg.com/newsapp_ls/0/14876049251/0)

[每日人物](https://news.qq.com/omn/author/8QMc13hb6ocduTnc)

2025-03-06 12:02发布于北京每日人物官方账号

关注

![图片](https://inews.gtimg.com/om_bt/OcdT093Bh7Y4EUv1wvqG0rGo59Kz89kHCNfjwT0XYDT98AA/641)

**这两年，文旅赛道越来越热闹。从哈尔滨、淄博，再到新疆的阿勒泰，总有爆款迎接着泼天富贵。**

**除了本身知名度超高的大型景区，一些中小型景区，也悄悄开始在短视频平台崭露头角，同时，它们的网红元素也多了起来——刷屏的视频里，似乎总有超大朵的漫画白云，乖巧可爱的麋鹿，色彩丰富的风车和小木屋。**

**只是，网红打卡地多了，人们发现，那些让自己心生向往的美好场景，好像永远只出现在短视频里，到了现场，失去滤镜，一切都变了。那么是谁制造那些视频？又是如何把它们推火的呢？**

**不久前，一位名叫张东亮的景区推手，出现在我们的视野。他今年35岁，已经从事这个行业8年，他助推洛阳老君山的视频破圈。这期间洛阳老君山景区的营收也从2018年的1.2亿，飙升到2024年的超10亿，各种中小型景区排队找他拍视频。他个人也由此从煮牛肉面的服务员，变成年入千万的老板。**

**在他眼里，让一个景区火起来，似乎没那么难，不过是一个流水线复制的过程。他不是很在乎景区被批评为“网红””流水线”，只要不涉及游客安全的底线，一切都是流量。**

**以下是张东亮的故事。**

**焦虑的中小景区**

我能够感觉到景区的焦虑。这几天，我写了几篇关于景区的文章，一发出来，就有20多家景区找到我，要跟我谈合作，有国企的，也有私企的。

其中，最焦虑的还是中小景区。他们现金流困难，要求都是尽快出成绩，催人催得很紧。有工作人员刚加上我微信，就想让我马上去实地看。

旅游业很火，但现在的情况是，好的景区持续向好，中小景区举步维艰。很多人都说，旅游旺丁不旺财。每年法定节假日，都是几千万人次出行旅游，但很多中小景区，并没有享受到这个红利。就像哈尔滨火了，得吸走多少景区的客源，才能推起一个哈尔滨？大景区越是火，中小景区的老板就越焦虑。

这样的场景，和我最开始做这行的时候，差别很大。2019年上半年，我已经拍火了好几个景区，比如江西婺源的油菜花，还有本地的小景区。当时，它们光是一个抖音企业号，一周就有2000万的播放量，像婺源油菜花还经常上热搜。

![图片](https://inews.gtimg.com/om_bt/OGuDn34RJ2Qk9UhlVMwOj0A3ONZYYURteGXwg6ur-1f3MAA/641)

▲ 张东亮曾运营过的江西婺源旅游企业的抖音账号，视频播放量过千万。图 / 讲述者提供

可我刚刚辞职，自己成立公司，单独出来找项目，没有资源。我去找景区，大家都觉得我是骗子，那个时候，景区老板们都没有想过能靠抖音把一个地方捧红。我直接到景区门口，让帮忙介绍企划部的工作人员。好不容易见到了，大多都爱理不理的，不会说让你去会议室聊聊。听到我讲的案例，都觉得我不过是运气好。

直到我找到了老君山，他们刚好也在做抖音，负责人愿意让我试一试，给了我一笔项目费用，制定的目标是，整个企业号所有视频加起来，全年观看量超过2亿。在那之前，他们的号已经运营半年，发了好几十条抖音了，整体观看量还不到2000万。

这其实是份吃苦的工作。运营老君山的那段时间，我在山顶上住，凌晨天亮就出发，去老君山各个地方拍视频，爬两三个小时山，晚上睡山上的员工宿舍。你肯定也不能坐索道，这样就拍不到路上的景色了，我感觉没有人能比我在老君山走得更熟。

最开始的时候，我主要拍十里画屏，是很多员工觉得好看的地方，不少宣传片里也有。拍了一个月，视频点赞量还可以，但没有爆款，距离2亿的目标还很远。

直到那年冬天，老君山下了一场大雪，景区闭园，游客来不了——那个时候，很多会下雪的山水类景区，冬季都是封山的。谁也没想到说，大冬天的，老百姓们愿意爬到2000多米去看雪。我当时住在山上，看到雪后的金殿，就觉得，稳了！山上温度低，雪是粉末状，比城市里的雪硬一些，配上金殿、霞光，真的很好看。

![图片](https://inews.gtimg.com/om_bt/GgxiW09XvbkCio_XacJ5c0E_cQuaN9uaJznHJm_9p9iJ4AA/0)

▲ 张东亮拍下的老君山视频。图 / 讲述者提供

最后，这个视频爆了，在抖音观看量有三四千万，相当于完成了全年四分之一的KPI。那条视频，成了老君山爆火的开端，后来，我们发一条视频，播放量能很快到三五千万。我也因此变得更受重视，最开始，山上没啥吃的，我天天吃泡面，视频火了之后，就经常有人上山，给我带烧鸡，有肉吃了。

发现大家想看雪景，我还跟老君山的负责人提建议，不封山了。那个冬天，很多游客上山，为了安全考虑，老君山所有员工上班的第一件事，都是去山上扫雪。

抖音爆了，景区的营收近乎翻倍。一年的时间，它的营业额从1.1亿左右，增长到了1.9亿。尤其是雪景火了之后，游客肉眼可见地多了，而且明显地在年轻化——以前老君山都是靠旅行社拉团来，全是中老年人，抖音上火了之后，很多年轻小情侣、大学生都来了。相比起来，他们的消费力会更高。

![图片](https://inews.gtimg.com/om_bt/ORDltVX_JXLktuCfoUAiDRi2xIyaV1mMrkVlrz_rc1gCkAA/641)

▲ 老君山雪景视频在抖音爆火。图 / 讲述者提供

也就是从这一年开始，很多景区都被短视频带火了。除了我拍的老君山雪景，还有重庆的洪崖洞等等案例。老板们突然意识到，抖音的确可以改变景区的命运。于是，我的活儿突然多起来了，很多景区都来找我，还需要排队，甚至快手的运营团队也专门来找到我，想让我帮他们的客户拍拍视频。

整个2021年，我一共做了13个旅游项目，你猜我一年能赚多少钱？1000多万。那个时候，我就有个准则，如果我去你的景区看一趟，不给我签合同，再联系我，我就不去了——真的排不过来。有一家景区的老板，我2019年出来找活儿的时候，给他报价90万，他不愿意，后来重新找到我，就是180万，一分钱便宜不了。

后来，疫情让旅游业受到了很大的冲击，一些中小景区，压力尤其大。因为大景区往往旅游资源丰富，找银行贷款也相对简单，但是中小景区完全没有资金流入，没办法，它们的风景就是不行，摄影师看了都摇头。

那段时间，有些景区的工资半年发不下来，甚至我去拍视频，还有员工因为急着用钱，只能找我借钱。但大景区就不一样。我们之前也联系过一个很有名的5A级景区，问要不要服务，景区的回复是，“做什么抖音？现在忙都忙不过来”。

后来哈尔滨、淄博火了，中小景区老板们变得又焦虑、又向往——向往自己成为下一个淄博。他们找到我都问：能不能像淄博一样，不花钱，也能火？当时，我不想接项目，有个老板甚至直接在我个人卡里转了10万块钱，想让我接单。

我现在只做抖音，纯粹是市场的需求。景区现在只会为抖音付费。

我们之前尝试过快手，结果一个号都1个亿播放量了，游客却没有抖音涨得明显。这两年还有一些社交平台比较火，但带来的游客量级完全跟抖音不一样，它能够让每天的客流增加到1万，但要增加到5万就不行。目前，那些平台只能捧红一些极其小众的景区，但很多中小景区，只需要赚人头，不需要什么游客质量——没有景区真的想成为“小众景区”。

**爆款是怎么诞生的？**

不知道你有没有感觉到，疫情过后这两年，网红景点变得越来越荒诞了，比如各种裸男。

我不支持这种拍法。在短视频里，大部分人都是追逐流量为上。今天这个景区让肌肉男裸露上身，明天那个景区就敢让女生穿比基尼，这都是下限。如果所有人都按照这个逻辑去卷，那就疯了，所有视频直接下架。

这样的景区，思路是不正向的，没法长久——人到一个地方旅游，为的是什么？不就是好看的景色吗？这是多么简单的道理，也是我们做视频的核心理念，却有那么多人都不懂。当然，也有例外，比如哈尔滨、淄博、王婆……这些属于无规则性火，是流量彩票，不需要人推广也能火，我们更多是提供一种稳定的、让景区火起来的方式。

我觉得，景区更应该营造的是那种美好的、让人向往的乌托邦场景。前几年，有一个我们当地营收不乐观的水公园，它原来会找穿得很暴露的女孩，做擦边演出。我接手运营之后，就专门等天气好、有丁达尔效应的时候，去拍视频。它每天都有花车演出，一场巡游，拍100多个短视频，回去选一个来发，要求是刚好有灯光、阳光、水汽的效果。

这是个十几年的老公园，已经很破了，景区没钱，漂流河旁边的这些彩灯，都是人家春节过了，不要的那些灯拿回来、插在岸上的，周边是小树林，两边都是土。就是这种破旧的场景，但拍好了，就是很动人的场景，一条视频播放量能上千万。

最后的营收也很好。我当时跟他们签合同，原本，这家公园的营收，一年800万元都是个大关，最多就1000万元，老板还承诺，如果营收超过3000万元，多出来的部分都是我的。只是当年遇到了郑州洪水，景区直接没有营业了，3000万元的目标只差一点就能达成。

而且，这些美好的场景，是可以反复火的——每个景区，只要能找到一个或者几个场景，不管你拍多少次，点赞量都有很高，那就反复拍，我把它称作“视频指纹”。

![图片](https://inews.gtimg.com/om_bt/O3X0dx_ImNy6ECsStOpA8N59zY1Yc0Ms6y4PZ9_2N8_2wAA/641)

▲ 大部分景区只要靠这些元素的堆叠就能爆火。图 / 讲述者提供

靠这个方法，我拍火了很多景区。比如，在前面提到的那个水公园，我就只拍丁达尔效应里的花车巡游。还有个冰雪世界，它是室内游乐场，一天会放三次烟雾气泡，我就去定点去拍泡泡飞出来。到后来，所有人来这里，都是想看这个场景，甚至有很多外省的人过来，进来拍条视频就走。

![图片](https://inews.gtimg.com/om_bt/OfhZy6an-2VAsAkSmUbIoaLwjYxaZjF2ezlx8zAL6MTZUAA/641)

▲ 张东亮拍摄的冰雪世界里泡泡飞出来的场景，引得许多人跟风打卡。图 / 讲述者提供

现在的年轻人，跟我们小时候已经不一样了。他们大多数人都处在倍速时代，看电视用5倍速，愿意去接受碎片化的内容，讲究的是“直接看精华就好，我也省事，你也省事”。就像旅游，大家都是想出片、想体验那几秒钟的瞬间，我们也是在迎合。

不仅要拍视频，也要做好运营。在老君山的时候，我们当时搞了一个活动，如果一对情侣，谈恋爱的时候来了老君山，拍个抖音，到你结婚的时候，老君山就会快递送你10张门票，作为份子钱随礼，当时门票送出去了2000多张。结婚算是一个人生命中最重要的时刻了，送10张门票，直接送给亲朋好友，能吸引更多游客。

这个活动，也是想尽可能地吸引情侣，包括我们给景区号做的人设，都是“追求女孩”的男生，配的文案是我上网搜的心灵鸡汤，主打传递“喜欢一个人，就带TA来老君山”。这样做，还是为了吸引成年人，尤其是情侣，他们的消费水平是最高的，时间也相对自由，一年四季，有假期的时候都可以来。

![图片](https://inews.gtimg.com/om_bt/OSeOAtohyF4TUfhVOJYXNQfFaOp4U1aiwq1I0WZCt0cJwAA/641)

▲ 老君山上情侣们可以祈福祈愿，系下红绳悬挂木牌。图 / 视觉中国

年轻人多，也是因为我们选对了目标群体。很多景区喜欢定位成亲子类，但小孩要上学，只能寒暑假来，其它季节怎么办？而且一旦定义成亲子的，很多成年人都不会想去了。

除了这些不变的核心理念，行业里也有很多变化，比如制造爆款越来越难了，竞争很激烈。我刚开始做这行的时候，要野生很多，像老君山给了我几十万的推广预算，这笔钱，怎么用他们不管，相当于打包一个项目，我就都存起来了。没有什么别的投入，不用请达人，没有做任何付费推广，设备就手机，啥都没买。

但现在，行业里进来很多人，大家都在拍，基本上没有什么秘密，你能拍到的，别人也能拍到，为啥你就百分百保证比别人火？保证不了。那就必须要拿一笔钱去推广、请一些达人。一个视频火了，你要让它爆火，必须追加一笔钱去投流，相当于大家都在排队等公交车，投流就能让你插队，提前上车。

投流也要基于你的视频内容，如果播放量高，有100万，你可以通过投流让它涨到1000万，但如果这个视频发出去，一星期也就一两千播放量，那就没必要花这个钱了。我也试过，不投流的话，自然流跑得就是没有那么大。还有请达人，光是花在达人身上的钱，一年就是100万，这都是硬支出，能占项目预算的三分之一。

所以，我现在接项目，都是要选择，我会考虑，你这个景区一年之内，有没有出现5次以上，点赞超过5万的短视频？哪怕是游客的也行，员工的也行，达人号、企业号都行，视频发布者不限，如果没有，我就不接了。因为这已经不是推广的问题，是景区底子不够好。

我以前也接过一些项目，和老君山很像，想通过抖音推广超过老君山的流量，或者争一争，但是就是争不过。这不是我的问题，也不是抖音的问题，这就跟人一样，有的人身高就是一米九，有的人身高就是一米七，没办法改变。

![图片](https://inews.gtimg.com/om_bt/Ob2rvZafh2jC-fP0wpoir43md6yOb4dW91m146tHXzPKQAA/641)

▲ 张东亮当时拍摄的老君山视频，数据至今依旧亮眼。图 / 抖音截图

**不爱旅游的人，却推红了景区**

对于我来说，推红一个景区，就是一份工作。我不带感情，在我眼里看到的场景都是数据，只有会不会火的区别。我要做的，就是用最快的速度，找到它的视频指纹，让大家都愿意来拍视频。

我不喜欢旅游，不喜欢社交，小时候，我家算我们村最穷的，我从来没有旅游过，15岁之前，都没出过我们村。上中专了，才第一次去郑州。现在从事这个工作，很多人让我去他们的景区看一看，我都不太喜欢去，都一样，只是不去又谈不成业务。

文旅热潮，的确改变了我的命运。我原来在郑州上班，但工资买不起房子，租房条件也不好。2016年，老婆怀孕，我想还不如回老家。刚好，老家附近新开了一个水乐园，刚刚建成，在招临时工，我就去了，先是到汉堡餐厅当收餐员，又去煮牛肉面，一个月工资两千八。

上班一年后，我通过内部考核，进入了景区的企划部。但没过多久，我爸就生病了，每个月吃药都要八九百，我想多赚钱，这家不能养不起，跟经理提了辞职。这个时候，经理告诉我，老板给领导层开会，研究怎么用抖音推广景区，如果我能研究出个名堂，这工资怎么涨都没问题。

这就是我入行的开端。这个时间点，抖音上最火的还是西安摔碗酒、茶卡盐湖这些第一代网红景区。那个时候，很多景区做宣传，都是把钱花在自己的景区企业号上，做一个号，又发景色，又发景区通知，追求粉丝量达到多少万。

![图片](https://inews.gtimg.com/om_bt/OKPAMzr9X1WucsV_l2Yqxsm-zA7LvmZp0-MjlAaFIyMWkAA/641)

▲ 第一代网红景点，西安摔碗酒。图 / 视觉中国

但在水乐园里，我想的第一个办法，就是把钱给游客。当时，我搞了一个策划，鼓励游客们拍视频。当时有一个健身教练，拍冲浪池“海啸”涌过来很多人的视频，后来有54万点赞，在那个时候，这已经算是比较火的视频了，我们就奖励了他一个苹果手机，当时价值一万块吧。但是老板很满意，那一年，我们那个景区就成了郑州、乃至全国流量第一的水公园。

发动游客有不确定性，他们拍得不好看怎么办？那我就自己拍，把不可控变得可控。我当时在抖音上下载了三五万条旅游类视频，放到电脑里，一条一条地看。研究这些视频为什么火？竖版的构图怎么好看？音乐配什么？我不是专业学营销出身的人，很多方法都是我自己硬是看视频看出来的。

所以我觉得，做旅游行业，你不一定需要很懂旅游，你只需要会观察游客。这也是我在水乐园当服务员、煮牛肉面得到的经验。很多景区，只知道卷大型设备，却不懂怎么做好细节，但我是站在太阳下、跟游客们一起站几个小时的人。我就跟他们提建议，很多游客不喜欢穿别人穿过的拖鞋，他们感觉脏，要做好卫生。夏天热，要买喷雾设备，让游客们身上随时是湿润的，不然会被晒伤。

![图片](https://inews.gtimg.com/om_bt/O1kcOCiJQ25gTAY9J-GWAAU-oNdBZDxksTzAZSQqvhUQQAA/641)

▲ 一拍摄，张东亮就要和游客们一起在景区内站上好几个小时。图 / 讲述者提供

后来，我把我们景区拍火了，又推火了老板的另一个项目冰雪世界，名气渐渐大起来。开始接一些外面的项目，比如去江西婺源拍油菜花，都火了。那个时候，我感觉到，我以后都不会再缺钱。原来我穷，都不舍得花钱，慢慢地，这消费也起来了，之前我没去过足疗店，有钱了才发现，爬完山累了，做个足疗挺舒服，去足疗店都直接捏399元的脚。

也有很多人说，我拍的这些视频，都是网红滤镜、是流水线。我听到过这样的批评，但我觉得无所谓。一个景区只要有60%的人觉得很好，就已经超过大部分景区了，迪士尼还有人骂呢。景区跟人一样，不能满足所有人的期待，尤其是网络舆论，10个人骂你有流量，就会有100个人、1万个人骂你。所以遇到了就只能冷处理，除非是游客受伤这样的底线问题。

至于你说的，快节奏里旅游失去了意义，我不会觉得遗憾，说实话，我感受不到这个细腻程度。就像我爸当年生病，当时医生说如果钱不够，就要截肢大腿，我妈受不了，但我很快同意了，因为不管多伤心，都改变不了这个事实，手里面没钱，能怎么弄？

我现在接项目，更希望能做出成就感。比如黄山，确实底子好，你去做，会有人问你，它火跟你有什么关系？

所以，我更想选择一些底子好、但运营状况不好的景区，可能它景色很好，但真没有钱，只需要我推一把，就能火。如果有这样的项目，我会很动心，甚至可以收费很低，能够带给我成就感，就足够了。
