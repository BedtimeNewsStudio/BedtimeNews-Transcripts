# 哈尔滨通报1014人死后多领养老金，官方责令退回

去年，哈尔滨市也有多个区在“哈尔滨社保”服务号发布公告，督促退回相关人员多享受的社会保险待遇。

[翟瑞民](https://a.jiemian.com/index.php?m=user&a=center&id=102682454) _·_2026年01月23日 05:51浏览 20.3w来源：界面新闻

![哈尔滨;1014人;死后多领养老金;官方责令退回](https://img.jiemian.com/101/original/20260123/176916528579555500_a700x398.jpg)

图片来源：界面图库

2026年1月23日，黑龙江省哈尔滨市社会保险事业中心微信服务号“哈尔滨社保”发布公告称，赵某芳等1014人存在死亡后多领取城乡居民养老保险待遇情形，责令退回。

哈尔滨市道外区社会保险经办服务中心在公告中称，经核查，赵某芳等1014人存在死亡后多领取城乡居民养老保险待遇情形，道外区社会保险经办服务中心发出的《退回社会保险待遇告知书》无法送达且无法联系或不配合返还，现依法公告送达《责令退回多享受社会保险待遇决定书》。自本公告发布之日起30日届满视为送达，超30日视为逾期。

道外区社会保险经办服务中心表示，根据《中华人民共和国社会保险法》《社会保险经办条例》等有关规定，责令家属自公告发布之日起30日内携带死亡证明并将一次性多享受的社会保险待遇存入个人农业银行账户，到户籍所在地街道/村镇的社保大厅办理退回业务。在法定期限内不申请行政复议或提起行政诉讼，又不履行本决定的，将依法申请人民法院强制执行。

公告所附的名单显示，“领取金额”一栏中，多领金额最高的为5974.74元，多领待遇属期为“201608-202008”。此外，公告中不少人仅多领取了一个月的城乡居民养老保险待遇，最低金额为55元。还有多人的多领取金额和多领取待遇属期为空白。

1月23日，道外区社会保险经办服务中心一工作人员告诉九派新闻，养老金继续发放的原因，可能是早期未全面联网，居民生存状态信息缺失导致。其表示，之所以采取公告方式，是因为多次电话通知家属无果，公告发出后已有人来咨询。

界面新闻注意到，日前，哈尔滨市道里区社会保险经办服务中心也发布多份《关于道里区退回多领取养老保险待遇公告》称，相关人员存在多领取养老保险待遇情形，该中心向相关人员邮寄发出的《责令退回多享受社会保险待遇决定书》无法送达且无法联系，现依法公告送达《责令退回多享受社会保险待遇决定书》。自本公告发布之日起6个月届满视为送达，超6个月视为逾期。公告显示，有的人员多领取的养老金多达13万元。

![](https://img.jiemian.com/101/original/20260123/176916528579555500.jpg)

去年，哈尔滨市也有多个区在“哈尔滨社保”服务号发布公告，督促退回相关人员多享受的社会保险待遇。公告称，针对逾期未退回且未申请分期退回的人员，若参保人存在继续发放的社会保险定期待遇，经办服务中心将依据《社会保险经办条例》第四十六条直接从参保人在后续享受的养老保险待遇中抵扣；若参保人不存在其他可享受的社保待遇，且无正当理由逾期仍不履行义务的，经办服务中心将依法申请人民法院强制执行。

哈尔滨市社会保险事业中心工作人员告诉极目新闻记者，1月23日他们确实发布了多条公告，要求家属退回多领取的城乡居民养老保险，数据来源于道外区社保中心核查中发现的异常，至于其他具体情况并不太清楚。
