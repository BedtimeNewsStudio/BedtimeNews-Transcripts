# 河南中牟通报“景区吊桥断裂”：未出现人员伤亡

2021-10-01 18:49:43来源： [中国新闻网](http://www.chinanews.com./sh/2021/10-01/9578455.shtml)作者：叶攀责任编辑：叶攀

2021年10月01日 18:49　来源： [中国新闻网](http://www.chinanews.com/) [![参与互动](http://www.chinanews.com/fileftp/2019/08/2019-08-19/U719P4T47D44991F24534DT20190819170959.jpg)参与互动](#zw_cyhd)

[中新网](http://www.chinanews.com/) 郑州10月1日电 (记者 刘鹏)针对辖内景区一吊桥绳索突然断裂导致多名游客掉入湖中一事，河南省中牟县委宣传部1日下午发布情况说明称，吊桥锁链崩断事件导致10余名游客落水，未出现人员伤亡，目前景区已封闭并停业整顿。

|  |
| --- |
|  |

1日，有网友爆料称在中牟县雁鸣蟹岛游玩时，景区内一吊桥绳索突然断裂，多名游客掉入湖中。据网友上传网络的现场画面显示，事发时，桥上站了不少游客，桥中心位置一侧的防护铁锁链断开，有游客掉进水中。

中牟县委宣传部通过官方微博@中牟发布情况说明称，当日上午，雁鸣蟹岛森林公园景区因客流量较大，部分游客在水上吊桥桥面嬉闹致使吊桥左右摇摆幅度偏大，吊桥一侧锁链崩断，桥身侧翻，导致10余名游客落水。景区管理人员和热心游客在3分钟内将落水游客全部救助上岸，未出现人员伤亡，目前景区已封闭并停业整顿，管理方正积极与落水游客协商理赔事宜。

通报称，该事件发生后，中牟县文广旅游体育局已对全县所有景区再次开展安全隐患排查，启动最大承载量预警机制，督导景区实行限流、预约、错峰措施，确保游览秩序和游客安全。(完)
