| 罗琦委员：第三代核电机组华龙一号可抵御大飞机撞击 |

|     |
| --- |
| 发布日期：2015-03-06 |

|     |
| --- |
| 3月4日，全国政协委员、中核集团核动力院院长罗琦接受中国经济网记者采访时表示，我国研发的华龙一号（ACP1000）核电机组拥有三代核电技术的完全自主知识产权，华龙一号（ACP1000）的出现意味着我国已有实力和世界核电大国进行竞争，为我国核电走出去提供了技术支撑。<br>我国核电或进入新一轮密集批复阶段<br>3月3日，记者获悉，今年2月17日辽宁红沿河核电站5、6号机组正式在国务院办公厅会议上获得核准开工，国务院总理李克强最后圈批通过。时隔26个月，中国终于再有新核电项目获准开工。自从2011年日本福岛核事故以来，中国政府一度暂停了新核电项目审批，直到2012年12月才核准田湾核电二期工程，此后再无新项目获批。<br>有业内人士认为，红沿河核电的获批可能意味着中国核电进入新一轮密集批复阶段。<br>中国核能行业协会数据显示，截至2014年12月，随着5台核电机组的陆续投运，中国共投运22台核电机组，总装机2010万千瓦，发电量1280亿千瓦时，占全国总装机容量2%。目前中国在建核电机组26台，共2850万千瓦，为世界之最。预计2015、2016年将先后有14台机组投运，到2016年整个核电装机容量将超过3400万千瓦，发电量将超过风电。而按照我国核电发展中长期规划，到2020年，中国将建成5800万千瓦核电装机容量，并有3000万千瓦在建。<br>华龙一号（ACP1000）安全性能高 目前已出口拉丁美洲<br>3月4日，全国政协委员、中核集团核动力院院长罗琦对中国经济网记者表示，我国是核大国，并非核强国。而完全拥有自主知识产权的三代核电机组华龙一号（ACP1000）的出现意味着我国已经有实力与国际核电大国进行竞争，也为我国核电走出去提供了技术支撑。<br>华龙一号是中核集团和中广核集团合作研发的具有完整自主知识产权的三代核电技术，据中核集团介绍，华龙一号（ACP1000）提出“能动和非能动相结合”的安全设计理念，采用“177”反应堆堆芯和双重安全壳。安全性上达到了福岛核事故后国家核安全局提出的新的核安全目标和需求，满足国际最高的要求。同时华龙一号（ACP1000）采用的技术，都是经过实践考验的成熟技术，降低了核电站在建设工期和质量上的风险。<br>据罗琦介绍，华龙一号（ACP1000）拥有的“能动和非能动系统”可以在厂区完全停电的情况下利用重力为反应堆堆芯降温。其拥有的双重安全壳可完全抵御大型商务飞机的碰撞，厂区也可抵御福岛核事故中的地震震级。<br>记者了解到，春节前夕中国和阿根廷两国签署了在阿根廷合作建设压水堆核电站的协议，华龙一号（ACP1000）已成功出口拉丁美洲，迈出核电走出去的第一步。 |
