# 姚明运动生涯回顾：一代巨星谢幕 辉煌难以复制

2011年07月20日 15:31　来源：中国新闻网　![](http://www.chinanews.com/fileftp/2010/04/2010-04-23/U76P4T47D13180F981DT20100423110629.jpg)[参与互动(0)](http://comment.chinanews.com/comments/comments.php?newsid=3196758)　　【字体：↑大↓小】

![](http://image1.chinanews.com.cn/cnsupload/big/2009/02-08/cnsphoto/a6db56d6b751470fbb919deebecacd7b.jpg)

    资料图：姚明在比赛中。

中新社北京7月20日电 北京时间20日下午2时，姚明在上海以“明谢”为主题的新闻发布会上亲口宣布结束自己的运动生涯，正式退役。

姚明于1980年9月出生于上海。1998年入选国家队，次年获得CBA“进步最快球员”称号。2002年在带领上海队获得CBA联赛冠军后，不足22岁的姚明成为NBA首个外籍状元秀，并在随后的9个赛季效力于休斯敦火箭队。

姚明的运动生涯自此分为NBA和中国国家队两个部分。

2002年10月，在NBA常规赛火箭队与步行者队的角逐中，姚明上演了处子秀，以一个1分未得的“菜鸟”形象拉开了征战NBA的序幕。

|  |
| --- |
|  |

2002年11月22日，姚明在与乔丹领军的奇才队一战中首次先发出场，得到18分8个篮板。在整个新秀赛季中，他打满了全部82场比赛，其中首发72次，场均获13.5分、8.2个篮板球。

2003年2月，姚明以联盟得票第四的身份首次入选全明星。

2003——2004赛季，二年级生姚明渐入佳境，在2004年2月得到单场41分、16个篮板、7次助攻、2个盖帽，得分和助攻均是他职业生涯中单场最高纪录。

这个赛季，火箭队以常规赛西部第七名的身份进入季后赛，遗憾的是在首轮被湖人队以4:1淘汰。姚明本赛季场均17.5分和9个篮板。

2005年6月，姚明在美接受骨刺去除手术，这也是他平生第一次被推上手术台。

2006——2007赛季是姚明在联盟的鼎盛期。带伤出战的他场均25分、10个篮板。这个赛季的后半程，他的场均得分更是达到26.6分，姚明也被公认为是超越“大鲨鱼”奥尼尔的NBA现役第一中锋。

随后，伤病成为姚明运动生涯的主旋律。

2008年2月，姚明因左脚应力性骨折，提前告别2007-2008赛季。随后赛季，姚明率领火箭打破球队多年来的“首轮魔咒”，以4：2击败开拓者，职业生涯中首次进入西部半决赛。但随后他被确诊为左脚骨裂，无缘火箭队与湖人队的西部半决赛后四场比赛，火箭队终以3：4不敌该赛季的总冠军湖人队。

2009年7月，在近两个月的保守治疗后，伤势未能愈合的姚明选择了接受脚部结构重建手术，并因此而缺席了整个2009——2010赛季。

2010年11月，新赛季重新复出的姚明，在与奇才的对阵中再次受伤，五场比赛之后，火箭宣布姚明左脚再次应力性骨折。

在NBA9个赛季，姚明8次入选全明星阵容。NBA历史上身高超过2.16米的球员中，姚明的罚球命中率是最高的，达到83.3%。姚明还在连续3个赛季场均超过22分，在NBA史上有相似身高还能场均砍下20分以上的球员，只有姚明和NBA前著名中锋拉尔夫·桑普森。

受伤病困扰，姚明在NBA的9个赛季里缺席252场比赛，场均19分9个篮板。如果以超级中锋的指标来看，其个人数据还不够耀眼，但姚明以他优秀的篮球天赋、卓越的职业精神、出众的人格魅力，以及在赛场内外的巨大影响力成为NBA难以复制的经典个例。

在国家队，姚明的地位更是无法取代。在2004年和2008年两届奥运会上，以姚明为核心的中国男篮两次取得平历史最好成绩的第八名。

在姚明参加的两届世锦赛中，他的答卷同样出彩——在2002年印第安纳世锦赛上，他场均砍下21分，在所有球员中排名第三，投篮命中率75.2%达到赛会排名第一。而在06年的大阪世锦赛，姚明场均25.3分荣膺“得分王”。

2008年北京奥运会，姚明作为中国代表团的旗手出场，而此时的姚明也已是中国体坛的一面“旗帜”。

北京时间2011年7月9日凌晨，美国媒体曝出“姚明退役”。20日，姚明在上海召开的新闻发布会上正式宣布结束运动生涯。

在美媒率先爆出“姚明退役”的消息后，各方反应各异，但无论是美国的主流媒体，还是中国的专家学者，无论是包括科比、纳什等在内的篮球巨星，还是中外普通球迷，对姚明的价值都有相似的认定——“中国国家名片”、“沟通中西方文化的桥梁”、“为NBA带来巨大市场和商业价值的国际巨星”、“理应入选名人堂的顶级球员”。
