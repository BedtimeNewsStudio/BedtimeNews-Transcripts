# 天津：“蓝印户口”冲击波

陈建强 《 光明日报 》（ 2014年04月23日   05 版）

|  |
| --- |
| CFP |

|  |
| --- |
| 房展会上，天津一楼盘开发商在利用最后的时间，加紧推销房产。CFP |

**“天津蓝印户口5月31日停止办理，最后时机”“天津蓝印户口，40万元学区现房，抓紧时间行动吧”……打开搜索网站，输入“天津蓝印户口”，各种广告语林林总总，不少人争着赶搭“末班车”。**

**4月17日，经天津市政府常务会议通过，天津市决定自2014年5月31日起，停止外省市户籍人员通过购买商品住房、投资兴办企业和引进人才办理“蓝印户口”。在天津实行近20年的“蓝印户口”政策即将消失，成为人们关注和讨论的焦点。**

**曾经的“升学利器”**

    1994年8月8日，天津市政府办公厅转发了《天津市蓝印户口管理暂行规定》，规定外省市户籍人员在天津市购买达到规定价格的商品住房、达到规定投资兴办企业以及天津市企业引进的各类人才，可以申请办理“蓝印户口”。

    “蓝印户口”因为户口的封皮和印章为蓝色而得名，不同于正式户口的红封皮、红印章，也因此被称为“介于正式户口与暂住户口之间的户籍”。

    天津市政府提供的材料显示，“蓝印户口”政策施行近20年来，天津市共批准各类“蓝印户口”312687人。据天津市国土房管部门统计，2009年以来，外省市户籍人员在天津市购买商品住房占全部销售比例的31%，其中办理“蓝印户口”的约占四成以上。

    “蓝印户口”缘何如此受青睐？原因只有一个：获得“蓝印户口”，即可在子女入学、高考等方面享受与天津市常住户口居民同等待遇。天津推出这一落户政策之际，正值天津乃至全国楼市低迷之时。该政策一出台，便被寄予“促进消化市场存量房”的厚望。事实上，由于将“买房”与“入学门票”挂钩，“购房落户”也确实对天津房地产市场产生了显著影响。尤其是在房价相对低廉的郊县，更是受益良多，房产市场迅速活跃起来，房产成交量巨量攀升。这一时期，诸如“40万元落户天津”之类的广告随处可见。以地处京津冀交界的武清区为例，2013年，非天津市户籍人士购买新建商品房12044套，占新建商品房成交套数的64.52%。蓝印户口政策不但刺激了当地的经济发展，还为众多外来人员提供了平等享受大城市福利待遇的机会。但是，不容否认，购房者多数是冲着“天津学籍”而来，他们有自己的如意算盘：在房产价值“只升不降”的预期下，在为子女高考升学抢占“有利地形”的同时，也为个人资产的保值升值觅到一个绝佳的投资机会——等到子女如愿以偿以“天津人”的身份考进大学后，即使将房子转卖，也能获得不菲的收益。正因为如此，在许多郊县售罄的楼盘内，入夜亮灯的窗口却“寥若晨星”，被外界称为“鬼城”。

    统计数字显示，该政策实施至今，武清区蓝印户口办理人数占全市总量的35.2%，引发了持“蓝印户口”外省市学生总量暴增与当地有限教育资源的矛盾。在全市范围内，高考考生数量急剧增加，年均达到3500人左右，约占天津市高考考生总量的5%。大量“高考移民”的出现，也引发当地居民的不满情绪。

**“落户新政”重在激发城市活力**

    事实上，天津停办“蓝印户口”的传闻已有月余。

    一个月前，记者曾专门探访近几年楼市十分火爆的武清区各处楼盘。当时，由于“靴子”尚未落地，本拟“购房落户”者大多还持观望态度，多方打探，欲辨真伪。保利海棠湾、亚泰澜公馆和恒大山水城等楼盘的售楼展厅里没了购房者的身影，显得十分冷清。“我们确实收到了区里的通知，暂停签订带‘蓝印户口’的购房合同。但到底取消与否，我们也不清楚。”某楼盘的销售人员无奈地对客户说。同样的话，那些日子他每天都要重复好多遍。“其实，取消‘蓝印’的说法几乎年年有，但这次是真的了，因为新的办法已经开始实施了。”

    售楼人员所说的“新办法”就是《天津市居住证管理暂行办法》，去年9月份公布，并于今年1月1日正式施行。新政策出台后，旧规定应该及时废止。

    此外，与《天津市居住证管理暂行办法》配套出台的《天津市居住证积分指标及分值表》，则从操作细节上，对外地人口落户天津做出了比较合理的安排。比如采取“居住证+积分入户+员额总量”的办法，以居住证制度管理外来常住人口、以积分制方式遴选外来拟落户人员、以员额总量控制年度落户人口总量等。符合申请条件的居住证持有人，由用人单位收集汇总其申请材料，于每年的规定时限提出积分入户申请。《天津市居住证积分指标及分值表》包括4大类、12项指标，各个指标累计相加为最终积分。居住证持有人申请“积分入户”时，将进行指标量化审核，根据积分确定落户人员。天津市将依据人口总量、用工需求及公共资源承载能力，于每年3月31日前向社会公布积分入户人口指标总量，并对年度计划执行情况进行监督检查。

    既然敞开了“居住证管理办法”这扇门，关上“蓝印户口”这扇窗也是水到渠成。

    今年新施行的落户“新政”，是在国家“积极稳妥推进户籍管理制度改革”的背景下出台的。天津市作为处于快速发展期的特大城市，常住人口高速增长与户籍人口老龄化问题并存。据统计，目前全市常住人口有1400多万人，近年来每年增加50万人左右，外来常住人口总数占全市人口比重已近30%。通过“公正、科学、有效”的制度，让符合条件的外来常住人口落户，可以吸引年轻、有文化、高技能人才来津落户，对改善人口结构、促进城乡一体化、增强经济社会发展活力具有重要意义。

**最后的冲刺**

    天津这次停办“蓝印户口”，按照老人老办法、新人新办法：在2014年5月31日前，通过天津商品房网上销售管理系统打印并签订预订协议的外省市购房者在取得产权证后，可继续按原规定办理“蓝印户口”。这就给外省市购房者和房地产开发商留下了一个“最后的冲刺机会”。

    连日来，津郊各区县的楼盘正在享用“最后的晚餐”。位于武清区的某楼盘销售人员告诉记者，这两天来电咨询“蓝印户口”的购房者明显增多，期盼通过“住房投资”换取“优质教育资源”的诱惑依然巨大。

    当然，此次政策的调整对天津楼市的影响也不可小觑。一位房地产业内人士告诉记者，落户政策的变化肯定会在短期内对天津商品房的销售带来巨大冲击，尤其是郊县偏远地段的楼盘可能导致“短期楼市库存消化困难”。事实上，前期投入规模较大的房地产开发商，目前配套速度正明显减慢。他预期：“‘蓝印户口’的取消，郊县商品房成交量有可能下滑四成。”

    专家分析，“蓝印户口”政策在人口导入和房地产投资等方面发挥了刺激作用。取消“蓝印户口”后，隐性福利消失，将使得天津楼市的竞争力和市场吸引力减弱。在当地楼盘库存的压力下，降价的可能性增大。

    但是，房地产市场的畸形繁荣毕竟是难以持久的，为了从根本上激发城市活力，实施“落户新政”，让“蓝印户口”寿终正寝，正当其时。(本报记者 陈建强)
