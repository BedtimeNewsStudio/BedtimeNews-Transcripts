### 自主创新带来产销两旺——格兰仕广交会签约大幅增长侧记

2018-10-23 07:53 来源：人民网－人民日报

**自主创新带来产销两旺**

——格兰仕广交会签约大幅增长侧记

本报记者 李 刚

|  |
| --- |
| ![](http://paper.people.com.cn/rmrb/res/2018-10/23/14/rmrb2018102314p17_b.jpg) |
| 第124届广交会现场。<br>资料图片 |

第124届广交会期间，格兰仕首次在广州举行全球客户晚宴，来自世界各地上千名客户济济一堂。格兰仕集团董事长兼总裁梁昭贤表示，本届广交会格兰仕签约金额增长20%以上，这是格兰仕与全球经销商合作，共同应对外部市场环境变化的结果。

“逆市飘红”高增长

广交会格兰仕展区琳琅满目，“G+智慧家居”平台、互联网生态冰箱、高端微蒸烤一体机……展出的200余款家电，创下格兰仕20年来产品参展最高纪录。

格兰仕第一次参加广交会是在1996年，当时格兰仕国际销售部的工作人员一个人扛着一台微波炉、两个电饭煲进了展馆，展台还是“借用”一家外贸公司展台的角落。尽管如此，那一届广交会格兰仕还是获得了两三千台订单，撬开了世界市场一条门缝。

以此为起点，格兰仕微波炉在国内国外两个市场迅猛发展，目前格兰仕家电出口到全球近200个国家和地区，自主品牌已在全球137个国家注册，成为广交会上的“成交大户”，今天的格兰仕不仅微波炉闻名世界，厨房电器、空调、冰箱、洗衣机4大品类出口也晋升十强企业。今年以来，格兰仕在英国、荷兰、匈牙利、比利时、西班牙等欧盟市场，土耳其、乌克兰、沙特阿拉伯等“一带一路”参与国家都取得了高增长业绩。

展示“智能烹饪”前景

智能化是格兰仕本届广交会展示的重要主题，记者在格兰仕互联网冰箱展区看到，依托格兰仕“G+智慧家居”平台，格兰仕互联网冰箱被打造成了一个智慧中枢。不管是硬件还是软件，互联网冰箱的配置都超过国际水准， 透过21.5英寸超大高清显示屏，用户可以通过图文、语音、视频、照片等多种形式与亲朋好友分享烹饪等居家趣事，可以连接微波炉、烤箱等智能设备，可以一边下厨一边点播自己喜爱的视频和音乐。一台互联网冰箱，诠释了格兰仕“努力，让顾客感动”的经营理念。

而格兰仕高端微蒸烤一体机，将变频微波、高温窖烤、立体蒸汽三大主流烹饪功能整合到一台微波炉上，一机实现变频微波、热风对流、蒸汽、微波热风组合、微波蒸汽组合、热风蒸汽组合等多种烹饪方式，用户可以通过一体机触控屏、手机APP或其他联网设备多种方式操作，根据自身喜好更新菜谱。

梁昭贤表示，格兰仕就是要以“品牌家电”“品质家电”推进品牌国际化，满足全球市场消费升级需求。

多品种多网点布局

聚焦高质量发展，以高品质产品、高效率制造、高效率流通为支撑点，格兰仕对北美、欧洲、日韩、东盟、南美、“一带一路”参与国家市场全面推进多品种、多网点布局。在北美、欧洲等重点市场，格兰仕加快本土仓储、物流配送体系建设，全面拓展与当地主流零售商的合作，对重要零售渠道逐步实现产品直供。

格兰仕在北美市场站住脚跟，是通过收购当地区域性品牌开始的，格兰仕联手当地知名品牌，运用属地化品牌结合属地化经营团队打开市场。以此为基础，格兰仕灵活采用“1+5”模式。这一模式让格兰仕能更好地与当地主流文化、消费理念相融合，极大地拓展了格兰仕产品在海外市场的销售，完善了品牌国际化经营支撑体系。

格兰仕有关负责人表示，外部市场存在诸多不确定性，但是通过全球领先的智造水平、流通效率和不可替代的产品力，我们有条件从产品占有率走向品牌占有率，实现更高品质的国际化。
