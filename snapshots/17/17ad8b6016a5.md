# 全斗焕：不被原谅的总统

《
文摘报
》（
2021年12月14日

05
版）

|  |
| --- |
| ![](https://epaper.gmw.cn/wzb/images/2021-12/14/05/p12_b.jpg) |
| 全斗焕 |

11月23日上午，1980-1988年担任韩国总统的全斗焕在确诊多发性骨髓瘤3个多月后，于首尔延禧洞的家中去世。青瓦台方面除去由新闻发言人做出“为故人祈求冥福，向家属表示慰问”的简单表态外，既未致送花圈，也未派出吊唁代表。反倒是在1980年“5·18”民主化运动的发生地光州，民众纷纷走上街头，拍下雨后彩虹，感慨11月23日是苍天送达的迟来慰藉。

2011年韩国国务会议修订通过的《国家葬法》曾经明文规定，“前、现任总统或总统当选人于身故后有资格享受国家葬待遇”，没有附加其他限制条件。2009年因身陷贪腐案调查而自寻短见的卢武铉，以及1996年曾被判处17年监禁的卢泰愚，因此都得以享受国葬或者规格与之近似的“国民葬”礼遇。唯独全斗焕其人，不仅青瓦台方面明确宣布不会为其举行国家葬，遗属也未曾就此提出任何异议，可谓当代韩国政治史上的特例。

以1981年3月全斗焕依据第八次修订的韩国宪法当选为正式总统、结束朴正熙开创的“维新体制”作为标志，这位前陆军大将凭借新生代军人集团（一般称为“新军部”）的支持和宪法授予的紧急状态权统治韩国的7年多时间，被历史学家称为“第五共和国”时代。从新军部势力悍然夺权的1979年“双十二”政变，到1980年光州民众的流血抗争，再到1988年全斗焕本人失势下野、遁入佛寺避难，这段不算漫长的历史自始至终都被暴力、阴谋和黑金政治的阴影笼罩着。以至于资深政治观察家、首尔总统领导力研究所所长崔振曾经感慨，“在韩国人心目中，‘全斗焕’这三个字几乎就是军事独裁者的同义词”。

2006年，在全斗焕时代短暂出任过国务总理的经济学家南德祐为了缅怀早逝的前同僚金在益（曾任全斗焕的首席经济秘书），组织历史亲历者编写了一部纪念文集《80年代的经济改革及其主导者金在益》。文集的执笔者普遍认为，尽管全斗焕本人对经济事务所知甚少，但他能任人唯贤、启用专家治国，一举扭转了朴正熙执政晚期通胀高企、城乡发展失衡的颓势，使韩国经济重新恢复活力，可称有功。在外交事务方面，全斗焕政权也能审时度势，在对朝、对日、对美、对华多个方向上全面出击，留下了丰硕遗产。首尔击败名古屋赢得1988年夏季奥运会主办权，尤其成为韩国“国运”扶摇直上的标志。尽管全氏本人在“双十二”政变、光州事件等国内政治问题上的首恶责任不容推卸，但终究没有效仿朴正熙建立终身独裁体制，因此称得上“功过相抵”。

然而“瑕瑜互见”“过不掩功”这样的词语，韩国民众可以将之加诸全斗焕的前任朴正熙以及他的继任者卢泰愚，却绝难用于评价全斗焕本人。日本东京都立大学法学系荣休教授森山茂德在其所著的《韩国现代政治》一书中一针见血地指出：全斗焕难以效仿朴正熙建立一人独裁，并非他个人不愿为之，而是执政精英集团内部分化以及高速城市化背景下社会力量持续抗争的结果。至于“专家治国”路线，在“维新体制”下固已有之，并非全氏所独创。相反，在1979年朴正熙意外身亡、韩国有可能启动和平政治转型的背景下，全斗焕基于一己私欲发动“双十二”政变，继而以残酷的暴力镇压光州抗争者，使整个社会蒙受巨大代价，负面影响至今未绝。而朴正熙时代基于政治需要建立的秘密献金运作制度，在全斗焕任内进一步发展为赤裸裸的裙带腐败、损公肥私。其中影响恶劣者如“张玲子事件”，甚至连执政集团成员也难以坐视。

更有甚者，上世纪90年代韩国政治民主化完成之后，已成一介平民的全斗焕非但不愿直面历史、承担必要的道义和财务责任，反而主动利用一切机会为自己辩护、开脱。甚至到2021年他离世时为止，依旧不曾缴清1996年司法判决中罚没的非法收入。这种极度自私的表现，使他最终成为唯一无法为韩国公众原谅的前总统：毕竟，记忆是不会轻易消退的。

（《三联生活周刊》2021年第49期 刘怡）
