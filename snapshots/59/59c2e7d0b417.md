|  | # 治理校车不该让学生步行上学 |
| --- | --- |
| * * * |  |
| http://www.sina.com.cn 2006年12月10日15:27 新民晚报 |  |
|  |  |
| ◆郑山海<br>一段时间以来，公安部和教育部联合开展了校车安全整治行动，全国各地掀起了一股治理校车的高潮，不断有违规校车被扣留的新闻见于各类媒体，其中尤以超载为重。<br>超载校车不安全，这是毋庸置疑的。但如果能退一步想，面对那些拥挤破烂的校车<br>，即便不考虑安全问题，仅从舒适性上出发，一般人也是不大喜欢乘坐的。这样的校车所以能够存在，在很大程度上是缘于一些家庭两害取其轻的原因。<br>因为没有这些校车，孩子上学途中的交通安全同样得不到保障。不论是孩子自己步行还是由家长骑自行车带着，他们同样面临着混乱交通秩序的威胁。对比违规校车，一般的家长更不敢让孩子独自走路去上学。<br>笔者就在一档电视节目中看见了这样的情节：因为校车被扣，很多外来打工子弟学校的学生只能徒步回家，由于冬天已经来了，走在路上的孩子，很多都被冻得瑟瑟发抖，不少孩子回到家时，天都黑了。记者问这些孩子，是否愿意乘坐拥挤的校车，孩子几乎异口同声地回答：喜欢，因为车里暖和！<br>童言无忌，尽管治理校车是为他们的安全着想，但对孩子而言，一个可以躲避寒风的车辆，同样重要。治理校车不应该把孩子们从一个困境转到另一个困境中。 |  |
