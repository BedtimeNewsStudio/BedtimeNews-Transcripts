**臺灣兵役制度**依照[中華民國法律](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E6%B3%95%E5%BE%8B "中華民國法律")，實施募徵併行的**[義務役徵兵政策](/wiki/%E5%BE%B5%E5%85%B5%E5%88%B6 "徵兵制")**，所有達到服役年齡的合格男子均須服1年常備兵役、或接受4個月軍事訓練。

[台灣歷史](/wiki/%E5%8F%B0%E7%81%A3%E6%AD%B7%E5%8F%B2 "台灣歷史")上，早期以招募[志願](/wiki/%E5%BF%97%E9%A1%98%E5%BD%B9 "志願役")從軍為主，[徵兵制度](/wiki/%E5%BE%B5%E5%85%B5%E5%88%B6 "徵兵制")始見於1945年1月[日本統治](/wiki/%E5%8F%B0%E7%81%A3%E6%97%A5%E6%B2%BB%E6%99%82%E6%9C%9F "台灣日治時期")末期，為[第二次世界大战](/wiki/%E7%AC%AC%E4%BA%8C%E6%AC%A1%E4%B8%96%E7%95%8C%E5%A4%A7%E6%88%98 "第二次世界大战")戰場之人力需求而產生[[1]](#cite_note-1)。二戰後台灣進入[中華民國時代](/wiki/%E8%87%BA%E7%81%A3%E6%88%B0%E5%BE%8C%E6%99%82%E6%9C%9F "臺灣戰後時期")，由於[第二次國共内战](/wiki/%E7%AC%AC%E4%BA%8C%E6%AC%A1%E5%9B%BD%E5%85%B1%E5%86%85%E6%88%98 "第二次国共内战")失利，[中華民國政府](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E6%94%BF%E5%BA%9C "中華民國政府")自1949年12月起在臺灣實施徵兵制度。1949年至1987年，[陸軍](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E9%99%B8%E8%BB%8D "中華民國陸軍")服役2年，[海](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E6%B5%B7%E8%BB%8D "中華民國海軍")[空軍](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E7%A9%BA%E8%BB%8D "中華民國空軍")3年，1967年新增[陸一特](/wiki/%E9%99%B8%E8%BB%8D%E7%AC%AC%E4%B8%80%E7%89%B9%E7%A8%AE%E5%85%B5 "陸軍第一特種兵")3年。1987年至1990年6月，陸海空軍服役2年，[海陸](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E6%B5%B7%E8%BB%8D%E9%99%B8%E6%88%B0%E9%9A%8A "中華民國海軍陸戰隊")3年並廢止陸一特。1990年7月起，不分軍種一律服役2年。2000年1月，役期減為1年10個月，爾後逐年遞減，至2008年1月，役期減至1年[[2]](#cite_note-義務役期沿革-2)。

2013年2月起，於1994年1月1日起出生者只須接受4個月軍事訓練即完成服役義務。至2018年12月末代1年制義務役士兵退伍後，2019年起開始採行「募徵併行」制[[3]](#cite_note-3)。

2024年1月起，於2005年1月1日起出生者[恢復服1年常備兵役](/wiki/%E5%BC%B7%E5%8C%96%E5%85%A8%E6%B0%91%E5%9C%8B%E9%98%B2%E5%85%B5%E5%8A%9B%E7%B5%90%E6%A7%8B%E8%AA%BF%E6%95%B4%E6%96%B9%E6%A1%88 "強化全民國防兵力結構調整方案") [[4]](#cite_note-4)[[5]](#cite_note-5)，1994年至2004年間出生者仍維持接受4個月常備兵役軍事訓練。

### 早期

[[编辑](/w/index.php?title=%E8%87%BA%E7%81%A3%E5%85%B5%E5%BD%B9%E5%88%B6%E5%BA%A6&action=edit&section=2 "编辑章节：早期")]

* 在[荷蘭](/wiki/%E8%87%BA%E7%81%A3%E8%8D%B7%E8%98%AD%E7%B5%B1%E6%B2%BB%E6%99%82%E6%9C%9F "臺灣荷蘭統治時期")以及[西班牙](/wiki/%E8%87%BA%E7%81%A3%E8%A5%BF%E7%8F%AD%E7%89%99%E7%B5%B1%E6%B2%BB%E6%99%82%E6%9C%9F "臺灣西班牙統治時期")殖民時期（1624年－1662年），殖民者都曾向[原住民](/wiki/%E8%87%BA%E7%81%A3%E5%8E%9F%E4%BD%8F%E6%B0%91%E6%97%8F "臺灣原住民族")[平埔族](/wiki/%E5%B9%B3%E5%9F%94%E6%97%8F%E7%BE%A4 "平埔族群")募集傭兵、勇士數百人。
* 在[明鄭時期](/wiki/%E8%87%BA%E7%81%A3%E6%98%8E%E9%84%AD%E6%99%82%E6%9C%9F "臺灣明鄭時期")（1661年－1683年），[東寧](/wiki/%E6%9D%B1%E5%AF%A7_(%E8%87%BA%E7%81%A3%E5%8F%A4%E5%90%8D) "東寧 (臺灣古名)")政府，徵兵制度尚不明確。
* 在[大清帝國統治時期](/wiki/%E8%87%BA%E7%81%A3%E6%B8%85%E6%B2%BB%E6%99%82%E6%9C%9F "臺灣清治時期")（1683年－1895年），有[大清帝國正規軍](/wiki/%E6%B8%85%E5%86%9B "清军")（[綠營](/wiki/%E7%B6%A0%E7%87%9F_(%E6%B8%85%E6%9C%9D) "綠營 (清朝)")、廣勇、[黑旗軍](/wiki/%E9%BB%91%E6%97%97%E8%BB%8D "黑旗軍")、新楚軍、滬軍、[淮軍](/wiki/%E6%B7%AE%E8%BB%8D "淮軍")、台勇等等）駐紮。
* 在[臺灣民主國](/wiki/%E8%87%BA%E7%81%A3%E6%B0%91%E4%B8%BB%E5%9C%8B "臺灣民主國")時期（1895年），有殘存的前[大清帝國正規軍](/wiki/%E6%B8%85%E5%86%9B "清军")、未經訓練的台勇（民主國正規軍）、無民主國番號的義軍（如十八堡軍、[六堆軍](/wiki/%E7%BE%A9%E8%BB%8D_(%E8%87%BA%E7%81%A3%E5%AE%A2%E5%AE%B6%E4%BA%BA) "義軍 (臺灣客家人)")、各地民防團練等）。

主条目：[台灣日治時期](/wiki/%E5%8F%B0%E7%81%A3%E6%97%A5%E6%B2%BB%E6%99%82%E6%9C%9F "台灣日治時期")和[護鄉兵](/wiki/%E8%AD%B7%E9%84%89%E5%85%B5 "護鄉兵")

1895年，[大清帝國](/wiki/%E6%B8%85%E6%9C%9D "清朝")與[大日本帝國](/wiki/%E5%A4%A7%E6%97%A5%E6%9C%AC%E5%B8%9D%E5%9B%BD "大日本帝国")簽訂《[馬關條約](/wiki/%E9%A9%AC%E5%85%B3%E6%9D%A1%E7%BA%A6 "马关条约")》（下関条約），[臺灣島](/wiki/%E8%87%BA%E7%81%A3 "臺灣")、[澎湖群島](/wiki/%E6%BE%8E%E6%B9%96%E7%BE%A4%E5%B3%B6 "澎湖群島")與相關島嶼改隸日本。但在[日本統治](/wiki/%E5%8F%B0%E7%81%A3%E6%97%A5%E6%B2%BB%E6%99%82%E6%9C%9F "台灣日治時期")初期[臺灣人](/wiki/%E8%87%BA%E7%81%A3%E4%BA%BA "臺灣人")發起了許多[反日起事](/wiki/%E5%8F%B0%E7%81%A3%E6%8A%97%E6%97%A5%E9%81%8B%E5%8B%95 "台灣抗日運動")，此時期[臺灣總督府](/wiki/%E8%87%BA%E7%81%A3%E7%B8%BD%E7%9D%A3%E5%BA%9C "臺灣總督府")曾經徵募本島人，以加強統治初期不穩定的治安，也用來加強鎮壓反抗勢力。

* 1897年11月，時任[臺灣總督](/wiki/%E8%87%BA%E7%81%A3%E7%B8%BD%E7%9D%A3 "臺灣總督")[乃木希典](/wiki/%E4%B9%83%E6%9C%A8%E5%B8%8C%E5%85%B8 "乃木希典")，開始徵募本島人（主要為[原住民](/wiki/%E8%87%BA%E7%81%A3%E5%8E%9F%E4%BD%8F%E6%B0%91%E6%97%8F "臺灣原住民族")）擔任「[護鄉兵](/wiki/%E8%AD%B7%E9%84%89%E5%85%B5 "護鄉兵")」[[6]](#cite_note-6)。
* 1898年5月，[兒玉源太郎](/wiki/%E5%85%92%E7%8E%89%E6%BA%90%E5%A4%AA%E9%83%8E "兒玉源太郎")成為台灣總督後，5月頒布勅令將護鄉兵改制為「軍役壯丁」。10月後將軍役壯丁廢止，改為「軍役志願制度」。並以漢人為主要募集對象。平時作軍中勞役工作，比起護鄉兵，較少進行戰鬥訓練。

主条目：[中国抗日战争](/wiki/%E4%B8%AD%E5%9B%BD%E6%8A%97%E6%97%A5%E6%88%98%E4%BA%89 "中国抗日战争")、[大东亚战争](/wiki/%E5%A4%A7%E4%B8%9C%E4%BA%9A%E6%88%98%E4%BA%89 "大东亚战争")、[太平洋战争](/wiki/%E5%A4%AA%E5%B9%B3%E6%B4%8B%E6%88%98%E4%BA%89 "太平洋战争")、[第二次世界大战](/wiki/%E7%AC%AC%E4%BA%8C%E6%AC%A1%E4%B8%96%E7%95%8C%E5%A4%A7%E6%88%98 "第二次世界大战")和[台籍日本兵](/wiki/%E5%8F%B0%E7%B1%8D%E6%97%A5%E6%9C%AC%E5%85%B5 "台籍日本兵")

[![](//thumb.wikimedia.org/wikipedia/commons/thumb/3/39/%E8%87%BA%E7%B1%8D%E6%97%A5%E6%9C%AC%E5%85%B5%E5%87%BA%E5%BE%81%E5%89%8D_Drafted_Taiwanese_soldiers_during_World_War_II.jpg/500px-%E8%87%BA%E7%B1%8D%E6%97%A5%E6%9C%AC%E5%85%B5%E5%87%BA%E5%BE%81%E5%89%8D_Drafted_Taiwanese_soldiers_during_World_War_II.jpg?utm_source=zh.wikipedia.org&utm_campaign=parser&utm_content=thumbnail)](/wiki/File:%E8%87%BA%E7%B1%8D%E6%97%A5%E6%9C%AC%E5%85%B5%E5%87%BA%E5%BE%81%E5%89%8D_Drafted_Taiwanese_soldiers_during_World_War_II.jpg)

[臺籍日本兵](/wiki/%E5%8F%B0%E7%B1%8D%E6%97%A5%E6%9C%AC%E5%85%B5 "台籍日本兵")出征前

在[二十世紀](/wiki/20%E4%B8%96%E7%BA%AA "20世纪")初期，[大日本帝國](/wiki/%E5%A4%A7%E6%97%A5%E6%9C%AC%E5%B8%9D%E5%9B%BD "大日本帝国")繼續奉行其[大陸政策](/wiki/%E5%A4%A7%E9%99%86%E6%94%BF%E7%AD%96_(%E5%A4%A7%E6%97%A5%E6%9C%AC%E5%B8%9D%E5%9B%BD) "大陆政策 (大日本帝国)")，對[中華民國](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E5%A4%A7%E9%99%B8%E6%99%82%E6%9C%9F "中華民國大陸時期")進行勢力擴張。1937年[第二次中日戰爭](/wiki/%E4%B8%AD%E5%9B%BD%E6%8A%97%E6%97%A5%E6%88%98%E4%BA%89 "中国抗日战争")全面爆發，隨後[大東亞戰爭](/wiki/%E5%A4%A7%E4%B8%9C%E4%BA%9A%E6%88%98%E4%BA%89 "大东亚战争")期間日本加入[軸心國](/wiki/%E8%BD%B4%E5%BF%83%E5%9B%BD "轴心国")參與[第二次世界大戰](/wiki/%E7%AC%AC%E4%BA%8C%E6%AC%A1%E4%B8%96%E7%95%8C%E5%A4%A7%E6%88%98 "第二次世界大战")。在戰爭背景之下，[臺灣總督府](/wiki/%E8%87%BA%E7%81%A3%E7%B8%BD%E7%9D%A3%E5%BA%9C "臺灣總督府")在實施募兵與徵兵以補充[日軍](/wiki/%E6%97%A5%E6%9C%AC%E5%86%9B "日本军")之人力需求。

* 1937年7月，爆發[七七盧溝橋事變](/wiki/%E4%B8%83%E4%B8%83%E4%BA%8B%E5%8F%98 "七七事变")，[第二次中日戰爭](/wiki/%E4%B8%AD%E5%9B%BD%E6%8A%97%E6%97%A5%E6%88%98%E4%BA%89 "中国抗日战争")全面打響。
* 1937年秋，開始動員徵用「軍屬」以擔負軍中雜役，也被徵調為翻譯人員，經訓練後負責[閩語](/wiki/%E9%96%A9%E8%AA%9E "閩語")、[客語](/wiki/%E5%AE%A2%E5%AE%B6%E8%A9%B1 "客家話")、[粵語](/wiki/%E7%B2%A4%E8%AF%AD "粤语")與[北京官話](/wiki/%E5%8C%97%E4%BA%AC%E5%AE%98%E8%AF%9D "北京官话")等[中國語言](/wiki/%E4%B8%AD%E5%9C%8B%E8%AA%9E%E8%A8%80 "中國語言")事務。
* 1941年12月，[珍珠港事件](/wiki/%E7%8F%8D%E7%8F%A0%E6%B8%AF%E4%BA%8B%E4%BB%B6 "珍珠港事件")後，[太平洋戰爭](/wiki/%E5%A4%AA%E5%B9%B3%E6%B4%8B%E6%88%B0%E7%88%AD "太平洋戰爭")爆發。
* 1942年初，開始招募志願原住民參戰，後通稱「[高砂義勇隊](/wiki/%E9%AB%98%E7%A0%82%E7%BE%A9%E5%8B%87%E9%9A%8A "高砂義勇隊")」，總數約5,000人，戰死超過4,000人。
* 1942年4月，開始實施與[朝鮮](/wiki/%E6%9C%9D%E9%AE%AE%E6%97%A5%E6%B2%BB%E6%99%82%E6%9C%9F "朝鮮日治時期")同性質的「[陸軍特別志願兵制度](/wiki/%E9%99%B8%E8%BB%8D%E7%89%B9%E5%88%A5%E5%BF%97%E9%A1%98%E5%85%B5%E5%88%B6%E5%BA%A6 "陸軍特別志願兵制度")」，募得總數約16,000人。
* 1943年8月，開始實施「[海軍特別志願兵制度](/wiki/%E6%B5%B7%E8%BB%8D%E7%89%B9%E5%88%A5%E5%BF%97%E9%A1%98%E5%85%B5%E5%88%B6%E5%BA%A6 "海軍特別志願兵制度")」。
* 1944年12月起全面實施徵兵制度[[7]](#cite_note-7)。

總計[第二次世界大戰](/wiki/%E7%AC%AC%E4%BA%8C%E6%AC%A1%E4%B8%96%E7%95%8C%E5%A4%A7%E6%88%98 "第二次世界大战")期間[台籍日本兵](/wiki/%E5%8F%B0%E7%B1%8D%E6%97%A5%E6%9C%AC%E5%85%B5 "台籍日本兵")人數共207,183名，其中軍人80,433人、軍屬126,750人，戰死約30,304人。

### 戰後時期與中華民國政府遷台

[[编辑](/w/index.php?title=%E8%87%BA%E7%81%A3%E5%85%B5%E5%BD%B9%E5%88%B6%E5%BA%A6&action=edit&section=4 "编辑章节：戰後時期與中華民國政府遷台")]

参见：[冷战](/wiki/%E5%86%B7%E6%88%98 "冷战")和[海峽兩岸關係](/wiki/%E6%B5%B7%E5%B3%BD%E5%85%A9%E5%B2%B8%E9%97%9C%E4%BF%82 "海峽兩岸關係")

[![](//thumb.wikimedia.org/wikipedia/commons/thumb/e/e2/Military_parade_in_front_of_Chiang_Kai-shek_Memorial_Hall.jpg/500px-Military_parade_in_front_of_Chiang_Kai-shek_Memorial_Hall.jpg?utm_source=zh.wikipedia.org&utm_campaign=parser&utm_content=thumbnail)](/wiki/File:Military_parade_in_front_of_Chiang_Kai-shek_Memorial_Hall.jpg)

[中華民國三軍儀隊](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E4%B8%89%E8%BB%8D%E5%84%80%E9%9A%8A "中華民國三軍儀隊")於[中正紀念堂](/wiki/%E4%B8%AD%E6%AD%A3%E7%B4%80%E5%BF%B5%E5%A0%82 "中正紀念堂")進行[操槍](/wiki/%E8%8A%B1%E5%BC%8F%E6%93%8D%E6%9E%AA "花式操枪")表演

1945年8月，[大日本帝國](/wiki/%E5%A4%A7%E6%97%A5%E6%9C%AC%E5%B8%9D%E5%9B%BD "大日本帝国")宣布向[同盟國](/wiki/%E5%90%8C%E7%9B%9F%E5%9C%8B_(%E7%AC%AC%E4%BA%8C%E6%AC%A1%E4%B8%96%E7%95%8C%E5%A4%A7%E6%88%B0) "同盟國 (第二次世界大戰)")[無條件投降](/wiki/%E7%84%A1%E6%A2%9D%E4%BB%B6%E6%8A%95%E9%99%8D "無條件投降")，[第二次世界大战](/wiki/%E7%AC%AC%E4%BA%8C%E6%AC%A1%E4%B8%96%E7%95%8C%E5%A4%A7%E6%88%98 "第二次世界大战")結束，[中華民國](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B "中華民國")代表盟軍佔領[臺灣](/wiki/%E8%87%BA%E7%81%A3 "臺灣")。1949年12月，由於[第二次国共内战](/wiki/%E7%AC%AC%E4%BA%8C%E6%AC%A1%E5%9B%BD%E5%85%B1%E5%86%85%E6%88%98 "第二次国共内战")失利，[中華民國政府遷台](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E6%94%BF%E5%BA%9C%E9%81%B7%E5%8F%B0 "中華民國政府遷台")。進入1950年代後戰事漸歇，[中國國民黨](/wiki/%E4%B8%AD%E5%9C%8B%E5%9C%8B%E6%B0%91%E9%BB%A8 "中國國民黨")領導的中華民國政府與[中国共产党](/wiki/%E4%B8%AD%E5%9B%BD%E5%85%B1%E4%BA%A7%E5%85%9A "中国共产党")領導的[中華人民共和國政府](/wiki/%E4%B8%AD%E8%8F%AF%E4%BA%BA%E6%B0%91%E5%85%B1%E5%92%8C%E5%9C%8B%E6%94%BF%E5%BA%9C "中華人民共和國政府")隔[台灣海峽](/wiki/%E5%8F%B0%E7%81%A3%E6%B5%B7%E5%B3%BD "台灣海峽")[兩岸分治](/wiki/%E8%87%BA%E6%B5%B7%E7%8F%BE%E7%8B%80 "臺海現狀")的格局型成。

* 1949年12月，中華民國政府遷臺後，在臺灣實施徵兵制以防止[中华人民共和国](/wiki/%E4%B8%AD%E5%8D%8E%E4%BA%BA%E6%B0%91%E5%85%B1%E5%92%8C%E5%9B%BD "中华人民共和国")進攻臺灣。
* 1954年，《[兵役法](https://zh.wikisource.org/wiki/%E5%85%B5%E5%BD%B9%E6%B3%95_(%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B) "s:兵役法 (中華民國)")》大幅修正，明訂軍官役與士官役的詳細規定，新增「預備軍官役」以及「預備士官役」等役別；建立[預備軍士官考選制度](/wiki/%E5%A4%A7%E5%B0%88%E7%A8%8B%E5%BA%A6%E7%BE%A9%E5%8B%99%E5%BD%B9%E9%A0%90%E5%82%99%E8%BB%8D%E5%A3%AB%E5%AE%98%E8%80%83%E8%A9%A6 "大專程度義務役預備軍士官考試")；並明訂義務兵役役期[陸軍](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E9%99%B8%E8%BB%8D "中華民國陸軍")為2年，[海軍](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E6%B5%B7%E8%BB%8D "中華民國海軍")[空軍](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E7%A9%BA%E8%BB%8D "中華民國空軍")為3年[[8]](#cite_note-8)。
* 1956年，頒布《[徵兵規則](/wiki/%E5%BE%B5%E5%85%B5%E8%A6%8F%E5%89%87_(%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B) "徵兵規則 (中華民國)")》，開始徵集第1梯次常備兵役現役入營。
* 1967年至1986年間，[中華民國政府](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E6%94%BF%E5%BA%9C "中華民國政府")進行「[國光計畫](/wiki/%E5%9C%8B%E5%85%89%E8%A8%88%E7%95%AB "國光計畫")」準備[反攻大陸](/wiki/%E5%8F%8D%E6%94%BB%E5%A4%A7%E9%99%B8 "反攻大陸")，實施[陸軍第一特種兵](/wiki/%E9%99%B8%E8%BB%8D%E7%AC%AC%E4%B8%80%E7%89%B9%E7%A8%AE%E5%85%B5 "陸軍第一特種兵")（陸一特）制度。陸軍將裝甲兵、通信兵、砲兵、工兵、兵工等5個兵科列為第一特種兵。該等兵科之義務役男在服完當時《兵役法》所規定之陸軍2年役期後，再以行政命令於其退伍同時另發為期1年的臨時召集令，實際役期成為3年[[2]](#cite_note-義務役期沿革-2)。
* 1987年，[陸軍第一特種兵](/wiki/%E9%99%B8%E8%BB%8D%E7%AC%AC%E4%B8%80%E7%89%B9%E7%A8%AE%E5%85%B5 "陸軍第一特種兵")廢止，且義務役役期陸軍、海軍、空軍皆縮短為2年、唯[海軍陸戰隊](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E6%B5%B7%E8%BB%8D%E9%99%B8%E6%88%B0%E9%9A%8A "中華民國海軍陸戰隊")維持3年役期[[2]](#cite_note-義務役期沿革-2)。

### 臺灣民主化

[[编辑](/w/index.php?title=%E8%87%BA%E7%81%A3%E5%85%B5%E5%BD%B9%E5%88%B6%E5%BA%A6&action=edit&section=5 "编辑章节：臺灣民主化")]

主条目：[臺灣民主化](/wiki/%E8%87%BA%E7%81%A3%E6%B0%91%E4%B8%BB%E5%8C%96 "臺灣民主化")

1990年臺灣經歷[野百合學運](/wiki/%E9%87%8E%E7%99%BE%E5%90%88%E5%AD%B8%E9%81%8B "野百合學運")後開始[民主化](/wiki/%E8%87%BA%E7%81%A3%E6%B0%91%E4%B8%BB%E5%8C%96 "臺灣民主化")，早年為[反攻大陸](/wiki/%E5%8F%8D%E6%94%BB%E5%A4%A7%E9%99%B8 "反攻大陸")而設計的兵役制度與建軍思維也開始遭到檢討。當時[國軍](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E5%9C%8B%E8%BB%8D "中華民國國軍")士兵仍然以義務役役男為多數、軍士官則多是志願役服役人員。政府打算逐步擴大募兵制，最終目標是形成一個全志願役的國家防衛軍隊。另外，也借由役期縮短與開辦替代役以從軍隊中釋放人員與勞動力，補足政府機關、科研單位、企業單位之部份人力上的不足。

* 1990年7月1日，義務役役期不分軍種，服役時間統一為兩年[[2]](#cite_note-義務役期沿革-2)。
* 1999年7月1日起，軍訓成績可折抵義務役役期，高中職畢業可折抵14天，大專畢業可折抵28天[[2]](#cite_note-義務役期沿革-2)。
* 1999年起，辦理「國防工業訓儲預備軍官預備士官甄選」，又稱「[國防役](/wiki/%E5%9C%8B%E9%98%B2%E5%BD%B9 "國防役")」，讓部份高學歷役男可以在相關產業之機關或公司服務的方式服役。
* 2000年，《[兵役法](https://zh.wikisource.org/wiki/%E5%85%B5%E5%BD%B9%E6%B3%95_(%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B) "s:兵役法 (中華民國)")》再度大幅修正，廢除士兵役中之「國民兵役」並加入「[替代役](/wiki/%E6%9B%BF%E4%BB%A3%E5%BD%B9_(%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B) "替代役 (中華民國)")」制度。
* 2000年1月1日起，實施義務役役期縮短為1年10個月[[2]](#cite_note-義務役期沿革-2)。
* 2000年8月1日起，首次徵集[替代役](/wiki/%E6%9B%BF%E4%BB%A3%E5%BD%B9_(%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B) "替代役 (中華民國)")[[2]](#cite_note-義務役期沿革-2)。
* 2004年1月1日起，實施義務役役期縮短為1年8個月[[9]](#cite_note-9)
* 2005年7月1日起，實施義務役役期縮短為1年6個月[[10]](#cite_note-10)。
* 2006年1月1日起，實施義務役役期縮短為1年4個月[[11]](#cite_note-11)[[12]](#cite_note-12)
* 2007年7月1日起，實施義務役役期縮短為1年2個月[[13]](#cite_note-13)，已經擴大實施志願役兵役招募制度。
* 2008年1月1日起，實施義務役役期縮短為1年[[14]](#cite_note-14)，持續擴大實施志願役兵役招募制度。[[15]](#cite_note-15)
* 2008年起，部份高學歷役男得在相關產業之機關或公司服務的方式服役的制度（[國防役](/wiki/%E5%9C%8B%E9%98%B2%E5%BD%B9 "國防役")）由[內政部役政署](/wiki/%E5%85%A7%E6%94%BF%E9%83%A8%E5%BD%B9%E6%94%BF%E7%BD%B2 "內政部役政署")接手辦理，改稱「[研發替代役](/wiki/%E7%A0%94%E7%99%BC%E6%9B%BF%E4%BB%A3%E5%BD%B9 "研發替代役")」。

### 募徵併行

[[编辑](/w/index.php?title=%E8%87%BA%E7%81%A3%E5%85%B5%E5%BD%B9%E5%88%B6%E5%BA%A6&action=edit&section=6 "编辑章节：募徵併行")]

主条目：[中華民國募兵制](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E5%8B%9F%E5%85%B5%E5%88%B6 "中華民國募兵制")和[志願役與義務役併用制](/wiki/%E5%BF%97%E9%A1%98%E5%BD%B9%E8%88%87%E7%BE%A9%E5%8B%99%E5%BD%B9%E4%BD%B5%E7%94%A8%E5%88%B6 "志願役與義務役併用制")

2008年[馬英九](/wiki/%E9%A6%AC%E8%8B%B1%E4%B9%9D "馬英九")就任[總統](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E7%B8%BD%E7%B5%B1 "中華民國總統")後，進一步推動[全募兵制](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E5%8B%9F%E5%85%B5%E5%88%B6 "中華民國募兵制")之軍隊改革。2009年3月10日，時任[國防部部長](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E5%9C%8B%E9%98%B2%E9%83%A8%E9%83%A8%E9%95%B7 "中華民國國防部部長")[陳肇敏](/wiki/%E9%99%B3%E8%82%87%E6%95%8F "陳肇敏")表示2014年底，會有一支全[志願役](/wiki/%E5%BF%97%E9%A1%98%E5%BD%B9 "志願役")的[國軍](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E5%9C%8B%E8%BB%8D "中華民國國軍")部隊。[[16]](#cite_note-16)。從2010年開始廢除徵兵制的過程中，由2014年底的全志願役部隊完全取代之。個人希望加入志願役士兵的人，必須有高中畢業之最低學歷；以及沒有加入志願役的役男必須完成4個月的「軍事訓練役」[[17]](#cite_note-17)。據2012年報導，從2013年開始，1994年1月1日後出生的役男只需要接受4個月的[軍事訓練](/wiki/%E5%86%9B%E4%BA%8B%E8%AE%AD%E7%BB%83 "军事训练")，將不再需服一年期的義務兵役，而且政府與國防部也在2016年年底全部更換為志願役部隊[[18]](#cite_note-18)。這個政策保持不變，中華民國將有一個純粹志願役的專業化國軍部隊，但仍然將徵召每一位達到役齡的男性並接受三至四個月的軍事訓練，以符合[中華民國憲法](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E6%86%B2%E6%B3%95 "中華民國憲法")規定。

* 2011年，修訂《[兵役法](https://zh.wikisource.org/wiki/%E5%85%B5%E5%BD%B9%E6%B3%95_(%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B) "s:兵役法 (中華民國)")》，在士兵役常備兵役中加入「軍事訓練」制度。
* 2013年12月起，在1994年1月1日及以後出生之役男僅須接受4個月軍事訓練役（8週新訓、8週下部隊）；1993年12月31日及以前出生之役男仍須服役1年。
* 2015年，[內政部役政署](/wiki/%E5%85%A7%E6%94%BF%E9%83%A8%E5%BD%B9%E6%94%BF%E7%BD%B2 "內政部役政署")實施納入更多產業類別的「[產業訓儲替代役](/wiki/%E7%94%A2%E6%A5%AD%E8%A8%93%E5%84%B2%E6%9B%BF%E4%BB%A3%E5%BD%B9 "產業訓儲替代役")」制度[[19]](#cite_note-19)。
* 2017年12月，末代義務役士兵入伍，海軍第735梯次（23日，39人）、陸軍第2225梯次（19日，299人）、空軍第892梯次（19日，33人）、海軍陸戰隊第811梯次（26日，41人）。
* 2018年1月1日起，非志願役而達到役齡的常備役男性則改服4個月軍事訓練役（訓期改前5週新兵基本訓，後11週初級至中級專長訓，無須下部隊，仍會抽籤分配至外島受訓）[[20]](#cite_note-20)。
* 2018年起，配合募兵制政策，[國防部](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E5%9C%8B%E9%98%B2%E9%83%A8 "中華民國國防部")之[義務役預備軍士官考選](/wiki/%E5%A4%A7%E5%B0%88%E7%A8%8B%E5%BA%A6%E7%BE%A9%E5%8B%99%E5%BD%B9%E9%A0%90%E5%82%99%E8%BB%8D%E5%A3%AB%E5%AE%98%E8%80%83%E8%A9%A6 "大專程度義務役預備軍士官考試")以及[內政部役政署](/wiki/%E5%85%A7%E6%94%BF%E9%83%A8%E5%BD%B9%E6%94%BF%E7%BD%B2 "內政部役政署")之[產業訓儲替代役](/wiki/%E7%94%A2%E6%A5%AD%E8%A8%93%E5%84%B2%E6%9B%BF%E4%BB%A3%E5%BD%B9 "產業訓儲替代役")等制度停辦。
* 2018年12月，末代義務役士兵各梯次全面退伍。1993年次以前出生、尚未服役的役男，全面轉服1年的替代役[[21]](#cite_note-21)[[22]](#cite_note-22)。

自2018年12月底起，正式進入「募徵併行」時代，所有[中華民國國軍](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E5%9C%8B%E8%BB%8D "中華民國國軍")部隊之現役軍官、士官、士兵均由招募而來的[志願役](/wiki/%E5%BF%97%E9%A1%98%E5%BD%B9 "志願役")組成；經由徵集而來的合格義務役男則在完成軍事訓練後返回民間，不進入[中華民國國軍](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E5%9C%8B%E8%BB%8D "中華民國國軍")部隊服役。

至2019年全面實施軍事訓練前，

* 常備兵役自1956年1月起開辦至2017年12月，共辦理陸軍2225梯次、海軍735梯次、海軍陸戰隊811梯次、空軍892梯次之入營，末梯於2018年底前退伍。
* [義務役預備軍士官](/wiki/%E5%A4%A7%E5%B0%88%E7%A8%8B%E5%BA%A6%E7%BE%A9%E5%8B%99%E5%BD%B9%E9%A0%90%E5%82%99%E8%BB%8D%E5%A3%AB%E5%AE%98%E8%80%83%E8%A9%A6 "大專程度義務役預備軍士官考試")自1952年起開辦至2017年，共辦理67期之考選與訓練，末期於2018年底前退伍。

### 恢復徵兵

[[编辑](/w/index.php?title=%E8%87%BA%E7%81%A3%E5%85%B5%E5%BD%B9%E5%88%B6%E5%BA%A6&action=edit&section=7 "编辑章节：恢復徵兵")]

参见：[第二次冷战](/wiki/%E7%AC%AC%E4%BA%8C%E6%AC%A1%E5%86%B7%E6%88%98 "第二次冷战")、[中美关系](/wiki/%E4%B8%AD%E7%BE%8E%E5%85%B3%E7%B3%BB "中美关系")、[海峽兩岸關係](/wiki/%E6%B5%B7%E5%B3%BD%E5%85%A9%E5%B2%B8%E9%97%9C%E4%BF%82 "海峽兩岸關係")和[強化全民國防兵力結構調整方案](/wiki/%E5%BC%B7%E5%8C%96%E5%85%A8%E6%B0%91%E5%9C%8B%E9%98%B2%E5%85%B5%E5%8A%9B%E7%B5%90%E6%A7%8B%E8%AA%BF%E6%95%B4%E6%96%B9%E6%A1%88 "強化全民國防兵力結構調整方案")

2017年以來，[中美關係](/wiki/%E4%B8%AD%E7%BE%8E%E5%85%B3%E7%B3%BB "中美关系")由合作轉為對抗，懸而未決的[臺灣問題](/wiki/%E8%87%BA%E7%81%A3%E5%95%8F%E9%A1%8C "臺灣問題")成為中國與美國之間的焦點。國際上也擔心，中共會打破1950年代以來的[臺海現狀](/wiki/%E8%87%BA%E6%B5%B7%E7%8F%BE%E7%8B%80 "臺海現狀")，對臺灣進行軍事威脅而再次出現[臺灣海峽危機](/wiki/%E8%87%BA%E7%81%A3%E6%B5%B7%E5%B3%BD%E5%8D%B1%E6%A9%9F "臺灣海峽危機")，2022年2月[俄羅斯入侵烏克蘭](/wiki/%E4%BF%84%E7%BE%85%E6%96%AF%E5%85%A5%E4%BE%B5%E7%83%8F%E5%85%8B%E8%98%AD "俄羅斯入侵烏克蘭")，再次引起[軍事激烈對抗](/wiki/%E8%A7%A3%E6%94%BE%E5%8F%B0%E6%B9%BE "解放台湾")有可能成為現實的關注。

* 2022年12月27日，[總統](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E7%B8%BD%E7%B5%B1 "中華民國總統")[蔡英文](/wiki/%E8%94%A1%E8%8B%B1%E6%96%87 "蔡英文")召開國安會議將義務役從現行的4個月改為1年，義務役士兵每月薪資由約6,500元調升至2萬6,307元新台幣。[[23]](#cite_note-23)[[24]](#cite_note-24)[[25]](#cite_note-25)
* 2024年1月1日起恢復[常備兵役徵集](/wiki/%E5%BC%B7%E5%8C%96%E5%85%A8%E6%B0%91%E5%9C%8B%E9%98%B2%E5%85%B5%E5%8A%9B%E7%B5%90%E6%A7%8B%E8%AA%BF%E6%95%B4%E6%96%B9%E6%A1%88 "強化全民國防兵力結構調整方案")，役期1年，對2005年1月1日起出生者適用。

* 屆時梯次編號延續2018年底的梯次，將由陸軍2226梯、海軍艦艇兵736梯、海軍陸戰隊812梯、空軍893梯起算[[26]](#cite_note-26)。

2024年[中華民國](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B "中華民國")恢復徵兵制後，再度成為實施徵兵制度的[已開發國家](/wiki/%E5%B7%B2%E9%96%8B%E7%99%BC%E5%9C%8B%E5%AE%B6 "已開發國家")。

## 法源依據

[[编辑](/w/index.php?title=%E8%87%BA%E7%81%A3%E5%85%B5%E5%BD%B9%E5%88%B6%E5%BA%A6&action=edit&section=8 "编辑章节：法源依據")]

目前臺灣兵役制度源自1947年《[中華民國憲法](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E6%86%B2%E6%B3%95 "中華民國憲法")》第二十條「人民有依法律服兵役之義務」，並以《[兵役法](https://zh.wikisource.org/wiki/%E5%85%B5%E5%BD%B9%E6%B3%95_(%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B) "s:兵役法 (中華民國)")》、《[兵役法施行法](https://zh.wikisource.org/wiki/%E5%85%B5%E5%BD%B9%E6%B3%95%E6%96%BD%E8%A1%8C%E6%B3%95 "s:兵役法施行法")》以及其他相關條例做為依據。[[27]](#cite_note-27)《兵役法》於1933年（民國22年）在[中華民國大陸時期](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E5%A4%A7%E9%99%B8%E6%99%82%E6%9C%9F "中華民國大陸時期")立法以來，隨著[行憲](/wiki/%E8%A1%8C%E6%86%B2 "行憲")、[政府遷臺](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E6%94%BF%E5%BA%9C%E9%81%B7%E5%8F%B0 "中華民國政府遷台")、以及[臺灣民主化](/wiki/%E8%87%BA%E7%81%A3%E6%B0%91%E4%B8%BB%E5%8C%96 "臺灣民主化")等國家重大事件經歷多次修正。現行的《兵役法》將兵役分為以下類別：

| 兵役 |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- |
| 軍官役 | 士官役 | 士兵役 | 替代役 |  |  |  |
| 常備軍官役 | 預備軍官役 | 常備士官役 | 預備士官役 | 常備兵役 | 補充兵役 |  |
| 現役 | 後備役 | 現役 | 後備役 | 現役 | 軍事訓練役 | 後備役 |

在相關法規中，兵役制度由[國防部](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E5%9C%8B%E9%98%B2%E9%83%A8 "中華民國國防部")以及[內政部](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E5%85%A7%E6%94%BF%E9%83%A8 "中華民國內政部")合作辦理。其中內政部設立[役政司](/wiki/%E5%85%A7%E6%94%BF%E9%83%A8%E5%BD%B9%E6%94%BF%E5%8F%B8 "內政部役政司")以及[替代役訓練及管理中心](/w/index.php?title=%E5%85%A7%E6%94%BF%E9%83%A8%E6%9B%BF%E4%BB%A3%E5%BD%B9%E8%A8%93%E7%B7%B4%E5%8F%8A%E7%AE%A1%E7%90%86%E4%B8%AD%E5%BF%83&action=edit&redlink=1 "內政部替代役訓練及管理中心（页面不存在）")專責處理兵役事務，並與戶政機關協同處理。

## 服役規定

[[编辑](/w/index.php?title=%E8%87%BA%E7%81%A3%E5%85%B5%E5%BD%B9%E5%88%B6%E5%BA%A6&action=edit&section=9 "编辑章节：服役規定")]

依照現行之法規，全國男性自滿18歲之翌年1月1日起稱為役齡男子，須要配合接受兵籍調查與相關健康檢查，並在除役年齡前完成兵役義務。除[志願役](/wiki/%E5%BF%97%E9%A1%98%E5%BD%B9 "志願役")之外，可用以下方式完成法定兵役義務。

**役別 / 內容**
