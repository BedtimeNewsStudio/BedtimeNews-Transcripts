|  |  |  | [新闻大观](https://www.chinanews.com/index.html) >>新闻报道<br> <br>**50年后可能不见黄河壶口瀑布**<br>* * *<br> 2000年8月12日 20:22 <br> <br>中新网北京8月12日消息：专家日前提出警告：如不进行综合治理，再过50年，黄河壶口瀑布将萎缩成不足10米的险滩。到那时，“飞黄”将是轻而易举的事。<br>北京晚报的一则消息说，今年以来壶口瀑布出现接近历史最低的罕见小水量。此外，由于河床两侧岩石剥落、崩塌，瀑布正以每年20厘米左右的速度萎缩。<br>壶口瀑布的萎缩还与地质作用有关。据山西省地质遗迹调查组专家提供的情况，由于壶口特殊的地质构造，河床两侧岩石易被侵蚀、剥落、崩塌，瀑布因之不断后退、萎缩。据史料记载，在最近的2700年间，这条瀑布已后退3000多米，宽度也缩小了七分之一。由于陡壁变缓，落差也在缩小，壶口瀑布渐失雷霆万钧之势。<br>[新闻大观](https://www.chinanews.com/index.html) >>新闻报道 |  |
