# 第9号：关于“利用海上火箭发射，做活海阳旅游产业”的提案答复

日期:2025-08-25阅读量:387

分享：

字号：
大中小

葛基军委员：

您提出的关于“利用海上火箭发射，做活海阳旅游产业”的提案收悉。现答复如下：

一、航天旅游发展现状与成效

1.航天观礼成为核心吸引力

东方航天港指控中心以商业海上火箭发射为牵引，借助海上火箭发射观礼活动与国内单一主题体量最大的航天科普体验馆单体项目运营，吸引全国航天迷和旅游群体目的地式前往我市，带动了文旅产业蓬勃发展。作为全国唯一海上发射观礼目的地，布局连理岛、河清岛、凤凰广场沙滩、航天科普馆四大观礼区，可容纳5万人观礼，将研学与科技体验深度融合，开发“火星任务”“星际航行”等60余项互动项目，联合多所中小学推出“红色文化+航天科技”研学套餐。

2.产业联动激活全域旅游

“航天+”业态创新，借力火箭发射节点，常态化开展海阳大秧歌公益演出，实现非遗与航天场景联动。打造精品研学线路，串联火箭总装厂房、卫星产业园及发射观礼点，增设主题雕塑、AR互动设施。

二、下一步打算

1.航天元素全域化建设

城市氛围营造方面，启动“航天主题城市更新计划”，在主干道设置航天路标、灯光装置及主题雕塑，连理岛观礼区配套建设航天文化墙和沉浸式声光电秀场。

2.产业链条深化与产品创新

做强研学与亲子市场，联合航天科技集团开发“火箭组装实践课”“卫星测控模拟”等课程，面向全国招募航天夏令营；推动科普馆申报“全国研学实践教育基地”。推出“观礼+民宿+采摘”组合产品，整合周边采摘园、特色民宿集群，打造2日游闭环体验。

3.强化产业招商

依托航空航天新的旅游资源，多个维度进行深化和拓展，持续提升并新增航天科技互动体验项目，计划招引VR、AR的体验型设备联营商；开发航空航天游乐设施，举办航天主题的音乐节等；开发航空航天主题酒店、民宿，打造独特的住宿体验；结合航空航天历史和文化，开发相关的文化旅游线路，打造航空航天工业游。通过灵活多样的招商形式、有效的市场运作，吸引有实力的投资公司和集团企业来海合作与开发，推动项目的洽谈落地，创树地方特色品牌，不断提高城市吸引力。

感谢您对我们工作的支持。

海阳市文化和旅游局
