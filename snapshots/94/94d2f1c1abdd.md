# 第一个计算机中文信息处理系统：“华光”激光照排系统

| **第一个计算机中文信息处理系统：“华光”激光照排系统** |  |  |  |  |  |  |  |  |  |  |  |  |

|  |  |  |  |  | --- | --- | --- |  |  | **成果简介**  1975年，当时还在北大当教员的王选用“参数表示规则笔画，轮廓表示不规则笔画”这种独一无二的方法，把几千兆的汉字字形信息，大大压缩后存进了只有几兆存储量的计算机，这是新中国在世界上首次把精密汉字存入了计算机。经过四年的连续攻关，1979年，王选团队用我国自主研发的汉字激光照相排版系统——“华光”激光照排系统，成功从计算机里输出了汉字。“华光”激光照排系统成为新中国第一个计算机中文信息处理系统，引起当代世界印刷界的惊叹，被誉为中国印刷技术的再次革命。  历史背景  四十多年前，我国的计算机还主要用于科学运算和国防尖端工程，系统里没有精密汉字。报纸、书刊主要用铅制的活字排版印刷，手工挑字、人工排版效率很低。为此，1974年8月，在周恩来总理的布置下，原四机部（电子工业部）、原一机部（机械工业部）、中国科学院、新华社等机构联合发起，设立了国家重点科技攻关项目“汉字信息处理系统工程”，简称“748工程”。“748工程”下设3个子项目，分别是汉字通信、汉字情报检索和汉字精密照排。  　　1975年，时年38岁、病休在家的王选，无意中从妻子陈堃銶嘴里听到了“748工程”这个字眼。缘于对其中“汉字精密照排系统”的强烈兴趣和对计算机技术会带给印刷行业有巨大价值和意义的革命的坚定认识，他义无反顾地踏上了这条改变他一生的研究道路。  创新历程  关于汉字精密照排究竟应该选择什么样的研究目标，采用什么样的技术路线，当时承担汉字精密照排项目研究的几个单位各有各的看法。在广泛研究分析了国际国内激光照排的发展趋势后，王选大胆提出跳过当时正在攻关的第二代、第三代照排机，直接研制当时尚无商品的第四代激光照排系统。这不仅需要有长远的目光，更重要的是冲破阻力的勇气和耐心。  　　激光照排技术，就是将文字通过计算机分解为点阵，然后控制激光在感光底片上扫描，用曝光点的点阵组成文字和图像。通俗一点来讲，实际上就是电子排版系统的简称。第四代激光照排系统的研制过程中的主要难关就在于汉字的信息量大。汉字的常用字在3000字以上，印刷用字体、字号又多，每种字体起码需要7000多字，这样印刷用汉字头数高达100万以上，汉字点阵对应的总储量将达200亿位！然而，当时科研条件十分简陋：国产计算机内存是磁心存储器，最大容量为64KB；没有硬盘，只有一个512KB的磁鼓和一条磁带。要想实现庞大的汉字字形信息的存储和输出，在许多人看来真是天方夜谭！  　　为了解决这一难点，让精密汉字进入计算机，王选决定使用“轮廓描述方法”描述汉字字形。为保证字形变大变小时的质量，他提出并实现了用“参数描述方法”控制字形变倍和变形时敏感部位的质量。这些方法达到了当时世界的最高水平。而西方在大约在十年后才开始采用类似的技术。经过8个月呕心沥血的奋斗，他就像一位魔术师那样，让庞大的汉字字模减少到1/500，扫清了研制汉字精密照排系统的最大障碍。不久，他又发明了汉字字形信息高速还原技术、不失真的文字变倍技术。  　　历经无数个日日夜夜的艰辛研发，王选的成果终于在白热化的国际竞争中脱颖而出。1979年7月27日，精密汉字照排系统的第一台样机调试完毕。科研人员用自已研制的照排系统，在极短的时间内，一次成版地输出一张由各种大小字体组成、版面布局复杂的八开报纸样纸，报头是“汉字信息处理”六个大字。这是首次用激光照排机输出的中文报纸版面，标志着第四代激光照排系统首先在中国诞生。  重大意义和深远影响  “华光”激光照排系统是由王选主持的一项伟大发明，是我国自主创新的典型代表。它的产业化和应用，淘汰了我国沿用数百年的铅字印刷。激光照排系统的研制过程经历了种种困难，包括国内和国外、技术和社会多方面的因素。王选凭着非凡的毅力和对创新的执著，带领研发团队，克服重重困难，使中文印刷业告别了“铅与火”，大步跨进“光与电”的时代。  　　随着研究工作的不断深入，“华光”激光照排系统日臻完善。1981年7月，我国第一台计算机激光汉字照排系统原理性样机“华光I型”通过国家计算机工业总局和教育部联合举行的部级鉴定，鉴定结论是“与国外照排机相比，在汉字信息压缩技术方面领先，激光输出精度和软件某些功能达到国际先进水平”。国内率先使用“华光”系统的是新华通讯社。1985年5月，《新华社新闻稿》首次采用“华光Ⅱ型计算机——激光汉字编排系统”获得成功。1987年，《经济日报》成为我国第一家试用“华光Ⅲ型机”的报纸，1988年，经济日报社印刷厂卖掉了全部铅字，成为世界上第一家彻底废除了中文铅字的印刷厂。使用“华光”系统，不仅提高了效率，改善了工人劳动环境，使印刷工人解除了铅粉中毒之虞，减轻了劳动强度，而且印刷工艺水平也得到空前提高，从版面编排到减少错误以至印刷效果都有了质的飞跃。后来“华光”系统不仅风靡全国，颠覆性改造了新中国的出版印刷行业，还出口到日本和欧美等发达国家。
