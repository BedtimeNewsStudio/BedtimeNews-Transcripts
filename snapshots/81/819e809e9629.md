# 海南党史百件大事|洋浦经济开发区的设立

洋浦半岛位于海南省西北部，面朝北部湾，三面环海。其自然禀赋最大的优势，深水近岸、避风少淤，能够建设大型港口。1987年10月，海南建省筹备组相关人员考察洋浦，设想在洋浦设立特别关税区，取得成功经验后，逐步在全岛推开，促进海南经济特区快速发展。

1988年，海南建省办经济特区，刚刚成立不久的海南省委、省政府谋划海南发展战略时，希望以洋浦开发作为特区建设的首要突破口。至此，洋浦开发成为建省之初海南扩大对外开放的头号工程。

1989年3月，五位全国政协委员在全国两会上，对海南向外商有偿出让30平方公里土地提出质疑。这就是“洋浦风波”。1989年4月28日，经邓小平同志在审阅海南省委上报党中央、国务院《关于海南省设立洋浦经济开发区的汇报》做出批示后，“洋浦风波”平息。

1992年3月9日，国务院下发《关于海南省吸收外商投资开发洋浦地区的批复》，正式批准设立洋浦经济开发区，中国首例外商投资成片开发区就此诞生。6月26日，开发区基础设施动工，拉开了洋浦开发建设的序幕。

![Image 1](http://hi.people.com.cn/NMediaFile/2021/0425/LOCAL202104251116000509183999644.jpg)

1993年4月10日，洋浦经济开发区管理局正式成立，代表海南行使对开发区和附近海域的行政管辖权。新华社 姜恩宇 摄

为了支持洋浦的发展，中央比照国际上通行的自由港政策，赋予洋浦比现在开发区、保税区、高新技术产业开发区、出口加工区“四区”更加优惠的政策。为了加强管理和服务，海南省政府于1993年设立了洋浦经济开发区管理局，作为省政府派出机构，代表省政府对开发区及临近划定的所属海域依法行使行政管理权。

1994年以后，国家实行宏观调控政策，洋浦优惠政策部分被取消，受其影响，开发商放慢了投资速度并停止了投资。2007年9月24日，国务院批准设立洋浦保税港区。10月，海南省发展控股公司与其他股东签署股权转让协议，实现政府独资开发洋浦；2008年4月3日，海南注册资金30亿元成立海南省洋浦开发建设有限公司，海南省政府完全主导发展战略，掌握发展主动权，使洋浦的开发建设进入一个新的阶段。

2010年3月，经海南省委、省政府批准，洋浦管理局更名为洋浦管理委员会，将控股公司成建制并入洋浦管委会，理顺了洋浦开发体制机制，建立了集经济、社会、行政于一体的党政企联席机制。

2011年12月26日，海南省委五届十二次全会讨论通过《海南省委省政府关于全面加快洋浦开发建设的决定》。海南省政府授权洋浦管委会履行出资人职责，对洋浦开发建设控股有限公司实行统一领导。

2012年7月19日，国务院批准调整海南洋浦经济开发区规划范围。根据《洋浦经济开发区总体规划（2011～2030）》，开发区规划面积120平方公里，其中建设用地115平方公里，空间结构概括为“四带两廊、一心多园”。“四带”是指开发区内4条南北向主要功能发展带，从西向东分别为港航物流产业发展带，临港石化、浆纸及下游产业发展带、现代加工制造配套产业和保税仓储物流发展带‘居住和配套公共服务发展带。“两廊”分别为洋浦大道市政防护绿化走廊，开源大道环境绿化走廊。“一心”即开发区的公共服务中心。多园，即多个功能园区，包括港口物流园区（南北两组团）、石油化工产业园区（南北两组团）、石油天然气储备中转园区、修造船及海洋装备制造园区、浆纸一体化产业园区、保税港区及配套加工产业园区和居住综合服务区等。

2019年7月，海南省政府印发《关于支持洋浦经济开发区发展的措施（试行）》，制定7条措施，推动洋浦经济开发区高质量发展，加快推进海南自由贸易试验区、中国特色自由贸易港建设。

2020年4月，《海南省人民代表大会常务委员会关于海南自由贸易港洋浦经济开发区等重点园区管理体制的决定》施行。东方临港产业园、临高金牌港开发区并入洋浦管理。2020年6月，海南自由贸易港洋浦经济开发区正式挂牌成立。

经过20多年的开发建设，洋浦已建成一批技术先进、附加值高、高环保水平的重点项目，成为海南实体经济的重镇和对外开放的前沿。油气储备能力超千万方，成为我国目前第二大的商业石油储备基地。已开通内外贸航线33条，实现国内沿海和东南亚国家主要港口全覆盖，还开通了海南自贸港首条洲际越洋航线（洋浦-南太-澳洲）。2020年全年完成地区生产总值279.6亿元、新增市场主体13794户、港口吞吐量5664.4万吨、集装箱吞吐量101.9万标箱。

![Image 2](http://hi.people.com.cn/NMediaFile/2021/0425/LOCAL202104251118000413268552732.jpg)

洋浦经济开发区。邓晓龙 摄

在海南自贸港建设新时代，洋浦被赋予建设自贸港先行区示范区、全省高质量发展增长极的重要使命，明确了西部陆海新通道国际航运枢纽、先进制造业基地、大宗商品集散交易基地、新型国际贸易创新示范区等四大产业定位。如今，洋浦正按照中央和海南省委省政府的部署要求，加快建设海南自贸港“先行区”“样板间”，为全岛自贸港建设率先开展压力测试，积累管理实践经验。
