| 淮河入海水道近期工程 |  |  |  |
|  |  |  |  |
| * * *<br> 2007-11-27 |  |  |  |
|  |  |  |  |
| 淮河入海水道是承泄洪泽湖洪水的重要防洪工程，关系到里下河、渠北地区人民生命财产安全。工程分近、远两期建设，近期工程于1999年10月正式开工建设，2003年6月通过通水验收，2006年10月21日通过总体竣工验收。近期工程按洪泽湖100年一遇设计洪水、行洪2270m3/s确定。工程总投资为41.17亿元。该工程荣获2006年度中国建筑工程鲁班奖（国家优质工程奖），2007年11月入选中国土木工程詹天佑奖。 |  |  |  |
