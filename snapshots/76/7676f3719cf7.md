# 鼎益丰被指涉嫌操纵一度跌超40% 公司称隋广义已辞职但仍为主要股东

###### 2024年02月27日 12:53   21世纪经济报道 21财经APP   曹媛

**21世纪经济报道记者 曹媛 深圳报道**

因涉嫌操控股价，2月26日，香港证监会宣布，已在原讼法庭对鼎益丰控股集团国际有限公司前主席兼非执行董事隋广义及另外20名人士展开法律程序，指他们涉嫌在2018年3月1日至2018年9月14日期间操纵鼎益丰的股份。

香港证监会发布公告第二天，即2月27日，香港上市公司“鼎益丰控股”（0612.HK）（简称“鼎益丰”）发布公告与隋广义“撇清关系”，公告称，“隋先生（隋广义）已于四年前辞去其于本公司担任的所有职务。隋先生（隋广义）为公司主要股东。”

受上述消息影响，鼎益丰股价持续跳水。截至记者发稿前，港股鼎益丰一度跌超40%。

自2023年9月开始，鼎益丰控股部分自然人股东也持续减持。如梁家辉、荆思源及王梦涛均陆续出售持股，其中梁家辉出售150万股、荆思源出售160万股，王梦涛出售83.2万股。

![](https://ocmsmedia.sfccn.com/vod-4310da/image/default/80BB97C00E03469CB74468FD8CDF7094-6-2.png)

#### 涉嫌操控股价，鼎益丰股价曾暴涨81.84%

港交所官网显示，鼎益丰是一家主要从事投资业务的香港投资控股公司，投资组合包括上市证券及非上市证券，于2002年1月2日在港交所上市。根据wind数据，截至2023年6月30日，香港鼎益丰国际控股集团有限公司为其大股东，占已发行普通股比例为12.68%，鼎益丰“核心人物”隋广义持股9.58%。

香港证监会认为，隋广义等人涉嫌在2018年3月1日至2018年9月14日期间内操纵鼎益丰的股份。在此期间，鼎益丰控股股价暴涨81.84%，从最低6.7港元/股最高涨至17港元/股。

据媒体报道，鼎益丰股价有坐庄之嫌。2018年中，香港证监会对鼎益丰股份的可疑交易展开调查，其明确表示，“有关交易看来就该公司股份营造虚假市场，以致股价不寻常地上升。”

从2019年3月开始，香港证监会分别向合计香港17家经纪行发出限制通知书以冻结中国鼎益丰股份涉嫌市场操控活动有关的客户账户。该17家经纪行分别是：富途证券国际（香港）有限公司、广发证券（香港）有限公司、国泰君安证券（香港）有限公司、海通国际证券有限公司、东方证券（香港）有限公司、软库中华金融服务有限公司、申万宏源证券（香港）有限公司、新鸿基投资服务有限公司、云锋证券有限公司、中州国际证券有限公司、招银国际证券有限公司、横华国际证券有限公司、佳兆业证券有限公司、天元金融有限公司、胜利证券有限公司、越秀证券有限公司及中泰国际证券有限公司。

此次，香港证监会重申有关的限制通知书仍然有效。“早前已向合共17家经纪行发出限制通知书，将各被告的资产冻结，并禁止有关经纪行在未取得香港证监会事先书面同意的情况下，处理在其客户账户内持有的若干资产，而该等账户与鼎益丰股份涉嫌市场操纵活动有关。”

2019年3月7日鼎益丰停牌，2020年1月23日复牌，复牌当日跌超90%。在复牌前一日（即2020年1月22日），香港证监会公布已决定就鼎益丰控股的涉嫌市场操控活动，对多名人士展开法律程序，同时决定撤销其在2019年3月8日作出有关暂停鼎益丰控股交易的指示。同日，鼎益丰控股非执行董事隋广义辞职。

#### 鼎益丰仍在兜售所谓的“数字期权”

在核心人物隋广义的带领下，鼎益丰长期深陷“庞氏骗局”“禅意投资法”诟病，监管部门曾两次对其进行风险提示，近期更是因兑付危机而备受关注。

此前，多位鼎益丰投资人告诉记者，从2023年8月开始，鼎益丰已经出现了兑付危机，本金和利息难以兑付。正值此时，鼎益丰开始推行所谓的“数字期权”转型，部分投资者认为这像是稳住他们的“缓兵之计”。2024年1月10日，鼎益丰发布公告称“所有投资者自2024年1月10日起到2024年9月10日止一律不能退出，封闭八个月。”

记者发现，目前，鼎益丰工作人员仍在“引导”投资者进行所谓的数字期权（DDO）合同转换。该公司内部公告，“鼎益丰集团所有合同需全部平移，不同的产品有不同的溢价和加权奖励。”

北京泽亨律师事务所律师冯志远曾告诉记者，“所谓的数字期权是最近比较流行的说法，公司基于业务之需将账户冻结后不再还本付息，把相关业务活动转变为数字期权，同时告知未来继续给投资人支付本息，如果在将来被认定构成违法犯罪的情况下，这种以数字期权名义冻结账户的行为就有可能是换汤不换药，实质上仍是‘非法集资’。它其实就是为了拖延时间让客户继续相信公司有能力还本付息，一旦资金链断裂，就面临新的无法兑付的困境。”

鼎益丰内部工作人员声称，“能在2月全部完成的尽量2月完成，不要等到3月，加快转型对公司对大家都好。”“先生（隋广义）知道大家每一个人的难处，解决问题的速度取决于我们转换平移数字期权的速度和进度。平移得越快越彻底，解决问题就越快。所以大家要快速全面100%平移。”
