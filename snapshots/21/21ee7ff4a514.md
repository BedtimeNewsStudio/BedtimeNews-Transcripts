# 漁農處加強執行狗隻查牌行動

|  |  |  |
| --- | --- | --- |
| ![新聞公報](https://www.info.gov.hk/gia/cpress.gif) |  |  |
|  | 漁農處加強執行狗隻查牌行動<br>＊＊＊＊＊＊＊＊＊＊＊＊＊<br>漁農處將於下月起，展開全港性狗隻查牌行動，提醒狗主必須為其狗隻領牌及植入微型晶片。<br>該處獸醫師葉明祥今日（星期五）在解釋有關詳情時說：「此行動為漁農處持續推廣狗隻植入晶片計劃的其中一個工作項目。」<br>狗隻植入晶片計劃乃根據《一九九六年狂犬病修訂規例》，自一九九六年十二月起實施。所有五個月大或以上的狗隻，在首次領取牌照時，均會同時植入晶片。<br>由於狗隻牌照有效期為三年，因此，至今年十二月，所有被畜養的狗隻均應植有微型晶片。<br>葉明祥說：「屆時，所有未為其狗隻植入晶片的狗主，均會被檢控。違例者最高可被判罰款一萬元。」<br>自十月中起，漁農處動物管理組已加強協助狗主為其狗隻植晶片的工作，行動會持續至十二月。<br>葉明祥表示：「漁農處已分別安排多次特別查牌行動，在街道上，以及到鄉村及建築地盤等進行巡查。」<br>他補充說：「本處職員會向未為其狗隻植入晶片的狗主派發宣傳單張，促請他們及早作出安排，以符合法例訂定的要求。」<br>至今，漁農處四個動物管理中心，共往訪逾一百二十條偏遠的鄉村，為三千三百多頭狗隻注射疫苗，及辦理領牌及植晶片事宜。<br>漁農處職員亦特別巡查一些建築地盤，在一百五十次巡查中，為一百頭狗隻辦理領牌及植晶片事宜。<br>另外，漁農處亦特別準備了一些宣傳單張，派發予寵物店及獸醫診所，供張貼於適當地方，提醒狗主有關規定。<br>現時，已有超過八萬頭狗隻植入微型晶片。<br>葉明祥說，每片晶片均儲存有一個獨有的編碼。<br>根據此編碼，便可透過漁農處電腦資料庫，翻查狗主的姓名、地址、電話及狗隻的防疫注射紀錄。<br>有關資料有助漁農處職員為狗主辨認走失了的狗隻。<br>葉明祥說：「這方法亦可助漁農處追尋讓寵物遊蕩及造成滋擾的不負責任的狗主。」<br>他指出，晶片系統有助辨識未注射預防狂犬病疫苗，或已到期注射加強劑的狗隻。<br>他稱：「為狗隻植入晶片是本港預防狂犬病工作的一部分。」<br>「雖然狂犬病已在香港絕跡超過十年，但我們仍需致力防止其再度發生。」<br>狗主可在漁農處四個動物管理中心為其狗隻植入晶片：<br>＊ 香港動物管理中心<br>香港薄扶林域多利道六八八號<br>（電話：二五五一 八五八六）<br>＊ 九龍動物管理中心<br>九龍城宋皇台道一零二號<br>（電話：二三六二 四一四七）<br>＊ 新界南動物管理中心<br>沙田大圍車公廟路九十八號<br>（電話：二六九一 二一九一）<br>＊ 新界北動物管理中心<br>上水石湖墟馬會道十三號<br>（電話：二六七零 二二零一）<br>狗主亦可在註冊獸醫及愛護動物協會的中心或診所，為其狗隻植入晶片。<br>狗主可致電漁農處動物管理中心熱線（二三六二 三二五七），查詢有關規定詳情。<br>完<br>一九九九年十一月十九日（星期五）<br>* * * |  |
