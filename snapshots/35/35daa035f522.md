# 教育部《重編國語辭典修訂本》

| 字　　詞 | [世](https://dict.revised.moe.edu.tw/search.jsp?word=%3D%E4%B8%96&v=1) [家](https://dict.revised.moe.edu.tw/search.jsp?word=%3D%E5%AE%B6&v=1) |
| 注　　音 | `ㄕˋ``ㄐㄧㄚ` |
| 漢語拼音 | shì jiā |
| 釋　　義 | 1. 世代做官的人家。亦泛指世代顯貴的家族。《孟子．滕文公下》：「仲子，齊之世家也。」《儒林外史》第三三回：「世家子弟，怎說得不肯做官？我訪的不差，是要薦的。」<br>2. 史傳中記載諸侯王事跡的一種體例。如《史記》有〈吳太伯世家〉。<br>* * * |
