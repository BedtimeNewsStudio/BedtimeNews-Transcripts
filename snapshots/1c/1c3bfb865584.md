**游戏物管理委员会**（韓語：게임물관리위원회／게임物管理委員會）是[大韩民国](/wiki/%E5%A4%A7%E9%9F%A9%E6%B0%91%E5%9B%BD "大韩民国")根据《游戏业促进法》[[1]](#cite_note-1)于2013年12月成立的[电子游戏分级](/wiki/%E7%94%B5%E5%AD%90%E6%B8%B8%E6%88%8F%E5%88%86%E7%BA%A7%E7%B3%BB%E7%BB%9F "电子游戏分级系统")组织。[[2]](#cite_note-2)

## 介绍

该机构的前身[映像物等级委员会](/wiki/%E6%98%A0%E5%83%8F%E7%89%A9%E7%AD%89%E7%BA%A7%E5%A7%94%E5%91%98%E4%BC%9A "映像物等级委员会")曾把一款有赌博性质的游戏《Sea Story》划为全年龄段，因而遭到媒体批评[[3]](#cite_note-3)，时任韩国总理[韩明淑](/wiki/%E9%9F%A9%E6%98%8E%E6%B7%91 "韩明淑")为此向国民道歉。[[4]](#cite_note-4)随后由游戏物管理委员会接管电子游戏分级事务。[[5]](#cite_note-5)

2017年遊戲物管理委員會向韓國國會申請預算建設「遊戲等級綜合管理系統」（GMS），2023年[監查院](/wiki/%E7%9B%A3%E6%9F%A5%E9%99%A2 "監查院")調查發現，委員會在該專案中存在[腐敗問題](/wiki/%E8%B2%AA%E6%B1%A1 "貪污")[[6]](#cite_note-4gamers-6)，以虛報專案進度的方式，造成了6億[韓元](/wiki/%E9%9F%93%E5%85%83 "韓元")的損失，委員會的管理规划、游戏内容管理和自律支持三個主要部門負責人引咎辭職[[7]](#cite_note-gamelook-7)。

遊戲物管理委員會於2022年11月27日通過《分级分类规定部分修订草案》，預計年來實施，修訂內容包括遊戲發行登陸不同平台不再需要額外分級分類審查，根據韓國《行政程序法》修訂，拒絕和取消分級分類時，遊戲開發者申辯期限從7天延期到10天；同性戀描述不再歸類為煽情性项目中的「不正常的性关系描写」[[8]](#cite_note-youxiputao-8)。

### 分级图标

游戏物管理委员会目前使用以下分级图标[[9]](#cite_note-9)。这些图标须在下列场合显示：在街机和盒装制品版游戏的正面；在[网络游戏](/wiki/%E7%BD%91%E7%BB%9C%E6%B8%B8%E6%88%8F "网络游戏")运行中每小时显示不少于3秒；在[手机游戏](/wiki/%E6%89%8B%E6%9C%BA%E6%B8%B8%E6%88%8F "手机游戏")的启动画面显示不少于3秒。

| 图标 | 名称 | 代表意义 |
| --- | --- | --- |
|  | 全年龄 (전체이용가) | 各年龄段人群均可游玩。 |
|  | 12岁以上 (12세 이상 이용가) | 满12岁人群方可游玩。 |
|  | 15岁以上 (15세 이상 이용가) | 满15岁人群方可游玩。 |
|  | 青少年不可遊玩 (청소년 이용불가) | 在满19岁那年的1月1日之后可游玩。[[10]](#cite_note-10)[[11]](#cite_note-11) |
|  | 不可出售，发行或租赁/拒绝分级 （발매나 판매 및 유통 불가） | 因游戏内容逾越GRAC标准而被禁止在韩国发行，出售或租赁的游戏。 |
|  | 测试 (평가용) | 用于测试版游戏、正接受稳定性和效能检查的游戏或等待正式评级结果的游戏。 |
|  | **18岁以上** (已于2024年废止並被「青少年不可遊玩」取代) | 满18岁人群方可游玩。 |
