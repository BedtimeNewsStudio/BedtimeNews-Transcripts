# 屡次刷新记录，美国史上最大山火是从哪儿来的？

![](https://img.jiemian.com/101/original/20200630/159350104126796300.jpg)

![](https://img.jiemian.com/jiemian/original/20181112/154199707223328100.jpg)

![](https://img.jiemian.com/jiemian/original/20181112/154199707223328100.jpg)

作者：猫斯图

制图：孙绿 / 编辑：酸奶泡

去年秋冬之交的时候，美国南加州就曾经爆发一场有史以来最大的山火，威胁着洛杉矶湾区的安全。没想到就在这几天，仅仅时隔一年之后，加州北部又爆发了另一场有史以来最大的山火。这次受灾的将会是旧金山湾区。

![](https://img.jiemian.com/jiemian/original/20181112/154199707241023000.jpg)

![](https://img.jiemian.com/jiemian/original/20181112/154199707241023000.jpg)

*去年洛杉矶被大火包围的样子*

不仅山林周边的平民被紧急疏散，连在此安置豪宅的明星们也不能幸免，纷纷打包撤离。而山火却似乎仍然没有停下脚步的意思，浓烟早已从内陆飘散到了海上。

这是怎么了？

**加州火葬场的气候影响**

去年的加州大火，让美国媒体一片哀鸣，因为当年最大的一场山火直接刷新了美国山火的记录，即使是70年代曾经爆发过的大型山火，在规模上也无法和这次大火相提并论。他们没想到的是，山火的记录在今年又被刷新了。

去年的南加州，大火包围洛杉矶

![](https://img.jiemian.com/jiemian/original/20181112/154199707283474600.jpg)

![](https://img.jiemian.com/jiemian/original/20181112/154199707283474600.jpg)

今年夏天，加州南部就爆发了两场巨型火灾，受灾面积达到了460000英亩（1860平方公里），成为了有史以来影响力最大的野火。冬天的这一场爆发于加州北部的新火灾，只是夏天这两场火灾的一个延续。而更令人忧心的是，自2000年以来，加利福尼亚州已经经历了12场不断刷新纪录的大火。曾经被认为是西部度假圣地的加州，已经变成了一座烟火气十足的火葬场。

加州山火中影响规模最大的一些山火，这一次山火的最终影响面积还无法计算，但应该不会小：

加州巴特县营地火灾

左下方就是加州的中央谷地

![](https://img.jiemian.com/jiemian/original/20181112/154199707318935100.jpg)

![](https://img.jiemian.com/jiemian/original/20181112/154199707318935100.jpg)

有媒体认为，不断被刷新的火灾记录，无疑是全球气候变暖的直观体现。这也确实有可能是近年来加州山火不断，而且规模不断刷新历史的重要原因。

美国气象部门对比了1970年代以来的气候数据后得出的结论是：如今加州的高温干旱季节平均至少比上世纪70年代延长了两个半月，而高温和干旱正是滋生山火的主要气候基础。

以后会不会越来越热？

![](https://img.jiemian.com/jiemian/original/20181112/154199707341749200.jpg)

![](https://img.jiemian.com/jiemian/original/20181112/154199707341749200.jpg)

加利福尼亚近年来也确实变得越来越热，今年夏天全州气温就创了历史新高，部分地区的极端高温甚至到了45℃，即使在气候比较适宜的棕榈泉市，七月气温也到达了36.3℃。被高温炙烤到发干的植物，只需要一个小小的火星，就会触发原初的山火。

棕榈泉是一座沙漠旁的绿洲城市

全年大部分时间阳光充足

（如同美国其他西部城市，有着巨大的用水量）

![](https://img.jiemian.com/jiemian/original/20181112/154199707361464100.jpg)

![](https://img.jiemian.com/jiemian/original/20181112/154199707361464100.jpg)

加州南部已经为此在夏天付出了代价，而这次爆发大火的加州北部，在夏天还未经历过大火的洗礼，森林和城市周边堆积了大量干燥的有机物，就差一个触发的时机。加州州长杰里·布朗似乎早就预料到了这场悲剧的到来，他说：“野火是加州的新常态，这可能是每年都会发生的事情。”

夏天没发生山火未必是好事

可能意味着秋冬更加凶猛的大火

![](https://img.jiemian.com/jiemian/original/20181112/15419970743675800.jpg)

![](https://img.jiemian.com/jiemian/original/20181112/15419970743675800.jpg)

其实气候变化也并不只是带来了全球升温这一个后果。空气中的二氧化碳含量超出正常值之后，还会干扰天气的可预测程度，让天气变得更加不稳定。比如在加州这样的沿海地区，通过陆地空气和海洋空气的互动，正常情况下白天会较为炎热，而夜间会急剧降温。但过去这六年，加州的夜间降温水平并不高。此外，还会会影响空气中水蒸气的含量，让堆积的有机物变得更干，一点就着。

但气候变化是一个全球性的事件，拥有密林的地区也不止加州一个，为什么唯独只有加州的火灾如此频繁而恐怖呢？这和加州独特的地理环境和由此带来的空气流向有关系。

年年岁岁有今朝

![](https://img.jiemian.com/jiemian/original/20181112/154199707424065800.jpg)

![](https://img.jiemian.com/jiemian/original/20181112/154199707424065800.jpg)

**风火相依的地理基础**

加州在美国西部大开发的时代就是一个充满神秘感的地区。来自东部的美国人在前往加州淘金时，往往将其形容为一个特别的世外桃源（抑或是世外地狱），而外界也确实对这个地方缺乏了解，主要还是源自加州封闭的地理环境。

相比高耸且干燥的美国西部内陆

西海岸的加利福尼亚确实是世外桃源

![](https://img.jiemian.com/jiemian/original/20181112/154199707443034300.jpg)

![](https://img.jiemian.com/jiemian/original/20181112/154199707443034300.jpg)

加州北缘是和俄勒冈州交界处的密林和丘陵；东侧是密实的内华达山脉，和内华达州相隔；东南部则是莫哈维沙漠，和亚利桑那相隔。在加州内部，还分布着一系列山脉和山脉间的盆地，一直到最靠海的部分，加州才拥有了可供人类大规模开发的沿海平地。

![](https://img.jiemian.com/jiemian/original/20181112/154199707494904300.jpg)

![](https://img.jiemian.com/jiemian/original/20181112/154199707494904300.jpg)

光秃秃的山地、沙漠和干燥的森林，是加州最常见的地表景观。这也让加州的公路景观与东部新英格兰到佛罗里达一线完全不同。对传统的美国人来说，这里甚至是一个充满异域情调的地方，也难怪成为了好莱坞这样造梦工厂的基地，并吸引着富人们前来购置度假住宅。

大型梦工厂基地

![](https://img.jiemian.com/jiemian/original/20181112/154199707534125200.jpg)

![](https://img.jiemian.com/jiemian/original/20181112/154199707534125200.jpg)

好莱坞标志的山脚下便是一众豪宅了

（这山也是很西部世界）

![](https://img.jiemian.com/jiemian/original/20181112/154199707566766200.jpg)

![](https://img.jiemian.com/jiemian/original/20181112/154199707566766200.jpg)

不过这样特殊的自然景观也是要付出代价的——加州会形成别的地区都无法形成的干热强气流。

观察这一次席卷北加州的大火，会发现它的成型和扩散与北加州一种名为“大恶魔风（Diablo Wind）”的气流故关系密切。

大恶魔风成形于加州东侧的内华达州。冬天，这里的陆地气流较冷，会向西试图进入大西洋海面上的高温低气压区。但是在北加州和内华达州之间有一道高耸的内华达山脉阻挡了气流。

来自内陆的高气压

涌向不同方向的海岸地区

比如向旧金山的大恶魔风，向洛杉矶的圣安娜风

![](https://img.jiemian.com/jiemian/original/20181112/154199707598506700.jpg)

![](https://img.jiemian.com/jiemian/original/20181112/154199707598506700.jpg)

这里的平均海拔在1500~2700米之间，当气流沿着山体的迎风面上升时，随着海拔上升温度下降，空气中含有的少量水分会从空气中脱离，形成降水，这样到达山顶的风就已经很干燥了。在越过顶峰之后，干燥的空气又会沿着另一面快速下降升温，而水汽又得不到补充，到达山麓时就变成了又热又干的风，是为焚风，对火灾的形成和扩散有很大的作用。

和广阔的西部内陆相比

内华达山脉以西的沿海盆地就很渺小了

当然也是加州精华所在

![](https://img.jiemian.com/jiemian/original/20181112/154199707630330600.jpg)

![](https://img.jiemian.com/jiemian/original/20181112/154199707630330600.jpg)

而且由于内华达山脉和内华达州大部分地区之间的高度差较大，风倾向于不从山顶翻越，而是和旅行者一样喜欢从山间的拗口中穿过。被挤压的气流流速也会大大上升，让火灾的扩散变得更容易。以至于加州大火期间甚至出现了全家驾车逃离现场，却没有跑过大火，被烧死在车内的情况。

这种地方最容易出事了

![](https://img.jiemian.com/jiemian/original/20181112/154199707669933500.jpg)

![](https://img.jiemian.com/jiemian/original/20181112/154199707669933500.jpg)

在加州南部，也有一种风，名为“圣安娜风（Santa Ana Winds）”。她的成型，也源自内华达陆地空气和大西洋洋面空气之间的气压差。虽然这种风不用翻越内华达山脉以至于形成焚风，但她会经过干燥的莫哈维沙漠，其实更加可怕。

一山之隔，洛杉矶离沙漠其实相当近

![](https://img.jiemian.com/jiemian/original/20181112/154199707744464200.jpg)

![](https://img.jiemian.com/jiemian/original/20181112/154199707744464200.jpg)

圣安娜风下的火势

![](https://img.jiemian.com/jiemian/original/20181112/154199707791580200.jpg)

![](https://img.jiemian.com/jiemian/original/20181112/154199707791580200.jpg)

这也是为什么南加州的火灾比北加州更频繁，危害也更大。

拥有这样地形、气候的地区都非常容易引发山火，比如同样位于地中海气候区，并位于沙漠和大洋之间的葡萄牙和澳大利亚，山火都是非常普遍的。但这些地区的山火造成的损失和引发的关注都没有美国加州的山火这么大，这和加利福尼亚的人又有关系。

**自我保护的糟糕副产品**

英语山火又称为野火（Wild Fire），听上去给人一种充满自然野性的感觉。然而实际上并非如此，大量野火的源头来自人为点火。根据统计，美国有90%的野火都来自进山人员丢弃的烟头、宿营地未能熄灭的篝火等人类活动残留。说是野火，实际上和人脱不了干系。

野火烧不尽 来年接着烧

![](https://img.jiemian.com/jiemian/original/20181112/15419970787007600.jpg)

![](https://img.jiemian.com/jiemian/original/20181112/15419970787007600.jpg)

加州是一个重视旅游业的州，尤其是山林探险旅游，是加州风情的一块招牌。来自美国东部人口稠密地区的游客，都喜欢进入加州探险。但只要有人的露营和探险，就难免会产生火源，这让加州的山火远远比人口稀疏的澳洲各地密集得多。

体验一把西部风情是美国人的刚需

![](https://img.jiemian.com/jiemian/original/20181112/154199707828663000.jpg)

![](https://img.jiemian.com/jiemian/original/20181112/154199707828663000.jpg)

而在大火蔓延的过程中，之所以造成如此惨重的财产损失，也是典型的人祸。

近年来，加州的经济一直在美国经济版图中非常坚挺。早在上个世纪初，伴随着美国西部大跃进的步伐，大量美国人来到此处，出现了旧金山湾区、洛杉矶长滩港等重要港口城市。现代化的进程则为加州带来了繁盛的娱乐业（好莱坞）和高科技产业（硅谷）。

硅谷的巨头们

![](https://img.jiemian.com/jiemian/original/20181112/154199707854555700.jpg)

![](https://img.jiemian.com/jiemian/original/20181112/154199707854555700.jpg)

有钱人一多，加州的城市规划就成了一道难题。原有的海滨湾区已经无法承载富人们的住宿需求，从旧金山和洛杉矶湾区向内陆，开始出现了大量新建的别墅。这些住宅区沿着城市边缘进入了林区。根据联邦紧急事务管理署本世纪初的一份统计，加州38%的新建住宅就建造在这种地区。这些住宅中，还有相当一部分是名人的豪宅。

加州豪宅千千万

硅谷里面占一半

![](https://img.jiemian.com/jiemian/original/20181112/154199707884588900.jpg)

![](https://img.jiemian.com/jiemian/original/20181112/154199707884588900.jpg)

这一类新扩张的城市区域，被称为“野外-城市交互区”（wildland-urban interface areas），简称WUIs，在加州已经很常见 。威斯康星大学麦迪逊分校的拉德洛夫教授（Prof. Volker Radloff）表示，这类区域是“背靠大森林的中世纪城市”，缺乏现代化的城市管理和自我保护能力。

你绑架了森林

森林也会绑架你

![](https://img.jiemian.com/jiemian/original/20181112/15419970796534200.jpg)

![](https://img.jiemian.com/jiemian/original/20181112/15419970796534200.jpg)

WUIs的出现，为加州的森林防火工作带来了前所未有的变局：人们会自发地扑灭出现在社区周边的小型山火，以免其蔓延，危害到自己价值不菲的住宅。但这样一来，就会让原本可以通过小型烧火消灭掉的干燥有机物产生堆积。这样堆到一个临界值之后，一旦发生火灾，就会迅速超出人类的控制能力，造成不可挽回的损失。

蓝色区域为WUIs区域

红点为2017年的大小山火策源地

![](https://img.jiemian.com/jiemian/original/20181112/154199707922769500.jpg)

![](https://img.jiemian.com/jiemian/original/20181112/154199707922769500.jpg)

美国的林业和消防部门在上个世纪70年代就面临过这样的困扰。

当时加州也是山火频发，因此联邦政府和州政府要求当地管理部门加强巡逻，把一切山火都消灭在萌芽状态。在经过了几年的太平光景后，加州开始大面积爆发巨型山火，消防部门根本无从控制。人们事后反思，发现小型山火是可以用来防止大型山火出现的，因此对小型火灾放任自流，甚至人为制造了小型山火，缓解大型火灾的压力。

但管理部门的这些科学模型，在别墅区富人们的自我保护倾向下被瓦解了。人们在控制小型火灾的同时，也增加了大型火灾的不可控性。
