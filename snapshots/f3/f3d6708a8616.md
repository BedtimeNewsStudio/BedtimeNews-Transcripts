| 创亚洲新纪录 中国基因编辑猪肾移植患者跨越100天生存关 |  |
|  |  |

中新网成都6月15日电(王爵 张小丽 徐艳梅)14日，亚洲首例接受多基因编辑猪肾移植的终末期肾病患者术后已超100天，成为全球仅有的2例猪肾移植存活病例之一，刷新亚洲纪录。

据悉，这次异种器官移植手术用的猪肾脏，来自中科奥格生物科技有限公司四川省内江资中基地培育的六基因编辑猪。此例手术在中国科学院院士窦科峰指导下，于3月6日由空军军医大学西京医院组织实施，接受手术的是一位69岁女性终末期肾病患者。截至目前，猪肾脏在人体内正常运行，肌酐维持在30-50微摩尔每升。

![](https://rmtzx.sciencenet.cn/kxwsprint/684e39ade4b078fce4497fd7.jpeg)中科奥格公司四川内江资中基地。中科奥格供图

?

据了解，就在患者术后百日当天，由同济医院组织实施的猪肾脏移植到猴体内平稳度过229天，刷新了之前韩国保持的猪到灵长类动物肾脏移植存活221天的亚洲纪录。该例异种器官移植手术用的猪肾脏，同样来自中科奥格四川内江资中基地。

一天创下两项亚洲纪录，异种器官移植从猪到猴再到人，基因编辑如何破解异种排斥难题？

对此，中科奥格公司创始人潘登科博士表示，科研人员通过精准敲除引发超急性免疫排斥的关键抗原α-Gal、引发急性血管性排斥的Sda和Neu5Gc抗原，同时转入人源化补体调节蛋白及凝血调节蛋白等，成功将供体猪肾脏“伪装”成人类器官，显著降低了免疫排斥风险。在此基础上，西京医院通过优化临床免疫抑制方案，并建立个性化精准管理策略，成功实现了患者术后生存百天无严重排斥反应。

中科奥格公司通过DPF级(无指定病原体)医用供体猪培育设施，从源头上控制跨物种病原微生物传播风险。目前，中科奥格公司位于四川省内江市资中的基地总占地面积达330亩，已建成1.17万平方米的医用猪产业园，培育可供器官移植的基因编辑猪品系10余个，年稳定产出3000头医用试验猪，除了猪肾脏，未来还将开发猪皮肤、红细胞等组织器官治疗技术，让更多患者重获新生。

据悉，我国约有1.3亿慢性肾病患者，其中终末期肾病患者数量庞大且呈逐年上升趋势。每年新增大量终末期肾病患者靠透析维持生命，肾移植是治愈终末期肾病的唯一有效方法。异种来源器官被视为解决这一危机的“战略技术”。此次中国在临床与临床前研究的双重突破，以“基因编辑+临床免疫+微生物控制”的综合方案，为全球异种移植提供了“中国路径”。

“等待器官的尽头，不再是绝望，而是基因编辑猪带来的新生曙光！”在四川省人民医院原院长、中科奥格公司联合创始人邓绍平看来，基因编辑猪器官的临床转化，将彻底改变“一器难求”的现状。接下来，中科奥格科研团队将持续优化基因编辑方案，探索更精准的免疫调控策略，同时与监管部门合作完善临床与安全性评价体系，努力实现异种器官移植的常态化应用，为解决人类器官短缺作出更多探索和更大贡献。(完)
