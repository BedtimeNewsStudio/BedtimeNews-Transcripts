| # 彭晓方老兵新传：喊我彭弹腿不生气 别说我假打 |
| --- |
| * * * |
| http://sports.sina.com.cn 2005年07月16日07:01 四川新闻网-成都日报 |
|  |
| 甲Ａ十年，有很多江湖故事。王健林拍案言退、渝沈案震惊全国、戴大洪炮打足协、彭晓方弹腿成名……在那个万人空巷的看球年代，川人嘴里叫得响当当的除了“魏大侠”、“小姚夏”以及一“兵”一“马”外，就数超级替补“彭弹腿”了。前几天彭晓方回归五牛当上教练，一脸兴奋的重庆崽儿嘴里冒出了一个“老兵新传”。那一天正好是他的乖儿子彭浩宸“满百天”，晓方嘟囔着说，“过去的都过去了，希望这一次是我彭晓方新的开始。”

23年前的一天，一个10岁的小娃娃在重庆大田湾小学的操场上颠起了足球。大大的脑袋灵巧的身手，那一年彭晓方上小学四年级。6年后，16岁的他离开父母只身来到成都，从此开始了他的足球生涯。随后他进入辜建明执教的成都市体工队，还在第二届城运会上夺得了第四名。“那时候大家都很单纯，哪像后来球迷张口就骂，在场上一听到就恼火，咋个不成‘弹腿’嘛？”如今已从当初毛头小伙子变成了“彭指导”，听到“弹腿”、“飞机”这些称谓他也一笑置之，“我还是那个火爆脾气，一点都没变，但不能总和他们计较个没完吧……”

**我那一脚**

**没有打歪是命**

彭晓方1998年把八一队打降级的那脚远射可以让人记一辈子。他本人也觉得那个球有点“邪”。“老实说我当年在全兴没进几个球，但那个球就偏偏碰上了。”1998赛季的最后一轮，八一队将保级的希望寄托在主场作战的全兴队身上，因为1995年全兴正是在八一队身上拿到三分才勉强保级。不过这次把他们推下“深渊”的却是三年前被他们拯救的川军。一个并不显眼的球员正是当年中国足坛最大的新闻制造者，而川军“以怨报德”放在“假球”横行的中国职业足球背景里，愈发显得光怪陆离。这场比赛也成为十年甲Ａ史仅有的标本。

歪脚定乾坤，彭晓方眼睛滴溜溜一转，“这就是命。谁叫八一队赶上了呢？1997年我腿断了，髌腱断裂，和罗纳尔多伤得一模一样。1998赛季我下半年才伤愈复出，正好黎兵前一场打深圳受伤了，最后一场我就首发。这是我整个赛季惟一一次首发出场，结果就进球了。还有哪个笑我‘弹腿’吗？”他至今仍说那一脚随意的吊射堪与“世界波”媲美。

**我没打假**

**也别说我假打**

有两件事彭晓方可以让人记一辈子，除了那脚“世界波”，另一件就是2001年底被中国足协禁赛半年的尴尬。当年骁勇的彭晓方一战成名，一夜之间披上了“打假英雄”的彩衣。但2001年“五鼠闹甲Ｂ”，彭晓方却被中国足协一纸禁赛令打入了黑名单。“真冤啊！就说11∶2那场球，球都滚到对方球门线上了，作为前锋你能不踢进去？这一切都是足协那一年取消降级闹的。足协、俱乐部惹的事，我们球员却来背黑锅！”他至今仍耿耿于怀。

打进八一队那个世界波之后，有球迷编了个段子，说彭晓方当时是瞄着钟楼的尖尖打的，本来想故意打歪，结果歪打正着。“太夸张了。”彭晓方对此一再强调，“在全兴时我没有打假，在五牛时也没有假打。”

时光又回到七年前，战八一队前受了伤的黎兵曾很坚定地与朋友打赌：“我赌全兴能胜八一。”谈到此彭晓方也说，“当时重庆2∶0战胜深圳，八一队扳平就保级，但我们领先后也没有要‘放’他们的意思。我都是按俱乐部的要求做的，我不懂什么‘行规’，也没啥子不好意思的。”

**喊我“弹腿”**

**是按到火巴的捏**

彭晓方说，如果再早几年说什么“弹腿”、“飞机”他肯定要冒火，现在退役当教练了，对这些也就看得淡了。“球迷也就喊了一阵子，电视解说员和报纸就总拿来说事，也应该客观一点嘛！”他还是有点尴尬，“现在想来当初一些球迷虽然很火爆但是很不职业，粘到啥子就在看台上乱喊‘下课’、‘弹腿’，过瘾唆？在国外高水平联赛中哪有球迷给主队喝倒彩的哟。而且，别个在门前也把球打飞为什么他们不吼，就因为我是替补唆，柿子也不能总按到火巴的捏噻！”

他坦言，在全兴那几年其实他很不如意，因为总是当替补，形象待遇都很受影响。他很诚恳地说：“其实我挺有天分的，但有时候在场上不是很自信，作为前锋这是致命的。所以太想踢好却总踢不好，球迷一吼自己的情绪就更受影响，多吼几次就更怀疑自己了，到后来变成了恶性循环。”后来他想，树挪死人挪活，于是给黄建勇打了个招呼就挂牌了，后来被陈亦明挖到了五牛。

**我带徒弟**

**不让他们再受气**

从球员过渡到教练，彭晓方只用了一年时间。作为成都市优秀中青年足球教练的重点培养对象，成都市足协秘书长辜建明对他非常器重，而且还坦言他是一个既聪明又用功的典型，和当初踢球时那股毛糙劲完全不一样。“我可以说是五牛这帮队员的老大哥，正好山哥（黎兵）、黑皮（徐建业）几名老的聚在了一起，总感觉又回到了老全兴。”“你那个火爆脾气怎么去调教队员啊？”记者问。“我骂都不敢骂他们。以前我当球员时受过这样的气，踢球就有抵触情绪就不好好踢，现在我不会再吃这个亏了。虽然都是小兄弟但一定要相互尊重，违反了队规按规矩处罚就是，这是基本的职业规矩。”他说。

**我的儿子**

**名字有点复杂**

谈到家庭，彭晓方马上把他的手机屏幕翻给记者看，画面里是一个白胖小子的照片。“这是我儿子，名字有点复杂，叫彭浩宸，是他婆婆取的名字，是宽广浩大的意思。”他说，“他们都说长得更像我一些，乖得很，只有我逗他他才笑，别个哪个都哄不到。”谈到儿子晓方又来了精神，“他以后踢不踢球我没多想，反正一切顺其自然……”所谓有其父必有其子，有个天不怕地不怕的老子，眼前的小胖墩儿也眯着眼睛一脸不屑的表情，似乎也在说，“谁敢横刀立马，看我彭小将军”。本报记者黄一可

**晓方逸事**

彭晓方一脚远射把八一队打掉级后，2000年转会到五牛队的他在海埂教学赛中与八一队队员狭路相逢，结果教学赛变成一场拳脚大战。肖坚兜腹的一脚直踹让彭晓方在地上痛苦地躺了好久。据说八一队员私下说：“要废了彭晓方。”彭晓方又攻进一球后，当场被对方围攻。他脱身退到另一块场地上，愤怒地说：“老子就是克八一队，下一场我还进你们球。”

彭晓方脾气火爆，是继魏群之后的又一性情中人。有一次，他甚至在训练场上就给前五牛主帅余东风“毛”起。彭晓方先是在训练中被东风呵斥了几声，不服气的晓方嘴上也不依不饶，和东风顶起嘴来。两个重庆崽儿的脾气都不小，如果不是教练和队员及时拉开，师徒二人差点直接就在训练场上干起来。“教练和队员之间应该相互尊重……”晓方后来回忆道。

有一次五牛队主场对阵霍顿执教的浙江绿城。霍师傅先是不满裁判判给五牛队一个点球，接着就认为五牛队外援哈拉假摔，冲到场边对主裁判直嚷嚷。这时彭晓方横刀杀出，指着霍顿叫他“闭嘴”，两个人开始愤怒地对峙。终场前绿城又被罚下一人，霍师傅又大吼着冲到场边。这一次还是彭晓方，怒指着霍顿向裁判示意，希望裁判把他罚上看台。霍师傅嚷嚷了几句，只好掉头走回了教练席……本报记者黄一可

**彭晓方档案**

1972年6月18日生于重庆

1988年进入成都市体工队

1991年底进入四川省一队

1994年－1999年效力于四川全兴队

2000年－2003年效力于成都五牛队

2003年底退役

2004年随成都虎少队征战室内五人制足球联赛

2005年初担任虎少队主教练

目前担任成都五牛队教练

采访手记

**跑龙套也要够专业**

黄一可

采访彭晓方是一件比较痛苦的事，因为他基本不“配合”记者的问题，而是天马行空想说什么就说什么。不过我也暗自庆幸，这一次他没有再回避关于对“彭弹腿”、“彭飞机”的批判话题，而是幽了一默，“你可以认为当初骂我的球迷不职业，但也可以认为他们的标准高。”联想到因为喊出“我的护球像亨利”而被球迷讥讽的“李毅大帝”，固执、嘴硬、不服输，有时候闹点小情绪，有时又大大咧咧滑稽可爱，这真是球迷又爱又憎的“喜剧之王”。

说白了，在不少球迷眼里，晓方只是个靠运气进球的二流射手。为此他也曾经郁闷过，离开全兴就是为了证明自己，到了五牛他成为球队的绝对射手，但仍然难以“洗脱”骂名。他曾经为此火冒三丈，但现在他渐渐平静了，“我的脾气没变，但角色转换了，没必要再去纠缠。”彭晓方性格较为内敛，平时不苟言笑，但那一句“我相信自己的表现对得起观众”，却真的值得球迷们玩味。

《喜剧之王》中的尹天仇不想在“跑龙套”的日子里厮混下去，小人物终于炮制出那个著名的“‘跑龙套’也要有专业精神”的大道理。彭晓方认真地对我说，“我平时没什么爱好，就是喜欢足球。很多球员退役做生意，我是大的做不起小的不想做，这一辈子就干足球吧。”每天早上8点起床、晚上12点睡觉，晓方说他当上教练后规律多了，除了训练就是看足球电视转播，有些还会录下来。昨天在城南紫荆小区的ｍ&ｍ咖啡馆，黎兵、彭晓方、张伟哲几名“少壮派”又坐在一起研究起五牛队的训练战术来。“我们总在一起讨论业务，这是职业也是生活。”

晓方还有一句话说得好，“每个人就有一次机会让大家记住你”。是的，一切在进球那刻的狂喜后又归于平凡，我们不能忘却那些改写历史的平凡人物。（来源：成都日报） |
