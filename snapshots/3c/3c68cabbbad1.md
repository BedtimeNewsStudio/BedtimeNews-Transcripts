| 国家中医药管理局报纸审读会召开：报纸专版很有特色 |  |
|  |  |
| 时间：2015-11-09 00:00:00 |  |
|  |  |

|  |  |
| --- | --- |
| 11月4号下午，国家中医药管理局组织召开了2015年度报纸集中审读会。来自《健康报》《中国青年报》等资深报人，就国家中医药管理局主管的《中国中医药报》，进行了审读评阅。<br>业内专家肯定了该报近年来的成长变化，认为《中国中医药报》在提升业内医疗工作者业务能力、捕捉社会热点，用新闻故事讲述中医药大政方针方面，具有突出水平和能力。原经济日报社科教文卫部主任郭晓认为，《中国中医药报》专版很有特色。<br>    业内专家指出了该报存在的问题。原人民日报社科教文卫部主任李新彦认为，报纸报道领导活动过多。《健康报》总编辑周冰认为，《中国中医药报》除了“自上而下”的报道外，更需要“自下而上”的选题，多关注行业发展，接近生产一线，聚焦基层中医药从业者，报道他们的所需与难题。<br>    中国青年报社长、总编辑张坤建议，《中国中医药报》应该一方面加强调查性报导，另一方面加强中医文化、中医故事的传播。同时，《中国中医药报》应该融入互动环节，重视对网站、微博、微信上读者留言信息的挖掘。<br>    中国传媒大学新闻传播学院教授唐远清表示，《中国中医药报》机关特色较为浓厚。他建议《中国中医药报》加强新媒体业务，“线上线下的互动结合起来，加强报纸与微信、微博的互动，将记者、编辑的新媒体工作量，纳入到绩效考核中来。同时做好中医药相关的舆论引导工作。<br>    中国中医药报社副社长濮传文表示，审读会后，报社将会积极落实专家提出的意见建议，在报社召开相关会议，进一步研讨，进行有针对性的整改。（张晓东） |  |
