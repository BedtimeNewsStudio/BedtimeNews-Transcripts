# 陈凯歌大理话剧被指破坏环境 制作方及管理方喊冤

2011年07月11日 14:24　来源：中国新闻网　![](http://www.chinanews.com/fileftp/2010/04/2010-04-23/U76P4T47D13180F981DT20100423110629.jpg)[参与互动(0)](http://comment.chinanews.com/comments/comments.php?newsid=3172634)　　【字体：↑大↓小】

![陈凯歌大理话剧被指破坏环境制作方及管理方喊冤](https://www.chinanews.com.cn/cul/2011/07-11/U238P4T8D3172634F107DT20110711143111.jpg)

《希夷之大理——望夫云》剧照。 作 者：秦晴

[【点击查看其它图片】](https://www.chinanews.com.cn/photo/index.shtml)

中新网昆明7月11日电(胡远航)投资逾2亿，由陈凯歌执导的首部大型魔幻实景舞台神话剧《希夷之大理——望夫云》自7月6日晚正式开演以来，民间对其质疑的声音就不绝于耳，不少网友更是“炮轰”该剧破坏古城自然人文环境、影响周边居民生活。

|  |
| --- |
|  |

某网站微博用户“荣翊如”便是众多炮轰《希夷之大理》网友中的一位。从6月底起，她便在其微博上连续发难，发出了“拯救大理”的声音。而不少网友更是翻出了陈凯歌《无极》破坏环境的旧案，调侃破坏环境是其一贯风格。不过，与网友和民间的质疑态度截然相反的是，有关部门人士在接受记者采访时却是齐齐喊冤。

荣翊如在《拯救大理》的帖子里爆料，制作方所称的“变废为宝”的舞台是搭建在大理北门水库(即北水库)上，并描述该水库：“一直在此养鱼的李希靖老板说：‘这个浇灌着果子园、才村等800多亩良田的水库怎么会是废弃的呢？’荣翊如还引用了“网友张先生”的话说，“大理北门水库是一个大理古城人熟知的标志性景点，吃完晚饭到那里走走，看白鹭叼鱼，看年轻人谈恋爱，多好的地方……这一切都将成为美好的回忆”。

大理市旅游度假区管委会主任赵廷标对此做了两点澄清，一是《拯救大理》帖子中的“北门水库”照片是假的，张冠李戴用了丽江黑龙潭公园的照片；二是北门水库此前不但一直存在着环保隐患，而且还存在着社会治安隐患。

据大理市水务局副局长杨艺芳介绍，北水库位于大理古城东北角，是1958年人民公社时期修建的水库，年久失修，但并未完全废弃，还负责周围几个村庄农田的灌溉。长期以来，包括医院污水、居民生活废水在内的很多污水都被直接排放到水库里，导致水库的水质很差。修建剧场以后，为保证演出用水，灌溉确实受到影响，但戏剧的投资方已和村民达成协议，从附近的中和溪中抽水供给村庄，村民不用负担任何费用。

《希夷之大理》制作方介绍，《希夷之大理》项目开工建设后，他们对水库四面坝体均进行了重铸和加固工作。舞台区域，整个水体仍然实现自然循环，由于建设中对水库库底进行了清污工作、对水质进行了净化，同时不再有垃圾倾入，水质比原水库储水水质有了大幅提高，其灌溉功能也并没有发生变化。记者看到，水库四面坝埂已被种植上了大量的花草植被和树木竹林。

《希夷之大理》制片人王兵强调，舞台建成后，水库的灌溉功能并没有发生变化，欢迎网友提出建议，每个人都有发言的自由，但希望批评要有根据，应该实地看过以后再发表意见。

在质疑《希夷之大理》破坏环境的同时，不少网友更担心演出的巨大声响造成扰民，大理古城生活环境和人文环境由此被破坏。微博用户罗梨珂表示：“大理其实真的不需要这个，真正的大理是诗意的生活方式。保存其原来的样子，阻止其现代化才能留住大理与世隔绝的风采。人多了，喧闹了，大理也就毁了。”

对此，《希夷之大理》制片人王兵也作出了回应，他表示，彩排期间为了调试出最佳视觉效果，所有排练和调试工作都只能安排在深夜进行，确实影响了周边居民的休息，制作方已经挨家挨户地表示了歉意。而随着演出步入正轨，《希夷之大理》每晚只演一场，演出时间是每晚8点至10点钟之间，这样的时段和长度将避免了对附近居民生活的影响。

大理市官员及旅游局有关负责人表示，近10年来，大理变成了游客从昆明到丽江的过路站，处境尴尬。如何重振大理旅游，如何把更多的游客留在大理，是地方政府始终在思考的问题。而《希夷之大理》将成为大理旅游的一张新名片，保守估计每天会为古城带来至少3000个过夜的客源。全年按300天演出场次计算，一年就可以为整个古城商户和居民带来4.5亿元的收入。除此之外，《希夷之大理》也将提升整个大理旅游的文化内涵。

记者在采访中发现，在网友质疑演出水平，担忧现代化的剧院会破坏古城原本平静的生活时，像杨国定一样居住在剧场周围的群众却正在考虑更现实的问题。“我打算买下一个沿街的房子，改成铺面。以后来看表演的人多了，或许可以开个餐馆、小超市，生意应该很好，”杨国定说。(完)
