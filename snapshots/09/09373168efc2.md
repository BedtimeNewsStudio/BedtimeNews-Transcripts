# 韩老龄化速度最快 2050将成世界第二大老龄化国家

2016-03-31 09:34:08来源： [中国新闻网](http://www.chinanews.com./gj/2016/03-31/7818509.shtml)作者：${中新记者姓名}责任编辑：何路曼

[中新网](http://www.chinanews.com/) 3月31日电 据韩媒报道，2050年，韩国将成为世界上65岁以上老龄人口比例第二高的国家。据美国统计局当地时间28日发布的《正在老去的世界2015》报告书(以 141个国家为对象)显示，2050年韩国的65岁以上人口比例预计将达35.9%，成为继日本(40.1%)之后世界第二大老龄化国家。韩国2050年预计人口为4337万，其中1557万人为65岁以上的老人。

|  |
| --- |
|  |

据报道，韩国老龄化增速也呈现出最快的势头。1980年65岁以上人口仅有 3.8%，而2015年达到了13.0%，预计2050年还将继续剧增至35.9%。

据预测，韩国将仅用27年就完成从2000年进入老龄化社会(65岁 以上人口占比7%以上)到2026年进入超级老龄社会(老龄人口占比21%以上)的快速老龄化过程。法国从老龄化社会进入到超级老龄社会用了157年，英国用了100年，美国用了89年。

韩国还将迎来人口的急剧减少。2050年，韩国人口将减少 570万，成为世界第七大人口减少国。

报告书分析显示，虽然韩国人口急剧老龄化，但福利水平却处在下游。领取国民养老金的比例虽然超过 了80%，但是以2010年为标准，老人贫困率超过45%，这在34个经济合作与发展组织(OECD)会员国中比例最高。

这一比例是老人贫困率占20%左右的美国、日本的两倍多，是荷兰的40倍多。韩国65岁以上老人中接受国家免费治疗支援的比例也仅有6.4%。而日本老龄化人口中正接受国家支援的比例为 12.8%，以色列为22.1%。

2050年韩国平均期望寿命预计将达84.2岁，成为世界上第五大国民活得最长的国家。那时韩国男性的期望寿命将达到 81.5岁，女性为87.1岁；日本和新加坡的期望寿命将达到91.6岁，成为国民最长寿的国家。
