# 投资百亿自建数据中心，快手不为人知的一面

|  |  |
| --- | --- |
| 本文作者： [张帅](https://www.leiphone.com/author/zhangshuai275) | 2020-06-06 18:30 |

当一些人对快手的印象还停留在“老铁666”的刻板画图，快手已经“快人一手”。

6月6日，快手宣布将投资百亿在内蒙古乌兰察布市建立数据中心。据介绍，快手乌兰察布大数据中心是快手第一个自建超大规模互联网数据中心，建成后可达60EB以上总存储容量，相当于超过300万个国家图书馆，这也是国内最大的专门为“大数据、人工智能”建设的数据中心。

以短视频闻名的快手，为何要大兴土木投资百亿建大数据中心？

![投资百亿自建数据中心，快手不为人知的一面](https://static.leiphone.com/uploads/new/images/20200606/5edb50059a4f8.jpeg?imageView2/2/w/740)

![投资百亿自建数据中心，快手不为人知的一面](https://static.leiphone.com/uploads/new/images/20200606/5edb50059a4f8.jpeg?imageView2/2/w/740)

## 快手为何自建数据中心

数据中心，顾名思义是承载着企业核心业务的基础设施，数据在其中计算、存储和传输，通过各类智能终端和互联网，我们每天都在和数据中心发生无法计数的连接。

数据中心增长和互联网的发展具有明显的同步性，互联网的典型业务从网站、电商、游戏进化到视频等，对于数据和流量的需要呈指数级增长，数据中心产业的“质”和“量”都有了明显提升。

信通院数据显示，2010年全球传统小型数据中心规模占计算实例的79%，而到了2018年全球超大型数据中心规模占计算实例的89%。

此外，2013年以前，全国对外服务型数据中心平均PUE（Power Usage Effectiveness，电源使用效率)在2.5左右，而到2019年底，全国对外服务型数据中心平均PUE近1.6。

数据中心朝着大型化、集约化的方向迈进，是由企业自身业务推动的，快手同样如此。

2020年2月21日，快手大数据研究院发布《2019快手内容报告》。报告显示，截至2020年初，快手日活已超过3亿，2019年共有2.5亿人在快手发布作品，快手App上已经有近200亿条视频，累计点赞数超过3500亿次。

快手多元内容生态爆炸式发展，背后需要海量的数据存储，在雷锋网看来，快手业务增长的速度肯定要远远超过数据中心规划建设的速度，数据中心从规划到投产以年计算，快手只能采取租赁的方式先行缓解业务增长需求，再逐渐过渡到自建模式。

尽管如此，快手选择自建数据中心的时间表也超出预估。以BAT为例，分别成立于2000年、1999年、1998年，但是自建数据中心的规划至少都在成立十多年后，正式落成同样需要数年。

这可从两方面来理解，快手主营业务是视频和直播等，和BAT业务属性不同，天生需要更多的数据中心资源，所以提前规划是正常的。

同时从国家角度，国家正在大力倡导新基建，数据中心是新基建的重要组成，也代表着企业的“硬实力”，快手选择此时自建数据中心也能获得更为便利的市场和行业条件，乌兰察布本身就具备良好的电力、空气、温度等条件，国内外一批大型数据中心都在此落成，快手选择乌兰察布是成熟稳妥的选择。

此外，自建数据中心还是企业的技术试验田，不论是数据中心自研核心技术，还是探索人工智能等各类应用技术，只有在企业自己的数据中心才能更好地实施。

在乌兰察布建设IDC将成为快手的标志性里程碑，雷锋网了解到，快手今后将充分评估各地的建设条件，在全国范围进行超大规模IDC布局。

## 数据中心怎样“快人一手”

快手APP背后，是一个不为人知的快手，体现在其对于数据中心技术的超前规划和大胆实践。

雷锋网此前走访过阿里、腾讯、百度、华为和京东等多家巨头的数据中心，和这些企业不同的是，快手没有历史包袱，也就意味着可以采用时下最前沿的技术，从土建到服务器，从选址到规划，从零打造快手式数据中心。

![投资百亿自建数据中心，快手不为人知的一面](https://static.leiphone.com/uploads/new/images/20200606/5edb4c99e22f1.jpeg?imageView2/2/w/740)

![投资百亿自建数据中心，快手不为人知的一面](https://static.leiphone.com/uploads/new/images/20200606/5edb4c99e22f1.jpeg?imageView2/2/w/740)

据介绍，快手乌兰察布数据中心PUE规划为预期最佳1.08，平均PUE1.15，这需要多方面的技术支撑，主要包括IT设备、制冷和供配电。

快手数据中心将采用新一代整机柜服务器设计，集中供电，独立散热，同时兼容整机柜方式和传统方式，采用模块化设计，计算存储解耦分离设计，有效提升单位部署密度，同时提升产品开发效率，打破传统服务器至少一年的研发周期限制，支持新机型快速研发上线。

整机柜服务器将电源、散热、交换等非计算机IT体系结构模块集成在一个机柜中，可以提高机柜空间利用率、提高电源效率、降低服务器能耗水平，整机柜模式还有利于快速交付，与传统的机架式服务器相比，交付效率可提升10倍以上。

制冷方面，快手数据中心计划采用间接蒸发冷却系统，并且规模应用在自建数据中心。制冷系统的能耗约占数据中心总体能耗40%，间接蒸发冷却是目前很多大型新建数据中心青睐的技术，利用直接蒸发冷却后的空气(二次空气)和水，通过换热器与室外空气进行热交换，实现新风(一次空气)冷却，虽然技术门槛较高，但是具备耗水量少（较业内方案节水60%）、节能水平高等优点。

供配电方面，快手将采用高压直流（HVDC）方案，较业内方案降低10%建设成本，HVDC方案将高压直流电直接供给服务器等IT设备，最大化减少电力传输、转换过程中的损耗。

除了IT设备、制冷和供配电之外，快手数据中心快手准备构建新型CLOS网络，采用“单芯片”高吞吐的盒式“交换机”，在数据中心内规模化部署高性能无损以太网（RDMA），将存储网络、AI计算网络、业务网络进行统一融合，支撑大数据、AI、推荐、分布式存储等业务的高速发展。

另外，快手将在自建数据中心内全面规模部署定制化硬件，包括AI(推荐、广告、内容理解)、视频、网络和存储设施等。

雷锋网获悉，该数据中心由快手技术团队自主研发，独立完成整体概念设计，自建数据中心是企业由大变强的标配，租不如买，买不如建，快手选择了一步到位，门槛更高却效果最长久。

从某种意义上，快手正走在和BAT相似的路上，但快手同时又有自己的鲜明特色。

## 九周年的快手

前有Amazon、Google、Facebook和微软等头部互联网公司引领，后有BAT等国内大型互联网公司跟进，自建数据中心已经成为巨头标配。

整体看，架构方面国内外差距逐步缩小，但在清洁能源应用、末端供电技术、监控智能化、运维能力方面海外依然保持一定的先进性。

“我们要更站在未来的角度看现在，因为快手业务发展快，我们被逼着必须得站在未来去看现在，要不然后面会非常痛苦。”快手数据中心技术负责人张子坚表示。

据他介绍，结合快手自身发展情况，其数据中心储备和规划可以分为三个阶段：

第一阶段，从成立到2018年，呈现分散化、小型化的特点；

第二阶段是2019年全年，主要布局在北京及周边，这一年快手数据中心规模直接从国内前十发展到第五，数据中心数量暴涨但仍旧分散；

第三阶段就是2020年之后，快手开始系统性从未来业务发展情况出发，大胆的做五年规划。

“数据中心小且多，成本压力和运营管理压力突出，给业务带来很大的不确定性，基础资源要能支持业务的发展，而不是阻碍它的发展。”张子坚表示。

业务体量大导致数据中心资源供应不及时，这是发生在每个快速增长企业的相同故事，但是快手业务和资源之间的矛盾也显得尤为不同。

以快手数据中心发展的第二阶段为例，仅用一年时间就过渡到第三阶段，在互联网行业也十分少有。BAT自建数据中心时，互联网还处于稳步增长而非爆炸式增长状态，BAT并不十分明确未来的业务模式，这也决定了BAT不会贸然自建超大型数据中心。

但快手不同，数据中心一直处于追赶业务发展的情况，自建数据中心也就不是激进，而是查漏补缺，既然早晚要自建，为何不是现在？

2019年，快手研究院出版了一本名为《快手是什么》的自白书，快手两位创始人分别回答了“快手是什么”的问题。

快手科技创始人兼CEO宿华：“注意力是互联网的核心资源，我们希望尽量让更多的人得到注意力，提升每个人独特的幸福感。”

快手科技创世人程一笑：“快手是一个连接器，连接每一个人，尤其是容易被忽略的大多数。”

在面对诸如快手如何向未来进化等持续不断的提问，快手已经得出了自己的结论。

2017年12月，快手DAU突破1.1亿，快手将之归因为技术驱动带来迅猛增长。2020年6月6日，恰逢快手成立九周年，这一次，快手再次选择了更为硬核的底层基础设施技术。

这不是什么难做的选择题，过去十年，商业模式驱动互联网创新，未来十年，技术才是撬动未来的那根杠杆。

![投资百亿自建数据中心，快手不为人知的一面](https://static.leiphone.com/uploads/new/images/20200606/5edb5038405d8.jpeg?imageView2/2/w/740)

![投资百亿自建数据中心，快手不为人知的一面](https://static.leiphone.com/uploads/new/images/20200606/5edb5038405d8.jpeg?imageView2/2/w/740)

说快手是一家视频公司，其实并不准确，视频是载体，正如文本改变了社会的方方面面，但是没有人会把文本当成一个行业，快手希望视频也能达到同样的目标。

文字能承载的信息，视频同样能承载并且更多。雷锋网观测到，疫情之后这种趋势分外清晰，快手正支持各行各业在快手之上产业化，通过直播给企业和个人提供各种各样的机会。

从另一个维度来说，快手和其他提供数字化转型能力的技术供应商一样，是在帮助各行各业打造数字化的世界，企业、产业和短视频、直播的集合，就是一个线下到线上的连接闭环。

疫情让大家看到了短视频平台+传统行业迸发的新机遇，展望未来，具有高速率、低时延、大容量等特征的5G网络的发展，将为短视频发展和应用提供更充分的基础设施支撑。

短视频、直播等业务模式，或是数字化、产业化的愿景，都离不开数据中心等基础设施，快手不能只在应用层做技术，更要在基础设施层有所作为。

数字基础设施是新的护城河，以十年为度量，快手还很年轻。
