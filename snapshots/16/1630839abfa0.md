# 从“安大简”读“楚文化”

# ——访安徽大学汉字发展与应用研究中心主任徐在国

- 2024-07-05 05:46
- 来源：
安徽日报
- 作者：

武王墩墓揭开神秘面纱，瑰丽雄奇的楚文化热点“出圈”。2015年初，一批珍贵的战国竹简入藏安徽大学。“安大简”是继“郭店简”“上博简”“清华简”之后出土先秦珍稀文献的又一次重大发现，蕴含目前所知时代最早、最为完整系统的楚史资料。安徽大学汉字发展与应用研究中心专家运用“冷门绝学”，解码千年简牍，为您讲述竹简背后的故事，揭示更为清晰生动的先秦历史文化容貌。

淮南武王墩墓上千墨书文字的发现，带动了战国文字及出土战国文献的讨论热度。战国时期是中国传统文化的重要形成时期，战国楚简牍的内容有卜筮祭祷、遣策、法律文书、古书等。遣策是古人在丧葬活动中记录随葬物品或葬仪用物的清单，古书对于传世典籍文本的解读和阐释意义重大。目前，记者了解到，淮南武王墩墓出土楚简以遣策为主，而安徽大学所藏的战国楚简全部是古书，这便是著名的“安大简”。

在周朝诸侯国之中，楚国的文化面貌，兼收并蓄又独放异彩。安大简呈现的大量新的学术信息，是否将会对司马迁在《史记》中一些无法厘清的楚国早期历史、令专家困惑难解的新出材料，提供合理的解释？是否会对楚史研究带来重大影响？

淮南武王墩墓考古发掘正在进行，安大简楚史研究继续发力，“楚墓”之最与“楚史”之最，两者或互为“新证”以待“新解”。记者近日专访安徽大学汉字发展与应用研究中心主任、中国古文字研究会理事、中国文字学会常务理事徐在国，通过安大简为大众提供了解楚世家与楚文化的新视角。

**述录“楚王故事”，消除历史疑云**

记者：淮南武王墩墓考古发掘成果中有很多“文字成果”，比如发现大量墨书文字，又如发现青铜器铭文“楚王酓前作铸金簠，以供岁尝”。楚国王族之姓写作“酓”，除了出现在青铜器上，楚简上有吗？

徐在国：以淮南武王墩墓为例，其墓主人的身份是什么？可以凭借墓葬形制、出土器物进行研判分析，但是如果有文字材料为佐证，对墓主人等相关信息的认定往往会更加明晰准确。这句青铜铭文的关键性信息是提供了楚王的名字，楚王“酓前”“酓悍”“酓章”等也见于其他青铜器铭文，实际上，楚王的名字多见于楚简文字，特别是大量地出现于安大简的楚史部分。

安大简中的楚史部分有一段非常有意思的记载，描述了楚王姓氏来历，非常详实地首次讲述“穴熊”的故事。在这篇文献里，祝融派使者去找季连，但季连躲在山洞不出来，外面的人放火烧洞，季连害怕了，说“酓”。使者回去禀告祝融，祝融说“是穴之熊也”，于是就将季连命名为穴酓（熊）。之后穴熊生熊鹿（丽），穴熊去世后熊鹿即位。根据这个说法，穴熊就是鬻熊，季连也就是穴熊。通过这批简文，解决了早年学界争论不休的季连与穴熊、鬻熊的关系问题，证实了季连与穴熊、鬻熊是同一个人的不同写法。

**解读“楚地”经典，探微中华文脉**

记者：如何“破译”安大简？此前已发布了哪些重要研究成果，通过这些成果可以勾勒出楚地乃至整个中华大地怎样的文化脉动？

徐在国：安大简历经了2000多年的岁月。出土的原简是黑色的，把竹简放入特定溶液里，竹简会恢复到它本来的颜色：竹面为黄色、字体为黑色。我们会根据文字的照片来做整理。竹简的整理要先做“编连”，再做疑难字的考释。分析每个字的形体、比照偏旁，考察每个字对应现今的什么字，认出这个字，并放入上下文看看是否讲得通，如果讲不通，要考虑这个字是不是“通假”？就像前文提到的“酓”读为“熊”一样，再结合上下文，可分析判断出大致的意思。

“安大简”入藏于2015年1月，经清洗整理，共有1167个编号。竹简总体状况良好，字迹清晰。竹简年代约在公元前400年至公元前350年之间，属战国早中期。内容涉及经学、史学、哲学、文学等领域，具体包括《诗经》、孔子语录和儒家著作、楚史、楚辞以及相术等方面的作品。这批竹简的发现，为古代经学史、思想史、楚史、文学史和语言文字研究提供了新的宝贵资料。2019年整理公布的《安徽大学藏战国竹简（一）》，内容为《诗经》。安大简《诗经》是目前已知年代最早、存诗最多的《诗经》抄本。《安徽大学藏战国竹简（二）》于2022年出版，内容为《仲尼曰》和《曹沫之阵》。聚焦楚辞和儒家著作的《安徽大学藏战国竹简（三）》将于明年发布。

“华繁而实厚，天；言多而行不足，人。”这是在告诫后人要谨言慎行、少说多做。务实本分是中华民族的优良品质。《仲尼曰》收录了25条孔子的语录，有的见于今本《论语》，有的可与《礼记》《大戴礼记》《孔丛子》等对照，还有的甚至不见于任何传世文献，失传数千年。安大简中有不少有关儒家的文献，我们可以以这些文献为媒介，传承传播中华优秀传统文化。

**先秦“官修楚史”，目前最早最全**

记者：安大简中的楚史部分受到关注，楚简研究与楚史研究有何重要关联？安大简《楚史》研究将如何丰富我们对于中华文明起源发展历程的认知？

徐在国：目前，考古发现的最早的简牍，就是战国的楚简。当前的研究证实，甲骨文中的“册”，就是竹木简编串成册的象形，与周代的简书一模一样；甲骨文中的“典”，是双手捧册的象形。商朝已存在竹简文书系统，但是迄今没有发现相关的出土文物。战国时期，其他诸侯国的竹简也没有发现，因此，楚简在先秦文献当中的分量是比较厚重的。

楚国早期历史的呈现，过去主要依据《史记·楚世家》。新中国成立以来，大量战国楚简的出土，让这个南方大国的早期发展史越发清晰地呈现在世人面前。近年发现的先秦竹简如郭店简、上博简、清华简、安大简大多是楚简，是先秦珍稀文献的重大发现。

安大简保存状况良好，经初步判读，记载楚史及相关内容的安大简有440多支，不仅数量较大，而且内容丰富。其《楚史》完全聚焦楚国的历史，是目前所知时代最早、最为完整的楚史资料，共有300多支简。简文自“颛顼生老童”始，至楚惠王“白公起祸”止，记载了各个楚王的终立更替和重大历史事件，是一部楚国官修史书。这批材料填补了楚史研究的空白，对于文献中有关楚史的记载可以起到重要的纠错和补充作用，有助于祛除学术领域相关的长期未决的疑虑。

安大简《楚史》以完整史料还原了楚国早期历史，丰富中华文明起源发展的历程，对探究先秦史乃至中华文明史都有巨大的推动作用。

记者 晋文婧
