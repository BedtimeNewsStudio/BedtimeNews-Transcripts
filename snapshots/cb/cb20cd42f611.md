| AI“龙虾”火爆会场内外引代表委员热议 |  |
|  |  |

2026年3月，OpenClaw爆火“出圈”，它不仅登上多个微博热搜，还成为全国两会代表委员热议话题。全国人大代表、中国工程院院士、鹏城实验室主任高文表示，“养龙虾”这么火，连马化腾都没想到——“现在大家急得不得了，生怕没有养上‘龙虾’。”

据了解，OpenClaw昵称“龙虾”，是一款开源AI智能体。AI“龙虾”可以替人执行终端命令、读写文件、收发邮件、管理日程，且这一切在自然语言的对话间完成。它不需要使用者懂代码、操作系统等。

全国政协委员、首都经济贸易大学中国市场主体研究院院长屈庆超8日接受中新社记者采访时表示，AI“龙虾”的爆火并非偶然，以后可能每个人都会“养”很多垂直类智能体，有的智能体负责学习，有的智能体负责规划生活，有的智能体负责工作。它的出现体现了AI发展的新趋势——从问答式大模型到“帮人类做事”，而这一新趋势也将推动监管的同步创新。

AI“龙虾”勾勒未来世界轮廓的同时，似乎也让社会滋生了一丝“不懂就会落后”的担忧。据报道，6日，深圳腾讯大厦楼下，众多市民携带电脑，争相参与AI“龙虾”免费安装活动，场面火爆。

“龙虾”好养吗？全国政协委员、360集团创始人周鸿祎表示，AI“龙虾”把原来看不见摸不着的云上软件，变成了每个人在电脑里养的专属助手，而且操纵起来非常方便。AI“龙虾”现在还在早期，配置AI“龙虾”对普通人来说是一件“非常难”的事，我们很快会发一个一键安装的版本，让每个人养AI“龙虾”都很方便。

全国人大代表、贵州图智信息技术有限公司董事长黄勇认为，对于年轻人，这是提升效率、降低门槛的工具，更是拥抱新质生产力的入场券；对于程序员，AI进阶意味着将从“写代码的人”升级为“定义智能的人”，“年轻人排队抢的不只是一个工具，更是对智能经济新形态的向往”。

对于AI“龙虾”全网爆火，全国人大代表、浙江宇视科技有限公司研究院院长、杭州电子科技大学教授周迪认为，这是技术发展必然性与市场需求的一次完美共振。长期以来，高端AI模型往往掌握在少数巨头手中，且运行成本极高。AI“龙虾”的出现，打破了这种垄断，它证明了高性能模型可以通过更优的架构设计实现“降本增效”，让中小企业和个人开发者也能“玩得起、用得上”。

周迪指出，　AI“龙虾”的成功很大程度上得益于开源社区的协作。这启示人们，在AI时代，封闭的“作坊式”开发已经落伍，开放协作才是加速技术迭代的正途。未来中国AI发展，不仅要有“大块头”，更要有“小精灵”。

“我们不能盲目跟风去拼参数规模、拼算力堆叠。中国AI的出路，在于‘软硬协同、大小结合’。”周迪表示，中国应大力发展像AI“龙虾”这样高效的小型化、轻量化模型，让它们在工业质检、智慧城市、医疗诊断等垂直场景中落地生根，解决实际问题，而不是仅仅停留在“炫技”层面。
