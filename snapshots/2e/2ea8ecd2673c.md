| # 1992年全国教育事业发展统计公报 |
|  |

|  |
| --- |
| 1992年全国上下积极贯彻邓小平同志南巡谈话和党的十四大精神，改革开放步伐加快，各级各类教育蓬勃发展，统计结果表明，1992年我国教育发展势态良好，研究生和本专科教育发展明显加快；职业技术教育有所加强；职工、农民职业技术培训迅速发展；普及九年义务教育稳步推进；高中教育的普及面扩大；特殊教育得到较大发展；幼儿教育取得可喜进展，扫盲教育成果继续巩固。 <br>　　一、普通高等教育<br>　　普通高等教育发展加快，当年招收本专科学生75.42万人，比上年增加13.43万人，年增长率为21. 66%。其中：本科招生34.98万人，专科招生40.43万人，本专科招生比由上年的1：0.88提高到1：1.15；本专科在校生218.44万人，比上年增加14.07万人，年增长率6.89%。其中：本科生132.95万人，专科生85.49万人，本专科在校生的比例由上年的1：0.55提高到1：0.64；本专科毕业生共60.42万人，其中：本科33.21万人，专科27.21万人。<br>　　研究生教育有所发展，当年招生达3.34万人（博士生0.5万人，硕士生2.83万人），比上年增加0.37万人，增长率为12.5%。在校生9.42万人，毕业生2.57万人。<br>　　普通高校招生数中，国家计划招生55.03万人，与上年基本持平。招收自费生和委培生20.12万人，比上年增长1.9培，占当年招生总数的比例由上年的11.2%提高到26.6%。<br>　　本专科招生的科类结构变动情况是：招生比例提高的科类有：财经、文科、工科、艺术，降低的科类是农科、林科、医药、师范、理科、体育，政法与上年基本持平。1992年全国普通高等学校教职工101.36万人，比上年增加0.47万人。其中：专任教师由上年的39.08万人减少到38.76万人，减少0.32万人。师生比由上年的1：5.23提高到1：5.64，专任教师中高级职称比例由上年的25.46%提高到26.85%。<br>　　由于招生增加，学校在校生规模由上年的1901人／校增加到2074人／校。其中高等专科学校从953人／校增加到1051人／校；本科院校从2542人／校增加到2677人／校。普通高校校舍建筑增加524.42万平方米，生均校舍面积由1991年的44.3平方米／人，减少到40.13平方米／人（用折合学生数计算）。<br>　　统计结果表明，1992年高等教育的形势是好的，不仅规模增大，层次结构、科类结构趋于合理，而且委托培养、自费生的比例和师生比都有提高。但是也存在若干值得注意的问题，如：有些地区扩招人数较多，增长过快，投入不足，校外办学点增多；个别地区不顾客观实际，盲目或违纪扩大招生，招生秩序混乱；教师队伍流失严重等。<br>　　二、基础教育<br>　　1992年全国有小学712973所，小学入学人数达到2183.2万人，比上年增加110万人。7至11周岁学龄儿童入学率达到97.95%，比上年提高0.11个百分点。女儿童入学率为96.98%。比上年提高0.02个百分点。小学在校学生数达到12201.28万人，毕业生为1872.35万人。初中招生1491.70万人（其中：普通初中招生1465.01万人，比上年增加53万人，职业初中招生26.68万人，比上年增加近3万人），比上年增加56，54万人，12至15周岁学龄人口入学率达66.91%。初中女学生入学率为64.01%。初中在校学生达到4122.92万人（其中：普通初中4065.91万人，职业初中56.38万人），初中在校生比上年增加109.31万人。小学毕业生升学率达到79. 67%，比上年提高1.96个百分点。普通初中学生辍学率为5.78%，比上年度的5.46%增加0.32个百分点。1992年高中阶段教育共招收学生426.91万人（未包括技工学校），比上年增加10.33万人。普通高中招生由上年的243.82万人，减少到234.73万人，减少9万人；在校生为704.89万人，毕业生226.13万人。<br>　　中小学办学条件进一步改善，全国中小学（含职业中学）校舍建筑面积达到75845.09万平方米，其中：当年新建校舍2831.84万平方米，危房比例由上年的2.75%下降到1.96%。<br>　　中小学教职工增加，小学教师减少。全国普通中学教职工数达411.26万人，比上年增加5.81万人；其中：专任教师314.11万人（初中256.5万人，高中57.61万人），比上年增加5.11万人。小学教职工数略有增加，达到619.9万人，比上年增加0.55万人；其中：专任教师略有减少，由上年的553.22万人，减少到552.65万人，减少0.57万人。<br>　　幼儿教育有所发展，全国有幼儿园17.25万所，比上年增加0.8万所。在园幼儿达到2428.21万人，比上年增加218万人。幼儿园教职工达112.14万人，比上年增加近6万人，专任教师81.5万人，比上年增加4.6万人。<br>　　特殊教育有较大发展，全国特殊教育学校达到1077所，比上年增加191所；当年招生2.95万人，比上年增加0.97万人；在校生12.95万人，比上年增加4.45万人，特教职工为2.7万人，比上年增加0.4万人。其中：专任教师1.85万人，比上年增加0.25万人。<br>　　三、职业技术教育<br>　　中等职业技术教育进一步发展，占整个高中阶段教育的比重继续增加。1992年高中阶段职业技术教育招生占高中教育的比重已达到53.8%，在校生比重达到49.2%。其中：中等专业学校招生87.92万人（中等技术学校63.84万人，中等师范学校24.08万人），比上年增加9.93万人，增长12.72%，在校生为240.84万人（中等技术学校174.28万人，中等师范学校66.56万人），比上年增加13.1万人，增长5.75%。技工学校招生60.18万人，比上年增加5.73万人，增长10.52%；在校生155.6万人，比上年增加13.39万人，增长9.4%。职业高中招生125.46万人，比上年增加11.46万人，增长10.05%，在校生286.38万人，比上年增加23.16万人，增长8.8%。职业初中招生26.68万人，比上年增加2.86万人，增长12.01%，在校生56.38万人，比上年增加4.05万人，增长7.74%。<br>　　中等专业学校招生科类结构变化情况是：招生比例提高的科类是财经、工科、农科、林科、艺术，降低的科类是师范、医药、政法、体育。<br>　　职业高中招生科类结构变化情况是：招生比例提高的科类是财经、医药、其他，降低的科类是农科、林科、政法、体育、艺术、师范。<br>　　中等专业学校教职工数达到50.3万人，比上年增加0.19万人，专任教师达到23.51万人，比上年增加0.28万人。中等师范学校专任教师略有减少，由上年的5.72万人减少到5.7万人。<br>　　职业中学教职工数达到37.63万人，比上年增加1.79万人。专任教师24.8万人，比上年增加1.33万人。<br>　　四成人教育<br>　　成人高等学校共1198所，招生数达到59.17万人（包括成人学校普通专科班招生3.57万人），比上年增加12.62万人，增长27.11%。其中：本科5.55万人，专科53.61万人。成人高等学校在校生达147.87万人，毕业生51.77万人。<br>　　在成人学历教育中，电大、函授、夜大招生增长比较快，职工高校比上年略有减少。<br>　　成人高校教职工数为20.6万人，基本与上年持平。其中专任教师也有减少，由上年的8.92万人减少到8.89万人。<br>　　成人中等专业学校招生有较大增加，招收学生71.31万人，比上年增加6.11万人，增长率为9.39%，在校生达174.43万人，比上年增加6.39万人，毕业生48.66万人。成人中等学校中，教师进修学校、函授中专、农民中专、干部中专分别比上年增招3.59、2.49、1.14、0.98万人，电视中专、职工中专分别比上年少招1.92、0.24万人。<br>　　成人技术培训学校继续快速发展，招生4541.84万人次（其中：职工技术培训学校招生585.31万人次，农民技术学校招生3956.53万人次），比上年增加1074.21万人次，增长31%。<br>　　成人文化补习学校相应减少，成人中学学校数共6071所，比上年减少660所。招生人数53.99万人，比上年减少22.18万人，在校生68.82万人，比上年减少21.05万人。成人小学校数共45630所（未包括扫盲），比上年增加654所。招生243.40万人，比上年减少19.46万人。在校生276.18万人，比上年减少14.52万人。<br>　　扫盲教育成果继续巩固，全年扫除文盲523.31万人，目前有552.71万人参加扫盲学习。扫盲教育教职工数达9.65万人，其中：专任教师2.79万人。
