| |  | | --- | |  |  |  | | --- | | 酒局吹牛牵出荒唐骗局 |  |  | | --- | |  |  |  | | --- | | **日期：**2026年06月03日    **作者：**傅杰 来源：检察日报    **字号：**[大](#) [中](#)[小](#) |  |  | | --- | | 14人打卡“上班”数月，一分工资没拿到还倒贴烟酒现金  酒局吹牛牵出荒唐骗局  　　酒局上吹的一句牛皮，竟上演一场荒唐诈骗，11名退休老人、3名年轻人，只因轻信一句“能帮忙找到地铁站工作”，不仅白白“上班”数月，还主动送烟送酒送现金，最终落得人财两空。经上海市奉贤区检察院提起公诉，近日，法院以诈骗罪判处被告人钱某有期徒刑六个月，缓刑一年，并处罚金4000元。被告人未上诉，目前判决已生效。  　　2024年6月的一天，在一次酒席间，钱某借着醉意吹嘘，称亲戚承包了上海地铁5号线的第三方服务，正在招收第三方工作人员，自己可以帮忙安排入职。  　　说者无心，听者有意。听闻此消息的姚女士等14人纷纷找上门来，请他帮忙。钱某骑虎难下，为了圆自己酒后的谎言，也为了继续享受众人的恭维和追捧，干脆将错就错，给这些人安排了“工作”：14人分批轮班，每天不定时间段前往5号线奉贤段的不同地铁站，负责检查站内工作人员在岗情况，同时帮助老幼病残孕乘客搬运行李等，许诺每人每月工资6000余元。  　　为了让这份“工作”更加真实，钱某煞有介事地设计了一套“完整工作流程”：他要求14名“入职人员”每天上下班时在地铁站门口的监控探头下敬礼打卡，营造正规工作的假象；随后还安排了“入职考试”，拿出录像设备对考试全程录像，称考试不通过就不能转正。  　　其间，钱某暗示这份工作“来之不易”，姚女士等人心领神会，或为了感谢钱某“牵线搭桥”，或为了通过“入职考试”，纷纷向其赠送烟酒、礼品券及现金等。  　　然而，姚女士等人按照钱某的要求“上班”数月后，迟迟没有拿到工资。他们找到钱某追问情况，钱某这才将实情说出。2025年1月，姚女士等人随即报警。  　　到案后，钱某如实供述了自己的犯罪事实及动机：“我不认识地铁站的工作人员，也没有能力介绍工作，只是为了享受别人恭维我、把我当领导的感觉。”  　　经查，钱某以介绍地铁站工作为名实施诈骗，共骗得21条香烟、6瓶白酒、3500元现金以及价值1000元的消费卡。经协商，钱某退赔了部分礼品、礼金，支付了部分拖欠的工资并取得被害人谅解。 | |  |  |  | | --- | |  |  |  | | --- | | **上一篇：** [“代发论文，包过审核”，这也能信？](/xwdt/yasf/134140.jhtml) | | **下一篇：** [巧言狡辩难掩售假事实](/xwdt/yasf/134080.jhtml) |  |  | | --- | |  |  |  | | --- | |  |  |  | | --- | |  |  |  | | --- | |  | |
