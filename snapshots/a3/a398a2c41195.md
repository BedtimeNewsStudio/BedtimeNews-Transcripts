# 月底开战！2025中国乒超联赛厦门站开票

来源：东南网 \| 作者：朱黄 郑丽金 \| 时间：2025-07-15


|     |
| --- |
| **月底开战！乒超联赛厦门站开票**<br>东南网7月15日讯（海峡导报记者 朱黄 郑丽金）2025中国乒超联赛常规赛第二阶段即将登场。15支乒乓球俱乐部队伍，将于7月25日至28日集结厦门奥体中心凤凰体育馆，展开新一轮较量。首轮门票发售在7月15日正式启动。<br>赛事全程采用奥运会团体赛方式，以5场3胜制进行，单场比赛采用5局3胜制。男子团体赛有9个俱乐部参加，女子团体赛有6个俱乐部参加。常规赛将进行双循环赛制，常规赛排名前四的俱乐部晋级到总决赛阶段。<br>本赛季乒超联赛设男、女团体赛，各俱乐部注册球员是否会代表各自队伍参加本次比赛，要到赛前7天才能确认。比赛期间，每个团体赛对阵名单待双方提交后，最迟于赛前1小时公布。<br>赛事全程4天，每天设置上午（10:30开球）和下午（18:30开球）两个场次。门票按场次发售，设置7个票价档位，匹配观众的多样化购票需求。最低价的G档门票仅88元，A档门票788元。赛事另设单日通票和全程通票，分别包括单个比赛日两个场次的A档门票，以及所有8个场次的A档门票。儿童购票按全价票处理。<br>首轮门票发售在7月15日正式启动，17:00和17:30将先后开售全程通票和单日通票，数量有限，售完即止；18:18起开售所有场次门票。全程通票、单日通票仅在秀动网发售，各场次门票则在秀动网、看个比赛两个平台同步发售。<br>以上售票平台为乒超联赛常规赛第二阶段仅有的官方票务平台，购票时请认准官方正规票务渠道。在非官方渠道购票导致无法入场等后果均由购票者自负。<br>赛事实行实名制电子票观赛，不支持门票转让。退票采用分阶段机制：7月15日18:18至7月16日23:59期间内无条件全额退票；7月17日00:00至7月18日23:59期间内退票将收取票价30%的手续费；7月19日00:00至7月21日23:59期间内退票将收取票价50%的手续费；7月22日00:00后不再接受任何理由的退票申请。 |
