# 福耀玻璃欲涉足光伏玻璃业务 拟募资33亿

2021-01-09 21:28:38来源： [财新网](http://companies.caixin.com/2021-01-09/101648733.html)作者：赵煊责任编辑：范若红

2021年01月09日 21:28

来源于
[财新网](http://www.caixin.com/)试听

福耀玻璃拟增发1亿股H股，约合人民币33亿元，布局国内光伏玻璃业务；光伏玻璃行业目前正在经历供不应求，价格飙涨，以及行业扩产潮

![](https://img.caixin.com/2021-01-09/1610199342908672_480_320.jpg)1月8日晚，福耀玻璃工业集团股份有限公司公告，公司拟新增发行H股不超过1.01亿股，募集资金将用于补充营运资金、扩大光伏玻璃市场等。

**【财新网】（记者 赵煊）** 全球规模最大的汽车玻璃供应商欲开拓国内光伏玻璃业务。1月8日晚，福耀玻璃工业集团股份有限公司（600660.SH/ 3606.HK，下称 [福耀玻璃](http://www.caixin.com/hot/fuyaoboli.html)）公告，公司拟新增发行H股不超过1.01亿股，募集资金将用于补充营运资金、扩大光伏玻璃市场等。

1月8日，福耀玻璃H股报港币45.8元/股，较前一交易日上涨4.21%。以公告当日港股收盘价预估，福耀玻璃此次募资金额将在港币40亿元（约合人民币33亿元）左右。当日，公司 [A股](http://search.caixin.com/search/A%E8%82%A1.html) 盘中最高触及53元/股，创历史新高，截止收盘，福耀玻璃A股报51.48元/股。
