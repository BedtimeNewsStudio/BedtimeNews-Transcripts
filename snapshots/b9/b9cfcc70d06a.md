# 大方奢香古镇：文化产业焕发新活力

2020年10月13日16:32

分享到：

|  |
| --- |
| 搬入奢香古镇的安毅一家。李粤平 摄 |

面对大方县贫困面大、贫困程度深，扶贫开发任务艰巨的现状，在中央、省、市各级领导的关心下，2005年12月引进恒大集团对大方县实行整县帮扶。其中，在易地搬迁扶贫工作中，恒大集团与大方县委政府因地制宜修建的奢香古镇，成为文化事业和文化产业发展助推脱贫攻坚的生动案例。

**融入文化因地制宜建古镇**

大方县属于典型的喀斯特地貌，交通闭塞，居住在深山区、石山区的群众过着“一方水土养不起一方人”的艰苦生活，易地移民搬迁成为脱贫措施中的一项重点工作。恒大集团和大方县坚持节约集约使用土地的原则，选择了原顺德街道办事处白石村一片荒无人烟的山丘，这片山丘的正中位置是一个巨大的积水洼地，被当地人称作“麻窝”。正是在这样一片外行人看不上的地方，被恒大集团用两年时间修建出了奢香古镇，位于正中位置的“麻窝”如今被修建成了“全国唯一城中花海梯田”。

修建好的奢香古镇占地1500余亩，充分融入大方县历史文化及奢香古彝文化，各种设施配套完善，是集移民安置、旅游观光和商业服务于一体的项目。分为南区（奢香印记）、北区（古镇遗风）和中区（都市禅心）三大主题商业街区，配有八大主题文化广场、十大艺术塔楼，充分展示了非物质文化遗产及彝族文化，从南至北由旅游步道和观光车道紧密环接约2.3公里，景色迷人、四季飘香。古镇建筑面积约48.9万平方米，其中易地扶贫搬迁27.6万平方米，安置贫困户2880户12507人；商业部分6.3万平方米，涵盖商铺、客栈、活动中心、博物馆等设施；公共建设部分15万平方米，涉及幼儿园、小学、中学、职业技术学院、医院、敬老院和儿童福利院等，同时，组建了九驿街道办事处，文化中心、文化书屋、全民健身广场、就业创业服务中心、道德讲堂、法律援助中心等社区文化设施全面覆盖。

**整合资源保障群众乐搬迁**

奢香古镇建好后，如何让群众愿意搬进来，搬进来以后能否住得下？奢香古镇在选址上充分整合了教育资源和医疗资源，配套建设学校、医院，让每一户搬迁入住家庭的子女在家门口就能入学，在家门口就能就医。

为了增加群众经济收入，奢香古镇在配置商业街和旅游观光区的基础上，积极招商引资，大力发展旅游业，同时与周边企业联手，让所有搬迁入住的贫困劳动力都有固定工作和稳定收入。

为了更好地实现就业，奢香古镇社区专门成立了就业服务中心，对搬迁群众开展技能培训。目前，集中开展技能培训158期，培训搬迁群众4056人次；统筹整合各级各部门力量，创新开发护路、护林、护河、护赛、治安巡防等扶贫公益岗位，解决就地就业1100余人；依托县劳务总公司和25个乡镇劳务分公司，向福建、广州、浙江等地输出3500余名技能人才，已解决易地扶贫搬迁劳动力就业7000余人，基本实现有劳动力的搬迁户“一户一人”以上稳定就业。

截至目前，大方县奢香古镇和50个恒大幸福新村已安置群众4878户，20910人世代居住在大山深处的老百姓搬出了大山过上了幸福的日子！

**夯实载体以文促旅助脱贫**

为了让文化产业促进旅游产业的发展，大方县以奢香古镇为主要活动场所，举办了一系列文艺活动，让根脉相连、枝繁叶茂的水西文化与全县经济社会发展得到深度融合，传承弘扬好源远流长、博大精深的水西古彝文化。文艺活动中举办彝人欢歌派对、古彝剧幕彝族山歌、杂技表演、走秀等节目，还有名家论道、古乐表演、书法演绎、画作展览、摄影创作、原创歌曲演出等活动，为全县人民奉献出一台台精彩的视听盛宴。

为了满足搬迁入住的贫困群众精神上的需求，奢香古镇所在的九驿街道办事处还开展了丰富多彩的活动，助推文化事业的发展。自奢香古镇建成以来，每年在春节、端午节、七夕节、中秋节、重阳节、彝族祭水节、火把节等民族传统节日及周末、劳动节、国庆节等法定节假日期间，举办了一系列的主题活动，在丰富搬迁群众精神文化需求的同时，大力传播社会主义核心价值观，让搬迁入住的贫困群众重新融入一个社区，组建成一个和谐幸福的大家庭。

通过举办各式各样活动的同时，也促进了旅游业、商业和手工业等的发展，如今，奢香古镇商业一条街的各种手工艺品、民族文化饰品、美食特产等一应俱全，已于2018年12月成功创建为国家AAAA 级景区，每年吸引全国乃至世界各地的游客前来旅游观光。（大方县委宣传部）
