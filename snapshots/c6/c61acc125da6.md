# 副部级高官任上落马，任职地多名前下属被查

佟西中　　2026-03-31 11:13:30

打“虎”不停步，广东省政协副主席郭永航任上落马。

3月27日，中央纪委国家监委网站发布消息，广东省政协党组成员、副主席郭永航涉嫌严重违纪违法，目前正接受中央纪委国家监委纪律审查和监察调查。

郭永航长期在广东省工作，担任过深圳市委常委、秘书长，珠海市委书记，广东省副省长，广州市市长，广东省委常委、广州市委书记，广东省政协副主席等职。

**十天前仍参加省政协会议**

十天前，郭永航仍参加了省政协会议。据广东省委机关网南方网报道，3月16日，广东省政协召开党组（扩大）会议暨十三届四十一次主席会议，省政协副主席郭永航作交流发言。

郭永航生于1965年10月，山东济阳人，20世纪80年代在武汉大学历史系就读，毕业后成为广东省深圳市委宣传部的一名科员。

之后，他在深圳市委组织部、深圳市委办公厅秘书处历练，2002年3月出任深圳市委宣传部副部长，2009年8月出任深圳市委副秘书长。

此后，郭永航主政深圳市盐田区，任区委书记，2015年5月成为深圳市委常委、秘书长。担任深圳市委常委、秘书长近3年，2018年2月转战珠海市任市委书记。

2021年10月，时年56岁的郭永航任广东省副省长，2022年1月任广州市市长，2023年6月任广东省委常委、广州市委书记。从2021年10月算起，不到两年时间履新三个岗位。

主政广州市两年半后，今年1月，郭永航转任广东省政协副主席，约两个月后，他在任上落马。

郭永航官宣被查当日，广东省委常委会召开会议，通报郭永航涉嫌严重违纪违法、接受中央纪委国家监委纪律审查和监察调查有关情况。与会同志一致表示，坚决拥护党中央决定，坚决拥护中央纪委国家监委决定。

会议强调，各级领导干部要始终从严要求自己，带头强化理论武装、带头严守纪律规矩、带头廉洁自律、带头接受监督，切实做到严于律己、严负其责、严管所辖。

3月27日，广东省委常委会会议召开后，广东省政协主要领导即主持召开省政协党组扩大会议，通报郭永航涉嫌严重违纪违法、接受中央纪委国家监委纪律审查和监察调查有关情况。

与会同志一致表示，坚决拥护党中央决定，坚决拥护中央纪委国家监委决定。

会议提到，要深刻汲取教训，做到警钟长鸣，严守纪律规矩，严格落实中央八项规定及其实施细则精神，做到党中央提倡的坚决响应、党中央决定的坚决执行、党中央禁止的坚决不做。

**主政地珠海，多名前下属被查**

回顾郭永航的仕途生涯，他在广东工作时间超过36年，其中在深圳工作超过28年，主政珠海市约3年9个月，任广州市市长近一年半，主政广州市约两年半时间。

近期，在他曾经的任职地，多位与郭永航有工作交集的干部被查。去年12月，已退休五年的深圳市政协原党组书记、主席戴北方被查。

资料显示，戴北方长期在深圳市工作，担任过市委常委、宣传部部长，市委常委、秘书长，市委常委、组织部部长等职。戴北方任市委常委、秘书长时，郭永航曾任深圳市委副秘书长。

今年1月初和2月下旬，珠海市委常委、统战部部长郭才武，珠海市二级巡视员梁兆雄接连被查。

资料显示，郭永航任珠海市委书记时，郭才武任珠海市委常委、统战部部长，梁兆雄先后任珠海高新区管委会党委副书记、珠海市信访局局长。

公开报道显示，郭永航曾推动珠海市市属国资企业改革。珠海市政府印发的《珠海市市属国有企业重组整合方案》提到，要通过股权整合、资产置换、无偿划转、战略合作等方式，调整优化国有资本结构，推动国有资本战略性调整和重组。改革完成后，珠海市属国企数量正式由16家变更为12家。

近年来，珠海市国资系统多人被查。2024年7月，时任珠海市工业和信息化局局长李丛山被查。郭永航任珠海市委书记时，李丛山任珠海市国资委主任，操盘市属国有企业改革。

珠海市纪委监委官网信息显示，从2024年7月至2025年12月底，珠海市至少有10名国有企业董事长、总经理、副总经理等企业高管被查。
