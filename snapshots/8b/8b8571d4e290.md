# “上学太耽误学习”，鸡娃家长又下猛药

![图片](https://inews.gtimg.com/news_bt/Oh7IOIWVnpjjQqdEXcwaSg96dTW8Oehp9z2A0U6sXIy98AA/641)

作者\|黄泽敏

编辑\|向现

一年级开学报到首日，周若便向班主任申请：女儿下午不再到校，每天只上半天学。

老师追问理由。周若起初想以病假托词，但“什么病能请6年？”她索性直白表明：“孩子下午有自己的学习进度，来不了。”

她的态度明确：“如果学校要求必须出具医学证明，我可以出，要什么证明我给什么证明。如果不需要这个证明，我就天天请假。”最终，学校让她签了一份保证书，同意让她中午把孩子接走。

周若从事教培工作13年。女儿三岁开始识字，幼儿园中班下学期便到机构学习数学。如今，女儿升上一年级，已经超前学习了校内知识。在周若的判断里，全天在校反而拖慢孩子的学习节奏。

类似的选择，正在多地中小学出现。前段时间，“小学生只上半天学”的话题引发热议。一位海淀家长给出的理由同样直接：“上学太耽误学习。”

![图片](https://inews.gtimg.com/news_bt/Oj5INKXEvw3GznfWMxK84utL9VhdlfJBLQFvRRPL0HlGEAA/641)

质疑者认为这是“过度鸡娃”，甚至怀疑是培训机构的营销文案。也有人表示理解，将中小学课堂比喻为“一辆火车车厢”——大家的起点和终点本就不同，“不用眼看着谁家乘车期间做了什么”。

事实上，早有家庭开始这类尝试。对这些家庭来说，孩子少上的半天并没有因此空下来。他们希望为孩子开辟一条更适配个体的路。

# 01“大锅饭哪有小炒香”

长春的毛俪桦，数年前就开启了半日上学的尝试。儿子中午离校之后，她会为孩子制定每日任务清单。

一次，她和丈夫外出，留孩子独自在家，并预先布置好了学习任务。等两人回家却发现，任务没有完成。

家里有一台可以看视频的设备。平时，毛俪桦允许孩子每天看20分钟，看完告诉她。孩子有时超时，她通常睁一只眼闭一只眼。

那天，孩子说自己看了大约40分钟。回看监控，毛俪桦才发现，他看了近两个小时。学习任务因此耽搁。

![图片](https://inews.gtimg.com/news_bt/OJ5qyI4QL51sRv70ovWbKNyyg5MYZ3Qx5wwnHGlerLh3YAA/1000)请假的日子里，毛俪桦有时会错峰带儿子去旅行/受访者供图

孩子父亲知道后很生气：“你如果没有这样的自控力，下次我们不会再让你单独在家了。”儿子没有接话，只默默去完成剩下的任务。

儿子知道家里装了监控。不在家时，毛俪桦不时打开监控，看孩子是否在学习。有时，她会通过监控喊话，让儿子用读写台写字，以免加剧近视。

这套管理模式，是半日就读之后逐步成型的。

三年级时，儿子近视接近300度。医生建议增加户外活动时间，她以此申请提前接走孩子。下午两点离校，之后又提出中午接走。请假过程相对顺利。

毛俪桦自认幸运，遇到一位愿意因材施教的班主任。她猜，孩子的成绩，也是老师愿意配合的前提。“我们一直在年级第一的位置，有一次还考了5科的全满分。”成绩同样是她请假的底气。

从那以后，孩子中午离校，用餐后，先安排游泳、跳绳，或是公园户外活动。下午三点多回家练琴，再进行文化课学习。多年下来，她摸索出一套适合儿子的安排。

![图片](https://inews.gtimg.com/news_bt/OTeJ4zWX-czkZf7f9Mh1KvLqkSE30OrVefeJJpF-0-phYAA/1000)毛俪桦给儿子做的每日安排

毛俪桦把学校形容为“大锅饭”。“它针对的是大多数的孩子，不可能兼顾到每一个人的口味”，而“大锅饭哪有小炒香”。

上海的陶萍选择半日就读，则源于孩子更具体的困境。

起初，孩子在幼儿园精力旺盛，午睡时常常睡不着，只能被安排在一旁或小房间里休息。她觉得，与其让孩子在那里无所事事，不如早点接回家。

升上小学后，孩子确诊ADHD合并读写障碍。标准化的课堂进度很难匹配孩子的特殊需求。陶萍最终决定，让孩子上午留校，跟随集体上课，下午回家开展针对性训练和学习。

这个决定意味着她必须放下工作。陶萍做了20多年的期货操盘手，大学毕业便进入这行。这份工作收入不错，这么多年来，她也很喜欢这份工作。但“工作和陪伴很难兼得”，犹豫了近一个月，她最终辞职。

![图片](https://inews.gtimg.com/news_bt/Of4jlfHUt9155AenV9aEQ2ihNYvxcbgciYL3UZkTHXf8EAA/641)

如今，孩子每月运动、学习等相关支出约2万元，主要由丈夫承担。谈起两人的分工，她笑称：“丈夫虽然全程不管任何教育，但是出钱，出钱的时候没有任何意见。”

陶萍希望通过下午的陪伴和训练，给孩子搭一个“脚手架”，让他将来能够更好地融入学校和社会。

# 02超前学，停不下来

更多家长，把离校的半天用于“学习”。周若女儿不在校的下午，编排得满满当当：周一学数学，周二学英语，周三学英语和国学，晚上再加一节外教课，周四学英语和阅读。

周五不安排文化课，周若会带女儿出门玩，下午去学舞蹈。周六休息，周日上午复习一周所学，下午继续英语和舞蹈。

课程大多持续到下午四点半。结束后，周若会带女儿进行一小时户外活动，再回家吃饭、写作业、练舞，直到晚上九点半左右休息。

![图片](https://inews.gtimg.com/news_bt/OANzBwEiEOYh87tCKBs2zlpLIPLSkb3iKH33XBmxUZTAYAA/641)周若的女儿正在练习舞蹈/受访者供图

这套主科的学习安排不只有女儿参与。一同上课的7个孩子，分属石家庄不同小学，目前以一、二年级为主，都只上半天学。

这些孩子都超前学习。幼儿园阶段，他们就已经开始学小学阶段的知识。因此，他们离开学校沿着另一套进度学习和训练。

“小学知识密度太低，中学知识密度太高。”周若说。在她看来，小学和初中的学习节奏有明显断层，初中科目增多、难度跃升，如果等到升上初中再发力，课业和考试会挤在一起，孩子难以兼顾。

多年英语教学经历里，她见过大量小学阶段就学完中考英语内容的学生。据她了解，当地不少孩子到了五、六年级，便会请半天假到校外机构学习，提前完成课程的情况并不少见。

![图片](https://inews.gtimg.com/news_bt/OzCA9cNc3qhiNYEPbWJLQ43j-0eWNV2NNdsJ7xyDkoADIAA/641)

“超前学是最科学的。”按照她的规划，女儿将在三四年级学完全部小学课程，六年级学完中考内容。

低年级学生在下午本就少有主课。周若觉得，时间本就有限，不如自行用起来。“退一万步说，（学校）下午有主课能咋地，哪个不会？”周若反问。

毛俪桦持有相似看法。“学校低年级下午没有主课，这也是我们当时特别大胆请假的原因。”她说。

儿子出生后，毛俪桦辞去工作，开始全职在家研究早教。儿子一岁起，她便在家里放英文音频，坚持亲子阅读。她说，进入小学前，儿子的英语听说能力已接近小学高年级水平，识字量约有四五千字。

在校内，儿子成了同学们口中的“袁神”。毛俪桦回忆，四年级下学期，儿子做高考英语试卷时，阅读和听力基本已经不会出错。

![图片](https://inews.gtimg.com/news_bt/OMyEX8duxzxfPdFVGotu4I6cLHeLVSKlLkDhAKuvMhxhMAA/1000)毛俪桦的儿子/受访者供图

数学也在往前赶。四年级上学期，儿子已经学完小学数学。到了五年级上学期，儿子提前把初中数学完整学了一遍，之后逐渐接触奥数等更深入的内容。

这套安排投入不菲。为更好地学习，家里购入了学习机、网课设备，还请了外教老师教英语。儿子升上高年级后，又增加了语文直播课、数学线下课，钢琴、体能训练也没落下。

“至少要四五十万。”毛俪桦说，“要是全部都找一对一，或者全部都去线下课，我感觉这个数下不来。”

但她认为投入值得。如今，本该就读六年级的儿子，跳级插班到一所民办初中，就读初一。“他这次小升初能够一下就上岸，我觉得也和他在家里头的积累是有关系的。”毛俪桦说。

# 03“全社会都在推着这件事”

周若对女儿的升学路径有着清晰规划。她希望女儿能够上重点高中，未来至少考入一所“211”院校，如果国内升学不理想，也考虑留学。

她不执着于具体专业，毕竟“也不一定（按照）专业就业”。比起将来学什么，她更在意女儿会进入怎样的环境，接触什么样的人。

“上了重点高中，不学习的孩子会少非常多，这些孩子的意志、品质以及家庭托举，就会好很多。”在她看来，“留学也好，中高考也好，是筛选周围的人。”

![图片](https://inews.gtimg.com/news_bt/ORU69LqMprAtIVazP_A5EyFWZ20dHr2oUnfeYxAgA-am4AA/641)

但她也不希望女儿只为学习而活。她接触过一些学生，白天上课，晚上还有晚自习，回家后继续写作业。有学生身体不舒服，仍不得不坚持完成作业，“连病都病不起”。

“孩子得活得像个人。”周若说。提前完成文化课的目标，正是为了预留未来的缓冲空间，“起码初中内容都学了，（将来）病了能休息，成绩也尚可”。

周若尽可能拓展女儿的生活边界。家里放着木工台、缝纫机、健身架、吊环和浪板。学习之余，女儿做手工，参加过儿童独立营，也会和朋友去户外活动、打桌游。

![图片](https://inews.gtimg.com/news_bt/O-guGzx2hk63iB9AbQF4mRsQjMcXAvwniNMoH5yAi9sLgAA/1000)周若女儿的手工桌/受访者供图

只是，想要保有未来的余裕，眼下的文化课不能落下。为了让女儿学习，她想尽办法。

幼儿园时，女儿有段时间不想学习。周若便告诉她，不学习也可以，但要能够养活自己。周若带女儿去找工作，没人收，便让她捡废品谋生。

第一天，母女俩翻出家里所有废品卖掉，只换来五块多钱。女儿拿钱买了水和饼。几天后，女儿哭着说想学习。

今年，女儿再次疑惑，是否能依靠收租、种地来生存。周若听后，租下一块100平方米的地，每天喊女儿早起翻地。才到第二天，女儿便想继续学习，想尝试别的职业。周若没有立刻应允，坚持让她完成劳作。母女俩连着吃了三天水煮菜和馒头，又种了好些白菜、萝卜。

![图片](https://inews.gtimg.com/news_bt/OOQRymadftedE_DYpWCMDU-CClMYrhCRpNrJDDYEqVNv0AA/1000)周若的女儿正在翻地/受访者供图

她理解女儿的情绪。“学习就是反人性的。”在她看来，正因为学习不易，才更需要外力推着孩子坚持。

这份坚持落到日常，也需要周若亲自做许多事。错题需要整理、讲解，舞蹈老师教过的动作回家还得反复练。除此之外，落在她身上的事情还有很多。

周若曾发来女儿学习后空翻的视频。视频里，孩子小小的身躯一次次向后翻，始终没有成功。翻着翻着，她嘴一撇，脸皱起来哭了。很快，她又调整好，继续尝试。

周若记得，女儿刚学舞时，因哭得太大声，邻居还来敲过门。

“你说不心疼吗？也真的是心疼。”她说。但她觉得，孩子总要独自面对困难，“我不能替她生存”。

女儿的学习和训练还要继续推进，周若也得一直跟在后面。“妈妈不坚持就散摊子了。”她说。

![图片](https://inews.gtimg.com/news_bt/Ot1evyyV5r-HZT1dVCq97mPVYAyNT5WQLA3kpQHHeEX3UAA/641)周若带女儿一起做的手工/受访者供图

周晓芳也看过许多“坚持”的家长。但她看到的，还有大量被学业压垮的孩子。她在广东一座三线城市合伙运营一家工作室，进行全科辅导。

从业4年，她接触过不少休学学生，近两年这类案例明显增多。她说，部分学生返校后出现躯体化症状，难以适应正常课堂。

她常劝说家长，先让孩子休息一段时间，却很难得到认同。家长普遍认为，孩子成绩已经落后，更不能停下学习。

她从一些孩子脸上看到麻木。许多人坐在教室，不愿意配合行动，甚至只是坐在那里一声不吭。“我现在面对的孩子，（成绩）属于中下层级的孩子，可能十个里面，八九个都是这种状态。”她说。

![图片](https://inews.gtimg.com/news_bt/ObXBzJ9rGseRDl28AAl6fQoZ7XzmgSOXo1bPwP3g_eOCoAA/641)

有时，为了满足家长的提分诉求，重建学生的学习自信，她会讲授应试答题技巧，比如利用作文押题，或教孩子套用模板，即便学生不具备完整写作能力，也能在考试中拿到高分。

在她看来，这种方式能产生结果，但不是理想的教育方式。“可是没办法，无论学校、家长、学生，全社会都在推着这件事。家长要看得到结果，学生也希望不那么努力就能取得结果，因为这会让学生有信心。”周晓芳表示，“我要生存的话，也得迎合着这件事。”

# 04半天假，也有边界

周晓芳在这套评价体系里谋生。但她不想让女儿的学习也被考试和分数牵着走。从一年级下学期开始，只要下午没有重要课程，周晓芳便给孩子请假，将时间留给非学科类拓展。

孩子喜欢天文和手工。周晓芳曾设想月球代步观光车的方案，与孩子一起学习。孩子搜索视频、查找资料，也会借助AI讨论。在这个过程中，她接触到了重力的概念。原本抽象的初中知识，因为一个需要解决的问题，成了可理解的对象。

除了月球车，周晓芳还会根据孩子的兴趣设计其他项目。她带孩子去博物馆、爬山，观察岩石和植物，也让孩子在家组装小车、制作消防安全手册，甚至借助AI尝试做小程序。有时，她会先给孩子设定一个角色，再提出问题，让孩子自己寻找解决办法。

![图片](https://inews.gtimg.com/news_bt/O0ONaWS7LcF8iDcKIe0ZJgofOzlksGvaB85FEGJLwk3lgAA/641)周晓芳的女儿正在给小车安遥控组件/受访者供图

在这个过程中，孩子需要查找资料、思考、表达，也会接触到超出当前年级的知识。这与“奔着分数去的超前学”不同，她希望女儿拥有“学习”的能力，而非考试的能力。

这份认知，源自她自身的职场挫折。周晓芳曾是一家企业的高管。但2022年后，受疫情和AI冲击，她失业了。

当时，年过30岁的她重新求职，却发现自己所在的城市岗位有限，年龄也成了一道门槛。过去的学历和工作经历，并没有给她带来想象中的保障。

“我不想孩子在这个浪潮里，最终被冲上岸然后干涸掉。”在周晓芳看来，学历无法保障一个人的一生，持续学习和适应变化的能力更重要。

不过，关于孩子就读半日的决定，远非家长与班主任之间的口头约定那么简单。

![图片](https://inews.gtimg.com/news_bt/O7LzT23TPkGYp1LsAgY2LrpDb-4joBs_f5Pgk54fN-IM0AA/641)《银河补习班》剧照

21世纪教育研究院院长熊丙奇区分了课后服务与正式教学。“课后服务本来就不是全员强制参与，家庭可以结合自身情况选择不参加，这是正常的。”他表示，“但有一个前提不能忽略，国家规定的义务教育必修课程，学生必须在校完成，不能缺课。”

他解释，义务教育阶段，国家规定的全部必修课程都应当完成，不仅包括语文、数学等学科课程，也包括音乐等课程。如果学生把下午的正常教学课程全部停掉，从义务教育课程完成的角度看，存在违反义务教育法相关要求的风险。

“学校目前的教学方式，很难解决家长所有个性化的教育需求，这是客观现实。”熊丙奇说。

现实中存在的各类在家自学、请半天假等做法，实际上仍游走在灰色地带。

“我希望孩子有个好的教育环境，让她能够健康快乐成长的同时，也能学习到知识。”周晓芳说，这是她对教育的设想。

![图片](https://inews.gtimg.com/news_bt/OzaQBSgVWMfAyOi8CBlXQsaZBFK2rDA5eggQ7adENtONwAA/641)《银河补习班》剧照

现阶段的教育环境并不能满足她的期待。因此，她把孩子带离学校。但她也没有完全抛弃校园生活。女儿就读三年级，每周有三四个下午不在学校。如果下午有主课，或者随堂测验等，就不请假。

她不急着让女儿马上拥有好成绩。她常告诉学生和家长，成绩是需要一步步往上提的，“就像人不是吃第6个饼就能饱，而是要把前面的5个饼都吃进去，吃到第6个饼才会饱”。

周晓芳希望女儿能保持喜欢学习的状态。目前，女儿读完一本书，会主动和她分享。学会一个新知识、技能时，女儿脸上也能明显看到成就感与快乐。

“我希望我女儿能保持这种状态。”周晓芳说。
