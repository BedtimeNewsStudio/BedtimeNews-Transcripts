| # 德州市2018年国民经济和社会发展统计公报 |
| 时间：2019-03-21 19:36:04　来源：德州市统计局　作者：　点击：6344次 |

|     |
| --- |
| 德州市统计局<br>国家统计局德州调查队<br>2019年3月18日<br>2018年，全市上下深入学习贯彻习近平新时代中国特色社会主义思想和党的十九大精神，坚持稳中求进工作总基调，全面落实上级各项决策部署，经济社会发展保持了总体平稳、稳中向好的态势，供给侧结构性改革深入推进，新旧动能转换全面起势，三大攻坚战成效突出，改革开放继续深化，营商环境显着优化，社会民生持续改善。<br>一、综合<br>经济运行总体平稳。初步核算，全市实现地区生产总值（GDP）3380.3亿元，按可比价格计算，比上年增长6.7%。其中，第一产业增加值320.13亿元，增长2.6%，第二产业增加值1612.79亿元，增长6.7%，第三产业增加值1447.38亿元，增长7.6%。产业结构进一步优化。三次产业比例由上年的10.0:47.7:42.3调整为9.5:47.7:42.8。人均GDP达到58252元，增长6.5%。<br>就业形势保持稳定。全市实现城镇新增就业62672人，其中，城镇失业人员再就业13679人，就业困难人员就业2441人。城镇登记失业人员19998人，城镇登记失业率为2.44%，均控制在计划目标范围内。<br>居民消费价格温和上涨，工业生产者价格涨幅回落。全市居民消费价格比上年上涨2.3%，处于温和上涨区间。分类别看，食品烟酒类上涨3.4%，衣着类上涨2.5%，居住类上涨1.9%，生活用品及服务类上涨1.1%，交通和通信类上涨1.4%，教育文化和娱乐类上涨2.2%，医疗保健类上涨1.6%，其他用品和服务类上涨2.7%。工业生产者出厂价格比上年上涨3.4%，涨幅比上年回落2.6个百分点；工业生产者购进价格比上年上涨4.1%，涨幅比上年回落2.5个百分点。<br>市场主体快速增长。全市各类市场主体户数、注册资金为40.01万户、5799.78亿元，分别增长9.8%和32.7%；各类企业户数、注册资金为8.8万户、5360亿元,分别增长19.1%和35%；民营经济户数、注册资金为39.36万户和4808.98亿元，分别增长10.0%和33.5%。<br>二、动能转换与创新<br>新旧动能转换全面起势。全市储备项目500个、投资规模5300亿元，40个项目列入省新旧动能转换重大项目库。新能源汽车及零部件、生物技术、医养健康、现代农业4个产业纳入全省首批现代优势产业集群。工业加快向中高端迈进。全市高新技术产业产值占规模以上工业总产值的比重达到38.1%。装备制造业增加值增长10.6%，高于规模以上工业增速3.3个百分点。六大战略性新兴产业引领作用增强。高端装备制造、生物制造、现代医药等六大新兴产业利润增长39.9%，比上年提高23.9个百分点。其中，现代医药（器械）、生物制造、新一代信息技术利润分别增长31.4%、43.6%和74.3%，分别比上年提高8.9、42.8和11.4个百分点。骨干企业提质增效，带动能力持续提高。4家企业获得新能源汽车整车生产资质。5个化工产业园获得省批复，294个化工项目完成整治。10家企业获评全国、省制造业单项冠军。26家企业获评省级“专精特新”，7家企业获评省级“隐形冠军”，5家企业进入省级瞪羚示范（培育）名录。<br>创新能力持续增强。新认定国家高新技术企业87家、省级企业创新平台61家，大中型企业设立研发机构比例达到64.3%，全年转化科技成果220项。1家企业获得中国优秀工业设计金奖，5家企业入选省级工业设计中心。年末，拥有工程技术研究中心355家（其中国家级4家，省级47家，市级304家），重点实验室131家（其中省级7家，市级124家），科技企业孵化器34家（国家级4家，省级19家，市级11家）。全年专利申请量7487件，其中，发明专利申请量1447件。专利授权量3854件，其中，发明专利授权量286件。截至2018年底，拥有有效发明专利1614件，增长3.9%；每万人口有效发明专利拥有量2.79件，增长3.0%。<br>三、农林牧渔业<br>农林牧渔服发展平稳。全市农林牧渔业实现增加值359.2亿元，按可比价计算，增长3.7%。其中，农业增加值190.1亿元，增长3.3%；林业增加值13.8亿元，增长4.5%；牧业增加值101.8亿元，增长1.3%；渔业增加值14.4亿元，下降1.0%；农林牧渔服务业增加值39.1亿元，增长14.9%。<br>粮食产量略有下降。全市粮食总产量729.95万吨，比上年下降1.8%。其中，夏粮产量361.15万吨，下降1.9%；秋粮产量368.85万吨，下降1.6%。棉花产量2.08万吨，增长31.4%。蔬菜及食用菌产量632.58万吨，增长4.7%。<br>农业供给侧结构性改革深入推进。建成高标准农田23.4万亩，新增水肥一体化面积8万亩。新增设施蔬菜6.2万亩、青贮玉 增长8.8%；人均消费支出14052元，增长8.2%。其中，城镇居民人均可支配收入26562元，增长7.8%；人均消费支出16272元，增长7.5%。农村居民人均可支配收入14564元，增长8.8%；人均消费支出11681元，增长8.3%。<br>社会保障水平稳步提升。全市职工基本养老、职工基本医疗、失业、工伤、生育保险参保人数分别达到88.97万人、73.28万人、40.46万人、60.80万人和43.22万人。居民基本养老保险和医疗保险参保人数分别达到304.70万人、454.13万人。企业退休人员养老保险待遇实现“十四连涨”，居民基础养老金实现“六连增”。城镇最低生活保障人数0.51万人，年人均保障标准5232元，比上年提高360元。农村最低生活保障人数4.79万人，年人均保障标准3780元，比上年提高360元。五保对象2.02万人，供养支出1.01亿元。养老事业加快发展，新增养老床位4500张。<br>1．公报数据均为初步统计数或初步核算数。<br>2．全市生产总值、各产业增加值绝对数按现价计算，增长速度按不变价格计算。<br>3．各类市场主体包括内资企业、外商投资企业、私营企业、个体工商户、农民专业合作社；各类企业包括内资企业、外商投资企业、私营企业；民营市场主体包括私营企业、个体工商户和农民专业合作社。<br>4．规模以上工业企业指年主营业务收入2000万元及以上的工业法人企业。<br>5.固定资产投资（不含农户）包括城镇和农村各种登记注册类型的企业、事业、行政单位以及城镇个体户计划总投资500万元及以上的建设项目投资，全部房地产开发经营业法人单位开发项目投资。<br>6．限额以上批发业企业指年主营业务收入2000万元及以上的批发业企业，限额以上零售业企业指年主营业务收入500万元及以上的零售业企业，限额以上住宿和餐饮业企业指年主营业务收入200万元及以上的住宿和餐饮业企业。<br>7.“市区”、“城区”指德城区、经济技术开发区、运河开发区合计。
