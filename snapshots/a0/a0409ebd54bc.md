|  |  |
| 新华社纽约电据此间媒体25日报道，在举办了1976年夏季奥运会30年之后，东道主加拿大的蒙特利尔终于在上个月付掉了最后一笔账，体会到“无债一身轻”的感觉。<br>蒙特利尔奥林匹克设施管理委员会主席吉勒·莱皮纳证实，当年为举办奥运会，场馆建设总支出高达12.8亿美元。他说:“这个数字现在看来或许太高了，但它已是“过去时”，你必须向前看。”<br>早期举办奥运会，并不是抢手的香饽饽。直到洛杉矶举办1984年奥运会，担任组委会主席的尤伯罗斯以商业运作的手段开拓经营，才开始扭亏为盈。但2004年雅典奥运会可能是个例外，希腊政府本来就财政窘迫，加上反恐的压力导致成本不断增加，赛后背了一屁股的债。 |  |
