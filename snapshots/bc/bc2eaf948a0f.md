# 中指研究院：2025年法拍市场量价双降 高价法拍房扎堆北上深

中指研究院：2025年法拍市场量价双降 高价法拍房扎堆北上深

2026年01月12日 13:36 [智通财经网](https://www.zhitongcaijing.com/content/detail/1391496.html)

1月12日，中指研究院发布法拍市场年终总结。2025年，法拍市场呈现挂拍量、成交量、成交金额及均价同比下滑态势，全年挂拍71.9 万套(同比降 6.6%)，成交 16.9 万套(同比降 4.4%)，总成交金额 2536.2 亿元(同比降 23.6%)，平均折价率 74.1%；物业类型以住宅为核心(成交金额占比 51.9%)，拍卖阶段二拍成交占比最高(46.9%)。区域分布上，高价房源集中于一线及核心二线城市，深圳、上海、北京构成第一梯队。住宅细分市场中，全年挂拍 32.7 万套(同比降 10.7%)，成交 11.3 万套，成交均价 8082 元 /㎡；各能级城市分化显著，一线城市成交均价达 36196 元 /㎡，三四线城市为 4750 元 /㎡。

高价法拍房扎堆北上深

根据中指法拍数据监测，2025年全年成交总价top500房源集中在57个城市；其中，前 5 个城市(深 、沪 、京 、广 、杭)成交约占 400套，占总数的 80%。第一梯队深圳(119套)、上海(117套)、北京(115套)仅 3 个城市，总计成交约351套，占总计数的 70.2%；数值远超其他城市，是高价法拍房源成交核心，与第二梯队形成 “断层式差距”(北京比广州高出88套)。

第二梯队广州(27套)、杭州(22套)2 个城市，top500中占 49套，占比约9.8%；属于相对成交核心，但数值与第一梯队差距较大。

第三梯队厦门(8套)、成都 / 南京 / 苏州(6套)、嘉兴 / 金华等(4套)、昆明 / 绍兴 / 西安(3套)、东莞 / 合肥等(2套)共19个城市，合计占67套，占总计数的 13.4%；以东部沿海、新一线 / 二线城市为主，成交套数集中在2-8套区间。

第四梯队安庆、大连、恩施等33个城市数据长尾，占城市总数的 57.9%，但合计仅成交33套，占总计数的6.6%；以三四线城市、中西部普通地级市为主，分布零散。

高价法拍住宅成交集中于一线城市核心地段的稀缺豪宅，例如，上海老洋房、深圳顶豪因地段不可复制性受高净值买家争抢，溢价显著。

从房源成交数量统计来看，深圳、上海、北京的法拍房源数量远远多于其他城市，并且成交总价最高法拍住宅房源位于上海；上海和深圳的成交总价较为接近，其他城市成交总价相对较低，与各城市的经济发展水平、房地产市场价值等因素相关。拍卖阶段看，高价成交的法拍房一拍的房源数量最多，占据了较大的比例，大部分法拍资产首次拍卖进入市场。二拍的房源数量次之，说明有一部分资产在一拍时未能成功拍出而进入二拍。变卖和重新拍卖的房源数量较少。

监测看高总价成交房源多位于一线城市的核心区域，如上海浦东新区、北京海淀区，深圳南山区等。这些地区交通便利，商业、教育、医疗等配套资源丰富，土地稀缺性高，使得房产具有较高的价值。例如汤臣一品位于上海浦东新区，中粮海景壹号也在浦东新区，地理位置优越。虽然是高价成交，但相较于评估价有一定的折扣，吸引了竞拍者参与竞拍，从而在竞争中推高了成交价。

从这些高总价成交房源中可以看出，尽管房地产市场存在波动，但对于高端房产的需求始终存在。一些高收入人群有改善居住条件的需求，或者企业有投资不动产的需求，这些需求推动了高价资产的成交。

各类法拍房量价走低，一拍阶段成交提升

全年数据来看，2025年全国法拍市场各类法拍房源累计挂拍数量71.9万套，同比下降6.6%，房源累计拍次共130.1万次(同一标的物可能存在一拍、二拍等多次拍卖)，最终成交拍品数量为16.9万套，同比下降4.4%，清仓率23.5%(成交拍品/交易截止拍品)，总成交金额2536.2亿元，同比下降23.6%。各类法拍房源成交均价4653元/㎡，同比下降12.7%，平均折价率为74.1%。

12月，全国法拍市场挂拍各类法拍房源数量12.2万套，同比下降3.0%，最终成交拍品数量为1.7万套，同比下降10.6%，清仓率14.0%，总成交金额287.6亿元，同比下降22.0%。各类法拍房源成交均价4287元/㎡，平均折价率为73.4%。

图：2022-2025年12月全国355城法拍市场挂拍、交易趋势

![数据来源：CREIS中指数据·二手房版](//n.sinaimg.cn/sinakd20260112s/333/w774h359/20260112/10fb-605ed61a96ae3b1b92ca92c008b30fcb.png)数据来源：CREIS中指数据·二手房版

不同类型拍品来看，2025年，住宅房源新上拍品数量27.4万套，交易截止拍品数量32.2万套，成交拍品11.3万套，成交总金额1315.8亿元，成交总金额占各物业类型成交51.9%。商业房源新上拍品数量13.7万套，交易截止拍品数量16.7万套，成交拍品3.1万套，成交总金额584.6亿元，占各物业类型23.1%。土地成交拍品约811件，成交金额约127.8亿元，占成交总金额5.0%。其他物业类型中，法拍工业厂房成交金额429.9亿元，法拍车位车库成交15.7亿元，其他62.5亿元。

各类拍品拍卖阶段中，可分为一拍、二拍、变卖、重新挂拍等情况，其中一拍流拍结束后需进行二次挂拍，二拍仍流拍情况需在申请执行人确认后进行变卖。一拍起拍折价率(起拍折价率=挂拍价/评估价)在0.7-1折之间；二拍为一拍起拍价的0.8，二拍起拍折价率(起拍折价率=挂拍价/评估价)在0.56-0.7折之间；一般情况下变卖起拍价等于二拍起拍价。二拍流拍后，拍品流入变卖阶段，起拍价与二拍一致，变卖周期1-60天，期间内任意时间点有报价即成交。

从成交拍品的拍卖过程来看，2025年在一拍阶段成交的拍品共6.6万套，占成交总量比重为38.9%，较上年提升1.6个百分点；一拍成交均价6223元/㎡，价格同比下跌10.4%。二拍阶段成交7.9万套，占比46.9%，成交均价4322元/㎡，同比下跌13.1%。变卖成交约1.8万套，占比10.8%。重新挂拍及其他情况成交约5575套，占比3.3%。

法拍住宅减少，市场回暖前奏?

住宅类法拍房方面，2025年法拍住宅挂拍房源数量32.2万套，同比下降10.7%；成交拍品11.3万套，同比下降3.3%；清仓率34.6%，较上年提升2.6个百分点；成交总金额1315.8亿元，同比下降19.8%。全年法拍住宅成交均价8082元/㎡，同比下降12.2%。

其中，12月份住宅法拍房源累计新上拍品2.8万套，挂拍拍品数量5.1万套，房源累计拍次共5.7万次，最终成交拍品数量为1.1万套，同比减少9.6%，清仓率22.1%，成交总金额118.8亿元。法拍住宅成交均价7252元/㎡。

总体来看，法拍住宅市场挂拍、成交拍品规模较上一年均收窄，成交均价受评估价影响走低。从趋势上看，法拍住宅市场周期在2024年量价冲顶之后开始回落，清仓率回升反弹。

各能级城市中，2025年一线城市法拍住宅房源成交7049套，成交总金额353.5亿元，成交均价36196元/㎡。其中，北京交易截止挂拍拍品3256套，成交1374套，清仓率42.2%，成交折价率75.9%，成交均价42916元/㎡，年总成交金额86.6亿元。上海交易截止挂拍拍品2169套，成交1433套，清仓率66.1%，成交折价率76.5%，成交均价42361元/㎡，年总成交金额98.8亿元。广州交易截止挂拍5640套，成交2496套，清仓率44.3%，成交折价率75.3%，成交均价18471元/㎡。深圳法拍住宅成交1746套，清仓率63.9%，成交折价率93.8%，成交均价48586元/㎡。

2025年法拍市场市场调整态势延续，量价双降成主基调，区域分化加剧，重点城市表现分化显著，交易结构优化，二拍成为核心成交渠道，竞买人更倾向于在价格更具吸引力的阶段出手。法拍房市场呈现独立周期性趋势，月度成交量、成交金额受法院执行节奏影响较大，波动特征显著。近年法拍市场交易越来越受到市场重视，更多的机构、银行、以及购房者参与到法拍市场中。
