# 中国造纸工业2024年度报告

阅读次数：     发布时间:2025-05-28 16:05:01

# 

据统计，制浆造纸及纸制品全行业2024年完成纸浆、纸及纸板和纸制品产量合计29593万t，同比增长1.56％；其中：纸及纸板产量13625万t，较2023年增长5.09％；纸浆产量9454万t，较2023年增长7.15％；纸制品产量6514万t，较2023年增长-11.39％；全行业营业收入完成1.46万亿元，同比增长3.88％；实现利润总额520亿元，同比增长5.23％。  
      **一、纸及纸板生产和消费情况**  
      **（一）纸及纸板生产量和消费量**

据中国造纸协会调查资料，2024年全国纸及纸板生产企业约2600家，全国纸及纸板生产量13625万t，较2023年增长5.09％。消费量13634万t，较2023年增长3.56％，人均年消费量为96.83 kg（14.08亿人）。2015—2024年，纸及纸板生产量年均增长率2.71％，消费量年均增长率3.11％（见图1）。

**1.新闻纸**

2024年新闻纸生产量70万t，较2023年增长-12.50％；消费量110万t，较2023年增长-14.73％。2015—2024年生产量年均增长率-14.77％，消费量年均增长率-10.52％。  
 **2.未涂布印刷书写纸**  
      2024年未涂布印刷书写纸生产量1845万t，较2023年增长2.22％；消费量1761万t，较2023年增长2.92％。2015—2024年生产量年均增长率0.62％，消费量年均增长率0.52％。  
 **3.涂布印刷纸**  
      2024年涂布印刷纸生产量705万t，较2023年增长6.82％；消费量533万t，较2023年增长3.90％。2015—2024年生产量年均增长率-0.98％，消费量年均增长率-2.05％。其中，铜版纸：2024年铜版纸生产量680万t，较2023年增长7.94％；消费量512万t，较2023年增长3.02％。2015—2024年生产量年均增长率0，消费量年均增长率-1.67％。  
 **4.包装用纸**  
     2024年包装用纸生产量775万t，较2023年增长2.65％；消费量796万t，较2023年增长2.98％。2015—2024年生产量年均增长率1.72％，消费量年均增长率1.75％。  
 **5.箱纸板**  
     2024年箱纸板生产量3035万t，较2023年增长4.84％；消费量3582万t，较2023年增长4.80％。2015—2024年生产量年均增长率3.41％，消费量年均增长率5.06％。  
     **6.白纸板**  
      2024年白纸板生产量1715万t，较2023年增长3.63％；消费量1491万t，较2023年增长2.40％。2015—2024年生产量年均增长率2.28％，消费量年均增长率1.54％。  
     其中，涂布白纸板：2024年涂布白纸板生产量1635万t，较2023年增长3.81％；消费量1411万t，较2023年增长2.62％。2015—2024年生产量年均增长率2.24％，消费量年均增长率1.46％。
