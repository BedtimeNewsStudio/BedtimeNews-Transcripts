# 腾讯游戏打了20年的生死仗

![头像](http://inews.gtimg.com/newsapp_ls/0/531396993_200200/0)![](http://inews.gtimg.com/newsapp_ls/0/14876051701/0)

[游戏葡萄](https://news.qq.com/omn/author/8QMc3npU5YQZujvd)

2025-05-19 21:30发布于广东游戏葡萄官方账号

| 非一日之功，非一家之力。 |

文/梁乐天

当你还在抱怨游戏中对手的走位诡异、枪法离谱，怀疑其是不是开了便宜脚本时，有没有想过，更隐秘、技术含量更高的外挂，可能已经悄然流行起来？

今年3月，在腾讯游戏安全团队的协助下，开封市杞县公安局网安大队就打掉了一个利用高隐蔽技术制作、贩卖外挂的团伙，共抓获嫌疑人12名，涉案资金超过400万元。

![图片](https://inews.gtimg.com/om_bt/OYvg5bGgrwVu-Ihwd0VdTOdKGCnhiPHnuhgzc92RWckVEAA/641)

图源杞县公安公众号

而在这起《三角洲行动》外挂案中，嫌疑人使用的，正是当前游戏安全领域比较头疼的DMA（Direct Memory Access，直接内存访问）技术。

这种技术可以通过特定的硬件设备，绕过程序检测，绘制游戏的运行状态和数据并将其叠加到画面上，实现位置透视、武器自瞄等功能，隐蔽性极强。

![图片](https://inews.gtimg.com/om_bt/GjyVXFZR761zkV88rpn02gwUvbouSvgVR7uaGKmoRrrwwAA/0)

图源B站@兔神CQC

这起案件算得上当前游戏安全严峻形势的缩影之一。

腾讯游戏安全的一项调研显示，外挂问题是玩家放弃一款游戏的重要原因。超过85%的玩家认为游戏安全非常重要；55%的玩家表示，只要游戏解决了外挂问题，他们就愿意回流游戏。这意味着，反外挂做得好不好，直接影响着游戏的生死存亡。

但与此同时，外挂也变得越来越强大、越来越难以捉摸。

在PC端，外挂一方面通过物理手段绕过检测，直接读取游戏核心数据；另一方面则利用AI技术，提高了识别难度。同时，借助内核Shellcode等高级隐匿技术，外挂还能做到深度隐蔽，甚至一人一挂、云端秒切，让追踪和封禁难上加难。

而在移动端，外挂不再止步于修改本地数据，它们利用ROOT、越狱环境下的高权限，以及网络流量限制来逃避检测。更有甚者，一旦发现自身运行在安全团队的测试机上，便会自动关闭，阻碍分析取证。

面对不断升级的技术对抗，以及日益猖獗的外挂问题，厂商该如何应对？行业又该如何治理？上周五举办的2025游戏安全行业峰会，在腾讯游戏安全成立20周年之际，或许能为我们带来一些启发。

![图片](https://inews.gtimg.com/om_bt/OFGEXqodH_tUSUAsZ70dRW8iUxD_Ue7rtNaXCYu0GsF5UAA/641)

# **01**    **反外挂的黑科技**

在这场峰会上，腾讯旗下长青游戏在庞大用户体量下积累的反外挂经验，以及腾讯游戏安全20年来总结的实践成果，应该是大家比较关心的部分。

腾讯游戏安全多游戏运营负责人酷柴在会上分享了《和平精英》的例子。

他表示，腾讯游戏安全为《和平精英》构建了一套从事前防御到事中对抗，再到事后追溯的全流程防御体系。

其中，一个具有代表性的技术是腾讯游戏安全首创的Replay反作弊技术。目前，该技术已具备实时化处理能力，处罚时效性已经提升到了开局后的分钟级别。

而且与过去仅检测开挂者不同，他们现在还会对局内微透视“演员”进行检测。

腾讯游戏安全借鉴军事领域的OODA（观察、定位、决策、行动）理论，从这四个方向拆解玩家的游戏行为。系统会对比玩家的行为与顶尖高手的正常反应模式，从而识别出无视环境的自杀式强攻、利用上帝视角进行选点转移等透视玩家的反常行为。

![图片](https://inews.gtimg.com/om_bt/O0HV0O9Lb8aL3DAtqnSpiG3mzcz361rHL5J9FDSdEF5BAAA/641)

不过，随着外挂的形态不断变异、技术门槛持续提高，仅依靠针对特定游戏的反作弊策略已不足以应对所有挑战。游戏安全需要更底层、更通用、更能适应未来变化的解决方案，而这正是AI所扮演的角色。

在峰会上，腾讯游戏安全高级工程师李洛勤介绍了腾讯在游戏安全领域的最新技术进展——ACE自主构建的基于Replay数据驱动的AI反作弊系统。

这套系统不再像传统方案那样，被动依赖外挂样本，而是通过对玩家行为差异进行建模，去主动学习和理解玩家的行为模式，并从多种游戏内信息中，捕捉到伪装极好的隐性透视、不符合逻辑的异常决策等作弊行为。

具体来说，该系统会同时站在“作弊玩家的视角”和“裁判的视角”来模拟和判断，这让它的识别结果不仅更精准，还能给出判断的理由。

同时，这个AI模型在设计上还考虑了泛化能力，能够跨越不同的游戏玩法和服务器区域，适配MOBA、FPS等复杂游戏场景。目前，该系统已经在《王者荣耀》《和平精英》等核心项目中完成了部署。

![图片](https://inews.gtimg.com/om_bt/Ohlbp03F-32vLxGYZnOgvme95r_vrxz1z1GN1tmv_oUNQAA/641)

腾讯游戏安全的技术探索，以及20年的实战经验，在国际舞台上也获得了一定的关注。

在今年的GDC 2025上，腾讯游戏安全还以《王者荣耀》等游戏为案例，分享了反作弊相关的内容。有在场的朋友告诉我，当时分享现场的上座率巨高。

这或许从一个侧面说明，在反外挂技术层面，中国厂商的经验已经引起了全球开发者的兴趣，甚至可以说是走在了前列。

![图片](https://inews.gtimg.com/om_bt/OeeHZGHeQ1LF95JBAMWnXm9WPzCREGQzKTYwcJW7-SXxIAA/641)

# **02**    **反外挂的朋友圈**

# 当然，游戏安全这场仗，从来都不是一家公司单打独斗能赢下来的，它需要整个行业的协作。

对于在反作弊领域，已经积累了20年经验的腾讯来说，他们并不打算闭门造车，而是计划在全球行业内进行高新技术的合作和输出。

一方面，他们积极与硬件提供商、非营利组织合作。

本次峰会上一个重要的看点，就是腾讯游戏安全与高通的行业生态合作签约。

双方宣布将基于骁龙X系列AI PC平台，为《无畏契约》等高热度PC端游提供本地化、高性能的安全防护方案。这意味着，未来在硬件层面，他们可能会引入更多专门针对外挂检测与防御的功能。

![图片](https://inews.gtimg.com/om_bt/OaOCgHZ3eFY_HmZRSSENeWUw4GR_o5LbxIYvym28CV9QQAA/641)

此外，行业非营利组织TIGG的执行总监Matthew Soeth在峰会上也进行了线上分享。

他强调了社区共建的重要性。这种共建不仅能营造良好的社区反作弊氛围，为安全团队减轻负担并提供支持，还能帮助安全团队更快地掌握外挂生态的最新动态，从而提高举报的效率和准确性。

另一方面，腾讯也在将自身的安全技术与解决方案，推广至国内乃至海外的游戏厂商。

无论是国内的《香肠派对》《重返未来：1999》《鸣潮》等产品，还是英国的Cathedral Studios、韩国的111%、东南亚的Asphere等海外团队，其背后都有腾讯游戏安全的身影。

以111%发行的《Lucky Defense》为例，腾讯游戏安全为其提供了一套包括应用加固服务、客户端和服务端SDK在内的闭环安全方案。

![图片](https://inews.gtimg.com/om_bt/OOiNt1PAUQ57Fj4-UbodQumQ9JZvWFBHiJAtR8WoxouZIAA/641)

韩国多家媒体报道了111%和腾讯游戏安全的合作

值得一提的是，腾讯游戏安全不仅与知名大厂合作，也面向中小型厂商提供技术方案和支持。

比如，在去年底的无畏契约x腾讯游戏安全年度发布会上，他们宣布推出ACE全案合作，涵盖实时红屏、战争迷雾等机制。此外，针对中小型射击游戏开发团队，他们还将提供额外的支持。

**03**

结语

除了技术对抗、合作案例分享外，这次峰会上还发布了在广东省游戏产业协会的指导下，腾讯游戏安全联合行业伙伴共同编撰的《2024游戏安全白皮书》。

该书梳理了游戏外挂、经济安全、内容安全、账号安全等核心议题，并盘点了我国在游戏安全领域的法律法规，以及行业共建的重要事件和成果。

白皮书提到，2024年检测到的PC游戏外挂样本数同比增长了74%，外挂功能数暴涨了149%。内核外挂均价从205元降至146元，DMA硬件外挂均价从6000元降至1500元。这说明高端作弊技术的门槛正在降低，更容易获取。

同时，官方的打击力度也在不断增强。2024年全年账号处罚量超过了1.87亿，相比2023年全年的1.07亿，增长了75.7%。

![图片](https://inews.gtimg.com/om_bt/OqDveeclKR1E5yVmkyI7dsFMY7rJRRrC7CaRxYhZXdHpIAA/641)

今年恰逢腾讯游戏安全团队成立20周年。这份白皮书，可以说也是腾讯游戏安全对多年来建设安全对抗体系经验的一次阶段性总结和对外呈现。

当然，你或许会质疑，这些努力真的有用吗？毕竟，20年过去了，外挂问题依然存在、难以根除。在我看来，对于这个问题，最有资格给出评价的，莫过于那些亲身体验游戏的玩家。

![图片](https://inews.gtimg.com/om_bt/OAqDWmThL-HjyLmqlRGqHwAZDaP4u_VjTGgCXE-S5XV_cAA/641)

![图片](https://inews.gtimg.com/om_bt/OMJeGX4eXbyYIdiLX0Qa_n8m16OQU_6MlkJwGoq-dpq24AA/641)

违规公告下的玩家评论

也许，这些反外挂行动的最终目标，不在于何时能彻底消灭外挂，而在于能否通过持续的努力和可见的行动，让那些曾因外挂问题，对游戏感到失望，选择放弃的玩家，重新体会到游戏中应得的公平和纯粹的快乐。

AI反作弊系统主要通过以下方式识别外挂：首先采集多维度数据，包括客户端操作日志、游戏状态数据和硬件环境检测信息，以及服务器端的Replay回放解析和分布式存储计算数据。接着构建正常行为基线，利用聚类算法区分玩家类型，识别显性、隐性和硬件外挂特征。再运用机器学习与AI模型，如监督学习、无监督与半监督学习及对抗样本防御来处理数据。然后通过客户端实时监控和服务器端动态验证进行实时检测与响应。最后腾讯ACE系统采用Replay + AI双引擎和多维度特征融合实现主动检测，还与各方合作共建生态。
