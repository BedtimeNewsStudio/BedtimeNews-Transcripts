# 去年11月至今686名内地港生报考香港警队 137名获录用

2023-11-25 14:32:10来源： [中国新闻网](http://www.chinanews.com.cn/dwq/2023/11-25/10117800.shtml)作者：唐炜妮责任编辑：唐炜妮

2023年11月25日 14:32　来源： [中国新闻网](https://www.chinanews.com.cn/)

大字体

小字体

分享到：

[中新社](https://www.chinanews.com.cn/) 香港11月25日电 香港特区政府警务处处长萧泽颐11月25日向媒体介绍，自去年11月香港警务处面向在中国内地大学就读的香港学生招聘警察以来，至今共有686名香港学生报考，有137名学生通过遴选程序被录用。

|  |
| --- |
|  |

据悉，香港警务处于2022年11月起举办“内地大学招募快线”，为内地港生举办招聘讲座，讲解警察招聘资讯，并安排即场遴选。萧泽颐当日在出席香港警察学院学员结业会操后会见媒体时表示，香港警务处过去一年在北京、广东、福建等地高校举办招募活动，希望有更多的内地港生加入香港警队。另外，自今年5月调整警察投考条件以来，报考警员和督察的人数均同比增长约六成，令人感到鼓舞。

萧泽颐还介绍，今年前9个月，香港录得约2.9万宗诈骗案件，案件数量同比增长超过51%，涉案金额近50亿港元。近期将推出包括10家主要银行职员进驻反诈骗协调中心等新举措，希望可以强化防诈骗工作。(完)
