# 南阳市七届人大第二次会议隆重开幕 - 南阳人大

__南阳市七届人大第二次会议隆重开幕__

__大会主席团常务主席主持会议听取政府工作报告__

__审查计划报告和草案、预算报告和草案__

__听取2024年民生实事候选项目议案的说明__

　　2月21日上午，南阳市第七届人民代表大会第二次会议在南阳人民会堂隆重开幕。

![Image 1: default (1)](https://oss.henanrd.gov.cn/hnsrd-lzpt-oss001/cms/img/20240221/56c3fa95b740455d83ef2acd5f2d4b42.jpeg)

　　大会主席团常务主席、执行主席张生起主持大会。

　　大会主席团常务主席、执行主席朱是西、金浩、张生起、李永、高贤信、王黎生、周天龙、苌其林、贾松啸、王兵、余广东、李甲坤、庞震凤、刘荣阁、全新明、李长江、莫中厚、刘中青在主席台执行主席席就座。

　　王智慧、张富治、马冰、李鹏、陈英杰、白红超、周大鹏、徐军、党全生在主席台就座。

　　南阳市第七届人民代表大会第二次会议应出席代表640名，出席开幕大会的代表623名，符合法定人数。

![Image 2: default (3)](https://oss.henanrd.gov.cn/hnsrd-lzpt-oss001/cms/img/20240221/fe8688ff1f77466aacb8111f44f5a72f.jpeg)

　　上午9时，张生起宣布：南阳市第七届人民代表大会第二次会议开幕。

![Image 3: default](https://oss.henanrd.gov.cn/hnsrd-lzpt-oss001/cms/img/20240221/40a5a709d7324e22a10b53fc9adcaced.jpeg)

　　与会人员全体起立，会堂内响起雄壮的国歌声。

![Image 4: default (2)](https://oss.henanrd.gov.cn/hnsrd-lzpt-oss001/cms/img/20240221/ca8ea2da0f2b47639b63f1729211126c.jpeg)

　　在热烈的掌声中，市长王智慧作政府工作报告。报告共分三个部分：一、2023年工作回顾。二、2024年工作总体要求和主要目标。三、2024年重点工作安排。

　　【南阳市人民政府市长王智慧：各位代表，现在，我代表市人民政府，向大会报告工作，请予审议，并请市政协委员和其他列席人员提出意见。】

　　王智慧在报告中指出，2023年，是极具考验而又富有成效的一年。面对深刻变化的外部环境和艰巨繁重的发展任务，我们坚持以习近平新时代中国特色社会主义思想为指导，全面贯彻党的二十大精神，认真践行习近平总书记视察河南视察南阳殷殷嘱托，在市委的正确领导下，锚定"两个确保""十大战略"，纵深推进"一二三六十"工作布局，全力打造"三区一中心一高地"，经济运行延续好态势，产业转型迈向高质量，科技创新步入快车道，改革开放取得新成效，城乡建设实现大提升，绿色发展厚植软实力，民生改善交出暖心卷。

　　王智慧在报告中指出，过去一年取得的成绩殊为不易，主要得益于以习近平同志为核心的党中央高瞻远瞩、领航定向，得益于市委科学决策、坚强领导，得益于市人大、市政协有效监督、鼎力支持，凝聚着全市千万干群的心血和汗水。

　　王智慧在报告中指出，做好今年的政府工作，要坚持以习近平新时代中国特色社会主义思想为指导，全面贯彻党的二十大、二十届二中全会和中央经济工作会议精神，深入贯彻习近平总书记视察河南视察南阳重要讲话重要指示，全面落实省委经济工作会议、省“两会”和市委经济工作会议部署，坚持稳中求进工作总基调，完整、准确、全面贯彻新发展理念，紧抓构建新发展格局战略机遇，着力推动高质量发展，锚定省委"两个确保""十大战略""十大建设"，紧紧围绕建设现代化省域副中心城市、打造"三区一中心一高地"，强力推进"一二三六十"工作布局，统筹扩大内需和深化供给侧结构性改革，统筹新型城镇化和乡村全面振兴，统筹高质量发展和高水平安全，切实增强经济活力、防范化解风险、改善社会预期，巩固和增强经济回升向好态势，持续推动经济实现质的有效提升和量的合理增长，增进民生福祉，保持社会稳定，奋力推进中国式现代化建设南阳实践迈出坚实步伐。主要预期目标是：生产总值增长7%左右，研发经费投入强度达到2%，规上工业增加值增长8.5%左右，固定资产投资增长9%左右，社会消费品零售总额增长9%左右，一般公共预算收入与生产总值同步增长，居民人均可支配收入增长与经济增长协调同步，居民消费价格涨幅控制在3%以内，单位GDP能耗与“十四五”目标统筹衔接。

　　王智慧在报告中指出，实现今年目标任务，需要我们洞察时代大势，锚定主攻方向，恪守初心使命，坚持底线思维。集中开展"科技创新年""开发区高质量发展突破年""金融服务提质增效年""营商环境成果巩固年""安全生产除险清患年""观念能力作风提升年"六大活动。重点抓好十个方面工作：一聚焦扩大有效投资、挖掘潜能消费，在稳定经济增长上攻坚突破。二聚焦培育产业链群、增强竞争能力，在推动产业升级上攻坚突破。三聚焦健全研发体系、催生技术成果，在强化科技创新上攻坚突破。四聚焦昂起城市龙头、隆起县域高地，在加快城镇发展上攻坚突破。五聚焦建设农业强市、打造和美乡村，在促进乡村振兴上攻坚突破。六聚焦完善基础设施、织密支撑网络，在增创发展优势上攻坚突破。七聚焦革新体制机制、激发动力活力，在深化改革开放上攻坚突破。八聚焦加强污染防治、抓好环境保护，在构建生态文明上攻坚突破。九聚焦增进民生福祉、繁荣社会事业，在创造美好生活上攻坚突破。十聚焦防化风险隐患、维护大局安定，在保障本质安全上攻坚突破。

　　王智慧在报告中指出，群众点点滴滴的"小心愿"，件件都是政府的"头等事"。今年，聚焦群众关切，遴选了14件民生实事，提交会议审议票决。各责任单位要用心用情抓好重点民生实事的推进落实，坚决做到多谋为民之策、多兴亲民之举、多增惠民之利，切实让群众从发展中得到实惠、看到变化、见到成效。

　　王智慧在报告中指出，建设现代化省域副中心城市，需要全市政府系统工作人员认真践行新时代好干部标准，牢记嘱托，忠诚为政；规范用权，依法行政；奋力拼争，实干勤政；清廉自守，从严治政；自觉当好执行者、行动派、实干家。

　　【各位代表，历史在继往开来中谱写，辉煌在创新实干中铸就。让我们更加紧密地团结在以习近平同志为核心的党中央周围，在省委、省政府和市委的坚强领导下，以坚如磐石的信念意志、一往无前的热血豪情、向难求成的坚韧执着，戮力同心、接续奋斗，努力在推动中原更加出彩的新征程中书写南阳高质量发展的新篇章。】

　　大会审查了关于南阳市2023年国民经济和社会发展计划执行情况与2024年国民经济和社会发展计划草案的报告、2024年国民经济和社会发展计划草案；审查了关于南阳市2023年预算执行情况和2024年预算草案的报告、2024年市级预算草案。

　　大会听取了市人民政府常务副市长白红超作关于提请审议南阳市2024年民生实事候选项目议案的说明。

　　阿颖、刘江、鲁文明、杨曙光、周华锋、张志强、李德成、褚清黎、刘永国、华道梅、李林、杨文普、李敬铎等在主席台就座。

　　郭斌也在主席台就座。

　　王良军、张宝锋、安士伟、罗永松、郝好山、常晖、谷永清、温道军、柳明伟、丁笑生、王伟、范真、陈西川在主席台就坐。

　　在主席台就座的还有大会主席团其他成员。

　　驻宛全国人大代表、省人大代表，出席政协第七届南阳市委员会第二次会议的政协委员及有关部门负责同志列席会议。
