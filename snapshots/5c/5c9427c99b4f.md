# 甲骨文宣布大规模裁员或达万人，烧钱投资的同时减员增效

![](https://img.jiemian.com/101/original/20181203/15438268238770800_a134x134.jpg)

互联网日常

2026年04月01日 04:55

员工在签署离职文件后将有资格获得遣散费。

![甲骨文;大规模裁员;万人;烧钱投资;减员增效](https://img.jiemian.com/101/original/20260401/177503240074000600_a640x364.jpg)

图片来源：界面新闻

全球软件巨头甲骨文（Oracle）于当地时间3月31日凌晨向员工群发邮件，宣布启动新一轮大规模裁员。

多名收到通知的员工在社交媒体上披露，甲骨文在通知邮件中措辞直白：“在认真评估甲骨文当前的业务需求后，我们决定取消您的职位，这是公司整体组织架构调整的一部分。因此，今天是您在公司的最后一个工作日。”邮件还告知员工在签署离职文件后将有资格获得遣散费。有在甲骨文工作四年的员工在社交媒体上表示，“对事情以这种方式结束感到非常失望”。

据受影响员工透露，甲骨文此次数千人的裁员涉及多个部门。有媒体报道称，此次裁员可能覆盖美国、印度、欧洲等多个市场，波及工程、云服务、技术支持等部门，预计受影响工作岗位最高或达到3万个，此次数千人裁员只是开始。根据甲骨文提交的10-K文件显示，截至2025年5月，甲骨文拥有16.2万名员工。

与亚马逊等云厂商一样，甲骨文近期加大了资本支出，用于推进AI基础设施建设。大规模的裁员也正是为了应对激增的AI资本支出。

在刚刚过去的季度财报电话会议上，甲骨文高层表示2026年目前没有进一步举债的计划。

当地时间3月10日，甲骨文公布2026财年第三财季业绩，期内总营收172亿美元，按美元计算增长22%，按固定汇率计算增长18%；云服务营收89亿美元，按美元计算增长44%，按固定汇率计算增长41%；软件营收61亿美元，按美元计算增长3%，按固定汇率计算下降1%。第三财季GAAP净利润为37亿美元，GAAP每股收益1.27美元。

![false](https://img.jiemian.com/101/original/20260401/177503240074000600_a320xH.jpg)

甲骨文预计2026财年资本支出350亿美元，相较上一财年的250亿美元大幅增加，绝大部分用于服务器和网络设备，而非土地或建筑项目。为此甲骨文不得不更多依赖债务融资。2026年1月，甲骨文宣布计划通过债务和股权融资筹集约500亿美元资金。

甲骨文表示，预计其2026财年重组计划的总成本将高达21亿美元，其中大部分将用于员工遣散费和相关费用。

公司预计2027财年营收将达到900亿美元，较此前预期上调10亿美元，高于市场预期的866亿美元。

3月18日，据“甲骨文中国”微信公众号消息，甲骨文与英伟达扩展AI合作。双方在NVIDIA GTC 2026上宣布，在 Oracle Cloud Infrastructure（OCI）上扩展AI能力，帮助重新定义可扩展的AI性能，加速向量数据库操作，并通过云原生服务简化企业AI部署。

除了甲骨文，多家美国科技巨头自去年以来纷纷启动大规模裁员，以应对AI热潮所带来的变革，“一边烧钱投资，一边裁员增效”正在成为科技行业的新常态。

2026年1月，亚马逊宣布再裁减约1.6万个职位，这是继2025年10月裁员1.4万人后的第二轮大规模调整，创下其成立30年来的最大规模裁员纪录。亚马逊CEO安迪.贾西在内部信中直言：“1000个生成式AI应用已在路上，未来真的不用这么多人了。”

Meta也在3月启动新一轮裁员，影响数百名员工。此前有消息称，Meta正考虑裁员超过20%，即可能超过1.5万名员工，旨在降低成本并聚焦于新AI技术的研发。

而在此之前，2025年4月，英特尔宣布裁员2.5万人，同年7月微软宣布裁员9000人。

此外，惠普已宣布全球裁员4000至6000人；戴尔宣布裁员11000人。
