| 596.5米！局承建的中国结构第一高楼天津117大厦喜封金顶<br> <br>* * * |  |  |
|  |  |  |
| 发布日期：<br> 2015-09-09<br>      字号：\[ 大中小 \] |  |  |
| 9月8日，中国在建结构第一高楼——天津117大厦核心筒结构封顶仪式在位于600米高空的顶升模架钢平台隆重举行。天津市滨海高新区工委书记荣建勋、香港高银金融地产控股有限公司董事局主席潘苏通，中建三局董事长、党委书记陈华元，中建三局总经理易文权等共同浇灌水晶钻石模型内的数字“117”，标志着中建三局总承包施工的天津117大厦核心筒结构正式封顶。<br>仪式现场，根据测量第三方的精准测量，117大厦混凝土泵送高度为621米，大厦混凝土泵送高度超越了迪拜哈利法塔建造时601米的混凝土泵送高度，创造了吉尼斯世界纪录。世界吉尼斯纪录认证官高建军先生宣布审核认证通过文件。<br>作为以中建三局资质和名义独立签约的国际顶级项目，天津117大厦在建造过程中创造了诸如“超高层建筑底板混凝土体量世界之最、超高层建筑水管压力世界之最”等12项世界纪录、中国纪录。该工程2008年9月10日开工建设，2012年7月30日地下室结构封顶，2013年7月5日突破百米，2015年1月19日突破500米，2015年9月8日封顶。（王腾 范宗臣） |  |  |
