江苏大丰电池企业污染导致51名儿童血铅中毒

2010年01月06日 00:11　来源：新华网　![](http://i2.chinanews.com/zwimg/01.jpg)[发表评论](http://comment.chinanews.com.cn/comments/comments.php?newsid=2055611)　　【字体：↑大↓小】

位于江苏大丰经济开发区的河口村共有16岁以下常住儿童132人，其中110人最近接受了血液检查，根据1月3日该市政府对外宣布的数字，他们中有51人血铅含量超标。大丰市委宣传部副部长孙杰表示：将对患儿实施妥善治疗，责令企业限期搬迁，由市纪委、监察局牵头成立调查组，实施责任追究。

|     |
| --- |
|  |

根据大丰市政府公布的调查结果，距离河口村村民住房最近处仅50米的电池生产企业大丰市盛翔电源有限公司是污染的源头，这家企业已被勒令停产。当地政府称已着手组织河口村全部儿童进行体检，并启动责任追究程序，调查处理责任人。

记者于5日赶到河口村现场采访。村民周翠玉告诉记者：2009年10月，她1岁多的孙女顾玮玮开始吃不下东西，当听说同村有别的小孩检查出血铅超标后，他们十分恐慌，在11月27日约了46户邻居带孩子一起去上海儿童医院、上海交大附属新华医院集体做了检查。结果发现血铅超过每升60微克的孩子有37人，其中超过每升100微克的二级、三级铅负荷状态的有22人，不同程度铅中毒的占送检儿童的47.8%。

周翠玉说，顾玮玮当时的血铅含量为每升178微克，在所有孩子中不算最高，最高的指标超过每升300微克。即便如此，医生也认为这种状况对孩子的身体发育、记忆力都有影响，要求给她吃特殊配方奶粉，一直吃到6岁。

记者了解到，大丰市盛翔电源有限公司是2006年9月经有关部门备案、审批同意建设的，2007年3月建成投入试生产后，还通过了环保“三同时”验收。但在2009年11月20日，环保部门监测到该公司排放的铅尘当中部分指标超标一到两倍，随即要求其停产整顿。11月24日晚，大丰有关方面对盛翔电源有限公司实施供电限制，强令其停产。

据介绍，“血铅事件”发生后，大丰市委、市政府高度重视，启动公共卫生事件应急预案，市委、市政府主要领导和分管领导先后8次召开专题会议，研究部署儿童血铅超标事件应急处理方案，形成处理意见，并迅速成立河口村儿童血铅超标问题调查组。(记者姜帆　顾烨）
