# 金价越涨，周大福们越难？

###### 2024年06月17日 14:51   豹变

金价一路高歌猛进，黄金品牌为什么没接到“泼天的富贵”？

> 金价一路高歌猛进，黄金品牌为什么没接到“泼天的富贵”？

**作者 \|** 宋子豪


**编辑 \|** 刘杨


6月9日，“黄金大跌”登上热搜。虽然各大黄金品牌还守着700多元/克的高位，但在端午期间，部分黄金品牌已经给出最高70元/克的优惠。


2023年以来一路狂飙的金价，难道已经临近拐点？


而在更早的6月5日，“周大福深圳工厂停工停产”的传闻备受市场关注。据一份流传于网络的周大福“停产待岗通知”，因市场环境变化，周大福公司股东已决定将北山工厂的生产制造业务进行迁移及相关生产线、设备、原材料等资产转移。


周大福随后发布声明回应称， **不存在停工停产，只是为进一步调整企业资源配置，提升运营效率**，因而对深圳厂区部分部门进行调整与重新规划，以及把深圳厂区部分生产部门迁往广东顺德厂区。


在黄金市场火爆的当下，周大福转移厂区的原因是什么？


**1、突然的停工**

据《中国新闻周刊》报道，早在今年3月2日，就有疑似周大福员工在社交媒体上发文称，深圳周大福研发中心将进行“大规模人员调整”。


但对于大多数员工来说，这一调整来得还是比较突然。


周大福给出两种赔偿方案，一是拿N＋3的赔偿金解约；另一种方案是随公司迁至顺德，并有上限为3万元的补偿款。在等待期间，周大福会为员工以深圳最低工资80%的标准发放工资。


周大福的几座工厂中，顺德工厂主要生产高品质、高附加值的产品，武汉工厂定位于综合性的珠宝生态产业园，此次转移的深圳工厂以研发为主。


企查查显示，深圳市周大福珠宝制造有限公司（即周大福深圳工厂）成立于2012年，主要从事珠宝首饰及有关饰品、钟表、工艺品等生产和研发，其2022年工商年报显示员工人数为1051人。


周大福深圳工厂还下设高新科技研发生产中心，2017年5月正式投入使用，距今已有7年。


**此次深圳工厂的转移，可能与成本有关。**

《2023-2024年度广东省薪酬调查报告》显示，顺德工厂所在的佛山市平均月薪为9000元，而深圳市平均月薪12300元，在广东排名第一，比佛山高了36%。


同时，在2024年7月，深圳将迎来社保缴费基数上涨。


此前，2024年1月1日至6月底，深圳社保最低缴费基数将从2360元上调至3523元。而在过渡期结束后，即从7月1日开始，最低基数将再次上调，达到5500元，对于企业来说人力成本有所增加。


更深层次的原因，或许是金价高企带来的连锁反应。金价影响销量，黄金品牌都有降本的需求，而基础成本最高的深圳工厂则挨了第一刀。


**2、金价越涨，金店越难**

黄金是一门周期性很强的生意。


2023年6月16日，周大福总经理黄绍基曾经在业绩说明会上表示：“我们做了45年的生意，每10年经历一个经营峰谷。”


所以， **黄金品牌都是应对金价变化的高手，但是这一轮金价上涨，似乎已经超出了周大福的预期。**

由于国际形势原因，各国央行加大黄金储备，国际金价在短时间内快速上涨。


万德数据显示，2023年全年黄金价格涨幅超过15%，2024年最高达到2444.4美元一盎司的历史高点，半年内上涨了17.7%。


**过快的上涨，让周大福在2024财年的黄金借贷合约中出现了亏损。**

所谓黄金借贷合约，简单说就是周大福向银行借贷黄金用于生产，并以约定偿还时的金价进行偿还。这期间，如果金价下跌就能盈利，如果上涨则亏损。本来是一种应对金价波动的对冲方法。


根据美银证券的研究报告，由于金价上升，周大福在2024财年期末录得约25亿港元的黄金贷款未变现亏损。


**和周大福一样猝不及防的还有消费者，在成本上涨的推动下，金店的售价也屡创新高，直接影响了消费者的消费热情。**

据金投网整理，截至6月13日，各大黄金品牌的金价普遍在713元/克左右。而在2022年6月14日的价格只有513元/克。


![](https://commom-oss.sfccn.com/21sj/mp_sfccn/2024/06/15/f18564673ae58e7e9a88300b0f8884b1.png)

根据周大福2023年11月24日发布的中报数据，报告期内，销售占比达到82.1%中国内地的营业额同比下滑0.6%。


2024年，金价再创新高，周大福的销售额下降也更为明显。


根据周大福披露的截至2024年3月31日止三个月未经审核主要经营数据，内地珠宝镶嵌、铂金及K金首饰类别的同店销售减少19.5%。


6月13日，周大福发布的2024年4月1日至5月31日未经审核的主要经营数据显示，报告期内，集团零售值同比减少20.2%。其中，中国内地同比减少18.8%。


实际上，受到金价上涨影响销量的黄金品牌不只周大福一家。


湖南黄金2024年一季度业绩报告显示，湖南黄金一季度黄金总销量15吨，自产销量912公斤，同比下降11%。


此外，据《第一财经》报道，受高金价影响，国内“五一”节假日期间金饰销售惨淡，有水贝商户称销量减半。


**为应对金价波动和销量下降，端午期间，老凤祥、潮宏基、六福珠宝等品牌都有每克20-40元不等的优惠活动。**

世界黄金协会4月30日发布的2024年一季度《全球黄金需求趋势报告》显示，随着国际金价上升，2024年一季度，全球总体黄金需求同比上升3%，达到了343吨，位于十年内的高位水平。但金饰销量不升反降，同比小幅下滑6%，为184吨。


可以看出，在金价上涨超出预期的情况下，黄金的投资属性越发明显，而作为消费需求的金饰类产品反而不断下降。


周大福等品牌也期望于通过提高工艺、打造一口价产品撑起售价，但消费者似乎对此不太买账。


《每日经济新闻》曾经报道，多名消费者投诉一口价产品定价过高，购买时没有被告知明确克重。在黑猫投诉网上，可以搜索到4475条一口价黄金相关投诉，主要集中在单克价过高，购买时并未被告知克重。


同时，由于金价处于历史高点，黄金质押的贷款利率水平也有所上涨，可能进一步加大周大福等黄金品牌在黄金贷款等对冲中亏损的可能。


而相对于其他黄金品牌，周大福还有自己更特殊的降本理由。


**3、扩张后遗症**

周大福相对其他品牌稍显特殊的是，刚经历了过去几年下沉市场的扩张。


从2018年开始，周大福加速扩张开店，陆续启动“新城镇计划”，推出“省代”政策，以加盟的形式与三四线金店经营者合作，快速抢占市场。


这一策略在前期取得不错的成绩。根据周大福财报，2021财年(2020年4月1日至2021年3月31日)的营业额为701.6亿港元，同比增长23.6%，其中内地营业额同比增长46.5%，占整体总收入的85.1%。


对于这一成绩，周大福解释为，在三四线城市及县级城镇的部署，抓住城镇化带来的机遇。同时，线上渠道销量也有一定的增长。


**尝到甜头的周大福，进一步加速扩张**，截至2023年6月，周大福在内地零售点数量达到7604个，原本计划在2025财年开设7000家门店的目标，提前两年超额完成。


周大福2024财年中报提到，内地的所有店铺当中有近一半是过去两年开设的。截至2023年9月30日，周大福加盟零售点位5734个，此类加盟零售点占内地店铺数目的77%，营业额占内地批发营业额约63%。


令周大福意想不到的是，消费者的消费能力没跟上自己扩张的速度。叠加金价上涨，消费者金饰需求下降，周大福的内地销量开始下跌。


值得注意的是，周大福的新店盈利水平没有老店高。平均下来，周大福的单店收入从2019年的1824.5万元降低至2022财年的1123.4万元，下降了38.4%。


**意识到这一趋势的周大福，自2023年年末开始降速。**

根据国盛证券的相关研报，2023年年末周大福拓店速度大幅减缓，10-12月公司在内地净开43家周大福珠宝店，


而在2023年6月的媒体交流会中，周大福执行董事、首席财务官郑炳熙也表示，未来会放缓门店增速，在内地新增600到800家新店，低于2023财年的1500多家。


实际上，周大福的拓店比这一方案更少。


截至2024年3月底，周大福珠宝总体门店数量从2023年底的7636家减少至7548家。在2024年上半年，周大福仅在三四线城市开了52家店。


同时，2024年4月18日， **周大福提出门店翻新计划，计划未来5年内，将对旗下全部门店进行策略性翻新，意在革新零售业务。**

这可能表明，周大福从抢占市场转为提高单店盈利能力。加上整体市场的销售压力，周大福采取降本的策略就不足为奇了。
