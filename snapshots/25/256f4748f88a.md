## 上海梅龙镇伊势丹关店，27年历史落幕

2024/07/01

6月30日，日本三越伊势丹控股设在中国上海市的百货商场“上海梅龙镇伊势丹”停业关店。因入住的建筑的租约到期，三越伊势丹控股决定关店，这家百货商场约27年的历史落下帷幕。目前中国大陆的伊势丹仅剩下天津市的一家店。

|  |
| --- |
| ![](https://cn.nikkei.com/images/2024/07/0701/0701-01-L.jpg) |
| **“上海梅龙镇伊势丹”长达约27年的营业历史落下帷幕（6月30日，中国上海市）** |

6月30日是最后一个营业日，在营业结束时相关人士在门店入口前讲话称：“感谢大家长期以来的支持”，并深深鞠躬行礼。

上海梅龙镇伊势丹于1997年开业。经营日本品牌的化妆品、服装和家电产品等诸多品类。居住在附近的一位60多岁的女性对关店感到惋惜。她说：“伊势丹离我家很近，接客服务等也很好，我经常来买东西”。

在中国的大城市，由于网购普及等原因，百货商场陷入苦战，中国资本的百货商场也接连关店。上海梅龙镇伊势丹的运营公司一直处于亏损状态。

与伊势丹入住同一栋建筑的健身俱乐部的一位20多岁女性会员说：“虽然我定期来健身，但没有在这家百货商场买过一次东西”。
