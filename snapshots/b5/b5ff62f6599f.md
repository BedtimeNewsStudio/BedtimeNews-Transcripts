# 美国限制对华半导体设备出口，韩国遭受最大打击

Posted April. 09, 2024 07:34

Updated April. 09, 2024 07:34

- listen
- Font size down
- Font size up

[한국어](https://www.donga.com/cn/article/all/20240409/4869742/1?m=kor)

![](https://dimg.donga.com/ugc/CDB/CHINESE/Article/66/14/70/ed/661470ed14f0d273823e.jpg)

据悉，自美国2022年10月禁止向中国出口尖端半导体设备以来，在主要半导体设备生产国中，韩国受到的打击最大。韩国企业向中国出口的设备大部分不是限制对象，而是通用设备，但去年的出口额比2022年减少了20%以上。有分析认为，中国担心美国的限制扩大，在先发制人购买装备的过程中，排除了技术力相对落后于发达国家的韩国产装备。

《东亚日报》8日通过联合国贸易数据，对去年中国的半导体设备进口额进行了统计，结果显示，韩国产设备的进口额为44.7609亿美元（约6万亿韩元），比2022年（56.1937亿美元）减少20.3%。这是对曝光、清洗、蚀刻、沉积、检查等相当于半导体设备的19个HS代码进行分析后得出的结果。

同期，美国产装备的进口额从95.5190亿美元减少到了92.5381亿美元，只减少3.1%。

从日本和荷兰的装备进口反而增加。日本产进口额从156.8398亿美元增加到164.1512亿美元，增加4.7%。荷兰从32.2108亿美元剧增到80.7306亿美元，增幅达150.6%。

据分析，之所以出现这种差异，是因为在美国限制出口后，中国提高了自给率，从容易替代的韩国产装备开始减少了进口。有人指出，由于担心美国的出口限制从尖端扩大到传统产品，在抢购装备的过程中，韩国产被挤出了优先顺序。三星电子、SK海力士对中国境内生产线的增设及升级持消极态度，也产生了影响。

韩国某半导体设备公司社长表示：“美国勒紧了中国半导体产业，反而是对美国、日本、荷兰产的需求剧增，反而成就了价格。相反，现在没有什么遗憾的韩国产设备的人气大幅下降。”

朴贤益记者 beepark@donga.com
