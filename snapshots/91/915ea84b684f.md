| 中国台湾网7月1日消息　据台媒报道，素有岛内研发武器重镇之称的“国防部”“中山科学研究院”，受六千亿特别军购预算影响，部分研发计划停摆，在业务不断萎缩下，运作更是雪上加霜。根据军方人士透露，“国防部”有意规划从明年开始，裁撤“中科院”1，500人，希望透过人事的精简，维持“中科院”的正常运作。 |  |

军购排挤经费

|  |
| --- |
|  |

“中科院”人员透露，近年来，在“国防部”外购武器比率偏高的情况下，“中科院”这三年的研发经费以每年减少十二亿的幅度减少，而“中科院”预算有45%是用在人事费上，因此当各军种委托“中科院”研发预算减少后，许多研发计划就受到影响。

尤其“国防部”以特别预算向美国采购爱国者三型导弹六套装备后，“中科院”研发的低层反战术弹道导弹计划，自然受到排挤，因此再度裁员是不得不进行的方案。“国防部”官员表示，“国防部”现阶段对“中科院”一切维持正常的基本武器研发。至于人员的精简，目前采遇缺不补，希望以此来精简人事。

“精实案”推行不顺利

“中科院”今天(七月一日)的三十五周年院庆，因经费不足，并未依过去逢五逢十邀请“国防部长”等高阶长官扩大举行，反而仅简单地由“军备局长”卢林赐中将主持院庆大会后，以音乐会和画展等活动来庆祝。

“中科院”人员透露，“中科院”早在1992年配合政策实施人事“精实计划”，每年裁减1%人力为目标，遇缺不补，经过五年的精实，全院员工从17，000“减肥”到13，500人，虽然科研人员遇缺不补，但军职人员仍然轮调，至今约有两千位军士官轮调；精实的3，500人大部分都是科技、研发部门专业人员，相对让“中科院”的研发受到不少影响。

“中科院”精实案推行不顺利，是发生在1998年的劳资纠纷，当时“院长”沈方枰主张“中科院”员工人数应维持在5，000人，在员工强烈抗议，加上重要武器研发人员也都站在工会这边，最后迫使沈自行提出辞职以示负责。

“国防部”官员表示，“中科院”目前年资在25年以上的人员有3，000人，若要办理这3，000人的退休，需要至少一百亿元的经费，由“中科院”本身提拨的退休金仅十七亿元，只能优退300到500人之间，因此，近年来，“国防部”只要谈到“中科院”的精简案，通常就此打住。(潇凝)
