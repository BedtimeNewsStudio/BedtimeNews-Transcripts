# 南京大学回应“智慧教室”争议：否认到课率挂钩成绩，称已不再统计抬头率

澎湃新闻记者 王选辉

2026-11-04 10:01

来源：澎湃新闻

∙ [直击现场 >](https://www.thepaper.cn/list_25428)

听全文

字号

针对近日引发广泛关注的“智慧教室系统统计课堂抬头率、出勤率”一事，南京大学本科生院与信息化建设管理服务中心于11月4日通过官方微信公众号发布《关于智慧教室系统有关情况的说明》，对网络流传的多项说法作出回应。

校方明确否认“到课率与平时成绩挂钩”“上级部门检查”等传闻，并强调系统“不采集人脸等生物特征信息、不进行人脸识别”，且“当前已不再统计抬头率数据”。

**“监测抬头率”引发争议**

事件源于南京大学学生近期收到的通知。通知称，学校将依托暑期升级改造的智慧教室系统，对相应教师课程的到课率进行为期一周的全程记录。

随后，一张智慧课堂系统的截图在网络上流传，画面中除监控影像外，还显示迟到学生、到勤率、抬头率等统计数据，迅速引发质疑。此外，有教师在班级群内通知时表示，智慧课堂采集的到课率“会直接影响平时分，甚至可能直接取消课程考试成绩”，这一说法进一步加剧了争议。

据封面新闻此前报道，南京大学智慧教室教学系统建设项目中标金额达3152余万元，涉及仙林校区113间公共教室的升级改造，招标文件中包含“人脸检测、人脸识别、AI人数统计、AI抬头率计算”等技术要求。

一些学生向媒体表示，学校并未事先征询学生同意，担忧人脸信息可能被校方与技术公司掌握，即便没有精确的人脸识别，“监测抬头率”本身也令人感到不适。舆论则将这一争议概括为技术赋能滑向“算法凝视”的风险，质疑以“抬头率”量化课堂学习状态是否合理。

**校方回应：未经授权不进行人脸识别，不再统计抬头率**

在11月4日的说明中，南京大学对争议中的关键问题逐一澄清。

关于系统功能，校方表示，智慧教室改造的目标是“升级课堂音视频环境、实现课程直播与跨校区互动、支持课程回放与教学数据复用”，项目“严格遵守政府采购法律法规有关信息公开要求，经专家论证、公开采购招标等程序”。

关于到课率统计的用途，校方解释称，期中教学检查是常规教学管理工作，本学期“拟试点通过智慧教室系统进行到课率统计，以客观数据支撑后续教学改革、课程建设等工作”，并明确“网传有教师通知期中教学检查是上级部门检查、到课率将与平时成绩挂钩等信息均不属实”。

针对最受关注的隐私与“抬头率”问题，校方回应称：“未经授权，我校智慧教室系统在教学应用中不采集人脸等生物特征信息、不进行人脸识别”，同时“考虑到课堂学习方式更加多元，当前我校智慧教室系统已不再统计抬头率数据”。对于网络上流传的教室拍摄画面，校方说明其“系苏州校区今年5月在线督导的个人截屏”，并非当前智慧教室系统的实时监控内容。

南京大学在说明末尾表示，身处数智时代，智慧教室是未来课堂的基本载体，未来将“一如既往地坚持以生为本，在充分尊重和保护学生隐私的前提下，帮助同学们更方便地获取学习资源，真正让数智赋能学习”。
