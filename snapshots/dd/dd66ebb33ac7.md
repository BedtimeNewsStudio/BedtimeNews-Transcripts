## 日本议员秋元司涉嫌从中国企业受贿被逮捕

2019/12/25

[PRINT](https://cn.nikkei.com/politicsaeconomy/politicsasociety/38737-2019-12-25-09-27-17.html?tmpl=component&print=1&page= "Print") [EMAIL](https://cn.nikkei.com/component/mailto/?tmpl=email&link=aHR0cHM6Ly9jbi5uaWtrZWkuY29tL3BvbGl0aWNzYWVjb25vbXkvcG9saXRpY3Nhc29jaWV0eS8zODczNy0yMDE5LTEyLTI1LTA5LTI3LTE3Lmh0bWw= "Email")

![](https://cn.nikkei.com/templates/nikkeisite/common/images/nikkei-chinese-logo-02.jpg)

![](https://cn.nikkei.com/templates/nikkeisite/common/images/nocookie.gif)

       东京地方检察厅特搜部12月25日以从力争参与日本综合度假区项目的中国企业“500.com”收取现金300万日元等贿赂为由，逮捕了负责度假区事务的内阁府副大臣、自民党众议院议员秋元司（48岁）。“500.com”相关人士违反外汇法事件发展成现任国会议员的贪污事件。特搜部将通过讯问秋元加紧弄清度假区项目不透明的资金流向的全貌。

|  |
| --- |
| **![](https://cn.nikkei.com/images/2019/12/1225/1225-05-2-L.jpg)** |
| **秋元12月9日出席众议院大会时** |

        此外，以行贿嫌疑逮捕了“500.com”日本法人一名前董事（37岁）、该公司的顾问绀野昌彦（48岁）和仲里胜宪（47岁）。

       秋元司的逮捕嫌疑是2017年9月担任国土交通副大臣和负责综合度假区的内阁副大臣时，在明知“500.com”为参与度假区项目谋求便利的情况下，从绀野等人收取300万日元现金的贿赂，并让该公司负担了2018年2月前往北海道的家庭旅行的约70万日元费用。

       秋元司在被逮捕前的日本时间25日上午10点多（北京时间上午9点多）发推特称，“此次发生这样的事态，引起外界惊动，对此我表示歉意。但是，我没有参与任何违法行为。我将继续主张这一点”。

       “500.com”总部位于中国深圳，从事网上体育彩票销售等。该公司力争参与日本的度假区项目，2017年7月成立了日本法人。绀野和日本法人前董事涉嫌在未经申请的情况下将超过外汇法规定上限（100万日元）的现金带入日本，涉嫌违反外汇法。秋元于2017年8月~2018年10月兼任国土交通副大臣和内阁府副大臣，负责观光相关对策和综合度假区。

       2017年8月“500.com”在冲绳县那霸市举办度假区相关的研讨会，秋元在研讨会上发表主题演讲。秋元在该公司力争参与度假区构想的北海道留寿都村以及担任副大臣职务的国土交通省内，多次与该公司相关人士会面。北海道2019年11月宣布暂停度假区项目招商，该公司的参与计划遇挫。

|  |
| --- |
| ![](https://cn.nikkei.com/images/2019/12/1225/1225-05-L.jpg) |
| **东京地检特搜部对秋元的事务所进行搜查（19日，东京都江东区）** |

       特搜部于12月7~8日对事件相关人员秋元前政策秘书等人的住宅、19日对位于众议院议员会馆的秋元的议员事务所等进行了入内调查，并在自愿前提下向秋元询问了情况。

       日本上一次逮捕现任国会议员是在2010年1月以违反《政治资金规正法》的嫌疑逮捕时任众议院议员石川知裕。秋元司曾担任国会议员秘书，于2004年作为参议院比例代表首次当选议员。2010年在参议院选举中落选后转战众议院选举，并在2012年当选，目前处于众议院议员的第3个任期。
