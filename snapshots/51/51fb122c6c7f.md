| 延安大学马克思主义学院简介 |
| --- |
|  |
| 马克思主义学院的历史可以追溯到1937年成立的陕北公学。当时学校设立的社会科学研究室即是马克思主义学院的重要历史源点。1941年，中共中央决定将陕北公学、中国女子大学、泽东青年干部学校合并成立延安大学，其中马克思主义理论的教学与研究占显著地位。1943年至1944年，鲁迅艺术文学院、自然科学院、新文字干部学校、民族学院、行政学院又相继并入延安大学，其中行政学院代替社会科学院，成为马克思主义理论课程教学与研究的重要载体。1958年，恢复重建的延安大学就设有马列教研室。1977年，在马列教研室基础上建立政治教育系。1986年，独立组建马列部。1999年，更名社会科学教研部。2005年，更名为思想政治理论课教研部。2008年，学校党委决定成立马克思主义学院，为陕西省第一批马克思主义学院。2018年，学院被确定为第一批省级标准化马克思主义学院；2022年，学院入选为省级重点马克思主义学院；2025年，入选教育部立德树人机制综合改革试点院系。  1.师资队伍  学院现有教师75人，其中教授18人（二级教授3人，三级教授5人，博导8人），具有博士、硕士学位者占90%以上。学院“延安精神铸魂育人教学团队”认定为教育部第三批“全国高校黄大年式教师团队”；拥有教育部示范马克思主义学院和优秀教学科研团队2个，陕西思政课教师省级名师工作室1个，其中，具有教育部马克思主义理论教学指导委员会委员、全国五一劳动奖章获得者、陕西省首批“特支计划”哲学社会科学领军人才、陕西省宣传思想文化系统“六个一批”人才、陕西省教学名师等省部级人才称号19人次。  2.学科建设  2004年，马克思主义理论与思想政治教育专业招收硕士研究生。2006年，马克思主义理论学科获批“陕西省首批一级学科”。2019年，马克思主义理论获批“省级一流学科”。2022年，马克思主义理论在全国第五轮学科评估中取得B-。2024年，马克思主义理论一级学科获批为博士学位授权点。学科下设“马克思主义基本原理”“马克思主义中国化研究”“思想政治教育”“中国近现代史基本问题研究”和“党的建设”五个二级学术硕士点和一个“学科思政”专业硕士点。  3.科研平台  学院聚合了九个高层次研究平台：一是教育部人文社会科学重点研究基地“中国共产党革命精神与文化资源研究中心”；二是教育部高校思想政治工作队伍培训研修中心；三是教育部思政课教师实践研修基地；四是教育部红色文化弘扬基地；五是陕西省社科联高端智库“延安十三年与中国式现代化研究中心”；六是陕西省延安精神研究中心；七是延安精神与红色文化传承协同创新中心；八是延安精神研究与传播基地。九是延安精神一体两翼育人模式研究基地。此外，还研发上线了《延安时期红色文献数字研究平台》。  4.本科教学  学院设立“一系一部”，即“思想政治教育系”和“思想政治理论课教学部”。  “思想政治教育系”拥有一个思想政治教育本科专业，下设“思想政治教育理论”和“思想政治教育实践”两个教研室。1977年，思想政治教育专业开始招收本科学生，是延安大学最早设立的专业之一；2020年，《延安精神筑梦红色青年》建成“国家级一流社会实践课程”；2021年，思想政治教育本科专业获批“陕西省一流本科专业”；2022年，思想政治教育专业获批为“国家级一流专业建设点”，2025年，在软科中国大学专业排名中评级为B+。  “思想政治理论课教学部”下设“马克思主义基本原理”“毛泽东思想和中国特色社会主义理论体系概论”“习近平新时代中国特色社会主义思想概论”“中国近现代史纲要”“思想道德与法治”“形势与政策”“大学生国家安全教育”七个教研室，承担着全校的思想政治理论课教学工作。《马克思主义基本原理》《毛泽东思想和中国特色社会主义理论体系概论》为省级精品课程。《延安精神代代传》建成省级“金课”。1997年，“新时期延安精神教育的实践与探索”获得国家级教学成果一等奖；2023年，“延安精神‘一体两翼’铸魂育人体系的构建与实践”荣获国家级教学成果二等奖。近年连续获得陕西省教学特等奖5项、二等奖4项。此外，获得教育部思政课教学展示二等奖1项，陕西省思政课教师“大练兵”各类奖项14项。  5.科学研究  近年来，承担国家社科基金重大重点及一般项目50项、省部级项目80余项。在人民出版社等学术出版机构出版学术专著100余部。公开发表论文400余篇，其中核心期刊近200篇，权威期刊近30篇。获陕西省哲学社会科学优秀成果奖一等奖1项，二等奖9项。  6.学生培养  目前，学院在校学生675人，其中本科生为330人，硕士研究生为316人，博士研究生27人。学生主持和参与项目60多人次，发表论文150余篇，其中20余篇发表在C刊、核心期刊或被人大复印资料转载。“小红专”荣获第三届全国“互联网+”大学生创新创业大赛银奖；2018年，研究生党支部荣获“全国百个样板党支部”；2024年，圣地青马宣讲团入选“全国大学生延安精神志愿服务团队”。  学院先后获陕西省“创佳评差”最佳单位、“陕西省师德建设先进集体”“陕西省弘扬延安精神研究示范基地”“陕西高校党建工作标杆院系”“陕西省巾帼标兵岗”“延安市弘扬延安精神研究示范基地”“延安市先进基层党组织”等荣誉称号。  （2026年9月更新） |
