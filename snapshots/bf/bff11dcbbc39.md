新乡“天力锂能”敲钟上市，成为河南首家锂电正极材料上市企

发布时间：2022-09-02

来源：大象新闻
**大** **中** **小**

|  |
| --- |
| 8月29日上午，新乡天力锂能科技股份有限公司在深圳证券交易所创业板上市，股票简称“天力锂能”，股票代码：301152。<br>天力锂能公司总部位于新乡电源产业开发区，是郑洛新国家自主创新示范区新乡片区辐射区、河南省（新乡）军民融合产业基地、河南省动力电源知名品牌示范区、新乡市电池及电动车先进制造业专业园区。<br>![](http://www.nea.gov.cn/2022-09/02/1310658659_16621114295031n.jpg)<br>新乡市被誉为“中国电池工业之都”，电池及新能源产业是十大战略新兴产业之一，在河南“十大战略”引领下，展现出勃勃生机和强劲发展势头。<br>作为国内较早从事三元材料及其前驱体研发与生产的企业之一，天力锂能入驻新乡电源产业开发区10多年来，逐渐发展为该细分领域的龙头企业、国家级高新技术企业。<br>目前，该公司客户涵盖星恒电源、海四达、阳光电源、长虹能源（836239.BJ）、横店东磁（002056.SZ）、天能股份（688819.SH）等国内小动力锂电池领域知名企业。2021年在数码、电动二轮车及电动工具领域应用的三元材料市场占有率高达47%，位居第一。<br>此次成功登陆创业板，天力锂能成为新乡市第一家新能源企业上市公司、河南首家锂电正极材料上市企业。<br>![](http://www.nea.gov.cn/2022-09/02/1310658659_16621114129461n.jpg)<br>据悉，到2025年，新乡市牧野区力争培育上市企业3家，超30亿元企业2家，超10亿元企业3家，形成年产10万吨电池材料、新能源电动车50万辆的产业规模，实现主营业务超百亿元，建成全国重要的新型电池及材料研发生产基地和全国重要的电动车研发生产基地。<br>新乡市金融局有关负责人介绍，至此，新乡市已有上市公司8家，总数位居全省第6位，增长数量居全省第2位。在审企业2家，在辅导企业4家。新三板挂牌企业23家，中原股权交易中心挂牌企业705家。（卢家民 陈培闯） |
