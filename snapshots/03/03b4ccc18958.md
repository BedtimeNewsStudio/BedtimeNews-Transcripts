《**红花坂上的海**》（日语：コクリコ坂から／こくりこざか から，英语：*From Up on Poppy Hill*）是一部2011年上映的[日本动画](/wiki/%E6%97%A5%E6%9C%AC%E5%8B%95%E7%95%AB "日本动画")电影，由[宫崎吾朗](/wiki/%E5%AE%AE%E5%B4%8E%E5%90%BE%E6%9C%97 "宫崎吾朗")执导，[宫崎骏](/wiki/%E5%AE%AE%E5%B4%8E%E9%A7%BF "宫崎骏")和丹羽圭子编剧，[吉卜力工作室](/wiki/%E5%90%89%E5%8D%9C%E5%8A%9B%E5%B7%A5%E4%BD%9C%E5%AE%A4 "吉卜力工作室")制作，[东宝](/wiki/%E6%9D%B1%E5%AF%B6 "东宝")发行。该片改编自[高桥千鹤](/wiki/%E9%AB%98%E6%A9%8B%E5%8D%83%E9%B6%B4 "高桥千鹤")插画，[佐山哲郎](/wiki/%E4%BD%90%E5%B1%B1%E5%93%B2%E9%83%8E "佐山哲郎")撰写的1980年[同名漫画](/wiki/%E4%BE%86%E8%87%AA%E7%B4%85%E8%8A%B1%E9%98%AA "来自红花阪")。电影的配音阵容包括[长泽雅美](/wiki/%E9%95%B7%E6%BE%A4%E9%9B%85%E7%BE%8E "长泽雅美")、[冈田准一](/wiki/%E5%B2%A1%E7%94%B0%E5%87%86%E4%B8%80 "冈田准一")、[竹下景子](/w/index.php?title=%E7%AB%B9%E4%B8%8B%E6%99%AF%E5%AD%90&action=edit&redlink=1 "竹下景子（页面不存在）")（日语：[竹下景子](https://ja.wikipedia.org/wiki/%E7%AB%B9%E4%B8%8B%E6%99%AF%E5%AD%90 "ja:竹下景子")）、[石田百合子](/wiki/%E7%9F%B3%E7%94%B0%E7%99%BE%E5%90%88%E5%AD%90 "石田百合子")、[风吹纯](/wiki/%E9%A2%A8%E5%90%B9%E7%B4%94 "风吹纯")、内藤刚志、[风间俊介](/wiki/%E9%A2%A8%E9%96%93%E4%BF%8A%E4%BB%8B "风间俊介")、[大森南朋](/wiki/%E5%A4%A7%E6%A3%AE%E5%8D%97%E6%9C%8B "大森南朋")和[香川照之](/wiki/%E9%A6%99%E5%B7%9D%E7%85%A7%E4%B9%8B "香川照之")等人。该片同时是宫崎吾朗继《[地海战记](/wiki/%E5%9C%B0%E6%B5%B7%E6%88%B0%E8%A8%98 "地海战记")》后，第二部执导的动画电影。

故事背景设定在1963年的[日本](/wiki/%E6%97%A5%E6%9C%AC "日本")[横滨市](/wiki/%E6%A9%AB%E6%BF%B1%E5%B8%82 "横滨市")，主要讲述了松崎海的故事，他与他的家人以及寄宿的房客一同生活在红花庄。当海遇到学校报社成员风间俊时，他们决定清理学校的社区中心“拉丁区”。然而，高中的校长计划拆除该建筑进行重新开发，这使得海等人开始参与保存社团大楼的行动，同时也发现自己与风间可能有某种血缘关系的秘密。

《红花坂上的海》最终于2011年7月16日在日本首映，电影发行后获得正面为主的评价，媒体与评论家主要称赞动画呈现的时代怀旧感和配乐，但同时也有部分评论家称角色的肢体动作略嫌僵硬，全球票房收入达到6100万美元。GKIDS发行了英文版，于2013年3月15日在北美上映。

## 情节

[[编辑](/w/index.php?title=%E4%BE%86%E8%87%AA%E7%B4%85%E8%8A%B1%E5%9D%82&action=edit&section=1 "编辑章节：情节")]

故事发生在1963年[横滨](/wiki/%E6%A9%AB%E6%BF%B1 "横滨")，就读港南学园二年级的女孩松崎海住在港口附近，与家人和寄宿的房客一起生活。时值举办[东京奥运](/wiki/1964%E5%B9%B4%E5%A4%8F%E5%AD%A3%E5%A5%A7%E6%9E%97%E5%8C%B9%E5%85%8B%E9%81%8B%E5%8B%95%E6%9C%83 "1964年夏季奥林匹克运动会")的前一年，日本政府为了举办奥运，意图将大量老旧的房舍拆除以改建新式建筑，港南学园也不例外，众多社团学生反对校方以老旧为由拆除他们使用的社团大楼“[拉丁区](/wiki/%E6%8B%89%E4%B8%81%E5%8C%BA "拉丁区")”（[日语](/wiki/%E6%97%A5%E8%AF%AD "日语")：カルチェラタン，[法语](/wiki/%E6%B3%95%E8%AF%AD "法语")：Quartier Latin），发起了校内抗争运动。在此期间，松崎海认识了参与抗争运动的学生之一风间俊。

起先松崎海对风间俊及其他抗议的社团学生颇不以为然，但禁不过妹妹空的要求，与她一起至校内的社团大楼。松崎海在那里再次遇见风间俊，往后俩人渐渐对彼此产生好感。但某一天风间俊拜访松崎家时，从松崎的家族照片中发现自己与海也许有血缘关系……[[8]](#cite_note-8)。

## 登场角色

[[编辑](/w/index.php?title=%E4%BE%86%E8%87%AA%E7%B4%85%E8%8A%B1%E5%9D%82&action=edit&section=2 "编辑章节：登场角色")]

**松崎海**（松崎 海）

:   17岁，泽村雄一郎的女儿，港南学园高二女生，本作女主角，长相清秀美丽，发形为双辫子。住家为房间有提供让外来人寄宿的服务，庭院外头围绕著红色的[虞美人](/wiki/%E8%99%9E%E7%BE%8E%E4%BA%BA_(%E8%8A%B1%E5%8D%89) "虞美人 (花卉)")花的“红花庄”（コクリコ莊）。
:   于母亲离开家中前往美国留学的期间，代理母职照料弟妹、外祖母以及其它住宿人的饮食。
:   小时候在得知父亲在[朝鲜战争](/wiki/%E6%9C%9D%E9%AE%AE%E6%88%B0%E7%88%AD "朝鲜战争")中罹难后，每日早晨皆会在家中升起[国际信号旗](/wiki/%E5%9C%8B%E9%9A%9B%E4%BF%A1%E8%99%9F%E6%97%97 "国际信号旗")中的U、W旗，想像著在海上的父亲看到旗帜后便会安全归来，喜欢风间俊。
:   被众人称呼的小名为“小海”（メル，MeRu）。（改自法语中“海洋”‘Mer’一词）[[9]](#cite_note-9)

**松崎空**（松崎 空）

:   16岁。松崎海的妹妹，港南学园高一生，崇拜著发动校内抗争运动的风间俊，但得知风间俊喜欢的是姊姊松崎海之后主动放弃追求。

**松崎陆**（松崎 陸）

:   松崎海及空的弟弟，为家中最年轻的成员。松崎海家中唯一的男性。

**松崎良子**（松崎 良子）

:   松崎三姐弟的母亲，因从事英语文学系的助教而有段时期在美国留学。

**松崎花**（松崎 花）

:   松崎海的外祖母，先前曾不赞成女儿良子与泽村雄一郎的婚姻。

**北斗美树**（北斗 美樹）

:   松崎海家里的住宿人之一，与水沼史郎的姐姐为港南学园同届的毕业生。
:   个人志向是成为一名医生，在松崎海家中宛如大姐般地存在。

**牧村沙织**（牧村 沙織）

:   松崎海家里的住宿人之一，于外国领事馆工作上班的女郎。

**广小路幸子**（広小路 幸子）

:   松崎海家里的住宿人之一，外型高挑的大三美术学生。
:   喜欢吃、容易睡过头，行事步调有点迷糊傻气的女性。

**风间俊**（風間 俊）

:   17岁。立花洋的孩子，港南学园高三男生，本作男主角。文艺社社长，校内新闻《拉丁区周报》（週刊カルチェラタン）的发行编辑者。
:   出生时父亲命丧于船难，母亲在出生时因[难产](/wiki/%E9%9B%A3%E7%94%A2 "难产")逝世，加上双亲的亲戚于[原爆](/wiki/%E5%8E%9F%E7%88%86 "原爆")中丧生的缘故，使父亲的好友泽村雄一郎将自己申报为其子并转交给对方的熟人风间明雄收为养子。
:   为了保存校内具传统意义的社团大楼免于被拆除的命运，而与水沼史郎及其它社团学生联手发动校内抗争运动，剧中一开始就喜欢松崎并且一直关注她，在与松崎海长期互动下互相产生好感。

**水沼史郎**（水沼 史郎）

:   17岁。港南高中三年级男生，俊的好友，港南学园的第一秀才。学生会会长。
:   头脑清晰，总是能冷静沉著地处理问题情况。擅长考试前的猜题，准确率达83%，知道风间俊喜欢松崎海，主动扮演爱情推手。

**伊藤**

:   港南学园三年级男生，社团大楼中的哲学社社长（成员只有他一名）。外型粗旷的热血派，但也有在女性学生面前不知所措的一面。

**横山信子**（横山 信子）

:   松崎海的朋友。因父亲为从事建筑性质工作的缘故，本身对于水泥涂抹方面的技巧相当了解，伊藤关注的女生。[[10]](#cite_note-Guide50-10)

**加藤悠子**（加藤 悠子）

:   松崎海的朋友。有著好嗓音、校内合唱团的成员之一。[[10]](#cite_note-Guide50-10)

**泽村雄一郎**（澤村 雄一郎）

:   松崎海的父亲。于[朝鲜战争](/wiki/%E6%9C%9D%E9%AE%AE%E6%88%B0%E7%88%AD "朝鲜战争")中于一艘战车登陆舰（英语：**Landing Ship，Tank**；缩写：**LST**）上被炸沉罹难。[[11]](#cite_note-11)
:   原先动画以泽村雄一郎过世的场景为开头，但被宫崎吾朗考虑到太过沉重而撤销。[[12]](#cite_note-12)

**立花洋**（立花 洋）

:   泽村雄一郎就读商船学校时结识的好友，风间俊的亲生父亲。二战结束时其搭乘的撤退船只因意外沉没而丧生，而妻子生下儿子时因难产离世。由于亲戚都在原爆中罹难，促使好友雄一郎将还在襁褓中的俊向事务所申报为其子并交给其熟人风间给扶养成人。

**小野寺善雄**（小野寺 善雄）

:   泽村雄一郎就读商船学校时结识的友人，事后担任远洋货船“航洋丸”的船长。

**风间明雄**（風間 明雄）

:   风间俊的养父，在横滨港口从事[拖船](/wiki/%E6%8B%96%E8%88%B9 "拖船")方面的工作，非常关心养子俊，并知道他对松崎产生钟情。
:   过去和妻子面临丧子之痛时，在雄一郎带著襁褓的俊到自己家门时收留俊。

**德丸**（徳丸）

:   德丸书店的社长，也是港南学园的理事长，能理解风间俊一行人发动保护校内旧建物运动的经营者。
:   角色范本为已逝的[德间书店](/wiki/%E5%BE%B7%E9%96%93%E6%9B%B8%E5%BA%97 "德间书店")创办者[德间康快](/wiki/%E5%BE%B7%E9%96%93%E5%BA%B7%E5%BF%AB "德间康快")。[[13]](#cite_note-#1-13)

**白木源之介**（白木 源之介）

:   商店街上和气的米店老板。

**白木友子**（白木 友子）

:   白木源之介的妻子，有时会来到松崎海家中帮忙的妇人。

## 制作

[[编辑](/w/index.php?title=%E4%BE%86%E8%87%AA%E7%B4%85%E8%8A%B1%E5%9D%82&action=edit&section=3 "编辑章节：制作")]

### 制作契机

[[编辑](/w/index.php?title=%E4%BE%86%E8%87%AA%E7%B4%85%E8%8A%B1%E5%9D%82&action=edit&section=4 "编辑章节：制作契机")]

将《红花坂上的海》改编为动画的契机，来自宫崎骏在完成动画《[风之谷](/wiki/%E9%A2%A8%E4%B9%8B%E8%B0%B7_(%E9%9B%BB%E5%BD%B1) "风之谷 (电影)")》后、在他岳父于山上搭建的小屋休养的那段时期。当时闲暇无事的宫崎骏翻阅了几本他外甥女留在小屋的几本少女漫画，便被其中一本《红花坂上的海》剧情里对于恋情的描写、以及男女主角的角色性格设定给吸引住。[[14]](#cite_note-14)之后宫崎骏便将《红花坂上的海》推荐给动画界的友人，并有尝试将此漫画搬上大银幕的念头，但之后受限于少女漫画与电影动画在剧情上有不同的表现手法限制而无后续结果。[[15]](#cite_note-15)

之后1989年宫崎骏注意到另一名少女漫画家[柊葵](/wiki/%E6%9F%8A%E8%91%B5 "柊葵")的作品《[心之谷](/wiki/%E5%BF%83%E4%B9%8B%E8%B0%B7 "心之谷")》、并推荐给[近藤喜文](/wiki/%E8%BF%91%E8%97%A4%E5%96%9C%E6%96%87 "近藤喜文")成功改编成电影动画后[[16]](#cite_note-16)；让宫崎骏再度考虑到将《红花坂上的海》搬上大银幕的可行性[[17]](#cite_note-project-17)，并在数十年后于2009年12月27日向铃木敏夫表示决定要将此漫画改编成动画电影，[[18]](#cite_note-GhibliHistory162-18)并亲自担任企划及编剧。

宫崎骏长子[宫崎吾朗](/wiki/%E5%AE%AE%E5%B4%8E%E5%90%BE%E6%9C%97 "宫崎吾朗")在初中时与父亲前往山上小屋也曾阅读过此作品，[[19]](#cite_note-19)在得知企划后，便主动自荐想担任该片导演。对于在数年前首度执导《[地海战记](/wiki/%E5%9C%B0%E6%B5%B7%E6%88%B0%E8%A8%98 "地海战记")》的长子，曾与他有过严重争执的宫崎骏这回只表示：“既然都拍过一次成品就已经是动画导演了，接下来要怎么样执行都看他本人的意思。”[[18]](#cite_note-GhibliHistory162-18)及“对动画导演来说，第2部作品就是要看成果”。[[20]](#cite_note-20)

### 角色设计

[[编辑](/w/index.php?title=%E4%BE%86%E8%87%AA%E7%B4%85%E8%8A%B1%E5%9D%82&action=edit&section=5 "编辑章节：角色设计")]

主角松崎海一开始的设定上因给人较消极的印象，之后经检讨后将眼睛描绘的部份加大、并将头部后方的发辫向上移到头部左右两侧，以增加能给人带来活力的感觉。外型打扮则以学生服造型为主，未采用原先宫崎骏在电影海报上所绘制的洋装打扮。[[21]](#cite_note-RomanAlbumPage62-21)

松崎三姊弟的母亲，原作名为：小松崎虹江，在本片则改为：松崎良子；原作曾在美国学习摄影，在本片亦改为：曾在从事英语文学系助教，前往美国留学。性格活泼开朗，同时也是个不善理财、毫无金钱以及经济观念。常一不小心就乱花钱，故让长女小海也十分头痛，由于年轻貌美就因丈夫为国捐躯，成为一名寡妇，更是邻舍口中：有名的‘美人’。此外，松崎家房客北见北斗，不仅姓名和职业被改，性别也作了变更。 从原作的男“兽医师”北见北斗，改为：女“医师”北斗美树。还有，本作与心之谷，有著相同的遭遇，皆为：同期连载、纯爱少女漫画，而且连载未完。

风间俊的外型模样上，则以导演宫崎吾朗的要求为主：“不以日本60年代当时男高中生所普及的七三分浏海、而改用一般的短发造型”。相较之下原先发型为呈现近代青年风格的水沼；最后采定的为七三分的浏海。[[21]](#cite_note-RomanAlbumPage62-21)风间与水沼所戴的学生帽格式，也从制作人铃木敏夫青年时所保存留下的帽子上获得参考。[[22]](#cite_note-22)

原作漫画中原为男性的住宿人“北斗”会被更动成女性，是为了让松崎海家中几乎以女性成员为主的模样、能和学校中“拉丁区”社团大楼里清一色皆为男性的情况成对比。其中住宿人“牧村沙织”的脸蛋、嘴唇造型以1930年代的美国动漫角色“[贝蒂](/wiki/%E8%B4%9D%E8%92%82%E5%A8%83%E5%A8%83 "贝蒂娃娃")”为范本。[[23]](#cite_note-23)而“广小路幸子”初期的设定原为身材矮小的女性，之后被修改为八头身、如模特儿般的身材。[[24]](#cite_note-24)

山下公园一景

 [![](//thumb.wikimedia.org/wikipedia/commons/thumb/a/a2/Hikawamaru_and_Marine_tower.jpg/250px-Hikawamaru_and_Marine_tower.jpg?utm_source=zh.wikipedia.org&utm_campaign=parser&utm_content=thumbnail)](/wiki/File:Hikawamaru_and_Marine_tower.jpg)

冰川丸与横滨海洋塔（右）

* **谷户坂**

:   横滨元町中华街5号出口一旁方向的斜坡，动画中松崎海通往街上的一带景色范本。[[25]](#cite_note-25)

* **观港公园**（港の見える丘公園）

:   位于元町中华街东方出口、能一览[横滨港](/wiki/%E6%A9%AB%E6%BF%B1%E6%B8%AF "横滨港")的公园。将“能清楚望见港口”的特点套用在动画中的松崎海家中。[[26]](#cite_note-26)

* **元町中华街**

:   [石川町车站](/wiki/%E7%9F%B3%E5%B7%9D%E7%94%BA%E8%BB%8A%E7%AB%99 "石川町车站")东北方的市集商店街，作为风间俊载送松崎海前往市场的场景。[[27]](#cite_note-Guide12-27)商店街里百年花卉老店“宫崎生花店”、[[27]](#cite_note-Guide12-27)以及1951年代起开始贩卖肉类、[可乐饼](/wiki/%E5%8F%AF%E6%A8%82%E9%A4%85 "可乐饼")的肉店“丸英商店”皆有作为动画的场景参考范本。[[28]](#cite_note-28)

* **山下公园**

:   面临横滨港的公园，松崎海与风间俊晚上散步的地点。[[29]](#cite_note-Guide14-29)

* **新格兰酒店**（Hotel New Grand）

:   山下公园西南方的老字号旅馆，于松崎海与风间俊晚上散步出现的背景建物。[[29]](#cite_note-Guide14-29)

* **[横滨海洋塔](/wiki/%E6%A9%AB%E6%BF%B1%E6%B5%B7%E6%B4%8B%E5%A1%94 "横滨海洋塔")**

:   于1959年庆祝横滨港成立100周年建造的高塔，松崎海与风间俊晚上散步出现的背景建物。[[29]](#cite_note-Guide14-29)

* **[冰川丸](/wiki/%E5%86%B0%E5%B7%9D%E4%B8%B8 "冰川丸")**

:   1930年作为由日本前往[西雅图](/wiki/%E8%A5%BF%E9%9B%85%E5%9C%96 "西雅图")、号称“北太平洋女王”的豪华游艇，二战时为日本帝国海军的运兵船，战后恢复邮轮职务，目前停泊于横滨港内，松崎海与风间俊晚上散步在背景出现的船只。（动画中船身为刚退役时的绿色隐蔽用迷彩涂装，现今则回复为战前邮轮标准黑色）[[30]](#cite_note-30)

* **[樱木町车站](/wiki/%E6%AB%BB%E6%9C%A8%E7%94%BA%E8%BB%8A%E7%AB%99 "樱木町车站")**

:   位于横滨港旁、松崎海一行人前往东京的车站。[[31]](#cite_note-Guide52-31)

* **[新桥车站](/wiki/%E6%96%B0%E6%A9%8B%E8%BB%8A%E7%AB%99_(%E6%97%A5%E6%9C%AC) "新桥车站 (日本)")**

:   故事中松崎海一行人到达东京拜访德丸社长下列车的地点。[[31]](#cite_note-Guide52-31)

## 音乐

动画配乐负责人[武部聪志](/w/index.php?title=%E6%AD%A6%E9%83%A8%E8%81%B0%E5%BF%97&action=edit&redlink=1 "武部聪志（页面不存在）")采用两种路线来制作配乐，其一风格以[直笛](/wiki/%E7%9B%B4%E7%AC%9B "直笛")、[口风琴](/wiki/%E5%8F%A3%E9%A2%A8%E7%90%B4 "口风琴")、[木琴](/wiki/%E6%9C%A8%E7%90%B4 "木琴")等学校音乐教室使用的乐器来搭配出学院的气氛；另一方式则以美洲的[爵士乐](/wiki/%E7%88%B5%E5%A3%AB%E6%A8%82 "爵士乐")、[拉丁音乐](/wiki/%E6%8B%89%E4%B8%81%E9%9F%B3%E6%A8%82 "拉丁音乐")来反映出当时1963年日本引进的流行音乐的风格。[[32]](#cite_note-32)在配乐的主题上则以“当下时代设定”及主角松崎海的“思绪”为主。[[33]](#cite_note-Guide94-33)

《红花坂上的海》的主题歌记者会于2011年3月28日举办，当时因先前发生[2011年日本东北地方太平洋近海地震](/wiki/2011%E5%B9%B4%E6%97%A5%E6%9C%AC%E6%9D%B1%E5%8C%97%E5%9C%B0%E6%96%B9%E5%A4%AA%E5%B9%B3%E6%B4%8B%E8%BF%91%E6%B5%B7%E5%9C%B0%E9%9C%87 "2011年日本东北地方太平洋近海地震")事故，在会场上以庄严静肃的排场进行。[[39]](#cite_note-39)在当时会场上手嶌葵演唱主题歌时，宫崎骏也一度有所感触而忍不住哽咽。[[40]](#cite_note-Guide103page-40)而事后手嶌葵也表示在地震发生前几天录制这首歌时，感觉这首歌就像抚慰人心的“镇魂歌”。[[40]](#cite_note-Guide103page-40)

电影首映后在2011年7月23日至28日期间于[池袋](/wiki/%E6%B1%A0%E8%A2%8B "池袋")西武百货举办原稿展览，[[41]](#cite_note-41)动画的场景来源横滨也在电影上映期间；特意在当地各代表景点（如横滨Marine Tower、看港公园等）或街道上的路灯挂上“U旗”、“W旗”标志，并于元町一带的山手西洋馆展示剧情中出现的港南学园“拉丁区周报”的特展。[[42]](#cite_note-42)

## 反应评价

[[编辑](/w/index.php?title=%E4%BE%86%E8%87%AA%E7%B4%85%E8%8A%B1%E5%9D%82&action=edit&section=19 "编辑章节：反应评价")]

动画电影于日本在2011年7月16日首映，共在457家戏院上档。在16日至18日期间观看人数约45万人，票房收入约5亿8仟7百万日币，为当周首映电影的第3名。[[43]](#cite_note-43)

[日本时报](/wiki/%E6%97%A5%E6%9C%AC%E6%99%82%E5%A0%B1 "日本时报")的马克．席林（Mark Schilling）认为这部影片虽然在剧情走向上容易预料，但在细节处理上容易让人投入在那充满怀旧又准备迎向现代化的时代。[[44]](#cite_note-44)。2023年4月，本片在[烂蕃茄](/wiki/%E7%88%9B%E8%95%83%E8%8C%84 "烂蕃茄")发表“根据烂番茄评论家评比，100部不限时间的最佳日本动画电影”排行榜名列第30名，同时是宫崎吾朗在该站评分最高的作品。该网站的驻站影评家给予本片87%的好评度，共识评论写道“温柔而怀旧，《来自红花坂》是吉卜力工作室最甜美的作品之一——即使它没有突破流派的界限，它仍然像吉卜力粉丝所期望的那样迷人可爱。”[[45]](#cite_note-45)。[Metacritic](/wiki/Metacritic "Metacritic")则依据20条评论（14条好评，6条褒贬不一），获得加权平均分数75分（满分100分），代表“普遍好评”[[46]](#cite_note-46)

松崎海每天在家中庭园升起的[国际信号旗帜](/wiki/%E5%9C%8B%E9%9A%9B%E4%BF%A1%E8%99%9F%E6%97%97 "国际信号旗")，U旗为代表“可能会遇到危险”、W旗为代表“有需要医疗援助”，[[56]](#cite_note-56)合并起来为“希望能航行平安”意思。[[57]](#cite_note-Guide18-57)

* [![](//thumb.wikimedia.org/wikipedia/commons/thumb/5/5c/ICS_Answer.svg/40px-ICS_Answer.svg.png?utm_source=zh.wikipedia.org&utm_campaign=parser&utm_content=thumbnail)](/wiki/File:ICS_Answer.svg)[![](//thumb.wikimedia.org/wikipedia/commons/thumb/e/e2/ICS_Uniform.svg/40px-ICS_Uniform.svg.png?utm_source=zh.wikipedia.org&utm_campaign=parser&utm_content=thumbnail)](/wiki/File:ICS_Uniform.svg)[![](//thumb.wikimedia.org/wikipedia/commons/thumb/8/88/ICS_Whiskey.svg/40px-ICS_Whiskey.svg.png?utm_source=zh.wikipedia.org&utm_campaign=parser&utm_content=thumbnail)](/wiki/File:ICS_Whiskey.svg)**回应旗、U旗、W旗**

风间俊每日早晨在养父的船上看到丘上松崎海家里飘扬的旗帜；而在船上升起的信号旗，为回应对方的意思。[[57]](#cite_note-Guide18-57)

为松崎海在北斗美树的欢送派对上升起的旗帜，是要用来表示“北斗”名字的意义（日文拼音为HOKUTO，只有5个旗帜是因“O旗”只有一份）[[57]](#cite_note-Guide18-57)，而在现实的国际信号旗则无如此的用法，最后一个字母O会以第二代表旗代替，即[![](//thumb.wikimedia.org/wikipedia/commons/thumb/0/0f/ICS_Hotel.svg/40px-ICS_Hotel.svg.png?utm_source=zh.wikipedia.org&utm_campaign=parser&utm_content=thumbnail)](/wiki/File:ICS_Hotel.svg)[![](//thumb.wikimedia.org/wikipedia/commons/thumb/c/c9/ICS_Oscar.svg/40px-ICS_Oscar.svg.png?utm_source=zh.wikipedia.org&utm_campaign=parser&utm_content=thumbnail)](/wiki/File:ICS_Oscar.svg)[![](//thumb.wikimedia.org/wikipedia/commons/thumb/a/a8/ICS_Kilo.svg/40px-ICS_Kilo.svg.png?utm_source=zh.wikipedia.org&utm_campaign=parser&utm_content=thumbnail)](/wiki/File:ICS_Kilo.svg)[![](//thumb.wikimedia.org/wikipedia/commons/thumb/e/e2/ICS_Uniform.svg/40px-ICS_Uniform.svg.png?utm_source=zh.wikipedia.org&utm_campaign=parser&utm_content=thumbnail)](/wiki/File:ICS_Uniform.svg)[![](//thumb.wikimedia.org/wikipedia/commons/thumb/1/1e/ICS_Tango.svg/40px-ICS_Tango.svg.png?utm_source=zh.wikipedia.org&utm_campaign=parser&utm_content=thumbnail)](/wiki/File:ICS_Tango.svg)[![](//thumb.wikimedia.org/wikipedia/commons/thumb/0/08/ICS_Repeat_Two.svg/40px-ICS_Repeat_Two.svg.png?utm_source=zh.wikipedia.org&utm_campaign=parser&utm_content=thumbnail)](/wiki/File:ICS_Repeat_Two.svg)。
