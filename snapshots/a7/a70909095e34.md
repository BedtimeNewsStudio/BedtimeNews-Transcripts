# 快了！淮安、宿迁两市将结束不通高铁的历史

![微信图片_20191112172146.jpg](https://wenhui.whb.cn/u/cms/www/201911/12172415lgvh.jpg)

![微信图片_20191112172146.jpg](https://wenhui.whb.cn/u/cms/www/201911/12172415lgvh.jpg)

记者从中国铁路上海局集团有限公司获悉，11月12日，新建徐州至盐城铁路以及连云港至镇江铁路（董集至淮安段）联调联试圆满结束，11月13日起进入运行试验阶段。目前，两条新线各项工作正有条不紊地展开，年底前将具备开通运营条件。

徐盐铁路横贯苏北沿海和腹地，线路起自徐州东站，终至新长铁路盐城站，正线全长315.55公里，设计时速250公里，为双线电气化高速铁路。全线设徐州东、后马庄、观音机场、睢宁、宿迁、泗阳、淮安东、阜宁南、建湖、盐城等10个车站，于2015年12月28日开工建设。

连镇铁路北承陇海铁路、青盐铁路，中连徐盐、新长、宿淮、宁启铁路，南接沪宁城际铁路，为国家快速铁路网和长三角城际铁路网的重要组成部分，全长约305公里，设计时速250公里，预计2020年全线建成通车。此次运行试验的连镇铁路董淮段正线长117.543公里，接轨于连盐铁路董集站，途经灌云县、灌南县、涟水县、淮安市区，与徐盐铁路交汇于淮安东站。

![微信图片_20191112172141.jpg](https://wenhui.whb.cn/u/cms/www/201911/12172431kvh0.jpg)

据介绍，徐盐、连镇铁路董集至淮安段自9月16日起进入联调联试阶段，期间，对线路各系统进行综合测试，以动态检测对各系统及相关系统间接口、匹配关系进行综合测试，评价和验证牵引供电、接触网、通信、信号、客服、灾害监测等系统的性能或功能，验证轨道、道岔、路基、桥梁、隧道等结构工程的适用性，评价相关设备设施是否满足相关标准的要求，为全线各业务系统和整体系统的调试、优化提供技术支持，使各系统和整体系统的功能及性能达到标准要求，为后期工作提供重要技术保障。上海局集团公司苏北铁路工程建设指挥部创新运用桥梁自动化监测技术、大跨度钢桁架结构整体提升施工关键技术、路桥过渡段填筑轻质混凝土应用等技术；在站房公共区域卫生间增加智能送排风系统、智能调节灯照系统、高清智能防雾卫浴镜等智能化设施，推进站城融合，打造具有文化特色的新时代客站。南京枢纽指挥部联合各参建单位推行标准化管理，优质高效推进工程建设。徐州电务段对信号设备组织集中整治。徐州供电段安排精干力量，加强接触网设备状态检测。

“转入运行试验后，我们会按照试验大纲要求进行列车运行图参数测试、按图运行试验、故障模拟和应急救援演练，检验列车运行图计算标尺的可靠性，验证系统列车追踪能力和各项运行图参数指标是否符合设计要求；检验各系统在正常与非正常条件下运输组织的适应性，验证行车组织方式能否满足运营要求；检验设备故障和自然灾害条件下的应急处理能力；为完善科学合理的运输组织方案提供技术依据。”中国铁路上海局集团有限公司技术人员告诉记者,运行试验使用的动车组车型与正式开通运行后的车型基本一致，但与正式运营列车不同的是，运行试验期间，列车仅模拟正式办理客运业务的相关作业，不载客运行。

据铁路工作人员介绍，徐盐、连镇铁路董集至淮安段此次运行试验为期一个月左右，年底前将具备开通运营条件。开通运营后，江苏省淮安、宿迁两市将结束不通高铁的历史，江苏13个省辖市也将全部迈入高铁动车时代，进一步拉近了沿线城市与长三角中心城市间的时空距离，方便了苏北地区沿线居民出行，推动了苏北地区加速融入长三角快速交通圈和城市经济圈，对振兴乡村经济，实现长三角更高质量一体化发展具有重要意义。
