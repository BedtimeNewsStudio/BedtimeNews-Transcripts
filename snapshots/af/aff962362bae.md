# 靠万达广场火遍全国，“电玩一哥”大玩家破产清算

2026-09-17 13:27:38　来源: [金融界](https://www.163.com/dy/media/T1510627880310.html) ![](https://static.ws.126.net/163/f2e/dy_media/dy_media/static/images/ipLocation.f6d00eb.svg)北京

一家曾把电玩城开进全国多座城市，门店最多超过400家的连锁品牌，如今迎来了破产清算。

今年6月，北京市通州区人民法院就已裁定受理了北京大玩家娱乐股份有限公司（下称"北京大玩家"）的破产清算申请。9月14日，公司召开第一次债权人会议，时代财经依据全国企业破产重整案件信息网公示的联系方式致电相关负责人，对方表示不便进一步披露更多细节。

作为中国最早一批商场大型电玩综合体，2005年7月，第一家“大玩家超乐场”室内游乐场在武汉万达广场开业。2008年，大玩家成为第29届夏季奥运会及残奥会奥组委指定的电子游戏（游戏机）供应商，进驻奥运村；同年，它与万达集团完成战略合作，成为万达广场的主力店。

随着万达广场在全国扩张，大玩家的门店数量也快速增长，2024年时，其门店一度超400家，成为全球最大的室内娱乐电玩连锁公司。但2025年以来，全国各地的大玩家门店开始出现闭店现象。

曾依托万达广场扩张，大玩家跌下神坛

作为历史最悠久的娱乐场所之一，电玩城是不少80、90后的集体记忆。20世纪90年代，游戏厅曾遍布城市的大街小巷，而随着行业逐渐规范，连锁经营的电玩品牌开始兴起，并从街边走进商场。

2005年创立于武汉的大玩家就是商场电玩城时代规模化发展的代表，品牌依托万达广场快速下沉二三线城市。2014年，大玩家在广东东莞开出第100家门店，并推出“PLAY1家庭娱乐中心”品牌；2016年，大玩家参与了“中国电子游戏超级联赛（CGL）”，同年，北京大玩家注册成立。

大玩家门店内配置了大量模拟赛车、音乐街机、IP卡牌机等设备。上游设备厂商广东世宇科技股份有限公司2019年的招股书显示，国内商用模拟竞速、音乐类游艺机市场销售均价超过4万元/台，高端IP机型价格更高。广州华立科技股份有限公司（以下简称“华立科技”）也在投资者交流中提及，千平规模购物中心游乐场整体初始投资区间高达400万—800万元。

在这种重资产的运营模式下，不少游乐连锁企业会高度依赖会员预付储值，并将预收的资金用于支付房租人力、增添新设备等，一旦新增充值放缓、客流下滑，刚性成本与海量待兑付储值负债会集中形成压力。

近年来，随着手游、密室、脱口秀等线上线下新业态的发展，持续分流年轻人休闲时间；叠加行业同质化严重，价格战盛行，大量商家依靠低价储值活动抢夺客流，进一步压缩门店利润空间。

图源：图虫

2024年11月，北京大玩家实控人维军就曾公开表达过担忧，“大玩家也做了一年的低价策略，但我们实践后发现，不是这么回事，低价赢回来的也同样可以失去，低价往往会带来服务质量的下降……无限度地低价是不好的。”

危机很快浮现。2025年，大玩家出现局部门店经营不稳定的问题。2025年6月，四川广元万达大玩家出现大量储值退费投诉，门店闭店，市场监管介入调解。同年9月，泉州浦西万达店宣告闭店，12月上旬设备直接搬空，无退费公告。

2026年大玩家的闭店情况集中爆发。2026年4月，四川遂宁河东新区万达广场店通知撤柜，原会员权益沿用至新品牌；8月，包头九原、青山两家万达广场店全部撤店。上述门店的储值余额大多未消费完，部分由商场协调新商户承接，部分转入司法途径。

最新的闭店案例发生在安庆吾悦广场店，该店于9月9日发布撤店提醒。9月15日，时代财经以消费者身份致电大玩家安庆吾悦广场店，店长表示门店目前仍在营业，但目前没有人员具备处理储值问题的权限。受人力成本因素影响，门店原本计划营业至9月20日，后根据相关要求延长营业时间至10月8日，不过其也无法确认门店能否维持到该时间节点。

此外，在黑猫投诉，也有多起关于大玩家的退款投诉，涉诉金额从数百元至数千元不等，投诉内容集中在“门店闭店后会员系统无法登录”、无法查询余额、退款无进展等。

6421万元的应收账款，上游供应商被拖下水

大玩家的困境，也影响到了上游供应商华立科技。

据了解，华立科技（301011.SZ）是国内商用游戏游艺设备的龙头企业，2021年登陆深交所创业板。公司手握宝可梦、头文字D、奥特曼等多个海外知名线下游艺IP国内发行权。

追溯两家公司公开可查证的早期合作，要回到华立科技还没上市的时候。

根据华立科技招股书披露，2018—2020年，北京大玩家连续三年成为公司断层第一的大客户。其中2020年针对北京大玩家的销售金额达5859.75万元，占华立科技当期总营业收入的13.79%。

如今，大玩家的经营问题直接影响了华立科技2026年半年报的财务数据。

据华立科技公告，截至2026年6月30日，华立科技对大玩家的应收账款原值为6421.56万元，其中本期计提坏账准备4788.80万元，期末单项认定并全额计提坏账准备，计提比例100%，理由为“客户已被裁定受理破产清算，预计款项较难收回”。此外，公司对大玩家的对外投放设备计提资产减值准备74.71万元。两项合计，减少2026年半年度利润总额4863.51万元。

华立科技半年报同期数据也在承压，公司上半年实现营业收入3.34亿元，同比下降30.59%；归属于上市公司股东的净亏损为1.09亿元，上年同期为盈利3497.96万元，由盈转亏。

9月15日，时代财经在华立科技半年报业绩说明会上，就公司与大玩家的纠纷处置进展、下游游乐连锁资本开支意愿，以及设备、场地投放订单是否短期承压等问题进行提问。公司财务总监冯正春回应称，华立科技已完成对大玩家的债权申报，将在破产清算程序中依法主张相关权利。

他同时提到，国内游乐行业同质化竞争加剧，下游客户新开门店趋于谨慎，致使公司国内业务阶段性承压。不过海外市场需求仍具备韧性，公司将寄望依靠海外业务对冲国内行业周期带来的经营压力。

受牵连的远不止华立科技。据天眼查，北京大玩家作为被告的诉讼超250条，其中2026年就超150条；公司目前已被列入失信被执行人名单，公司实控人维军和法定代表人舒戎被限制高消费。

“我们员工自己原来的工作系统都无法打开了，消费者如果坚持要求退款风险还是比较大的。”面对时代财经全额退款的要求，大玩家安庆吾悦广场的店长如是回应。

此外，北京大玩家管理人近日发布的《职工债权公示（第一批）》显示，共有174名员工合计被欠工资与经济补偿金达4360.26万元。

对于权益受损的员工、供应商、商场和消费者来说，关于大玩家的清算或许才刚刚开始。
