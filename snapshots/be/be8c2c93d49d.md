# 香港亚视复活 改玩网络电视

## 

#### 雷 蕾

|  |
| --- |
|  |
| 亚视复活启动仪式现场。 　　（资料照片） |

![](../../../res/1/20180203/1517595712930_1.jpg)

　　亚视复活启动仪式现场。  
　　（资料照片）

　　香港历史最悠久的电视台——亚洲电视前些年陷入经营危机许久，终于2016年4月1日停播，令老少观众唏嘘不已。然而，随着娱乐方式日趋多元与互联网产业日益发达，亚视经历重组后再度“复活”！1月29日，亚洲电视数码媒体（亚视）正式启播，目前投资额达4亿元。

　　复活后的亚视如何收看？观众不仅可以走“传统路线”，购买机顶盒连接电视收看，还可以走“时尚路线”，通过手机下载“ATV 亚洲电视”软件收看网络电视。机顶盒连1年会员服务套餐价为680港元，手机软件则分为收费和免费，收费月费为38港元，可以观看更多节目。

　　亚视行政总裁吴雨表示，启播后的亚视节目中，重点是播放韩剧及电影，上周他们已经签约买下几百部。音乐方面，腾讯将提供音乐流行榜，每周在内地与港台以及韩国挑选10首歌推介。自制节目则会推出有奖竞答《百万富翁2018》，自制剧集则会推出吴宇森版的《英雄本色》等。

　　自去年12月18日“ATV 亚洲电视”软件开放下载以来，已有大批香港市民点击下载，开台以来的浏览次数已达700万次。

　　参加亚视启播礼的嘉宾任贤齐认为，亚视复活是好事，因为香港有很多优秀的艺人，如果没有平台给他们发挥实在可惜，若多一个平台供大家发挥，就会有良性竞争。艺人苏永康也表示，看到亚视复播感觉好神奇，当年自己曾在电视上见证亚视熄机，如今感到世事无绝对。

　　香港亚洲电视台在上世纪80年代推出的《大侠霍元甲》《精武门》《纵横四海》等电视剧，成为港澳台和内地众多观众心中的经典记忆。
