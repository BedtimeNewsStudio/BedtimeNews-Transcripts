| 甲A第21轮盘口扑朔迷离 连津、沪滇两战最蹊跷 |
| --- |
| * * * |
| http://sports.sina.com.cn 2003年10月17日22:23 新浪体育 |
|  |
| 新浪体育讯　周三、周四甲A刚打完第20轮的赛事，本周末马上开始第21轮的比赛，四川冠城本轮轮空。

第20轮的赛事的7场比赛只有青岛贝莱特在主场2比0击败了陕西国力，另外6支主队的战绩为4平2负。而澳门彩票有限公司对20轮的6场比赛都开出了盘口，陕西国力的比赛再次被舍弃。有意思的是，这6场开盘的赛事最终的盘口都是平手，这是极为罕见的现象。值得一

|     |
| --- |
|  |

提的比赛是上海国际主场对山东鲁能泰山的比赛，一开始的正式盘口是上海国际让一球，接着跌到让半球/一球，让半球，让平手/半球，最终定格在平手。而那场比赛两队最终0比0战平，多少有点让人意外。应该说，澳门彩票有限公司对第20轮的开盘“证明了自己的实力”。

由于近来的甲A实在是问题多多，让澳门彩票有限公司在选择赛事时更加谨慎。目前它已经对深圳健力宝和青岛贝莱特的比赛开出了正式的盘口，而其它6场比赛只有大连实德VS天津康师傅、上海申花VS云南红塔2场比赛留在“赛程表”里面，这样澳门将只是对本轮的3场比赛开盘，创下新低。而连津、沪滇之战到今天21点30分依然没有开出初步盘口，这也是近来少见的。

下面先为大家介绍澳门彩票有限公司开盘的3场比赛(主队列前)：

**深圳健力宝VS青岛贝莱特(18日15:30)**

本赛季首回合深圳健力宝客场和对手0比0战平，两队近6次交手深圳健力宝4胜2平保持不败，这6次交手青岛贝莱特只是取得1个进球。周三深圳健力宝客场0比0战平了天津康师傅，连续17轮不败，继续占据积分榜首位。但近来深圳健力宝进球不多，因此有不少平局。有消息说，为了刺激球员多进球，俱乐部打算在赢球奖金的基础上，每净胜1球多奖10万。深圳健力宝和上海国际同为目前甲A主场不败的球队，本赛季9个主场深圳健力宝6胜3平。近5个主场赛事该队4胜1平，甚至没有一个失球。这5场比赛的盘口则是4赢1走，相当强劲。周三青岛贝莱特主场2比0完胜陕西国力，止住了2连败的颓势。本轮高明因累积3张黄牌而停赛，他在过去的5轮比赛有4场比赛有进球，他的缺席对青岛贝莱特打击很大；安德烈和马荃因为有伤，本场比赛无法上阵。面对这样的困境，前一段时间被“下放”的白毅被主帅李章洙召回。当前澳门盘口为深圳健力宝让一球，贴水为0.825。临场时这个盘口可能上浮，选择入手时机是关键。

**大连实德VS天津康师傅(19日14:30)**

本赛季首回合大连实德客场2比0击败了天津康师傅。大连实德周三在客场2比0击败了云南红塔，结束了此前4轮只是拿到1分的尴尬，对鼓舞士气至关重要。现在它离榜首的深圳健力宝只有3分的差距，依然是冠军的有力争夺者。天津康师傅周三在主场0比0战平了领头羊深圳健力宝，在第3阶段的5场比赛中取得2胜2平1负的佳绩。核心于根伟的出色发挥是该队近来成功的关键，他在近5轮比赛取得5个进球。本轮中场悍将托夫丁解禁复出，能让康师傅的中场防守更加稳固。到21点30分，澳门连初盘都未给出。易胜博初盘是大连让一球/球半，贴水为0.95。

**上海申花VS云南红塔(19日15:30)**

本赛季首回合上海申花客场0比2失利。凭借张玉宁的进球，上海申花在周四晚上的比赛中客场1比0击败了辽宁中顺，近4轮2胜2平。张玉宁近2轮包办了球队的3个进球，状态正佳。云南红塔在输给深圳健力宝后，周三又在主场被大连实德2比0击败，输掉这2场关键的比赛对士气的打击可想而知。在这个赛季云南红塔也曾遭遇2连败，随后该队打出3连胜。云南前卫史鸣本轮解禁复出。澳门现在还没有对本场比赛开出初盘。易胜博初盘为上海申花让半球，贴水为0.85。这个盘口比较合理。

另外，易胜博公司对本轮澳门彩票有限公司不打算开盘的赛事也都开出了盘口(暂时未正式接受投注，不排除临时撤盘的可能。和澳门一样，该公司甲A盘口的贴水总和为1.80。)

下面为大家简单介绍易胜博开盘的几场赛事(主队列前)：

**北京现代VS上海国际(18日18:00)**

首回合北京现代客场0比1落败。北京现代意外地在足协杯后夺冠后，尽管缺兵少将，但是在近3轮取得1胜2平的不败战绩。本场比赛雷吉纳尔多、崔威、徐云龙、张帅依然停赛。上海国际上轮0比0主场被山东鲁能逼和，一时间引来不少流言飞语。易胜博初盘为平手，北京现代贴水为0.85。

**陕西国力VS重庆力帆新感觉(19日15:30)**

本赛季首回合陕西国力主场2比0获胜。两队目前在联赛垫底，这场比赛也是关系到冲“中超”的关键战役。另外，两队在第3阶段开始前曾经打过1场热身赛事，结果比赛中出现了火爆的球员冲突场面，因此本场比赛会非常激烈。周三重庆力帆新感觉在主场和北京现代0比0战平，联赛3连败后3连平。门将李健因被追加处罚而依然停赛，外援哈吉累积3张黄牌停赛。好在邱卫国、张远杰、魏新解禁复出。陕西国力在本赛季已经进行的9场主场联赛中，除了第1个主场没有丢球，后面的8场都有失球，多达21球，为甲A最差。本场比赛刘正坤累积3张黄牌而停赛。易胜博初盘为平手，陕西国力贴水为0.80。

**沈阳金德VS辽宁中顺(19日15:30)**

同省球队的德比战，本赛季首回合赛事沈阳金德客场2比3失利。沈阳金德周三在客场1比1战平了四川冠城，已经连续10轮不败，其中近4轮1胜3平。张晓鸥本轮解禁复出，不过外援埃孔累积3张黄牌而停赛。辽宁中顺和上海申花的比赛是在周四晚上才进行的，因此体能上辽宁中顺会比较吃亏。那场比赛辽宁中顺是主场0比1失利，近4轮2平2负(但只有输给陕西国力让人意外，因为另外3个对手是深圳健力宝、大连实德、上海申花)。易胜博初盘为沈阳金德让半球，贴水为0.95。

**山东鲁能泰山VS八一湘潭(19日15:30)**

本赛季首回合两队0比0闷和。周三山东鲁能泰山在客场0比0逼和上海国际，2连胜后取得取得2连平。山东后卫矫喆本轮解禁复出。八一湘潭在周中的那轮赛事轮空，对近5轮1平4负的它是不错的喘息良机。易胜博初盘为山东鲁能泰山让一球，贴水为0.80。
