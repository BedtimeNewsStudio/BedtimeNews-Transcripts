# 亏损2000亿，卖总部求生：日产汽车经历了什么？

**01 卖掉总部大楼，日产也难回血**

全球第九、日本第三的车企，日产陷入了危机。8年前中国销量第一的日系车，如今半年亏损2000亿，全球裁员2万人，CEO跑路，业务大范围收缩。

![图片](https://inews.gtimg.com/news_bt/Okk_Y6u3ieQqEhJNS8T3NisHBlpqqXWt9CicBq_GMaWP4AA/641)

不久前日产发表公告：把横滨的总部大楼，卖给了一家中国企业，买家那已经谈妥了，卖掉后再把整栋楼租回来，从房东变成租客，一来一回，回血了700多亿现金。

2025年2月4号，日产在高层会议上爆发了激烈的争吵。分管制造的副总裁坂本秀行，在会上强烈反对本田把日产变成子公司的方案。日产董事会不得不在次日紧急召开会议。经过表决，以2比10的压倒性比例，否决了子公司化的提案，并终止了和本田的合并谈判。

![图片](https://inews.gtimg.com/news_bt/Oz6j8zb79AU6x2ugVb_dJ2KsKpAgfWTZZEWQGthjg5fxEAA/641)

02 **与本田合并谈判破裂，CEO权威受质疑**

2月6号上午，日产CEO内田诚带着一众高管，来到了东京南青山的本田总部大楼。双方谈了近1个小时，内田诚向本田CEO三部敏宏，正式传达了终止合并的意向。

面对接二连三的“变卦”，本田的忍耐已经到达了极限。本田的不满，有相当一部分，直指日产CEO内田诚。从谈判的一开始，本田就把“日产先完成重组”写进了前提，要求日产提出更激进的裁员、产能削减方案。

![图片](https://inews.gtimg.com/news_bt/OhEoXcqm_uUk_9ullke2hF1gW7HT1_tRNLplW0d2j8Lq4AA/641)

但在本田看来，日产的调整不仅力度太小，还总是“说一套、做一套”。最典的一幕，出现在日产提出裁员9000人、关闭五分之一产能的重组方案后不久。

2025年1月，日产副总裁，坂本秀行造访九州，不仅高调宣布要投资1500亿日元，新建一座电池工厂，还在当地政界人士陪同下郑重承诺：日产不会削减九州工厂产能。这让本田极为震惊。

![图片](https://inews.gtimg.com/news_bt/Omf6qavXeGS-fO5JfkOa-yVFVUYh-BQvLtCoNLI8oZJv0AA/641)

一位本田内部人士透露：“谈判过程中，经常出现双方CEO已经谈好的事情，回到日产内部后又被推翻的情况。”这里的问题不仅是判断力，更是CEO是否“说了算”的能力。

经过多次“反复”后，本田逐渐得出判断：内田诚无法真正控制日产内部的派系。要想推进合并，只剩下两条路：要么换掉内田诚，来一个能镇住场的人；要么让日产彻底成为本田的子公司，由本田主导重组。

![图片](https://inews.gtimg.com/news_bt/OPO-nS9DOa9dzP_vKDKVT62LqxXSO1319pJyb_WdEznPsAA/641)

本田的判断，或许并不是空穴来风。一位日产员工表示：和内田诚相比，副总裁坂本秀行无论年龄、资历还是履历，都更有“分量”。在日产内部，相当一部分人私下里更认可坂本，而不是那位名义上的“社长”。

所以，就在坂本在九州宣布投资的第二天，本田CEO三部敏宏就告诉内田诚：日产需要成为本田的子公司。这当然是日产无法接受的。

![图片](https://inews.gtimg.com/news_bt/OsrqKlJJwmidpcXm52c_WnaBGicFODprqesITYogr0dzMAA/641)

# **03 外部董事掌权，无人为未来拍板**

可更重要的一个问题是：为什么一家公司CEO的决策，总是在内部被推翻？这和日产曾经的“传奇CEO”，卡洛斯·戈恩有关。

1999年，法国雷诺入股濒临破产的日产，派时任高管戈恩来日本救火。戈恩通过大规模裁员、关厂、砍成本，让日产迅速扭亏为盈。巅峰时期的戈恩，一人身兼雷诺、日产和三菱三家CEO，雷诺日产三菱联盟的销量，一度可以和丰田、大众分庭抗礼。

![图片](https://inews.gtimg.com/news_bt/O4HJh_FRuC3OHuxQxOKdP6DxENXWJWV9YQqqrRbrDb3t0AA/641)

但在戈恩时代，权力也高度集中。 一位日产前高管回忆，戈恩曾直言：“不要选会提出异议的外部董事。”结果是，外部董事人数偏少、权力被弱化，无法对CEO形成有效的制衡。

2018年，日本检方逮捕戈恩，指控其少报收入、滥用公司资产。戈恩则坚称：这是日本政府和日产内部的保守派，阻止他推进雷诺和日产合并的报复。

戈恩风波后，为防止CEO“一人独大”，日产改变了公司的治理结构。看现在日产的董事会，很难让人相信，这竟然是一家车企。12人董事会里，有8名是外部董事，剩下的4人里，又有2人来自雷诺。真正算得上属于日产的，只有2个人，就连董事会主席，都是由外部董事担任。

![图片](https://inews.gtimg.com/news_bt/OTjVencF-Hi7EGsamScr3XxXqxbiUwNxCGe9xTopveDJ0AA/641)

对一般日本公司来说，外部董事通常只是董事会的一部分，负责帮忙看战略方向、内部控制、合规有没有跑偏，“点到为止”。但日产，却是少见的由外部董事主导经营的公司。

来自官僚、IT、能源、银行、大型商社和消费品企业的外部董事们，不仅能自己决定谁当董事、谁当CEO、薪酬多少，还能直接拍板日产的经营方针、重大投资，甚至联盟战略。

他们熟悉管理、财务、监管、资本市场，却对于日产的车型、产品力、区域市场、经销体系几乎没有一线经验。这也导致：在面对电动化转型和全球布局这些问题时，他们总是“问的多，拍板少”，更倾向于规避风险，而不是押注未来。很多人有否决权，却没有人能拍板负责。

![图片](https://inews.gtimg.com/news_bt/OtG6YhiHHzgTTkz4zE1PoJIQz4OSQ6YS0XCnZMlXNGrPcAA/641)

他们更像是用来修复治理、安抚资本市场、制衡大股东和内部派系的工具，而不是决定下一代奇骏长成什么样的人。

# **04 十年吃老本，谁都没错但机会没了**

过去十年，日产都在“吃老本”。明知中国市场不买账，却强推三缸的奇骏，一辆逍客卖了8年才换代，老款还要改名成“逍客经典”，和新款一起卖。

美国市场更是夸张：一款老皮卡卖了十几年，当丰田和起亚凭着混动风生水起的时候，日产却连个像样的插混都拿不出来，全靠几款老车支撑销量。

![图片](https://inews.gtimg.com/news_bt/Oc4Z6sRPKegYS_o76euX5c_AtpZEE0KQdrFXGNhYhDdLcAA/641)

一名日产开发人员无奈地说：日产缺乏有竞争力的新车型，很多本该改款的车一拖再拖，主要原因就是“内部拉扯得太久”。开发部门说有机会，财务说成本太高，区域事业体担心销量不达标，董事会又顾虑股东反应…

谁都没犯错，但机会就这么没了。一名行业分析师回忆：早在2023年，外界就不断追问日产管理层——“没有混动怎么办？” “美国和中国市场真的没问题吗？”

![图片](https://inews.gtimg.com/news_bt/OpdAWYWuA6iv47wInbIudpQiRat8w4mToPdMC7Yk9DxdEAA/641)

管理层的回答都是“没问题”。他事后评价：“日产对形势的认识太过天真。这是经营的失败，是人祸。”

可能是预感到了风向的变化，2025年2月13日，在第三季度的业绩发布会上，内田诚意味深长地说：如果有人说已经不再需要我了，我不会赖在CEO的位置上。但话锋一转，他又表示：自己对日产的重建负有责任，“很想把这件事做完”。

![图片](https://inews.gtimg.com/news_bt/OONZuel5jeWPZ49KE4mmtKp2qaF6UMGvDkWFbZKnHITQ4AA/641)

一个月后，日产董事会果然宣布：内田诚将卸任总裁兼CEO。和他一起退场的，还有副总裁坂本秀行、CTO中畔邦雄等多名高管，整个执行层几乎被重组了一遍，包括雷诺派来的两名董事也被“换血”。与此同时，8名外部董事却无一变动，全部留任。

对此，一名前日产高管的评价是：“难以置信。”接任CEO的，是墨西哥人伊万·埃斯皮诺萨（Ivan Espinosa）。

![图片](https://inews.gtimg.com/news_bt/Oi3_w4QRlvJ1ELYhFilaJa-3g9kMWZ5nMN_gOt6vNOp7YAA/641)

# 05 股东怒吼也枉然，重建在骂声中开始

5月13号，日产公布2024年业绩：从上一年盈利4200亿日元，跳水成巨亏6700亿。董事会决定全年不分红，并暂停发放股息。

在随后的说明会上，日产提出了新的重组计划，“Re:Nissan”，准备裁员2万人，关闭17座工厂里的7座，缩减30%的产能，暂缓部分车型的开发。压抑已久的不满，终于在股东大会上爆发了。6月24号的股东大会足足开了3小时6分钟，比去年多了1小时19分。

![图片](https://inews.gtimg.com/news_bt/OJbGwssiYTHvOhrGq7PFDVB19mNfXBXIJRnRgj9uY4Th8AA/1000)

在会场入口，愤怒的日产员工向入场者派发传单，用扩音器大声演讲，反对裁员关厂的重组计划。在大会现场，同样有股东质问：为什么董事们给自己开着高薪，却在公司亏损时关厂裁员，让一线员工承担后果？

![图片](https://inews.gtimg.com/news_bt/O5E4G6cJbNn_z65XCHPTUdeywoMFtyNyCs6CcL7SRuL0YAA/641)

还有人现场质问董事会：你们是否会感到羞耻？现场一片混乱，甚至出现了怒吼声。股东提出了5项议案，包括限制董事会权力、恢复分红、将董事薪酬与股价挂钩等，但全部遭到了否决。8名外部董事无一例外，全部留任。

会场内外的愤怒，最终没能撼动日产的权力结构。重建就这样，在一片反对和骂声中开始了。11月6日，日产公布了重组计划的最新进展：把位于横滨的总部大楼，卖给了一家中国企业，预计可录得739亿日元的一次性收益。

但同期发布的2025半年报却显示：公司又创下了2219亿日元的亏损。卖总部换来的收益，还是填不上亏损的窟窿。

![图片](https://inews.gtimg.com/news_bt/Oj7qTcIyyVExyIJXQW-NY3doGl5a278lLA7caaHczbVJUAA/641)

归根结底，最关键的问题还是没有答案：如果靠卖车赚不到钱，靠卖楼，又能支撑多久呢？
