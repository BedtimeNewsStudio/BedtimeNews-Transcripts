| ![](https://www.chinawater.com.cn/js/gcjsxw/202304/W020230421329246312365.jpg)<br>环北部湾广东水资源配置工程云开山隧洞先行建设项目施工现场 本报记者 **杨晶** 摄<br>**本报讯**（记者 **杨晶 周华宁**）4月20日上午，在环北部湾广东水资源配置工程B1施工标段郑村倒虹吸出口施工现场，数台大型设备忙碌运转，建设者正在进行隧洞口支护施工。自此，环北部湾广东水资源配置工程已开工建设48个工区，43家参建单位全面进场，3000多名施工人员和460多台大型机械设备进场作业，工程进入全线施工阶段。<br>环北部湾广东水资源配置工程是国家水网骨干工程、国家150项重大水利工程之一，是广东历史上引水流量最大、输水线路最长、建设条件最复杂、总投资最高的跨流域引调水工程。工程北起云浮市郁南县西江干流地心村，南至湛江市徐闻县大水桥水库，横跨云浮、阳江、茂名、湛江4市，输水线路总长490.33公里，总投资614.56亿元，总工期96个月。工程建成后，将系统性解决粤西4市水资源短缺问题，彻底结束雷州半岛千年苦旱的历史，惠及沿线1800万人。<br>来源：中国水利报 2023年4月21日 |  |  |  |  |  |  |
