# 镜铁区

**镜铁区**，是[中华人民共和国](/wiki/%E4%B8%AD%E5%8D%8E%E4%BA%BA%E6%B0%91%E5%85%B1%E5%92%8C%E5%9B%BD "中华人民共和国")[甘肃省](/wiki/%E7%94%98%E8%82%83%E7%9C%81 "甘肃省")[嘉峪关市](/wiki/%E5%98%89%E5%B3%AA%E5%85%B3%E5%B8%82 "嘉峪关市")下辖的一个[行政管理区](/wiki/%E8%A1%8C%E6%94%BF%E7%AE%A1%E7%90%86%E5%8C%BA "行政管理区")[[1]](#cite_note-1)。

2009年12月1日，嘉峪关市[雄关区](/wiki/%E9%9B%84%E5%85%B3%E5%8C%BA "雄关区")、[长城区](/wiki/%E9%95%BF%E5%9F%8E%E5%8C%BA "长城区")、镜铁区挂牌成立。“中共嘉峪关市镜铁区委员会”、“嘉峪关市人民政府镜铁区”是市委、市政府派出机构，县级建制。区委、区行政内设党群工作部、经济发展部、综合管理部、社会事业部、办公室、卫生和计划生育办公室6个职能科室，均为科级建制，后陆续增加妇联、基层精神文明建设办公室、人大代表联络工作办公室。鏡鐵區辖[前进街道](/w/index.php?title=%E5%89%8D%E8%BF%9B%E8%A1%97%E9%81%93_(%E5%98%89%E5%B3%AA%E5%85%B3%E5%B8%82)&action=edit&redlink=1 "前进街道 (嘉峪关市)（页面不存在）")，[峪苑街道](/w/index.php?title=%E5%B3%AA%E8%8B%91%E8%A1%97%E9%81%93&action=edit&redlink=1 "峪苑街道（页面不存在）")，[朝阳街道](/w/index.php?title=%E6%9C%9D%E9%98%B3%E8%A1%97%E9%81%93_(%E5%98%89%E5%B3%AA%E5%85%B3%E5%B8%82)&action=edit&redlink=1 "朝阳街道 (嘉峪关市)（页面不存在）")，[文殊镇](/wiki/%E6%96%87%E6%AE%8A%E9%95%87_(%E5%98%89%E5%B3%AA%E5%85%B3%E5%B8%82) "文殊镇 (嘉峪关市)")，为[嘉峪关市人民政府](/wiki/%E5%98%89%E5%B3%AA%E5%85%B3%E5%B8%82%E4%BA%BA%E6%B0%91%E6%94%BF%E5%BA%9C "嘉峪关市人民政府")的正县级派出机构。全区共有干部职工487人，其中：在编干部154人（行政编制35人，参公编制1人，事业编制112人，工勤编制6人；处级干部11人，科级干部80人，一般干部63人），大学生村官、进村进社、三支一扶及民生实事人员共计28人，社区工作人员204人，协理员101人。2017年，管辖1个镇（文殊镇）、6个行政村（河口村、团结村、石桥村、冯家沟村、文殊村、塔湾村），13个社区（铁北社区、迎宾社区、铁南社区、德惠社区、昌盛社区、峪苑社区、曙光社区、和城社区、佳苑社区、朝晖社区、紫轩社区、明珠社区、南湖社区），总人口124515人，其中常住人口108473人。2017年实现农村社会总产值4.1亿元，其中农业总产值1.87亿元，二、三产业总产值2.05亿元。

辖区属于管理区，还不是正式的[县级行政区](/wiki/%E5%8E%BF%E7%BA%A7%E8%A1%8C%E6%94%BF%E5%8C%BA "县级行政区")。但是此三区的设置也结束了嘉峪关市不设区的历史。但嘉峪关市没有成立完全的区政府，只是将原来的市城区[工委](/w/index.php?title=%E5%B7%A5%E5%A7%94&action=edit&redlink=1 "工委（页面不存在）")、郊区工委、工业园区三个单位撤了，职能转到三个重新划片管理区。

2019年6月28日《甘肃省人民政府关于同意嘉峪关市设立雄关街道办事处和钢城街道办事处的批复》（甘政函〔2019〕74号），撤销了镜铁区，辖域分入新设立的[雄关街道办事处](/wiki/%E9%9B%84%E5%85%B3%E8%A1%97%E9%81%93 "雄关街道")和[钢城街道办事处](/wiki/%E9%92%A2%E5%9F%8E%E8%A1%97%E9%81%93_(%E5%98%89%E5%B3%AA%E5%85%B3%E5%B8%82) "钢城街道 (嘉峪关市)")。
