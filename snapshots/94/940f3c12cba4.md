### CNB 是什么？

[CNB - Cloud Native Build](https://cloud.tencent.com/developer/tools/blog-entry?target=https%3A%2F%2Fcnb.cool%2F&objectId=2556651&objectType=1&contentType=undefined)

CNB (Cloud Native Build) ，中文名“云原生构建”，是一个由腾讯云原 Coding 团队打造的，集成 [代码托管](https://cloud.tencent.com/product/coding?from_column=20065&from=20065)、云原生 CI/CD 构建（秒级启动）、云原生开发的一站式开发平台。主打一个开发人员的时尚单品，Everything as code

### CNB MCP 又是什么？

[CNB MCP服务器 - 腾讯云](https://cloud.tencent.com/developer/mcp/server/11716?from_column=20421&from=20421)

CNB MCP 是一种基于 Model Context Protocol (MCP) 开放协议的服务器，它标准化了应用程序向大模型提供上下文的方式，主要用于自动化管理 CNB 代码仓库，提升开发者的工作效率的工具包。其核心功能包括：

1\. 代码仓库操作。支持文件读写、仓库创建/删除、分支管理等操作，开发者可通过自然语言指令让 AI 自动执行代码仓库的日常维护任务

2\. 问题跟踪与协作。自动搜索 CNB 仓库中的 Issues 和 Pull Requests，识别相似问题并提供解决方案。例如，当开发者询问“某个错误是否已知”，AI 可结合错误信息自动搜索相关仓库并生成反馈，甚至直接创建新 Issue

3\. 集成开发流程。作为 AI 工具（如 Cursor、Windsurf）的扩展模块，CNB MCP Server 使 AI 能够深度参与开发流程，例如自动审查代码、生成 PR 描述、合并分支等，减少人工操作

4\. 标准化接口优势。通过 MCP 协议，开发者无需重复对接 CNB API，即可复用现有服务。同时，AI 模型可动态发现并调用服务器提供的工具，实现灵活的上下文交互

总结来说，CNB MCP Server 通过自动化和智能化手段，将 AI 能力嵌入代码管理场景，显著提升开发效率与协作质量

### 开工！手把手教你「云原生开发」

#### 第一步：准备「云原生开发」

先申请访问令牌，操作步骤见 [访问令牌 \| 云原生构建](https://cloud.tencent.com/developer/tools/blog-entry?target=https%3A%2F%2Fdocs.cnb.cool%2Fzh%2Fguide%2Faccess-token.html%23fang-wen-ling-pai-shen-qing&objectId=2556651&objectType=1&contentType=undefined)

令牌场景选择“MCP 读写凭据”，创建后一定一定一定要复制到其他地方保存，关闭弹窗后无法查看

再创建密钥仓库，操作步骤见 [密钥仓库 \| 云原生构建](https://cloud.tencent.com/developer/tools/blog-entry?target=https%3A%2F%2Fdocs.cnb.cool%2Fzh%2Frepo%2Fsecret.html&objectId=2556651&objectType=1&contentType=undefined)

“仓库归属”下拉框，选择自己的用户名

密钥仓库创建成功后，进入仓库创建名为“envs.yml”的文件，填入 CNB\_API\_TOKEN=<刚才保存的令牌>，点击完成创建

![新建文件](https://developer.qcloudimg.com/http-save/yehe-6868864/bbafb3e978c47c1499eab56243eec65a.png)

新建文件

![添加密钥](https://developer.qcloudimg.com/http-save/yehe-6868864/a7997d16bde59f3dd40400e66c059a78.png)

添加密钥

#### 第二步：打开「云原生开发」传送门

不用下载任何东西，手机/平板/公共电脑都行——直接戳进项目仓库地址。这里以 [https://cnb.cool/wanpy/vuepress-starter](https://cloud.tencent.com/developer/tools/blog-entry?target=https%3A%2F%2Fcnb.cool%2Fwanpy%2Fvuepress-starter&objectId=2556651&objectType=1&contentType=undefined) 仓库为例

找到「新建分支」按钮，点击新建

![新建分支](https://developer.qcloudimg.com/http-save/yehe-6868864/23d6c42e85a887e8186c034d34802c25.png)

新建分支

会出现弹框，“分支名称”方便记忆即可，“创建来源”默认

成功创建名为“have-a-try”的分支后，点击右边“云原生开发”按钮，开始创建开发环境

![云原生开发，启动！](https://developer.qcloudimg.com/http-save/yehe-6868864/a31e5a20ed69ab295c0e533d8c910073.png)

云原生开发，启动！

![云原生开发加载中](https://developer.qcloudimg.com/http-save/yehe-6868864/99736db3bef0797a06c1a974a368b448.jpg)

云原生开发加载中

#### 第三步：召唤「云原生开发」搭子

点进「云原生开发」入口，这时候两个神器会自动上线：

注：代码仓库已提前做好了配置，详情见示例仓库的 .ide 和 .cnb.yml

● 腾讯云 [代码助手](https://copilot.tencent.com/?fromSource=gwzcw.9659298.9659298.9659298&utm_medium=cpc&utm_id=gwzcw.9659298.9659298.9659298&from_column=20065&from=20065) CodeBuddy：AI 时代你的智能编程伙伴，让灵感即刻落地

● CNB MCP Server：你的开源社区管家，提 ISSUE、改代码、跟进度全包揽

CodeBuddy 阅读整个仓库并进行理解，准确找到需要修改的文件，然后调整代码
