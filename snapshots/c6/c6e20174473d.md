| 北京国际高尔夫俱乐部邻近风光秀美的十三陵水库，球场总面积达100万平方米，全长6,986码，18洞，标准72杆。俱乐部于1986年开业，是北京市第一家高尔夫球场，距离北京市中心仅40分钟车程。极目远眺，北京著名风景区十三陵水库全景尽收眼底，18洞球道沿途群山耸立，无限风光在球会之中。<br>曾连续三年举办"富豪中国公开赛"。中国著名球手程军便于1997年在这里捧走了第三届总奖金40万美元的"富豪中国公开赛"的冠军军宝座。1988年的世界名人邀请赛和1992年的第二十一届池田厚子杯比赛也相继在这里举行。<br>球场绿茵如织，500码以上长球道。难度系数最大的要算是7号洞和4杆洞，发球台前水池碧绿，流水潺潺。17号球道是一个长199码的3杆短洞，短球道，水池中荷花丰姿绰约、悠悠小桥流水、翠绿的草坪，波光盈盈的水面……堪称本球场的精采球道。发球好手在这里的最前和最后一个球洞，都大有表演和发挥的机会。<br>联系地址： 北京市昌平区十三陵水库北侧<br>球会电话： (86 10) 6076 2288<br>球会传真： (86 10) 6076 1111<br>球会网址： |  |  |  |  |  |  |
