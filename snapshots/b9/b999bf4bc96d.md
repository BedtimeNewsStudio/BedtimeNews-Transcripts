# 抖音电商“双11”开局数据公布 助力商家稳增长

人民网北京10月20日电 （记者乔雪峰）10月15日，2026年抖音商城双11好物节启动。抖音电商公布的首日数据显示，平台成交额新突破百万元的商家数量同比增长74%，店播成交额破千万元的商家数量同比增长96%，首次参加双11且成交额突破百万元的达人数量同比增长30%。与此同时，服饰、美妆个护、快消、宠物用品等类目也呈现高增长，中小新商、达人及特色行业商家的阶段经营表现受到关注。

记者了解到，活动将持续至11月11日，今年双11主要围绕优惠机制、商家经营扶持和秋冬换季消费需求展开，平台通过消费券、流量激励及经营补贴等措施，为商家参与大促提供支持。10月15日至18日，抖音电商双11“开门红”阶段延续了首日的增长态势，店播新商及特色行业产业带商家继续取得良好表现。

**优惠做减法，购物体验做加法**

今年抖音电商双11活动周期为28天，采用现货销售模式，不设置预售环节。活动期间，平台延续“立减折扣”“一件直降”两种优惠方式，减少凑单要求，并通过平台出资消费券进一步增加优惠。

其中，“立减折扣”在商品报名价基础上立减15%，“一件直降”由商家自主确定直降金额，两种方式均由商家出资；平台消费券则由平台出资，并在抖音及豆包、红果短剧、今日头条等多个端分批发放。消费者按照活动规则参与，累计最高可享万元优惠。

平台出资消费券在大促期间为消费者提供了额外优惠，也为商家承接消费需求提供了支持。“开门红”阶段，消费券带动成交额破百万元的商家数量同比增长38%。活动期间，平台还将结合“现货日”“品类日”等安排，覆盖秋冬换季、日常消费及囤货等场景。

来自河北清河羊绒产业带的一家商家，借助直播向消费者介绍羊绒产品，凭借品质积累客户。今年双11期间，商家借助平台消费券引导成交，备足现货，日销成交额增长250%。平台消费券等优惠机制与消费者换季需求相结合，产业带商家为源头好货连接全国消费者提供了机会。

**中小新商与达人开局表现突出，平台提供分层扶持**

从首日到第一阶段，中小商家和新入场经营者持续展现经营活力。“开门红”期间，成交额破千万元的店播直播间数量同比增长98%，店播成交额破千万元的新商数量同比增长133%。相关数据反映出，商家店播、新商入局在大促开局获得了更多生意增量。

杭州一家宠物用品商家借助平台扶持取得不错的增长。这家研发导向型公司拥有两个自有工厂，坚持原创设计和自主研发，产品覆盖宠物智能玩具、饮水机、清洁用品等品类。其推出的不带滤芯、不做循环的宠物饮水机，以差异化设计回应养宠需求。今年双11首日，宠有引力店播成交额同比增长超99%。

针对不同阶段商家的经营需求，抖音电商推出覆盖入驻开店、流量曝光、物流发货及售后履约等环节的11大权益。符合条件的新商家完成指定任务后，最高有机会获得2450元投放补贴，并享受运费险等支持；主营自播的新商家可报名“新商万店激励”，高潜力中小商家则可通过“挑战赛”获得千川赠款激励。

在流量扶持方面，符合条件的商品最高可获得“猜你喜欢”和搜索5倍流量激励，优质达人及商家自播也可通过相关活动获得更多展示机会。与此同时，商品卡和搜索等直播之外的经营场域，也为商家拓展成交路径提供了支持。从扶持开店到拓展经营渠道，平台资源与商家的选品、内容和服务能力相结合，帮助更多好产品找到消费者。

**秋冬换季消费释放需求，多个重点类目实现增长**

随着秋冬换季和囤货需求释放，服饰、美妆个护、快消等类目在双11首日表现活跃。其中，服饰行业成交额破千万元的商家数量同比增长69%。特色行业的增长在第一阶段也有所延续：“开门红”期间，农产品生鲜、宠物行业成交额过千万元的商家数量分别同比增长250%和200%，母婴、快消等行业同样实现增长。

农产品商家的表现更加具体。来自江苏扬州宝应的一家商家，由夫妻二人分别负责直播和运营，坚持精挑大闸蟹、足斤足两，经过三年的客户积累，从日均店播成交额几千元成长为突破20万的商家。今年大促期间，店铺主推精挑大规格螃蟹，结合投流扶持和平台消费券承接需求。10月15日至18日，其日均成交额同比增长308%。长期积累的产品品质和客户信任，在大促中转化为更多好生意。

浙江舟山一家售卖海鲜的商家则通过溯源直播拓展销路。店铺拥有舟山小黄鱼、带鱼、鲳鱼、梭子蟹四款产品的地理标志认证，并有自有工厂。商家通过舟山海鲜溯源专场及日常直播介绍产地产品，今年双11第一阶段成交额同比增长300%，特色风味物产斩获更多消费者的青睐。

清河羊绒、宝应大闸蟹、舟山海鲜，商家的增长既来自日常对品质把控的持续投入，也与大促期间平台的优惠券、流量扶持和消费需求相结合。短视频和直播让产地风貌、商品细节及使用场景被更多消费者了解，为产业带商家拓展市场提供了机会。

“双11首日商家经营增长亮眼，‘开门红’阶段延续了良好势头。优惠方式更加直接、中小新商获得分层扶持、换季与特色消费需求释放，共同构成了本届大促开局的主要特点。”抖音电商相关负责人表示，随着活动继续推进，平台扶持与商家的产品、服务能力持续配合，有助于将大促期间的成交机会转化为更稳定的经营基础。

(责编：杨虞波罗、高雷)
