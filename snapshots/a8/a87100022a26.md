# 顺德122台电梯“超期服役”待大修 首创云平台

2013年05月31日 15:31　来源：南方日报　![](http://i3.chinanews.com/2011/news/images/1.png)[参与互动(0)](http://comment.chinanews.com/ci/index.php/comment/news/more/4880479)

日前，湖北、西安、深圳等多地发生电梯“吞人”事件，电梯安全监管难再一次触及社会各界神经。记者昨日从顺德区市场安全监管局获悉，该区目前有122台使用时间在20年以上的在用住宅电梯，全部已进入维修高峰期，实际上顺德区电梯保有量已达13821台，电梯安全监管成为难题。据悉，乐从将在全市率先启用物联网技术对电梯运行“实时体检”。

|  |
| --- |
|  |

昨日，记者来到顺德区容桂富丽大厦，这座已超过15年楼龄的住宅前几年因质量问题存在安全隐患，而今问题仍然未能解除。住户李先生称，自己住19楼，有一次电梯停靠在16楼时，居然发现电梯出口比地面高了7厘米。“大楼物管人员却称维修麻烦，这是人命关天的事啊！”

顺德区市监局相关负责人表示，目前全区电梯保有量13821台，其中使用时间在10年以上的在用住宅电梯为1508台，20年以上的在用住宅电梯为122台，已经进入维修高峰期。目前国内高层住宅设计使用年限通常为70年，而电梯一般使用满15到20年便需要大规模更换主要部件，无法维修的将直接报废。但目前国家对于旧电梯并未出台强制报废标准，顺德“超期服役”电梯面临尴尬处境。

顺德区乐从镇目前有较大区域被纳入佛山新城地块，该地块原来是成片工厂，并有一批使用年限10年以上的电梯。“带病作业的电梯肯定不能用，但旧电梯不一定都带病，做好监管很重要。”顺德区市场安全监管局乐从分局相关负责人透露，“辖区内将在全市首先利用物联网技术，改变传统的监管方式，在今明两年内，对乐从镇内的1000多台电梯安装智能电梯监管系统，实时监控，及时排除故障。”

“当电梯出现故障时，系统会自动拨号和发送短信，并进行语音播报，告知电梯维护方及时排除电梯故障，让受困者静静等待。”记者了解到，乐从分局还将建设云平台，通过平台实施联网，对全镇所有电梯实现实时监管。目前，智能电梯监管系统已在该镇医院、学校、小区等40部电梯上安装了系统，下一阶段将会继续推广，有望在今明两年实现全覆盖。 (记者/尹辅华)
