# 天津警方侦破特大跨省贩卖曲马多案 涉案金额400余万元

2023-11-08 19:57:19 来源：[中国新闻网](http://www.chinanews.com.cn/sh/2023/11-08/10108558.shtml) 作者：黄钰涵 责任编辑：黄钰涵

[中新网](/)天津11月8日电 (周亚强)记者从天津市公安局获悉，近日，天津警方侦破公安部目标贩卖曲马多案件，该起案件经第一次、第二次和全国集群收网行动，共抓获涉案人员160人，依法处置110余人，缴获国家规定管制的曲马多类精神药品9600余片，涉案金额达400余万元。

|  |
| --- |
|  |

　　据了解，今年7月1日起，复方曲马多等6种药品被列为二类管制麻精药品。天津市禁毒部门依托污水监测技术，发现宝坻区部分村镇麻精药品曲马多成分数值偏高。经天津市公安局联合公安宝坻分局排查，发现宝坻区无业人员王某资金流水巨大且存在明显异常，其日常活动形迹可疑，涉嫌贩卖国家管制的二类精神药品曲马多。

　　根据案情，天津警方成立联合工作组深度调查，发现这是一起以王某为首的通过邮寄方式辐射全国多地的特大跨省市贩卖国家管制二类精神药品曲马多的团伙案件。该团伙有着明确分工和完整的利益链条，具有贩卖、分销、转卖、吸食多个层级，毒品下线近百人，涉及华北、华南等11个省份。经公安部批准，该案被确立为部级毒品目标案件，并列为全国“夏季行动”第二批次集群战役重点案件之一。

　　7月25日，专案组组织多警种联合作战，展开第一次收网行动，抓获涉案嫌疑人67人，后续几日又陆续抓获9人，缴获国家规定管制的曲马多类精神药品6800余片。8月21日，天津市公安局禁毒总队会同全国11个省市禁毒部门开展集群战役，截至目前，全国相关省市共依法处置涉嫌吸贩曲马多人员64名。

　　9月20日，天津市公安局禁毒总队组织开展第二批集中收网行动。截至目前，共查获涉嫌吸贩曲马多人员24名，破获5起贩卖国家管制麻精药品案件，缴获曲马多类精神药品2800余片。

　　据悉，该案件是天津市近年来破获的涉案人员最多、跨省市区域最广、涉案金额最大的涉毒团伙案件。(完)
