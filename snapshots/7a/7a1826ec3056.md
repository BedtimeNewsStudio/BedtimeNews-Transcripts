# 关于转转

![](https://campus.zhuanzhuan.com/img/about1.jpg)

转转二手交易网是国内领先的二手交易平台。

转转由腾讯与58集团共同投资，二手交易品类覆盖手机、图书、3C数码、服装鞋帽、母婴用品、家具家电等三十余种。转转致力于打造标准化的服务，开创了二手手机的验机和质保服务，为广大用户提供可靠、便捷的二手交易。2020年5月6日，转转合并找靓机成为转转集团；2021年2月，转转集团获得GBA大湾区基金、青樾基金共计3.9亿美元投资；2021年6月，转转集团完成1亿美元D1轮融资，由小米集团领投，尚珹资本、顺为资本跟投，是国内二手电商领域唯一一家短期内获得两轮大规模现金融资的公司。

- # 公司使命

让人们享受闲置交易的快乐,

让世界因流转更可持续。

- # 公司愿景

成为全球最受用户信赖的闲置交易平台；

到2025年年服务超过5000万交易用户，

完成2001亿闲置价值的流转。

- # 公司价值观

用户第一/始终创业/团队合作/猛保增长/简单正直/乐观激情

# 致力于循环经济——让世界因流转更可持续

![](https://campus.zhuanzhuan.com/img/work4.jpg)

### 在当今物质横飞的社会，循环经济是一件非常有意义的事情，把物品流转起来，送到需要的人手里，一双鞋、一本书、一件潮流服饰、一部智能手机、都会带给人无价的快乐。

转转社会责任小组由集团CEO黄炜发起，成立于2021年2月25日，传播及践行转转使命。今年将聚焦“可持续”方向，推动转转使命在公司产品、服务及内部落地，让更多用户及员工感知并参与传播转转使命。

优品服务上线，开创二手手机平台验机服务，极大降低二手手机交易门槛

转转平台日订单量突破50万，日成交额 **突破9000万**
