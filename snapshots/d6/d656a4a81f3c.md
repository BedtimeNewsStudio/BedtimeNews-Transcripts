| 专家呼吁，儿童肺炎链球菌结合疫苗纳入免疫规划 |  |
|  |  |

肺炎链球菌是我国儿童呼吸道疾病最常见的病原体之一，5岁以下儿童负担最为集中。

“虽然名字里带着‘肺炎’，但肺炎链球菌造成的疾病却不局限于肺炎。严重感染还可能累及其他器官，引起脑膜炎等并发症。”南京医科大学附属儿童医院感染科、预防接种评估门诊主任医师田野表示。

11月12日是世界肺炎日。

近日，在北京大学社会化媒体研究中心举办的“儿童肺炎链球菌疾病防控与疫苗应用研讨会”上，多位专家呼吁，提高家长对肺炎链球菌疾病及疫苗的认识，并在现有证据基础上，推动儿童肺炎链球菌结合疫苗（PCV）纳入免疫规划，鼓励有条件的地方试点先行。

**危害不只在肺部**

复旦大学公共卫生学院流行病学教研室主任王伟炳向记者提供了一组研究数据：一项2009年至2019年中国急性呼吸道感染研究发现，儿童中肺炎链球菌在细菌阳性检出中占比最高：占所有细菌阳性检出的38.5%，位列第一，高于肺炎支原体（18.8%）和流感嗜血杆菌（20.3%）。大约93%的儿童重症肺炎是肺炎链球菌感染引发的。

每年全国约有8000名儿童死于肺炎链球菌疾病，主要发生在5岁以下儿童，农村和西部区域的疾病负担更重。

根据严重程度分类，肺炎链球菌会引发两类疾病。第一类是肺炎（非菌血症性）、中耳炎、鼻窦炎等非侵袭性的疾病；第二类是菌血症、败血症、化脓性脑膜炎和菌血症性肺炎等侵袭性疾病。一旦发展成侵袭性疾病（即重症），医疗体系需要投入大量时间和资源救治，对患儿和家庭都是很大的负担。

田野曾经收治过一名患儿，除了常见呼吸道症状，还伴有精神状态异常和烦躁。进一步检查后，医生在其脑脊液中发现了肺炎链球菌，这说明感染已经累及了患儿的中枢神经系统。

因颅内积液等问题，患儿最终接受了开颅手术。从发热咳嗽到开颅手术，这场漫长而复杂的病程，对任何一个家庭来说都是始料未及的。

王伟炳表示，肺炎链球菌并不是只有在发病时才会出现在人体内。它可以定植于鼻咽部，携带者可能没有明显症状，但仍可能参与传播。在一定条件下（如感染病毒后人体免疫力脆弱时），这种定植状态可能进一步发展为感染。

**不容忽视的抗生素耐药威胁**

特别是近年来，抗生素耐药的问题日趋严重，使得儿童肺炎链球菌疾病治疗变得更加复杂。

2025年全国细菌耐药监测网监测报告显示，肺炎链球菌对某些常用抗菌药物（如红霉素、克林霉素、四环素等）的耐药率已经超过90%。这意味着临床医生经验性治疗失败风险增加、患者住院时间延长、费用上升。

田野指出，临床上肺炎患儿往往缺乏充分的病原学检测。一方面，由于肺炎链球菌广泛定植的特性，“检测到肺炎链球菌，并不意味着它们就必然是儿童发病的主要原因”；另一方面，在基层和门诊，受实验室条件、检测费用和家长接受程度影响，病原学检测的开展非常有限，经验性治疗仍是主流。医生在确定不了明确病原体时，只能靠临床经验联合用药，进一步增加了抗生素管理的难度。

而疫苗接种显然是儿童肺炎链球菌疾病的重要预防手段。田野表示，疫苗的意义不仅在于减少患病，也在减少耐药等方面有更广泛的意义——"哪怕减少一半的发病率，我们的耐药问题就能得到非常大的一个解决。"

**接种率有待提高**

目前，全球已上市6种肺炎链球菌结合疫苗（PCV7/10/13/15/20/21价）。国内目前主要以覆盖13种血清型的PCV13为主，有4家厂商供应，其中3家为中国本土企业。

王伟炳告诉记者，我国肺炎链球菌不同地区流行的血清型存在差异，但主要以19F（27.7%）和19A（21.2%）为主。这两种血清型均包含在PCV13的覆盖范围内。对于肺炎链球菌侵袭性疾病（IPD）而言，13价疫苗的血清型覆盖率约88%。从苏州、上海等地的经验看来，PCV13普及后，疫苗覆盖血清型导致的IPD占比逐年下降，直接说明了疫苗的保护效果。

此外，国内也有企业正在研发更高价次（24/25/31价）的疫苗。目前来讲，虽然更高价次疫苗理论保护上限能达90%，提升幅度有限。大规模接种后，一些疫苗未覆盖的新兴血清型的检出占比可能上升，要保持持续的监测，以指导后续长期的研发和接种策略。

早在2007年，世界卫生组织已将肺炎链球菌性疾病列为需“极高度优先”使用疫苗预防的疾病。不过，目前，国内PCV的接种率还有待提高。

苏州市疾病预防控制中心主任医师栾琳认为，家长对肺炎链球菌结合疫苗（PCV）的认知总体仍然不足，即使在经济较发达地区，接种仍有较大提升空间。当然，价格也是重要因素。由于现在PCV在国内仍然未被纳入免疫规划，需要自费接种，一剂次的价格在几百元不等，按照标准免疫程序全程接种的费用在几千元。

以江苏地区为例，在南京等接种率较好的城市中心城区，PCV接种率约为50%，周边区县约为20%—30%；苏州总体约为30%，接种较好的中心城区约为40%，呈现明显的区域差异。

盖茨基金会北京代表处首席项目官杜珩也表示，应更多关注资源匮乏地区的家庭和脆弱人群，他们获得医疗服务的机会更少，儿童患病后对家庭的冲击也更大，她呼吁PCV疫苗纳入国家免疫规划，让低资源地区的孩子也能获得疫苗保护。

**多重公共健康效果**

值得一提的是，PCV 疫苗纳入免疫规划可以产生多重公共健康效果。杜珩指出：“免疫规划的收益不仅属于接种者，还包括对老年人等群体的间接保护，以及减少抗生素使用、减轻医疗系统服务压力，在整个人群中的收益预计是非常显著的。”

一项针对苏州接种的模型研究显示，儿童PCV13群体性接种后可以产生群体免疫效应，使老年群体中肺炎链球菌性社区获得性肺炎减少约30%，由此可以避免老年群体感染耐药相关死亡每年约170例，到2050年则估计累积可避免死亡可达920例。

2026年7月，国家疾控局、国家卫生健康委等七部门联合印发《疾病预防控制“十五五”规划》，提出按照“有进有出”原则，动态优化国家免疫规划疫苗种类。

肺炎链球菌疫苗应成为优先考虑纳入免疫规划的疫苗之一。王伟炳认为，目前国内从疾病负担估计到血清型覆盖、疫苗效果评估再到成本效果测算的证据链已逐渐闭合，应推动有条件的地区先行先试。

但采购价格和筹资机制是当前的核心变量。不过，越来越多的国产疫苗上市，为集采降价创造了空间，也为逐步将PCV纳入国家免疫规划提供了重要的产业基础。

在服务能力方面，栾琳以苏州为例谈到，目前该地已经建立了完善的预防接种体系，而随着出生人口减少，增加一两种疫苗，对冷链和接种工作量的影响相对有限。她建议，可以在符合接种规范的前提下，考虑通过使用联合疫苗或多个疫苗同时接种减少前往接种门诊次数、优化接种安排，为PCV接种留出空间，提高全程接种的依从性。
