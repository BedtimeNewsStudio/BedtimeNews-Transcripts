| 黑茶收藏不会走暴涨暴跌老路 |
| 时间：2011.10.07来源：北国网-辽宁日报 |
|  |
| **黑茶成收藏新宠**<br>  在黑茶保健功能得到消费者青睐的同时，其收藏价值亦逐渐被人们所认可。市场需求量不断扩大，也是支撑黑茶价格上涨的动力之一。<br>  据媒体报道，湖南安化一家茶厂上世纪70年代生产的“四合一”黑砖，当年的价格是3元左右，现在的售价已经超过了1万元。2005年，央视《鉴宝》栏目对一位陕西茶商收藏的一篓1953年前生产的黑茶进行了验证鉴评。结果专家对这篓黑茶的评估价为48万元，这一新闻轰动了收藏界，也将很多收藏家的视线吸引到黑茶上来。<br>  沈阳茶城有限公司经理毕世才表示，近年来不仅陈年黑茶价格一路攀升，一些优质的新黑茶，价格也不断上涨。<br>  黑茶价格稳步上涨，激活了茶叶市场，也激活了收藏市场。许多藏家和商贩闻风而动，或到黑茶生产厂家收购，或去民间挨家挨户搜集。 “辽宁也有陈年黑茶的藏家与卖家，虽然数量还不是很大，但说明黑茶在沈阳收藏市场上正在兴起。 ”毕世才说。<br>  毕世才表示，随着黑茶保健价值和经济价值被越来越多的消费者所熟知，其市场也会有更大的发展空间。<br>**投资黑茶要慎重**<br>  但是，黑茶究竟是否适于投资，在业内还有不同的看法。辽宁省茶叶协会秘书长高玉瀛告诉记者，如果购买黑茶是为了降低喝茶成本或者馈赠亲友，是可以的。沈阳的黑茶市场从去年才开始兴起，在这之前沈阳的黑茶销售还只是零星进行。高玉瀛说，由于黑茶价格每年都在上涨，消费者可以适当地收藏一些黑茶。<br>  黑茶的兴起说明黑茶正在受到业界的认可，高玉瀛认为这是件好事，不过在黑茶普及的过程中也出现了一些不和谐的音符，比如肆意夸大黑茶的保健功效。因此，他提醒茶叶收藏者和爱好者在把黑茶作为投资对象的时候，需要对黑茶有足够的了解和认识，黑茶的生产商有几百家，如果盲目投资，就容易被黑茶“黑”了。<br>  高玉瀛表示，收藏黑茶要看原材料、年份、产品加工等元素，只有质量上乘的黑茶才具有不断升值的空间。<br>  高玉瀛说，年代越久的黑茶价值越高，特别是茯砖及千两茶两个种类的茶叶中，含有俗称“金花”的冠突散囊菌。起降血脂和促消化作用的“金花”一般只能在灵芝中找得到。陈年黑茶在存放过程中会发酵，通过微生物的参与作用，使“金花”的大分子变成小分子，分裂出更多的冠突散囊菌，这就是陈年黑茶价值高的原因所在。 | |
