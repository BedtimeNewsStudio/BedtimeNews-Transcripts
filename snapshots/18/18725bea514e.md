# 小鹏汽车推出“行业唯一”5 年 0 利息 0 首付金融政策，至高贴息 5.7 万元

2025/2/5 10:29:56来源： [IT之家](https://www.ithome.com/0/828/600.htm)作者： **清源**责编： **清源**

[评论：0](#post_comm)

[IT之家](https://www.ithome.com/) 2 月 5 日消息，IT之家从小鹏汽车官微获悉，小鹏汽车今日正式推出号称“行业唯一”的 **5 年 0 利息 0 首付** 金融政策，至高贴息金额 57000 元。

- 小鹏 X9：月供 5830 元，至高贴息 5.7 万元

- 小鹏 G9：月供 6636 元，至高贴息 2.8 万元

- 小鹏 P7i：月供 5969 元，至高贴息 2 万元

- 小鹏 G6：月供 4997 元，至高贴息 1.8 万元

![](https://img.ithome.com/newsuploadfiles/2025/2/a5de8ebe-a688-4f97-94d1-31c1aa50c864.jpg?x-bce-process=image/quality,q_75/format,f_webp)

**小鹏汽车 2025 年 1 月共交付新车 30350 台，同比增长 268%**。小鹏汽车已连续 3 个月交付量破 30000 台，小鹏 MONA M03 连续 2 个月交付超 15000 台，小鹏 P7 + 上市 2 个月，累计交付突破 20000 台。
