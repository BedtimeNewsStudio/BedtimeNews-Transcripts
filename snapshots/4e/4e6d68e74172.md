--- | | |  | | --- | | 伊春机场新航站楼正式启用 | | |  |  | | --- | --- | | 来源：中国民航网 | 2021-12-24 14:48:00 | | | | 中国民航网 通讯员仇建、王蕊娇 报道：12月23日，伊春机场新航站楼正式启用，进一步提高了伊春民航运输能力和服务水平，标志着伊春民航事业发展迈上新台阶，为伊春高质量转型发展增添了新引擎。  伊春机场改扩建工程项目为黑龙江省重点工程，于2018年6月开工建设。机场跑道由2300米延长到2800米，可起降所有C类机型；新建航站楼面积9139平方米，是原航站楼的3.3倍，按满足2030年旅客吞吐量60万人次、货邮吞吐量1300吨规划建设。新航站楼为两层式流程设计，一层主要功能为旅客办理乘机手续、出港旅客安检、远机位候机、行李提取等；二层主要功能为普通旅客候机、贵宾候机等。改扩建后，新航站楼硬件设施有了质的飞跃，清晰的标识标牌，完善的设施设备，顺畅的乘机流程，让旅客候机体验感更强，出行更加方便快捷，有效提升了旅客的获得感、幸福感。  伊春机场自2009年建成通航以来，以“服务国家战略、服务地方发展、服务广大旅客、服务航空公司”为己任，大力开拓航空市场，先后开通了至北京、大连、上海、沈阳、广州等城市航线，自通航以来共运送旅客121万人次，为服务广大旅客出行、促进地方经济发展作出了积极贡献。  伊春机场将以新航站楼启用为契机，秉承“人民航空为人民”的宗旨，践行真情服务，着力将其打造成为增进对外合作的窗口和展示伊春形象的靓丽名片，为伊春“十四五”高质量转型发展提供坚强交通保障，助力伊春全面振兴全方位振兴。 | | | |  | | |  | | |  |  |  | | --- | --- | --- | |  | 责任编辑：wangyaling |
