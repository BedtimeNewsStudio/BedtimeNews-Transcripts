| ![](https://ipc.fmprc.gov.cn/chn/hdtz/202308/W020230825290939230550.jpg)<br>2023年8月24日，中国代表团新闻中心在南非约翰内斯堡举行中外媒体吹风会，邀请外交部金砖国家事务特使、国际经济司司长李克新介绍习近平主席出席金砖国家领导人第十五次会晤相关情况并答问。<br>李克新说，8月22日至24日，习近平主席出席金砖国家领导人会晤，与其他金砖国家领导人就金砖合作和国际形势等重要问题深入交换意见。习主席深入阐述构建人类命运共同体理念和全球发展倡议、全球安全倡议、全球文明倡议，深刻揭示中国式现代化的丰富内涵。习主席阐述了中方关于金砖国家加强经贸、安全、人文、全球治理等务实合作的立场主张，提出一系列具体合作倡议，为金砖发展指明方向。<br>李表示，这是疫情后金砖国家领导人会晤首次线下举行，也是金砖会晤第三次走进非洲。会晤主题是“金砖与非洲：深化伙伴关系，促进彼此增长，实现可持续发展，加强包容性多边主义”，对金砖合作与非盟《2063年议程》、非洲大陆自由贸易协定进程对接等具有重要意义。五国领导人就扩员指导原则、标准和程序达成一致，同意邀请沙特、阿联酋、埃及、阿根廷、伊朗、埃塞俄比亚作为正式成员加入金砖。<br>李指出，金砖国家坚定支持包容性多边主义、维护和平与发展，强调要根据《联合国宪章》宗旨原则解决和平与安全问题。今年是联合国2030年可持续发展目标中期评估年，五国致力于实现可持续发展的17个目标，同意把发展问题作为国际议程优先事项。呼吁在气候变化领域深化合作，遵循共同但有区别的责任原则，发达国家应兑现每年向发展中国家提供1000亿美元的气变资金承诺。同意加强在贸易、粮食、能源、安全等领域合作，早日实现疫后经济复苏。强调继续加强跨境支付合作和支付系统对接，增加本币使用比例，研究本币结算合作支付工具和平台，继续发挥新开发银行作用。<br>关于金砖合作，李强调三点：<br>一是这次扩员具有重要历史意义。去年，中国担任金砖国家主席国，启动了扩员进程。此后，中方一直同金砖成员一道，稳步推进扩员进程。许多新兴市场和发展中国家积极考虑加入金砖，20多个国家提出了申请，彰显了金砖国家的吸引力和感召力，以及新兴市场和发展中国家开展合作的热情和愿望。这次扩员体现了金砖国家同广大发展中国家团结合作的决心，符合国际社会期待，符合新兴市场和发展中国家的共同利益。这次扩员也是金砖合作的新起点，将为金砖合作机制注入新活力，进一步壮大世界和平和发展的力量。扩员后，金砖国家国土面积占世界领土总面积比重从26%升至32%，人口从42%升至47%，经济总量从26%升至29%，货物贸易总额从18%上升至21%。<br>二是继续强化金砖国家政治安全、经贸财金、人文交流“三轮驱动” 互利合作架构，加强金砖成员国，特别是同新加入的6国在数字经济、人工智能、中小企业、工商贸易、旅游卫生等领域合作。<br>三是坚持金砖国家与发展中国家、“全球南方”合作方向，倡导互利共赢，维护共同利益，不是拉帮结派，不搞阵营对抗。<br>李还应询进一步阐释金砖合作和金砖扩员所体现的互尊互谅、主权平等、团结民主、开放包容、深化合作、协商一致的金砖原则和精神，并就加强金砖国家跨境支付合作、本币结算、新开发银行扩员和金砖扩员之间的联系等回答中外记者提问。<br>![](https://ipc.fmprc.gov.cn/chn/hdtz/202308/W020230825290940213222.jpg)<br>南非《邮卫报》、南非商业直播、南非外交学会、金砖电视、路透社、彭博社、法新社、《人民日报》、新华社、中央广播电视总台、中国新闻社、凤凰卫视、《环球时报》等30多家中外媒体出席。<br>![](https://ipc.fmprc.gov.cn/chn/hdtz/202308/W020230825290940859347.jpg)![](https://ipc.fmprc.gov.cn/chn/hdtz/202308/W020230825290941453470.jpg) |  |  |  |  |  |
