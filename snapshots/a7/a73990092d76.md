# “债都是前面欠的，凭什么让我还”，毕节市委原书记吴胜华化债不力被通报

央视财经

2026-09-11 16:04

**来源：央视财经**

有干部“新官不理旧账”、违规决策新增隐性债务；有地方化债不实、把化债资金挪作日常经营……为坚决遏制新增隐性债务，进一步严肃财经纪律，发挥警示教育作用，中央纪委办公厅、财政部办公厅今天（9月11日）公开通报了六起地方政府隐性债务追责问责典型案例，涉及违规新增隐性债务、隐性债务化解不实等突出问题。

![](https://ocmsmedia.sfccn.com/vod-4310da/image/default/6B84F42AD31D45CAADB1D4E67F3B68A5-6-2.png)

**从通报看，六起典型案例集中在违规新增隐性债务和隐性债务化解不实两类问题：**

一、贵州省委原常委、毕节市委原书记吴胜华：政绩观严重偏差，“新官不理旧账”，落实党中央关于防范化解地方债务风险的重大决策部署不力。2022年至2025年吴胜华担任毕节市委书记期间，对化债工作不抓不管，放纵违规化债等乱象滋生，多次在公开场合发表“债都是前面欠的，凭什么让我还”等错误言论。其任期内毕节市债务余额不降反增，2024年全市隐性债务化债任务完成率仅为20%，排名贵州省倒数第一。吴胜华还存在其他严重违纪违法问题，被开除党籍、开除公职，涉嫌犯罪问题被移送检察机关依法审查起诉。

二、四川省宜宾市人民政府原党组成员、副市长兰宏彬：违规决策，违规新增隐性债务37.7亿余元。2020年6月至2021年7月，时任宜宾临港经济技术开发区党工委书记和宜宾三江新区党工委副书记、管理委员会主任兰宏彬在引进相关企业项目过程中，违规决策或参与决策对招商引资企业进行补贴，涉及新增隐性债务共计37.7亿余元，兰宏彬对此负有主要领导责任。兰宏彬还存在其他严重违纪违法问题，被开除党籍、开除公职，涉嫌犯罪问题被移送检察机关依法审查起诉

三、陕西省渭南市临渭区：通过公立医院举债实施公益性项目，新增隐性债务1亿元。时任渭南市临渭区卫生健康局党工委书记、局长曹杰等相关责任人被问责。

四、安徽省阜阳市界首市：1.82亿元化债资金，仅0.42亿元真还了。时任界首市城乡建设发展集团有限公司董事长李攀等相关责任人被问责。

五、江西省九江经济技术开发区：债券资金、往来款 "冲账"，化债不实10亿元。时任九江经济技术开发区财政综合服务中心主任游曦等相关责任人被问责。

六、宁夏回族自治区银川市：18 亿元化债资金被挪作日常经营。时任银川滨河黄河大桥管理有限责任公司法定代表人、总经理王荣亚等相关责任人被问责。

隐性债务，指的是地方政府及其部门在法定政府债务限额之外，直接或承诺以财政资金偿还及提供担保等方式举借的债务。这类债务未纳入政府预算管理，像“隐藏的冰山”，透明度低、不易监管，一旦风险积聚，可能冲击财政金融安全。

通报强调，以上六起典型案例，暴露出一些地方和单位的领导干部政绩观存在偏差，纪律观念淡薄，在贯彻落实党中央、国务院决策部署中，有令不行、有禁不止，打折扣、搞变通，严重影响了隐性债务风险防范化解工作成效。对相关责任人予以严肃追责问责，是落实党中央、国务院要求的有力举措。下一步，中央纪委、财政部将持续加强隐性债务问题查处工作，抓实追责问责，对新增隐性债务和化债不实等违法违规行为，发现一起、查处一起、问责一起，切实严肃财经纪律，推动有效防范化解地方政府债务风险。
