## 日本一兰拉面推出杯面

2021/02/24

       日本一兰拉面发售了重现自家拉面味道的杯面。据悉这款杯面比一兰以往销售的袋装拉面等更方便料理，该公司期待抓住新冠疫情下的居家需求。

|  |
| --- |
| **![](https://cn.nikkei.com/images/2021/02/0224/0224-07-L.jpg)** |
| **一兰推出的杯面** |

       这款杯面的商品名称为“一兰 豚骨”，价格为490日元（约合人民币30元）。可以在一兰拉面的店铺和网购网站上购买，部分便利店和零售店也有销售。除了面和汤以外，还带有一小包一兰拉面特色秘制酱料。
