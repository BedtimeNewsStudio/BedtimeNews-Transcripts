# 煤炭洗选节能减排作用巨大---国家能源局

煤炭洗选节能减排作用巨大

 发布时间：2013-05-08   来源：中国能源报  **大****中****小**

|  |
| --- |
| “煤炭洗选节能减排作用巨大，是我国节能减排和煤炭清洁高效利用，实现高碳能源低碳排放的重要措施。原煤经过洗选，能够更清洁高效使用。”中国煤炭加工利用协会副会长张绍强日前在接受《中国能源报》记者采访时表示，“电用煤灰分每降低1%，发热量可以提高200-360千焦/千克，采用洗精煤比用原煤可综合节能10-15%。”      他向记者介绍，根据研究试验，锅炉采用洗精煤作为燃料，可提高燃煤效率10-15%。每多入选1亿吨原煤，仅提高燃煤效率，就可节约1000-1500万吨煤炭。  **节能减排重要举措**      根据有关研究资料，煤炭是我国最大的空气污染源，我国每年约80％的二氧化碳、85％的二氧化硫、67％的氮氧化物、70％的悬浮物排放来自于燃煤，燃烧煤炭还造成了土壤污染和土地损耗，煤炭含有的汞等重金属对土壤污染也不可小觑。      煤炭洗选是我国节能减排的重要措施。我国动力煤平均灰分28.6%，平均硫分1.01%，洗后混配的优质动力煤平均灰分15.5%，平均硫分0.66%。每入选1亿吨原煤，可排除灰分1300万吨，硫分35万吨，减少二氧化硫排放49万吨。如果22亿吨动力煤全部入选，将就地排除灰分2.86亿吨、硫分770万吨，可以减少二氧化硫排放1078万吨。      在采访中记者了解到，原煤先集中进行洗选洁净化和均质化后，再分散供应市场，把灰分、硫分等污染物大量留在矿井进行集中治理，其治理成本、治理效率和治理措施比用户分散治理效果更好，仅SO2的治理成本，洗选降硫比烟气脱硫降低设备投资和运行成本90%以上。燃煤发电烟气脱硫设施和脱硫负荷将大大降低。      以煤炭长途运输为例，随着煤炭主要产区的西移，我国商品煤的平均运输距离已超过580km，并还在逐渐延长，随着新疆自治区煤炭的大量外运，商品煤运输距离还在加大。道路运输所带来的环境外部成本也不容忽视，主要包括煤尘的遗撒、以及尾气排放增大了公路沿线的污染强度。而铁路运输和水路运输所带来的外部成本、主要是环境外部成本，如噪声、废气和煤尘遗撒。      我国铁路货运总量中，煤炭运输一直占50%以上，2010年全国铁路运输商品煤20亿吨，占全国货运总量的60%，平均运距超过600km，铁路运输一直是我国煤炭供应的瓶颈。      而通过煤炭洗选可以就地排除大量煤矸石（约占入选原煤量的15%-20%，按平均18%计算），即运输洗选煤与运输原煤相比，可以节约运力18%。每入选1亿吨原煤，可排除1800万吨洗矸，按铁路运输煤炭20亿吨、平均运距600公里计算，可以节约运力2160亿吨公里，节省运费约230亿元。2010年，入选原煤16.5亿吨，共就地排除近3亿吨洗矸，节运1800亿吨公里，节约运费支出190亿元。  **煤质差不利节能减排**      长期以来，煤炭消费一直占全国能源消费总量的70%左右，84%的火力发电燃烧煤炭，所以提高煤炭质量，进而提高煤炭的燃烧利用效率和降低燃煤污染物排放，是关系到我国节能减排的最主要问题，原煤洗选提质责任重大。      随着煤炭开发布局战略西移和集中度提高，带来了低阶煤煤种总量增大，煤质逐渐变差，运输距离大大延长等一系列新的问题，亟待研究解决。      据中国煤炭加工利用协会提供的材料显示，我国资源分布，从东往西、从南往北，煤种逐渐年轻化，东南地区煤种主要是较高变质程度的无烟煤、贫瘦煤、气肥焦煤，往西部主要是长焰煤和褐煤，蒙东、辽北、吉南和云南小龙潭矿区主要是褐煤，东南部地区由于开采早、开发强度大，资源已经严重枯竭，产量快速下降。      而西北地区的陕北、蒙西、宁东、新疆是东部资源枯竭矿区的主要接替区，是未来大型煤炭基地的建设重点，但是这些地区煤种主要是长焰煤和褐煤，尤其是蒙东地区，主要为褐煤，热值只有3500cal/kg左右，原煤的发热量严重下降，预计未来十年内，我国褐煤产量有可能达到5亿吨左右。      其次是煤质普遍下降较大。东南部地区煤炭资源已经基本开发，这些煤矿大多已经长时间、大强度开发，资源枯竭严重，为了维持生产，不得不加大开发深度，不少矿区矿井开发深度已经超过-1200米，煤质普遍下降，原煤灰分、硫分明显上升，毛煤灰分多在40％以上，个别的灰分已经达到50-60%也在开采，同时原煤硫分大大增加，普遍上升一个百分点以上，原煤硫分超过2%不在少数，而且有机硫的比例大幅度上升，东部主要产煤省的安徽、江苏、山东尤其严重。      此外是原煤含矸率大幅度上升。随着采掘机械化程度的大幅度提高、综采放顶煤技术的全面推广应用、中小煤矿资源整合，在工作面单产大幅度提高的同时，原煤含矸率也在大幅度提高。      资料显示，目前含矸率普遍提高10-20％,大大恶化了原煤品质，导致原煤热值下降严重，估计平均下降300-500kcal/kg。      张绍强表示，随着原煤生产和入洗总量的增加，排放的煤矸石、洗矸、煤泥量也急剧增长，降低煤矸石排放带来的环境污染难度也越来越大。      鉴于此，我国煤炭企业必须加大原煤洗选力度，提高商品煤质量。  **洗选标准需强制执行**      “洗选总量及洗选副产品与环境总量不相平衡、节约能源和资源以及老企业效率有待提高。企业缺乏把发展煤炭洗选加工提高到作为调整产业、产品结构，发展循环经济高度来认识。”      山西省大同市一洗选企业负责人对记者表示，通过对遗留在煤炭生产区域的煤矸石、洗矸和煤泥等废弃物进行综合利用发电，可以有效消纳处理废弃资源，回收其中的有效能量，固化这些废弃物中富含的硫分，灰渣用于生产利废建材，使废弃物得到充分的资源化利用，减少土地占压和对矿区环境的损害。这也恰恰是矿区环境保护、节能减排的重要目标之一。      “煤炭洗选加工提质和清洁化，对我国节能减排具有重要的影响。”张绍强认为，转变煤矸石、洗矸、煤泥等低热值固体废弃物综合利用现状，还需政策保障机制的加强，落实优惠扶持政策，调整不适应发展水平的各种政策措施。记者 闫志强 |
