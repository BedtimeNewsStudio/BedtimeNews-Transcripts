|  | # 泰州通火车　盐城接“大网” |
| --- | --- |
| * * * |  |
| http://www.sina.com.cn 2005年07月05日00:33 人民网-江南时报 |  |
|  |  |
| 本报记者　栾争春、丁晓杰　扬州　报道　7月1日上午，宁启铁路南京至海安段全线开通客货运营暨泰州站建成投入运营仪式在泰州隆重举行，铁道部部长刘志军、江苏省委书记李源潮、省长梁保华等领导参加了这一仪式。<br>随着宁启铁路泰州客站的投入运营，泰州结束了不通火车的历史，宁启线也实现了真正意义上的全线贯通。当日，该市3000余旅客乘坐5列首发列车，走向祖国大江南北。此次首发的5趟列车分别是：泰州－深圳、泰州－杭州、泰州－兰州、泰州－北京－哈尔滨和泰州－成都。6月30日下午，记者来到泰州站现场，次日发车的各项准备工作已经准备就绪。在火车站的售票大厅，记者见到一位姓王的先生，他告诉记者他一下子买了四张7月1日发往姜堰的票，他说：“我一直盼望能在家乡坐上火车，如今这个梦想圆了，而且我会坐上第一趟列车，那种感觉会终身难忘的。”有这种想法的人不在少数，记者随机采访了几位购票的群众，大家都表示，能在家乡乘上火车真开心。本报记者姜振军盐城报道记者昨日获悉，从7月1日开始，新长铁路客运线全线扩容，正式并入全国铁路大网。据悉，此次“并网”的长途列车的开通，将给沿线泰州、盐城、淮安等地的3000多万人民群众的出行、工作和生活带来极大的便利和实惠，也给沿线的经济发展带来强大的助推力。<br>据了解，每天20：05从盐城出发开往哈尔滨的列车全程票价为硬座257元、硬卧452元；该线路沿途经过北京站，盐城到首都北京的票价为硬座180元、硬卧285元。22：10出发到成都、19：21出发到兰州、11：38出发到青岛等城市的列车全程票价硬座和硬卧分别为214元/377元、199元/366元、81元/149元。另外，记者从盐城新客站了解到，从盐城开往青岛、北京、西安、沈阳、哈尔滨、成都等城市的汽车票价分别为113元（中威）、275元（中威）、265元（空调卧铺）、445元（北方卧铺）、632元、648元。<br>盐城火车站徐站长介绍，从目前的售票情况来看，去北京、青岛的旅客较多，其中当天仅在盐城车站上车到北京的旅客就有64人。<br>《江南时报》 (2005年07月02日 第三版) |  |
