# 新生婴儿奖励金

![新生婴儿奖励金](https://www.cso.gov.hk/newbornbabybonus/images/newborn-baby-bonus-sc-dt.jpg)

![新生婴儿奖励金](https://www.cso.gov.hk/newbornbabybonus/images/newborn-baby-bonus-sc-mb.jpg)

## 概说

- 政府在2023年《施政报告》以组合拳的方式公布一系列的鼓励生育措施，当中包括向合资格的父母，就每名于2023年10月25日起出生的婴儿给予2万元的现金奖励（即新生婴儿奖励金），计划为期三年（即由2023年10月25日至2026年10月24日）。
- 为持续鼓励市民生育婴儿，行政长官在2026年9月16日发表的《施政报告》宣布延长以上计划三年至2029年10月24日，并将于2026年9月16日或打后在港出生的第二名（或排序更后的）子女的奖励金，提高1万元至3万元，以加大支援两孩或以上的家庭的力度。合资格的父母在为婴儿办理出生登记及申领出世纸时，可同时提交奖励金的申请。

## 申领资格

- 符合领取2万元奖励金的资格是：

1. 新生婴儿须于上述期间在香港出生；及
2. 递交申请时，父母其中一方必须是香港永久性居民。
- 符合领取3万元奖励金的资格是：

1. 新生婴儿须在2026年9月16日至2029年10月24日期间在香港出生；
2. 新生婴儿须为其父或母在香港出生的第二名或排序更后的子女（就此而言，在香港以外出生的子女不计算在计划之内）。政府会根据香港出生登记纪录，审视申请资格；及
3. 递交申请时，父母其中一方必须是香港永久性居民。

## 提交申请及时限

- 必须由父或母本人提交申请及领取现金奖励（不能授权他人代为申请或领取）；
- 父母应于婴儿出生42日内，在为婴儿办理出生登记时申请奖励金；如未能的话，也要**在婴儿出生当天起计6个历月**之内提交申请1；及
- 父母申领第二名或排序更后子女的三万元奖励金，须提供其首名或较年长在香港出生的子女之姓名、性别及出生日期。

## 亲身或网上申请

- ### 亲身办理

在出生登记处亲身办理出生登记及申领出世纸时，合资格父母可就奖励金一并作出申请。

- ### 网上申请（使用者须先登记成为「智方便+」的用户）

入境处的网上办理出生登记系统，附设申请表供合资格人士作出申请。

网上办理出生登记请参阅 [https://www.gov.hk/sc/residents/immigration/bdmreg/onlinebirthregistration.htm](https://www.gov.hk/sc/residents/immigration/bdmreg/onlinebirthregistration.htm)。

## 常见问题

| 问 1 | 如果婴儿在香港以外地方（海外或中国内地）出生，是否可获发放有关现金奖励？ |
| --- | --- |
| 答 1 | 不可以。为鼓励香港市民在本地孕育新生命，婴儿必须在香港出生，才可获发有关现金奖励。 |
| 问 2 | 如何申领新生婴儿奖励金？ |
| 答 2 | 合资格父母可透过网上申请或在出生登记处亲身办理。 |
| 问 3 | 谁可透过网上申领新生婴儿奖励金？ |
| 答 3 | 跟网上办理出生登记的准则一致，相关条件可参阅 [https://www.gov.hk/sc/residents/immigration/bdmreg/onlinebirthregistration.htm](https://www.gov.hk/sc/residents/immigration/bdmreg/onlinebirthregistration.htm)。 |
| 问 4 | 如何界定奖励金下合资格的第二名子女？是否其父母的首名或较年长子女必须在港出生及递交申请时父母其中一方必须是香港永久性居民？ |
| 答 4 | 要合乎资格领取第二名或排序更后子女的3万元奖励金，新生婴儿须在2026年9月16日至2029年10月24日期间在香港出生；及在递交申请时，父母其中一方必须是香港永久性居民。同时新生婴儿父或母的首名或较年长的子女也须于香港出生（香港以外出生的子女不计算在计划之内）。<br>政府处理申请奖励金时，会根据香港出生登记纪录，审视新生婴儿父母提交的申请，决定该新生婴儿的父母是否合资格领取为第二名或排序更后在港出生子女而设的3万元奖励金。 |
| 问 5 | 如何计算多胞胎的奖励？ |
| 答 5 | 现金奖励是以每一名新生婴儿计算，如双胞胎是在2026年9月16日至2029年10月24日期间在香港出生，而该双胞胎的父或母此前没有其他在港出生子女，其父母可获发总共5万元的现金奖励，即首名子女2万元奖励金及第二名或排序更后子女的3万元奖励金。如双胞胎是在2026年9月16日至2029年10月24日期间在香港出生，而该双胞胎的父或母此前已有在香港出生子女，则其双胞胎可获发总共6万元的现金奖励。 |
| 问 6 | 新生婴儿奖励金何时发放？ |
| 答 6 | 计划所需的拨款有待立法会财务委员会通过，我们的目标是就90%的合资格申请在三个星期内发放奖励金。<br>如合资格申请人填写的银行资料正确毋误，奖励金会发放到收款人的本地个人名义的银行户口。政府在安排发放奖励金后，会透过名为「#BabyBonus」的短讯发送人名称，发出通知短讯到申请表上提供的本地手提电话号码。 |
| 问 7 | 申请新生婴儿奖励金时须要提供什么资料？ |
| 答 7 | 申请人须提供父或母其中一方以个人名义开立的本地港元储蓄或往来银行帐户的资料（即持有人英文姓名和户口号码），以及一个可以接收本地短讯的本地手提电话号码。<br>父母申领第二名或排序更后子女的3万元奖励金，须提供其首名或较年长的子女之姓名、性别及出生日期。 |
| 问 8 | 如在递交新生婴儿奖励金申请后发现资料填写错误（例如银行户口资料或联络电话号码），如何提出更改？ |
| 答 8 | 在提交新生婴儿奖励金的申请后，如发现填报的资料有误并需要作出更改，同一位申请人（即提交原本申请的申请人）须尽快前往任何一间出生登记处亲身提交更改申请。提交更改申请时，申请人须带同香港身份证或有效旅行证件的正本，以及提供婴儿的出生登记编号。出生登记处的地址及联络方法如下： [https://www.immd.gov.hk/hks/contactus/birth.html](https://www.immd.gov.hk/hks/contactus/birth.html)。 |
| 问 9 | 如于网上申请新生婴儿奖励金时因网络异常以致申请中断，应如何处理？ |
| 答 9 | 在此情况下，奖励金申请可能尚未成功递交。合资格父母可先联络任何一间出生登记处查询申请状况。如确定奖励金申请尚未成功递交，合资格父母可于婴儿出生后6个历月内亲身向出生登记处递交奖励金申请。递交申请时，父或母须带同香港身份证或有效旅行证件的正本，以及提供婴儿的出生登记编号。登记处的地址及联络方法如下： [https://www.immd.gov.hk/hks/contactus/birth.html](https://www.immd.gov.hk/hks/contactus/birth.html)。 |
| 问 10 | 成功申请新生婴儿奖励金后是否有确认通知？ |
| 答 10 | 经网上成功提交奖励金申请后，网页会即时显示电子确认书；而在出生登记处申请后，会即场收到纸本确认书。 |
