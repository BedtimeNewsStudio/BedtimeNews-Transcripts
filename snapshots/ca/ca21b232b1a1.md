# 10万全款拿房，年轻人涌向“新鹤岗”？调查：地段偏远、留意产权，出手请冷静

首页头条收录

湖南日报·新湖南客户端全媒体记者 黄亚苹 实习生 李澳丹

与俄罗斯隔江相望、努尔哈赤点兵出征的鹤岗，因“5.8万全款买房”的新闻火了，这座处于“房产洼地”的小城惹人注目。“鹤岗化”，成为房子“白菜价”的代名词。

近日，一份综合媒体报道、房价行情数据的“鹤岗化”城市名单流传网络。名单中称全国95个城市出现“鹤岗化”现象，包括北京冬奥会的举办场地之一河北张家口，湖南株洲、贵州毕节、四川达州等地。拿下全款房，最低总价不超10万元。

8月26日，湖南日报记者了解到，湖南株洲、河北张家口等地确有“鹤岗房”，但大多是老破小、集体产权房或老旧毛坯房。专家称，买房前需综合考虑工作能力、生活成本等因素，出手需冷静。

**河北张家口6.5万买房，去北京还得3小时**

与北京相邻的张家口，被冠以“房价洼地”之名后，吸引众多北漂年轻人的目光。

今年8月，网友热议“00后北漂女生毕业一年张家口买房”。当事女生小姚，10万元在河北张家口买下70平方米的房子。在接受北京日报采访时，小姚提到买房原因：“不想背负太大房贷压力，正好离北京近，高铁非常方便。”

张家口的房价如何？8月26日，湖南日报记者在某知名找房APP检索发现，河北省张家口市多套新挂牌二手房源总价均在10万元左右。其中，一套建筑面积56.65平方米的2室1厅，于今年6月售出，成交价仅6.5万元；该套房位于下花园区电石厂住宅楼，建于1982年，楼龄已有42年，且位于整栋楼房次顶层的6楼，入住前需重新装修。

![](https://vod-benshipin-xhncloud.voc.com.cn/208/2024/08/26/ab2550e3326bbff8205ccf5e3324f04a4610c5bd1724664594.jpg?pid=16377117)某知名找房APP显示，河北张家口下花园区电石厂住宅楼房屋成交价为6.5万元。 图片来源：网络

“6月还成交了一户60平方米的住宅，5.3万元。”房屋中介任女士透露，近期不少年轻人到张家口买公寓，相较于住宅，公寓更新、环境更好，总价在10万元上下，“老小区都是毛坯房，想要住得花钱重新装修，以后也比较难转手。”

此外，中介小金提到，张家口市下花园区有很多便宜房源，“都是老小区，单位家属楼居多，有70年产权。不过，有的房子是集体产权、大产权房，没有房屋产权证，只能签协议保障客户利益。”

值得一提的是，在张家口买房、去北京上班，没想象中方便。举个例子，一个在北京国贸的上班族买下张家口下花园区电石厂住宅楼的二手房，需转乘“下花园5路”公交、火车、地铁共3种交通工具，单程耗时约2小时30分、花费约50元。

**地处郊区、有的无产权，买“鹤岗房”需冷静**

不只是北京周边城市，全国多地房价“鹤岗化”趋势加剧。据中国综合门户网站统计，截至2024年6月，全国有10个省份的24座城市卷入“几万元全款买房”的讨论，涉及东北三省的鹤岗、大庆、黑河，广深地区的惠州、清远以及湖南株洲、湘潭等地。

显而易见的是，看似房价亲切的城市，已被列入许多急需安家、计划“躺平”的95后甚至00后的购房清单。

![](https://vod-benshipin-xhncloud.voc.com.cn/208/2024/08/26/920f4d343c3ee2272e29bc45c569e94039846dfe1724664608.jpg?pid=16377142)网友“宋小猫”花3万在鹤岗购置的30㎡小家。图片来源：网络

某知名找房APP显示，株洲有近50套二手房售价不超10万元，面积在25平方米至60平方米之间。与张家口在售的“鹤岗房”相似，房源大多是老旧小区或高楼层，如朝阳村、601世贸广场、红旗广场等。其中，有房产中介挂出一套位于荷塘区荷塘大道朝阳村的一套2室1厅，挂牌价9万元，前往繁华市区天元区，需要坐B20和T88路公交，全程约90分钟。

![](https://vod-benshipin-xhncloud.voc.com.cn/208/2024/08/26/e94a7789de0919ba6efec3bbc4a6b98f2133c4d91724664624.jpg?pid=16377172)房产中介挂出荷塘区荷塘大道朝阳村的一套2室1厅，挂牌价9万元。 图片来源：网络

中介凌先生提到，10万元以内可买到的二手房基本是90年代建成的“老破小”，“好在周围的配套设施还可以，医院、超市、学校都有。”

总价几万元的二手房，谁在买？2023年底，网友“初尘子”花1.8万元在辽宁阜新买下55平方米二手房。“平时我在北京上班，休息就回来住，消费低，住着感觉还不错。现在带着孩子来这边避暑了，还是很喜欢这边的生活。”接受湖南日报记者采访时，“初尘子”如是说。

在云南省楚雄彝族自治州，夏小姐花4万元买下现在的家。

“2022年在云南旅行，机缘巧合下了解到这套房子在出售，觉得很便宜就买下了。”夏小姐称，买房后没有过多改变硬装，像蚂蚁搬家搬一点点添置软装物品，“以前不管去哪，都有一种漂泊感，现在有自己的小窝了，心里也踏实。”

然而，靠买“鹤岗房”治愈“精神内耗”不一定是良方。据报道，江西人花花在鹤岗购置了一套4.7万元的学区房，每月摊煎饼能赚3000元左右，然而，鹤岗冬天的气温骤降至零下30多摄氏度，煎饼摊没了生意，还得承担不菲的暖气费用。最后，花花离开这里。

中国人民大学经济学院教授关权接受媒体采访时表示，几万元的鹤岗房大多处于郊区、偏远地区、矿区，“中小城市出现低价房，绝不会处于城市的中心区，购买前要冷静看待问题。”
