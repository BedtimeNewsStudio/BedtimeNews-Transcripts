# 益阳市政府信息公开自助查询服务平台-安化县2024年国民经济和社会发展统计公报

安化县2024年国民经济和社会发展统计公报

2024年是贯彻落实党的二十大精神关键之年，是实施“十四五”规划的攻坚之年。一年来，全县上下在县委县政府的坚强领导下，深入实施“一四五”发展战略，大力推进“八大行动”，经济社会发展各项工作取得积极成效。

一、综合

经初步核算，全年实现地区生产总值305.37亿元，同比增长6.5%，按常住人口计算，全县人均GDP达40095元。其中，第一产业增加值60.05亿元，同比增长2.1%；第二产业增加值100.71亿元，同比增长9.3%；第三产业增加值144.6亿元，同比增长6.6%。三次产业比为19.7:32.9:47.4，一产业比重下降0.6个百分点，二产业比重下降1.4个百分点，三产业比重上升2.0个百分点。一、二、三产业对经济增长的贡献率依次为7.15%、46.53%和46.32%，分别拉动GDP增长0.46、3.03、3.01个百分点。

全年消费品价格指数99.9%，邮递服务价格指数100%，交通费价格指数100.2%，服务项目价格指数100.1%，采矿业工业生产者出厂价格指数101.6%，制造业工业生产者出厂价格指数99.2%，在外餐饮食品价格指数99.3%，旅馆住宿价格指数96.4%，通讯服务价格指数100%。

二、农业经济和乡村振兴

全年完成农林牧渔业总产值111.32亿元，同比增长2.6%。

全年粮食播种面积67.29万亩，比上年增加0.19万亩。其中，稻谷播种面积44.6万亩，增加0.75万亩；玉米播种面积16.36万亩，减少0.51万亩；大豆播种面积2.89万亩，增加0.07万亩。油料播种面积43.5万亩，增加0.92万亩。

全年粮食产量24.18万吨，比上年增加0.1万吨，增产0.42%。其中，夏粮产量0.24万吨，减产1.61%；早稻产量2.45万吨，减产0.37%；秋粮产量21.5万吨，增产0.54%。谷物产量22.76万吨，增产0.45%，其中，稻谷产量17.83万吨，增产0.42%,玉米产量4.78万吨，增产0.92%。

大豆产量0.48万吨，增产4.84%。油料作物产量4.85万吨，增产4.01%，其中，油菜籽3.79万吨，增产3.68%，花生产量1.06万吨，增产5.22%。水果产量6.29万吨，其中柑橘类3.65万吨，增产12.53%。茶产量8.09万吨，增产3.39%，其中，黑茶产量7.28万吨，增产3.29%，绿茶0.54万吨，增产3.25%，红茶产量0.28万吨，增产6.3%。中药材产量4.02万吨，增产4.24%，其中，黄精产量1.28万吨，增产12.58%。

全年猪牛羊禽肉产量9.49万吨，同比增长0.28%，其中，猪肉产量7.83万吨，同比下降0.07%，牛肉产量0.47万吨，同比增长17.13%，羊肉产量0.66万吨，同比下降5.56%，禽肉产量0.53万吨，同比增长0.4%。禽蛋产量1.72万吨，同比下降14.54%。年末生猪存栏61.69万头，同比增长2.38%,生猪出栏103.61万头，同比下降2.81%。

紧紧围绕确保不发生规模性返贫底线，组织实施2024年度省帮扶产业重点项目和年度继续帮扶项目，统筹推进了集中排查、监测帮扶、“3+1”保障、产业帮扶、就业帮扶、易地搬迁后续帮扶等工作。实施易地搬迁后续扶持产业项目23个，稳定保持公益性岗位3000个、就业帮扶车间88家，完成监测户小产业奖补4730户，农村危房改造290户，发放“雨露计划”职业学历教育生活补助9933人次。全力保障教育、医疗、住房、饮水等基本保障政策100%落实到位，义务教育阶段贫困家庭学生“零辍学、资助零遗漏”，脱贫群众医保参保率100%，符合条件的困难群体全部得到救治。

三、工业和建筑业

工业经济稳中加固。全年全部工业增加值同比增长9.1%，其中，208家规模以上工业增加值同比增长10.4%。分门类看，全部采矿业增加值同比增长7.4%，制造业增加值同比增长7.1%，电力、热力燃气及水生产和供应业增加值同比增长21.7%。全年新增规模工业企业21家，总数达到175家，规模工业总产值、增加值同比分别增长8.2%、10.4%。

规模工业中，五大产业链产值同比增长9.37%，其中茶产业链产值同比增长5.17%，矿产建材产业链产值同比增长13.82%，生物医药产业链产值同比下降9.44%，新能源产业链产值同比增长32.88%，新材料产业链产值同比增长12.83%。

全年实现园区技工贸总收入124.27亿元，同比增长14.09%，工业总产值同比增长9%，其中，规模工业增加值同比增长11.5%；工业税收同比增长16.84%，亩均税收23.9万元。

全年完成资质以上建筑业总产值30.3亿元，增长6.1%。其中建筑工程、安装工程产值分别为27.53亿元、1.14亿元。房屋建筑施工面积12.68万平方米，其中，本年新开工面积6.95万平方米。从事建筑业活动的平均人数4532人。建筑业增加值20.82亿元，增长10.6%。

四、固定资产投资和城镇化水平

全年500万元以上在库项目202个，其中5000万以上的项目88个，亿元项目55个。全县固定资产投资同比增长15.8%，其中建设项目同比增长19.8%，房地产项目同比下降21.5%，电力项目同比下降19.7%。从投资结构来看，工业投资同比增长52.2%，产业投资同比下降4.8%，民间投资同比增长16.6%，制造业投资同比增长64.2%。

全年完成省重点项目投资31.03亿元，为年度目标任务的111.9%，其中安化茶旅文康一体化项目、安化抽水蓄能电站项目、安化雪峰湖综合开发项目分别完成年度计划的126.3%、123.4%、120.8%；全年完成市重点项目投资69.05亿元，为年度目标任务的109.4%，完成市重点产业项目39.69亿元，为年度目标任务的117.6%。

全年商品房销售面积17.92万平方米，同比增长14.7%，其中，住宅销售面积15.84万平方米，同比增长9.39%。全年发放金塘冲水库移民安置票房991张，网签备案商品房608套。

全年新开工改造城镇老旧小区140个，惠及居民13434户；全年开工建设和筹集保障性租赁住房382套，完成农村危房改造290户。

五、交通、水利、邮电

全年完成交通基础设施建设投资13.6亿元，东渠公路、金田至茶马古道旅游公路、东山至高明公路建成通车，仙溪至芙蓉山公路预计25年完成主体工程；此外，实施国省干线大中修66.1公里、集镇路段路面改善工程25.7公里，完成农村“三路”建设259.5公里、安防工程923公里、危桥改造25座。

全年完成14座小型水库除险加固、211处小型农田水利设施建设和红岩灌区续建配套与节水改造项目，新增蓄水能力59万方；仙丰水库已于汛前下闸蓄水，钟鼓山水厂正式开始运营；扎实推进农村供水工程维修养护和净化消毒设备的建设，提升农村自来水普及率1个百分点以上，农村人口自来水普及率增长至84.5%。

全年投入6120万元完成324个4G基站建设，其中，移动基站102个、联通基站31个，电信基站191个，4G基站累计建设2965个；全年投入3.9亿元完成729个5G基站建设，其中，移动基站180个、联通基站280个，电信基站369个，5G基站累计建设2279个；新增千兆光网端口1.5万个，其中，电信5500个、移动5000个、联通4500个，千兆光网端口累计53.62万个。

全县邮政行业业务收入11090.18万元，比去年下降9.08%，快递业务量587.97万件，同比增长4.94%，其中进口邮件491.36万件，同比增长7.76%，出口邮件96.61万件，同比下降7.4%。

六、招商引资、国内贸易、旅游

全县累计新签约项目42个，新开工项目35个，新投产项目27个，引进外商直接投资7万美元，新引进“三类500强”企业投资项目2个，湘商回归新注册企业15家，湘商回归投资累计到位资金37.1亿元，引进境内省外资金107.48亿元，引进域外省内资金6.02亿元，全年完成外贸进出口总额1.47亿元，对外承包和劳务合作完成2864.88万美元，荣获省政府“八大行动”之激发需求行动表现优异单位。

全年实现社会消费品零售总额118.8亿元，增长7.0%,其中，全县限额以上法人单位实现零售额27.62亿元，占全县社会消费品零售总额的23.25%。分行业从销售额来看（全口径），批发业同比增长6.5%，零售业同比增长8.0%，住宿业同比增长2.2%，餐饮业同比增长12.4%。

2024年接待游客达1240万人次，旅游综合收入90亿元，同比增长8%。百花寨成功通过4A级旅游景区景观质量评定及现场验收; 雪峰湖度假区成功创建省级旅游度假区;浅斟百龙泉、马路溪乡村生态旅游区获评省五星级乡村旅游区; 茶马古道民宿集群、云台山星空营地、云上茶旅休闲精品廊道和马路溪村被评为“四个一百”省级乡村旅游精品民宿聚集区、精品营地、精品廊道、精品村。

七、财政、金融、保险业

全县完成地方一般公共预算收入11.99亿元，同比增长4.5%，其中，税收收入8.71亿元，同比增长4.69%，非税收入3.28亿元，同比增长3.99%。分税种来看，完成增值税73749万元，同比增长10.66%，耕地占用税13095万元，同比增长3.31%，企业所得税24803万元，同比增长10.58%，房产税9610万元，同比增长159.38%。全年完成地方一般公共预算支出710658万元，同比增长3.11%。其中：一般公共服务支出49031万元，下降34.13%，教育支出121678万元，增长0.49%，科学技术支出25312万元，增长47.08%，社会保障与就业支出144756万元，增长14.72%，城乡社区支出61654万元，增长47.51%。

年末全县金融机构各项存款余额543.42亿元，增长10.6%,其中，住户存款471.40亿元，同比增长12.5%。各项贷款余额371.46亿元，增长11.1%。全县人寿保险支公司6家，营销部17家，财产保险支公司7家，营销部10家。全年实现保费收入9.94亿元，其中财产保险收入5.05亿元，人寿保险收入4.89亿元。全年赔款给付支出5.13亿元，其中财产保险支出3.9亿元，人寿保险支出1.23万元。

八、科技、教育、文化

全年商标申请1543件、注册977件，商标累计有效注册量12095件；专利授权量为172件，其中发明专利授权量为28件。全县高新技术企业实现增加值31.44亿元，同比增长12.7%，占GDP的比重为10.3%。

2024年，全县共有中小学校170所，其中普通高中8所（包括省级示范性普通高中2所）、国家级重点职业中专1所、初中39所（含九年一贯制学校7所）、小学121所（含教学点49所）、特殊教育学校1所。在校中小学生106466人，其中义务教育85871人、普通高中13623人、职业学校6972人。幼儿园（含幼教点）141所，其中公办园110所，在园幼儿14168人。在职教师7275人（含特岗171人，硕师计划15人），退休教师4912人。补充编制教师381名，其中特岗转正30名，公费师范生分配351名。另招募硕师计划8人。与省内12所院校签订协议，培养公费定向师范生105人，其中高中起点75人，初中起点30人。

全年组织 “欢乐潇湘•神韵安化”月月乐群众文体活动12场，完成科技、文化、卫生“三下乡”示范活动3场、送戏下乡惠民演出近100场。持续开展文化人才专项工作，选派28名优秀文化人才，分别在28个村（社区）指导基层文化人才队伍建设、文化活动组织、文旅产业发展等文化工作。农村广播通村率达100%，有线电视通村率达100%。

九、卫生、体育、环境保护

全县基本药物实行省级平台统一采购、配送、结算，全面落实药品零差率销售，实现药占比控制在30%以下的目标。以提升医疗服务舒适化、流程化、智慧化水平为出发点，出台看病就诊便民措施24条。公立医院高质量发展稳步推进。县人民医院顺利通过三级医院复评，被评为三级乙等医院；马路镇中心卫生院被评为二级综合医院。县人民医院和县第二人民医院纳入首批全国“千县工程”县医院综合能力提升工作名单。县人民医院被确定为省级公立医院高质量发展示范性医院建设单位。全县现有省级重点专科10个，市级重点专科27个。年末全县共有执业（助理）医师人数2374人，医疗机构床位数5836张。

承办了2024年全县干职工羽毛球赛、湖南省“流行羽”羽毛球品牌赛事、“国窖杯”全省羽毛球邀请赛等。在全省青少年羽毛球锦标赛中，我县获得金牌2枚、铜牌6枚的好成绩；省第十五届运动会场馆建设工作正有序推进，已完成场馆提质改造工程的可研、初步设计方案编制等；依规采购全民健身体育器材，全年共下发器材39套，增添公共体育场所54处。

全年空气质量优良天数345天，优良率达94.3%；完成8个省控断面达Ⅱ类水质。扎实开展“生态三湘”专项行动，加强六步溪等自然保护地生态保护监管，打好长江“十年禁渔”保卫战，生活垃圾填埋场实现生态封场。全年预计削减氮氧化物52.48吨，挥发性有机物0.09吨。

十、人口和人民生活

2024年,全县公安户籍人口数98.02万人，常住人口75.83万人，其中城镇常住人口29.66万人，农村常住人口46.17万人，城镇化率达39.11%。

2024年,全县共出生4866人，死亡5865人，出生人口性别比108:100,人口出生率4.78‰，死亡率5.76‰，自然增长率-0.98‰。

抽样调查显示，全县全体居民人均可支配收入18475元，增长5.5%。其中，城镇居民人均可支配收入25705元，增长4.0%；农村居民人均可支配收入14977元，增长6.4%。全县全体居民人均生活消费支出15629元，增长4.5%，其中，城镇居民人均生活消费支出16722元，增长5.1%，农村居民人均生活消费支出15100元，增长4.2%。

十一、社会保障和安全生产

全年新增城镇就业5796人，农村劳动力转移就业4998人，创业带动就业959人。全县基本养老保险参保69.21万人，医疗保险、工伤、失业保险参保人数分别为72.4万人、7.26万人、4.41万人。城镇登记失业率控制在4.5%以内；发放创业担保贷款3755万元。

全县共发生各类生产经营性安全生产事故8起，死亡8人，连续9年未发生较大及以上生产安全事故，全县安全生产形势稳定向好。亿元GDP生产经营性伤亡事故数0.026次；亿元GDP生产经营性伤亡事故死亡人数0.026人。全年共办理安全生产行政执法案件399起，经济处罚800余万元，有效遏制了安全事故发生。
