# “宁王”每月涨薪150元

多处信源爆料，宁德时代已经通过电子邮件方式，向全体员工发送了调薪通知。

而且，多家媒体向宁德时代和董事长曾毓群求证了调薪的消息，得到的答复都是“属实”。

根据通知来看，涨薪针对的是宁德时代和其独资分子公司内 **1~6职级的员工，从2026年1月1日起，统一将基本工资上调150元/月**。

有知情人士透露，这次1~6级调薪是“普调”，7级以上员工可能还会有“特调”。

![宁德时代给9万+基层员工涨了薪！每月150元](https://i.qbitai.com/wp-content/uploads/replace/f2638aa183fe9f8fe0fa4a31c75f3a49.png)

# △网传通知截图

涨薪通知里一同出现的，还有三家宁德时代的子公司，分别是屏南时代、屏南润能信材料，还有宁德时代（贵州）。这些子公司的基本工资也出现上调，100~150元不等。

那么月薪上调150元，在宁德时代内部是个什么概念呢？

如果一位基层员工周末单休，由于加班费基数的提高，Ta每个月收入大约会有 **300~600元** 增长，一个月综合收入大约在7500元左右。

或许有人觉得，月薪上调150元，平均下来就是每天上涨5元，调整幅度并不算高，不过结合覆盖范围，实际增长的支出也不是一笔小数目：

在宁德时代内，1~6级员工多数是生产线操作工、技术员，或是其他一线的基层员工，大约在 **9万人** 以上，能覆盖到公司 **70%以上** 的员工。

就按 **9万人** 算，如果每人最低涨薪150元，一个月下来宁德时代需多掏 **1350万元**。

另外，宁德时代还发布了一则“春节留守致富指南”——其实就是春节加班补贴。

2026年2月9日-2026年2月28日期间，出勤满足条件的员工，就能获得 **至少3200元** 的额外奖励。

范围覆盖宁德时代及国内独资分子公司电池、材料制造基地下沉十大部门、中心MEVEOPN JG1-10级员工。

# 起底宁德时代薪酬明细

员工的薪酬结构，可以从公司的成本维度去拆解。

一般来说，这些具体信息只在年报和半年报有披露，所以我们以 **2025年半年报、2024年年度报告** 为例。

首先来看宁德时代的员工规模是多少。

截至2024年末，公司在职员工数总计为 **13.2万人**，由生产、销售、技术、财务以及行政五大类别构成。

其中，生产人员 **为9.67万人，占总员工数的比重最大；数量第二多的类别则是** 技术人员，相关人数为2.03万人。

![宁德时代给9万+基层员工涨了薪！每月150元](https://i.qbitai.com/wp-content/uploads/replace/8750b083e0fd1446d339b70aa1a34e32.png)

通过财报能发现，宁德时代的薪酬是基于 **岗位价值** 和 **个人业绩贡献** 来考核，通过 **短期薪酬** 和 **长期激励** 实施。

**短期薪酬** 面向所有员工，当期发生、当期计入成本，与股权激励无关。

具体项目包括工资、奖金、补贴，还有职工福利费、社保、公积金等等。另外公司还会承担离职后福利，比如社保中的养老、失业等等。

而2024年全年，宁德时代计提的短期薪酬为 **281.5亿元**，其中工资、奖金等是薪酬大头；加上离职后福利新增支出的 **15.28亿元**，应付职工薪酬合计是 **296.8亿元**。

![宁德时代给9万+基层员工涨了薪！每月150元](https://i.qbitai.com/wp-content/uploads/replace/e7945380a3d96dc6781504cffbdbb7cd.png)

大致计算一下 **人均短期薪酬**，大约是 **21.3万元/人·年**，基本是最贴近实际工资的口径。

而2025年上半年，宁德时代的短期薪酬 **171.8亿元**，加上离职后福利9亿元，合计是180.8亿元。

![宁德时代给9万+基层员工涨了薪！每月150元](https://i.qbitai.com/wp-content/uploads/replace/06cb29a8793bd31a9df5ae896d9ef063.png)

假设员工规模还维持在13万人左右，那么这半年的人均短期薪酬约为 **13.8万/人·半年**，年化后大约是 **26.7万/人·年**，较去年的薪酬水平实际已经提升了。

除了短期薪酬以外，宁德时代还提供 **长期激励**。

这部分包括限制性股票、股票期权、科创类激励等等，一并算作股权激励费用，大多是属于研发或是管理层。不过并不是实际的现金支出，只是在财报中作为摊销费用体现。

2024年全年，宁德时代的股权激励费用为 **68.9亿元**，今年上半年为 **21.99亿元**。

如果加上股权激励，那么2024年公司的 **人均综合成本**，也就是（短期薪酬+股权激励）/人数，结果约是 **26.6万/人·年**，今年上半年算出来的则是 **29.3万/人·年**，同样是同比增长的。

![宁德时代给9万+基层员工涨了薪！每月150元](https://i.qbitai.com/wp-content/uploads/replace/85ec51bf99f5de2dd237ded5f5c357f4.png)

而宁王之所以选择这个节点大范围调整薪酬，其底气很可能来自于公司当前增长的业绩。

从第三季度财报来看，公司单季总营收1041.86亿元，同比增长12.90%；前三季度累计营收2830.72亿元，同比增长9.28%。

Q3归母净利润为185.49亿元，同比增长41.21%，创历史新高；三个季度累计净赚490.34亿元，同比增长36.2%。

![宁德时代给9万+基层员工涨了薪！每月150元](https://i.qbitai.com/wp-content/uploads/replace/fc502e7c87f6c12e8868d6398378b74e.png)

而三季度财报中，虽然没有像半年度报告一样披露员工薪酬细节，但在合并现金流表中，也点出公司前三季度”支付给职工以及为职工支付的现金”为 **234.13亿元**，同比增长了21.13%。

以上种种都在证实，宁德时代的员工薪酬的关键词只有一个：涨，涨，涨。
