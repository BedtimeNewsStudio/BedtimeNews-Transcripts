| **炮口直指赌球和派系 中国足协抓牢G7两大命门** |

|  |

| 2004年12月01日 11:30 |

|  |

|  |
| --- |
| 中新网12月1日电 赌球和派系，是危害中国足球的两大毒瘤。东方体育日报今日报道，中国足协与“造反派”在联赛结束后的抗衡中，中国足协势必会从中选择一个问题的解决作为彻底瓦解“造反运动”的突破口。<br>赌球 需坚决打击<br>赌球是引起“人神共愤”的问题，不仅中国足协反对，“造反派”也反对。打击赌球，维护的是足球界的整体利益，而且也能在社会上起到震慑作用。目前，一些线索已经浮出水面，一旦抓住，应该能够形成突破。<br>今年联赛后半段，不少俱乐部都在内部进行“打鬼运动”，已经有部分球员被俱乐部怀疑从而停训停赛，个别运动员还因为别的丑闻被闹得沸沸扬扬，这些都是打击赌球的突破口。<br>就中国足协来说，在10月26日执委会议和“造反派”对话后，听到赌球的危害那么骇人听闻，一方面也通过自己的渠道进一步了解赌球情况，另一方面则也向有关部门发文或者加强联系，以期在打击赌球问题上取得进展。甚至，中国足协发给相关部门的文件里明确提出要求加强对媒体的监管力度，特别是针对部分体育专业媒体假借足彩报道，实际上大肆介绍海外盘口，中国足协希望主管部门对其进行约束。在地下赌球活动中，中国足协一直认为部分媒体起到了推波助澜的作用。<br>10月26日执委会议和投资人对话后，中国足协在“深化改革”问题上步伐比较大，动作也比较迅速，但是在11月17日国家队从世界杯预赛出局后，各项“改革”工作放缓，特别是联赛改革工作小组成立至今已经有两周时间竟然还没有举行过一次会议。中国足协“深化改革”步伐放慢，在足协内部也出现了不解。一些人认为：很可能中国足协正在忙于另外更重要的事情，这件事情的急迫性甚至超过联赛改革小组的第一次会议——这只有一件事情最有可能：打击赌球。“足协现在的状况和当年抓黑哨时候有些像，足协本身的工作都没有太大的变化，但是某天很可能突然就出了巨大变化。”<br>派系 需彻底瓦解<br>在中国足协自身能力范围内，能够解决的另一个问题就是派系问题。<br>“造反派”本身就是由“实德系”和“张海系”为主构成的。足协也一直有着这样的担心：“造反派”最终也形成一个利益联盟，操控联赛。打击派系，首先能够瓦解“造反派”联盟体系，同时也能保证今后联赛的公平和秩序。今年联赛后半段，发生在“造反派”球队之间联赛场次的离奇比分，已经引起了中国足协的警觉，但是因为“造反”和国家队两方面压力，中国足协甚至连调查都顾不上了。<br>目前，以“中超俱乐部投资人联席会议”名义纠集的“造反派”，涉及到七家中超俱乐部：大连实德、辽宁中誉、北京国安、青岛颐中、四川冠城、深圳健力宝、上海国际，但是“投资人”真正能够完全支配俱乐部的，只有大连实德、北京国安、青岛颐中、四川冠城、上海国际五家俱乐部。名为辽足俱乐部大股东，张曙光不能完全代表俱乐部；而张海则自称是按照惯性以“健力宝俱乐部转让前大股东”的身份活跃在“造反派”里，公开场合不能代表任何一家俱乐部。<br>这五家俱乐部里，一直笼罩在“实德系”阴影下的冠城俱乐部是一个薄弱环节。首先，该俱乐部总经理李丹阳在中央电视台公开宣称“中国足协逼迫我们俱乐部做假账”落下口实；其次，作为公认的“实德系”小弟，冠城俱乐部有着自己的先天缺陷。<br>有人建议，联赛结束，中国足协就应该首先从冠城俱乐部入手，以李丹阳总经理在电视台公开讲话为突破口，中国足协可以公开声明要调查该俱乐部做假账的问题。如果是中国足协的确逼迫俱乐部做假账，中国足协自己也要给全社会一个交代；如果是该俱乐部总经理自己信口胡说，或者说冠城是做假账进入中超的，完全可以吊销这家俱乐部的中超资格。——大家不是要求治理联赛环境吗？中国足协就从做假账和核查中超资格、打击关联关系入手来解决。而对于实德和冠城之间的“关联关系”，中国足协一方面可以再次进行调查，另一方面可以举行公开“听证会”方式公开确定和处理。如果查明关联关系，要么两家俱乐部彻底脱离关系，要么剥夺其中一家俱乐部的中超资格。(秦云) |
