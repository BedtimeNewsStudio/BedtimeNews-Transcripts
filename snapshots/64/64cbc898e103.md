**台湾兵役制度**依照[中华民国法律](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E6%B3%95%E5%BE%8B "中华民国法律")，实施募征并行的**[义务役征兵政策](/wiki/%E5%BE%B5%E5%85%B5%E5%88%B6 "征兵制")**，所有达到服役年龄的合格男子均须服1年常备兵役、或接受4个月军事训练。

[台湾历史](/wiki/%E5%8F%B0%E7%81%A3%E6%AD%B7%E5%8F%B2 "台湾历史")上，早期以招募[志愿](/wiki/%E5%BF%97%E9%A1%98%E5%BD%B9 "志愿役")从军为主，[征兵制度](/wiki/%E5%BE%B5%E5%85%B5%E5%88%B6 "征兵制")始见于1945年1月[日本统治](/wiki/%E5%8F%B0%E7%81%A3%E6%97%A5%E6%B2%BB%E6%99%82%E6%9C%9F "台湾日治时期")末期，为[第二次世界大战](/wiki/%E7%AC%AC%E4%BA%8C%E6%AC%A1%E4%B8%96%E7%95%8C%E5%A4%A7%E6%88%98 "第二次世界大战")战场之人力需求而产生[[1]](#cite_note-1)。二战后台湾进入[中华民国时代](/wiki/%E8%87%BA%E7%81%A3%E6%88%B0%E5%BE%8C%E6%99%82%E6%9C%9F "台湾战后时期")，由于[第二次国共内战](/wiki/%E7%AC%AC%E4%BA%8C%E6%AC%A1%E5%9B%BD%E5%85%B1%E5%86%85%E6%88%98 "第二次国共内战")失利，[中华民国政府](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E6%94%BF%E5%BA%9C "中华民国政府")自1949年12月起在台湾实施征兵制度。1949年至1987年，[陆军](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E9%99%B8%E8%BB%8D "中华民国陆军")服役2年，[海](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E6%B5%B7%E8%BB%8D "中华民国海军")[空军](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E7%A9%BA%E8%BB%8D "中华民国空军")3年，1967年新增[陆一特](/wiki/%E9%99%B8%E8%BB%8D%E7%AC%AC%E4%B8%80%E7%89%B9%E7%A8%AE%E5%85%B5 "陆军第一特种兵")3年。1987年至1990年6月，陆海空军服役2年，[海陆](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E6%B5%B7%E8%BB%8D%E9%99%B8%E6%88%B0%E9%9A%8A "中华民国海军陆战队")3年并废止陆一特。1990年7月起，不分军种一律服役2年。2000年1月，役期减为1年10个月，尔后逐年递减，至2008年1月，役期减至1年[[2]](#cite_note-義務役期沿革-2)。

2013年2月起，于1994年1月1日起出生者只须接受4个月军事训练即完成服役义务。至2018年12月末代1年制义务役士兵退伍后，2019年起开始采行“募征并行”制[[3]](#cite_note-3)。

2024年1月起，于2005年1月1日起出生者[恢复服1年常备兵役](/wiki/%E5%BC%B7%E5%8C%96%E5%85%A8%E6%B0%91%E5%9C%8B%E9%98%B2%E5%85%B5%E5%8A%9B%E7%B5%90%E6%A7%8B%E8%AA%BF%E6%95%B4%E6%96%B9%E6%A1%88 "强化全民国防兵力结构调整方案") [[4]](#cite_note-4)[[5]](#cite_note-5)，1994年至2004年间出生者仍维持接受4个月常备兵役军事训练。

### 早期

[[编辑](/w/index.php?title=%E8%87%BA%E7%81%A3%E5%85%B5%E5%BD%B9%E5%88%B6%E5%BA%A6&action=edit&section=2 "编辑章节：早期")]

* 在[荷兰](/wiki/%E8%87%BA%E7%81%A3%E8%8D%B7%E8%98%AD%E7%B5%B1%E6%B2%BB%E6%99%82%E6%9C%9F "台湾荷兰统治时期")以及[西班牙](/wiki/%E8%87%BA%E7%81%A3%E8%A5%BF%E7%8F%AD%E7%89%99%E7%B5%B1%E6%B2%BB%E6%99%82%E6%9C%9F "台湾西班牙统治时期")殖民时期（1624年－1662年），殖民者都曾向[原住民](/wiki/%E8%87%BA%E7%81%A3%E5%8E%9F%E4%BD%8F%E6%B0%91%E6%97%8F "台湾原住民族")[平埔族](/wiki/%E5%B9%B3%E5%9F%94%E6%97%8F%E7%BE%A4 "平埔族群")募集佣兵、勇士数百人。
* 在[明郑时期](/wiki/%E8%87%BA%E7%81%A3%E6%98%8E%E9%84%AD%E6%99%82%E6%9C%9F "台湾明郑时期")（1661年－1683年），[东宁](/wiki/%E6%9D%B1%E5%AF%A7_(%E8%87%BA%E7%81%A3%E5%8F%A4%E5%90%8D) "东宁 (台湾古名)")政府，征兵制度尚不明确。
* 在[大清帝国统治时期](/wiki/%E8%87%BA%E7%81%A3%E6%B8%85%E6%B2%BB%E6%99%82%E6%9C%9F "台湾清治时期")（1683年－1895年），有[大清帝国正规军](/wiki/%E6%B8%85%E5%86%9B "清军")（[绿营](/wiki/%E7%B6%A0%E7%87%9F_(%E6%B8%85%E6%9C%9D) "绿营 (清朝)")、广勇、[黑旗军](/wiki/%E9%BB%91%E6%97%97%E8%BB%8D "黑旗军")、新楚军、沪军、[淮军](/wiki/%E6%B7%AE%E8%BB%8D "淮军")、台勇等等）驻扎。
* 在[台湾民主国](/wiki/%E8%87%BA%E7%81%A3%E6%B0%91%E4%B8%BB%E5%9C%8B "台湾民主国")时期（1895年），有残存的前[大清帝国正规军](/wiki/%E6%B8%85%E5%86%9B "清军")、未经训练的台勇（民主国正规军）、无民主国番号的义军（如十八堡军、[六堆军](/wiki/%E7%BE%A9%E8%BB%8D_(%E8%87%BA%E7%81%A3%E5%AE%A2%E5%AE%B6%E4%BA%BA) "义军 (台湾客家人)")、各地民防团练等）。

### 日治时期

[[编辑](/w/index.php?title=%E8%87%BA%E7%81%A3%E5%85%B5%E5%BD%B9%E5%88%B6%E5%BA%A6&action=edit&section=3 "编辑章节：日治时期")]

主条目：[台湾日治时期](/wiki/%E5%8F%B0%E7%81%A3%E6%97%A5%E6%B2%BB%E6%99%82%E6%9C%9F "台湾日治时期")和[护乡兵](/wiki/%E8%AD%B7%E9%84%89%E5%85%B5 "护乡兵")

1895年，[大清帝国](/wiki/%E6%B8%85%E6%9C%9D "清朝")与[大日本帝国](/wiki/%E5%A4%A7%E6%97%A5%E6%9C%AC%E5%B8%9D%E5%9B%BD "大日本帝国")签订《[马关条约](/wiki/%E9%A9%AC%E5%85%B3%E6%9D%A1%E7%BA%A6 "马关条约")》（下関条約），[台湾岛](/wiki/%E8%87%BA%E7%81%A3 "台湾")、[澎湖群岛](/wiki/%E6%BE%8E%E6%B9%96%E7%BE%A4%E5%B3%B6 "澎湖群岛")与相关岛屿改隶日本。但在[日本统治](/wiki/%E5%8F%B0%E7%81%A3%E6%97%A5%E6%B2%BB%E6%99%82%E6%9C%9F "台湾日治时期")初期[台湾人](/wiki/%E8%87%BA%E7%81%A3%E4%BA%BA "台湾人")发起了许多[反日起事](/wiki/%E5%8F%B0%E7%81%A3%E6%8A%97%E6%97%A5%E9%81%8B%E5%8B%95 "台湾抗日运动")，此时期[台湾总督府](/wiki/%E8%87%BA%E7%81%A3%E7%B8%BD%E7%9D%A3%E5%BA%9C "台湾总督府")曾经征募本岛人，以加强统治初期不稳定的治安，也用来加强镇压反抗势力。

* 1897年11月，时任[台湾总督](/wiki/%E8%87%BA%E7%81%A3%E7%B8%BD%E7%9D%A3 "台湾总督")[乃木希典](/wiki/%E4%B9%83%E6%9C%A8%E5%B8%8C%E5%85%B8 "乃木希典")，开始征募本岛人（主要为[原住民](/wiki/%E8%87%BA%E7%81%A3%E5%8E%9F%E4%BD%8F%E6%B0%91%E6%97%8F "台湾原住民族")）担任“[护乡兵](/wiki/%E8%AD%B7%E9%84%89%E5%85%B5 "护乡兵")”[[6]](#cite_note-6)。
* 1898年5月，[儿玉源太郎](/wiki/%E5%85%92%E7%8E%89%E6%BA%90%E5%A4%AA%E9%83%8E "儿玉源太郎")成为台湾总督后，5月颁布敕令将护乡兵改制为“军役壮丁”。10月后将军役壮丁废止，改为“军役志愿制度”。并以汉人为主要募集对象。平时作军中劳役工作，比起护乡兵，较少进行战斗训练。

主条目：[中国抗日战争](/wiki/%E4%B8%AD%E5%9B%BD%E6%8A%97%E6%97%A5%E6%88%98%E4%BA%89 "中国抗日战争")、[大东亚战争](/wiki/%E5%A4%A7%E4%B8%9C%E4%BA%9A%E6%88%98%E4%BA%89 "大东亚战争")、[太平洋战争](/wiki/%E5%A4%AA%E5%B9%B3%E6%B4%8B%E6%88%98%E4%BA%89 "太平洋战争")、[第二次世界大战](/wiki/%E7%AC%AC%E4%BA%8C%E6%AC%A1%E4%B8%96%E7%95%8C%E5%A4%A7%E6%88%98 "第二次世界大战")和[台籍日本兵](/wiki/%E5%8F%B0%E7%B1%8D%E6%97%A5%E6%9C%AC%E5%85%B5 "台籍日本兵")

[![](//thumb.wikimedia.org/wikipedia/commons/thumb/3/39/%E8%87%BA%E7%B1%8D%E6%97%A5%E6%9C%AC%E5%85%B5%E5%87%BA%E5%BE%81%E5%89%8D_Drafted_Taiwanese_soldiers_during_World_War_II.jpg/500px-%E8%87%BA%E7%B1%8D%E6%97%A5%E6%9C%AC%E5%85%B5%E5%87%BA%E5%BE%81%E5%89%8D_Drafted_Taiwanese_soldiers_during_World_War_II.jpg?utm_source=zh.wikipedia.org&utm_campaign=parser&utm_content=thumbnail)](/wiki/File:%E8%87%BA%E7%B1%8D%E6%97%A5%E6%9C%AC%E5%85%B5%E5%87%BA%E5%BE%81%E5%89%8D_Drafted_Taiwanese_soldiers_during_World_War_II.jpg)

[台籍日本兵](/wiki/%E5%8F%B0%E7%B1%8D%E6%97%A5%E6%9C%AC%E5%85%B5 "台籍日本兵")出征前

在[二十世纪](/wiki/20%E4%B8%96%E7%BA%AA "20世纪")初期，[大日本帝国](/wiki/%E5%A4%A7%E6%97%A5%E6%9C%AC%E5%B8%9D%E5%9B%BD "大日本帝国")继续奉行其[大陆政策](/wiki/%E5%A4%A7%E9%99%86%E6%94%BF%E7%AD%96_(%E5%A4%A7%E6%97%A5%E6%9C%AC%E5%B8%9D%E5%9B%BD) "大陆政策 (大日本帝国)")，对[中华民国](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E5%A4%A7%E9%99%B8%E6%99%82%E6%9C%9F "中华民国大陆时期")进行势力扩张。1937年[第二次中日战争](/wiki/%E4%B8%AD%E5%9B%BD%E6%8A%97%E6%97%A5%E6%88%98%E4%BA%89 "中国抗日战争")全面爆发，随后[大东亚战争](/wiki/%E5%A4%A7%E4%B8%9C%E4%BA%9A%E6%88%98%E4%BA%89 "大东亚战争")期间日本加入[轴心国](/wiki/%E8%BD%B4%E5%BF%83%E5%9B%BD "轴心国")参与[第二次世界大战](/wiki/%E7%AC%AC%E4%BA%8C%E6%AC%A1%E4%B8%96%E7%95%8C%E5%A4%A7%E6%88%98 "第二次世界大战")。在战争背景之下，[台湾总督府](/wiki/%E8%87%BA%E7%81%A3%E7%B8%BD%E7%9D%A3%E5%BA%9C "台湾总督府")在实施募兵与征兵以补充[日军](/wiki/%E6%97%A5%E6%9C%AC%E5%86%9B "日本军")之人力需求。

* 1937年7月，爆发[七七卢沟桥事变](/wiki/%E4%B8%83%E4%B8%83%E4%BA%8B%E5%8F%98 "七七事变")，[第二次中日战争](/wiki/%E4%B8%AD%E5%9B%BD%E6%8A%97%E6%97%A5%E6%88%98%E4%BA%89 "中国抗日战争")全面打响。
* 1937年秋，开始动员征用“军属”以担负军中杂役，也被征调为翻译人员，经训练后负责[闽语](/wiki/%E9%96%A9%E8%AA%9E "闽语")、[客语](/wiki/%E5%AE%A2%E5%AE%B6%E8%A9%B1 "客家话")、[粤语](/wiki/%E7%B2%A4%E8%AF%AD "粤语")与[北京官话](/wiki/%E5%8C%97%E4%BA%AC%E5%AE%98%E8%AF%9D "北京官话")等[中国语言](/wiki/%E4%B8%AD%E5%9C%8B%E8%AA%9E%E8%A8%80 "中国语言")事务。
* 1941年12月，[珍珠港事件](/wiki/%E7%8F%8D%E7%8F%A0%E6%B8%AF%E4%BA%8B%E4%BB%B6 "珍珠港事件")后，[太平洋战争](/wiki/%E5%A4%AA%E5%B9%B3%E6%B4%8B%E6%88%B0%E7%88%AD "太平洋战争")爆发。
* 1942年初，开始招募志愿原住民参战，后通称“[高砂义勇队](/wiki/%E9%AB%98%E7%A0%82%E7%BE%A9%E5%8B%87%E9%9A%8A "高砂义勇队")”，总数约5,000人，战死超过4,000人。
* 1942年4月，开始实施与[朝鲜](/wiki/%E6%9C%9D%E9%AE%AE%E6%97%A5%E6%B2%BB%E6%99%82%E6%9C%9F "朝鲜日治时期")同性质的“[陆军特别志愿兵制度](/wiki/%E9%99%B8%E8%BB%8D%E7%89%B9%E5%88%A5%E5%BF%97%E9%A1%98%E5%85%B5%E5%88%B6%E5%BA%A6 "陆军特别志愿兵制度")”，募得总数约16,000人。
* 1943年8月，开始实施“[海军特别志愿兵制度](/wiki/%E6%B5%B7%E8%BB%8D%E7%89%B9%E5%88%A5%E5%BF%97%E9%A1%98%E5%85%B5%E5%88%B6%E5%BA%A6 "海军特别志愿兵制度")”。
* 1944年12月起全面实施征兵制度[[7]](#cite_note-7)。

总计[第二次世界大战](/wiki/%E7%AC%AC%E4%BA%8C%E6%AC%A1%E4%B8%96%E7%95%8C%E5%A4%A7%E6%88%98 "第二次世界大战")期间[台籍日本兵](/wiki/%E5%8F%B0%E7%B1%8D%E6%97%A5%E6%9C%AC%E5%85%B5 "台籍日本兵")人数共207,183名，其中军人80,433人、军属126,750人，战死约30,304人。

### 战后时期与中华民国政府迁台

[[编辑](/w/index.php?title=%E8%87%BA%E7%81%A3%E5%85%B5%E5%BD%B9%E5%88%B6%E5%BA%A6&action=edit&section=4 "编辑章节：战后时期与中华民国政府迁台")]

参见：[冷战](/wiki/%E5%86%B7%E6%88%98 "冷战")和[海峡两岸关系](/wiki/%E6%B5%B7%E5%B3%BD%E5%85%A9%E5%B2%B8%E9%97%9C%E4%BF%82 "海峡两岸关系")

[![](//thumb.wikimedia.org/wikipedia/commons/thumb/e/e2/Military_parade_in_front_of_Chiang_Kai-shek_Memorial_Hall.jpg/500px-Military_parade_in_front_of_Chiang_Kai-shek_Memorial_Hall.jpg?utm_source=zh.wikipedia.org&utm_campaign=parser&utm_content=thumbnail)](/wiki/File:Military_parade_in_front_of_Chiang_Kai-shek_Memorial_Hall.jpg)

[中华民国三军仪队](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E4%B8%89%E8%BB%8D%E5%84%80%E9%9A%8A "中华民国三军仪队")于[中正纪念堂](/wiki/%E4%B8%AD%E6%AD%A3%E7%B4%80%E5%BF%B5%E5%A0%82 "中正纪念堂")进行[操枪](/wiki/%E8%8A%B1%E5%BC%8F%E6%93%8D%E6%9E%AA "花式操枪")表演

1945年8月，[大日本帝国](/wiki/%E5%A4%A7%E6%97%A5%E6%9C%AC%E5%B8%9D%E5%9B%BD "大日本帝国")宣布向[同盟国](/wiki/%E5%90%8C%E7%9B%9F%E5%9C%8B_(%E7%AC%AC%E4%BA%8C%E6%AC%A1%E4%B8%96%E7%95%8C%E5%A4%A7%E6%88%B0) "同盟国 (第二次世界大战)")[无条件投降](/wiki/%E7%84%A1%E6%A2%9D%E4%BB%B6%E6%8A%95%E9%99%8D "无条件投降")，[第二次世界大战](/wiki/%E7%AC%AC%E4%BA%8C%E6%AC%A1%E4%B8%96%E7%95%8C%E5%A4%A7%E6%88%98 "第二次世界大战")结束，[中华民国](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B "中华民国")代表盟军占领[台湾](/wiki/%E8%87%BA%E7%81%A3 "台湾")。1949年12月，由于[第二次国共内战](/wiki/%E7%AC%AC%E4%BA%8C%E6%AC%A1%E5%9B%BD%E5%85%B1%E5%86%85%E6%88%98 "第二次国共内战")失利，[中华民国政府迁台](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E6%94%BF%E5%BA%9C%E9%81%B7%E5%8F%B0 "中华民国政府迁台")。进入1950年代后战事渐歇，[中国国民党](/wiki/%E4%B8%AD%E5%9C%8B%E5%9C%8B%E6%B0%91%E9%BB%A8 "中国国民党")领导的中华民国政府与[中国共产党](/wiki/%E4%B8%AD%E5%9B%BD%E5%85%B1%E4%BA%A7%E5%85%9A "中国共产党")领导的[中华人民共和国政府](/wiki/%E4%B8%AD%E8%8F%AF%E4%BA%BA%E6%B0%91%E5%85%B1%E5%92%8C%E5%9C%8B%E6%94%BF%E5%BA%9C "中华人民共和国政府")隔[台湾海峡](/wiki/%E5%8F%B0%E7%81%A3%E6%B5%B7%E5%B3%BD "台湾海峡")[两岸分治](/wiki/%E8%87%BA%E6%B5%B7%E7%8F%BE%E7%8B%80 "台海现状")的格局型成。

* 1949年12月，中华民国政府迁台后，在台湾实施征兵制以防止[中华人民共和国](/wiki/%E4%B8%AD%E5%8D%8E%E4%BA%BA%E6%B0%91%E5%85%B1%E5%92%8C%E5%9B%BD "中华人民共和国")进攻台湾。
* 1954年，《[兵役法](https://zh.wikisource.org/wiki/%E5%85%B5%E5%BD%B9%E6%B3%95_(%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B) "s:兵役法 (中华民国)")》大幅修正，明订军官役与士官役的详细规定，新增“预备军官役”以及“预备士官役”等役别；建立[预备军士官考选制度](/wiki/%E5%A4%A7%E5%B0%88%E7%A8%8B%E5%BA%A6%E7%BE%A9%E5%8B%99%E5%BD%B9%E9%A0%90%E5%82%99%E8%BB%8D%E5%A3%AB%E5%AE%98%E8%80%83%E8%A9%A6 "大专程度义务役预备军士官考试")；并明订义务兵役役期[陆军](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E9%99%B8%E8%BB%8D "中华民国陆军")为2年，[海军](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E6%B5%B7%E8%BB%8D "中华民国海军")[空军](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E7%A9%BA%E8%BB%8D "中华民国空军")为3年[[8]](#cite_note-8)。
* 1956年，颁布《[征兵规则](/wiki/%E5%BE%B5%E5%85%B5%E8%A6%8F%E5%89%87_(%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B) "征兵规则 (中华民国)")》，开始征集第1梯次常备兵役现役入营。
* 1967年至1986年间，[中华民国政府](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E6%94%BF%E5%BA%9C "中华民国政府")进行“[国光计画](/wiki/%E5%9C%8B%E5%85%89%E8%A8%88%E7%95%AB "国光计画")”准备[反攻大陆](/wiki/%E5%8F%8D%E6%94%BB%E5%A4%A7%E9%99%B8 "反攻大陆")，实施[陆军第一特种兵](/wiki/%E9%99%B8%E8%BB%8D%E7%AC%AC%E4%B8%80%E7%89%B9%E7%A8%AE%E5%85%B5 "陆军第一特种兵")（陆一特）制度。陆军将装甲兵、通信兵、炮兵、工兵、兵工等5个兵科列为第一特种兵。该等兵科之义务役男在服完当时《兵役法》所规定之陆军2年役期后，再以行政命令于其退伍同时另发为期1年的临时召集令，实际役期成为3年[[2]](#cite_note-義務役期沿革-2)。
* 1987年，[陆军第一特种兵](/wiki/%E9%99%B8%E8%BB%8D%E7%AC%AC%E4%B8%80%E7%89%B9%E7%A8%AE%E5%85%B5 "陆军第一特种兵")废止，且义务役役期陆军、海军、空军皆缩短为2年、唯[海军陆战队](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E6%B5%B7%E8%BB%8D%E9%99%B8%E6%88%B0%E9%9A%8A "中华民国海军陆战队")维持3年役期[[2]](#cite_note-義務役期沿革-2)。

### 台湾民主化

[[编辑](/w/index.php?title=%E8%87%BA%E7%81%A3%E5%85%B5%E5%BD%B9%E5%88%B6%E5%BA%A6&action=edit&section=5 "编辑章节：台湾民主化")]

主条目：[台湾民主化](/wiki/%E8%87%BA%E7%81%A3%E6%B0%91%E4%B8%BB%E5%8C%96 "台湾民主化")

1990年台湾经历[野百合学运](/wiki/%E9%87%8E%E7%99%BE%E5%90%88%E5%AD%B8%E9%81%8B "野百合学运")后开始[民主化](/wiki/%E8%87%BA%E7%81%A3%E6%B0%91%E4%B8%BB%E5%8C%96 "台湾民主化")，早年为[反攻大陆](/wiki/%E5%8F%8D%E6%94%BB%E5%A4%A7%E9%99%B8 "反攻大陆")而设计的兵役制度与建军思维也开始遭到检讨。当时[国军](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E5%9C%8B%E8%BB%8D "中华民国国军")士兵仍然以义务役役男为多数、军士官则多是志愿役服役人员。政府打算逐步扩大募兵制，最终目标是形成一个全志愿役的国家防卫军队。另外，也借由役期缩短与开办替代役以从军队中释放人员与劳动力，补足政府机关、科研单位、企业单位之部份人力上的不足。

* 1990年7月1日，义务役役期不分军种，服役时间统一为两年[[2]](#cite_note-義務役期沿革-2)。
* 1999年7月1日起，军训成绩可折抵义务役役期，高中职毕业可折抵14天，大专毕业可折抵28天[[2]](#cite_note-義務役期沿革-2)。
* 1999年起，办理“国防工业训储预备军官预备士官甄选”，又称“[国防役](/wiki/%E5%9C%8B%E9%98%B2%E5%BD%B9 "国防役")”，让部份高学历役男可以在相关产业之机关或公司服务的方式服役。
* 2000年，《[兵役法](https://zh.wikisource.org/wiki/%E5%85%B5%E5%BD%B9%E6%B3%95_(%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B) "s:兵役法 (中华民国)")》再度大幅修正，废除士兵役中之“国民兵役”并加入“[替代役](/wiki/%E6%9B%BF%E4%BB%A3%E5%BD%B9_(%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B) "替代役 (中华民国)")”制度。
* 2000年1月1日起，实施义务役役期缩短为1年10个月[[2]](#cite_note-義務役期沿革-2)。
* 2000年8月1日起，首次征集[替代役](/wiki/%E6%9B%BF%E4%BB%A3%E5%BD%B9_(%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B) "替代役 (中华民国)")[[2]](#cite_note-義務役期沿革-2)。

* 2008年1月1日起，实施义务役役期缩短为1年[[14]](#cite_note-14)，持续扩大实施志愿役兵役招募制度。[[15]](#cite_note-15)

### 募征并行

[[编辑](/w/index.php?title=%E8%87%BA%E7%81%A3%E5%85%B5%E5%BD%B9%E5%88%B6%E5%BA%A6&action=edit&section=6 "编辑章节：募征并行")]

主条目：[中华民国募兵制](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E5%8B%9F%E5%85%B5%E5%88%B6 "中华民国募兵制")和[志愿役与义务役并用制](/wiki/%E5%BF%97%E9%A1%98%E5%BD%B9%E8%88%87%E7%BE%A9%E5%8B%99%E5%BD%B9%E4%BD%B5%E7%94%A8%E5%88%B6 "志愿役与义务役并用制")

2008年[马英九](/wiki/%E9%A6%AC%E8%8B%B1%E4%B9%9D "马英九")就任[总统](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E7%B8%BD%E7%B5%B1 "中华民国总统")后，进一步推动[全募兵制](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E5%8B%9F%E5%85%B5%E5%88%B6 "中华民国募兵制")之军队改革。2009年3月10日，时任[国防部部长](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E5%9C%8B%E9%98%B2%E9%83%A8%E9%83%A8%E9%95%B7 "中华民国国防部部长")[陈肇敏](/wiki/%E9%99%B3%E8%82%87%E6%95%8F "陈肇敏")表示2014年底，会有一支全[志愿役](/wiki/%E5%BF%97%E9%A1%98%E5%BD%B9 "志愿役")的[国军](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E5%9C%8B%E8%BB%8D "中华民国国军")部队。[[16]](#cite_note-16)。从2010年开始废除征兵制的过程中，由2014年底的全志愿役部队完全取代之。个人希望加入志愿役士兵的人，必须有高中毕业之最低学历；以及没有加入志愿役的役男必须完成4个月的“军事训练役”[[17]](#cite_note-17)。据2012年报导，从2013年开始，1994年1月1日后出生的役男只需要接受4个月的[军事训练](/wiki/%E5%86%9B%E4%BA%8B%E8%AE%AD%E7%BB%83 "军事训练")，将不再需服一年期的义务兵役，而且政府与国防部也在2016年年底全部更换为志愿役部队[[18]](#cite_note-18)。这个政策保持不变，中华民国将有一个纯粹志愿役的专业化国军部队，但仍然将征召每一位达到役龄的男性并接受三至四个月的军事训练，以符合[中华民国宪法](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E6%86%B2%E6%B3%95 "中华民国宪法")规定。

* 2011年，修订《[兵役法](https://zh.wikisource.org/wiki/%E5%85%B5%E5%BD%B9%E6%B3%95_(%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B) "s:兵役法 (中华民国)")》，在士兵役常备兵役中加入“军事训练”制度。
* 2013年12月起，在1994年1月1日及以后出生之役男仅须接受4个月军事训练役（8周新训、8周下部队）；1993年12月31日及以前出生之役男仍须服役1年。
* 2015年，[内政部役政署](/wiki/%E5%85%A7%E6%94%BF%E9%83%A8%E5%BD%B9%E6%94%BF%E7%BD%B2 "内政部役政署")实施纳入更多产业类别的“[产业训储替代役](/wiki/%E7%94%A2%E6%A5%AD%E8%A8%93%E5%84%B2%E6%9B%BF%E4%BB%A3%E5%BD%B9 "产业训储替代役")”制度[[19]](#cite_note-19)。
* 2017年12月，末代义务役士兵入伍，海军第735梯次（23日，39人）、陆军第2225梯次（19日，299人）、空军第892梯次（19日，33人）、海军陆战队第811梯次（26日，41人）。
* 2018年1月1日起，非志愿役而达到役龄的常备役男性则改服4个月军事训练役（训期改前5周新兵基本训，后11周初级至中级专长训，无须下部队，仍会抽签分配至外岛受训）[[20]](#cite_note-20)。
* 2018年起，配合募兵制政策，[国防部](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E5%9C%8B%E9%98%B2%E9%83%A8 "中华民国国防部")之[义务役预备军士官考选](/wiki/%E5%A4%A7%E5%B0%88%E7%A8%8B%E5%BA%A6%E7%BE%A9%E5%8B%99%E5%BD%B9%E9%A0%90%E5%82%99%E8%BB%8D%E5%A3%AB%E5%AE%98%E8%80%83%E8%A9%A6 "大专程度义务役预备军士官考试")以及[内政部役政署](/wiki/%E5%85%A7%E6%94%BF%E9%83%A8%E5%BD%B9%E6%94%BF%E7%BD%B2 "内政部役政署")之[产业训储替代役](/wiki/%E7%94%A2%E6%A5%AD%E8%A8%93%E5%84%B2%E6%9B%BF%E4%BB%A3%E5%BD%B9 "产业训储替代役")等制度停办。
* 2018年12月，末代义务役士兵各梯次全面退伍。1993年次以前出生、尚未服役的役男，全面转服1年的替代役[[21]](#cite_note-21)[[22]](#cite_note-22)。

自2018年12月底起，正式进入“募征并行”时代，所有[中华民国国军](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E5%9C%8B%E8%BB%8D "中华民国国军")部队之现役军官、士官、士兵均由招募而来的[志愿役](/wiki/%E5%BF%97%E9%A1%98%E5%BD%B9 "志愿役")组成；经由征集而来的合格义务役男则在完成军事训练后返回民间，不进入[中华民国国军](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E5%9C%8B%E8%BB%8D "中华民国国军")部队服役。

至2019年全面实施军事训练前，

* 常备兵役自1956年1月起开办至2017年12月，共办理陆军2225梯次、海军735梯次、海军陆战队811梯次、空军892梯次之入营，末梯于2018年底前退伍。
* [义务役预备军士官](/wiki/%E5%A4%A7%E5%B0%88%E7%A8%8B%E5%BA%A6%E7%BE%A9%E5%8B%99%E5%BD%B9%E9%A0%90%E5%82%99%E8%BB%8D%E5%A3%AB%E5%AE%98%E8%80%83%E8%A9%A6 "大专程度义务役预备军士官考试")自1952年起开办至2017年，共办理67期之考选与训练，末期于2018年底前退伍。

### 恢复征兵

[[编辑](/w/index.php?title=%E8%87%BA%E7%81%A3%E5%85%B5%E5%BD%B9%E5%88%B6%E5%BA%A6&action=edit&section=7 "编辑章节：恢复征兵")]

参见：[第二次冷战](/wiki/%E7%AC%AC%E4%BA%8C%E6%AC%A1%E5%86%B7%E6%88%98 "第二次冷战")、[中美关系](/wiki/%E4%B8%AD%E7%BE%8E%E5%85%B3%E7%B3%BB "中美关系")、[海峡两岸关系](/wiki/%E6%B5%B7%E5%B3%BD%E5%85%A9%E5%B2%B8%E9%97%9C%E4%BF%82 "海峡两岸关系")和[强化全民国防兵力结构调整方案](/wiki/%E5%BC%B7%E5%8C%96%E5%85%A8%E6%B0%91%E5%9C%8B%E9%98%B2%E5%85%B5%E5%8A%9B%E7%B5%90%E6%A7%8B%E8%AA%BF%E6%95%B4%E6%96%B9%E6%A1%88 "强化全民国防兵力结构调整方案")

2017年以来，[中美关系](/wiki/%E4%B8%AD%E7%BE%8E%E5%85%B3%E7%B3%BB "中美关系")由合作转为对抗，悬而未决的[台湾问题](/wiki/%E8%87%BA%E7%81%A3%E5%95%8F%E9%A1%8C "台湾问题")成为中国与美国之间的焦点。国际上也担心，中共会打破1950年代以来的[台海现状](/wiki/%E8%87%BA%E6%B5%B7%E7%8F%BE%E7%8B%80 "台海现状")，对台湾进行军事威胁而再次出现[台湾海峡危机](/wiki/%E8%87%BA%E7%81%A3%E6%B5%B7%E5%B3%BD%E5%8D%B1%E6%A9%9F "台湾海峡危机")，2022年2月[俄罗斯入侵乌克兰](/wiki/%E4%BF%84%E7%BE%85%E6%96%AF%E5%85%A5%E4%BE%B5%E7%83%8F%E5%85%8B%E8%98%AD "俄罗斯入侵乌克兰")，再次引起[军事激烈对抗](/wiki/%E8%A7%A3%E6%94%BE%E5%8F%B0%E6%B9%BE "解放台湾")有可能成为现实的关注。

* 2022年12月27日，[总统](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E7%B8%BD%E7%B5%B1 "中华民国总统")[蔡英文](/wiki/%E8%94%A1%E8%8B%B1%E6%96%87 "蔡英文")召开国安会议将义务役从现行的4个月改为1年，义务役士兵每月薪资由约6,500元调升至2万6,307元新台币。[[23]](#cite_note-23)[[24]](#cite_note-24)[[25]](#cite_note-25)
* 2024年1月1日起恢复[常备兵役征集](/wiki/%E5%BC%B7%E5%8C%96%E5%85%A8%E6%B0%91%E5%9C%8B%E9%98%B2%E5%85%B5%E5%8A%9B%E7%B5%90%E6%A7%8B%E8%AA%BF%E6%95%B4%E6%96%B9%E6%A1%88 "强化全民国防兵力结构调整方案")，役期1年，对2005年1月1日起出生者适用。

* 届时梯次编号延续2018年底的梯次，将由陆军2226梯、海军舰艇兵736梯、海军陆战队812梯、空军893梯起算[[26]](#cite_note-26)。

2024年[中华民国](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B "中华民国")恢复征兵制后，再度成为实施征兵制度的[已开发国家](/wiki/%E5%B7%B2%E9%96%8B%E7%99%BC%E5%9C%8B%E5%AE%B6 "已开发国家")。

## 法源依据

[[编辑](/w/index.php?title=%E8%87%BA%E7%81%A3%E5%85%B5%E5%BD%B9%E5%88%B6%E5%BA%A6&action=edit&section=8 "编辑章节：法源依据")]

目前台湾兵役制度源自1947年《[中华民国宪法](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E6%86%B2%E6%B3%95 "中华民国宪法")》第二十条“人民有依法律服兵役之义务”，并以《[兵役法](https://zh.wikisource.org/wiki/%E5%85%B5%E5%BD%B9%E6%B3%95_(%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B) "s:兵役法 (中华民国)")》、《[兵役法施行法](https://zh.wikisource.org/wiki/%E5%85%B5%E5%BD%B9%E6%B3%95%E6%96%BD%E8%A1%8C%E6%B3%95 "s:兵役法施行法")》以及其他相关条例做为依据。[[27]](#cite_note-27)《兵役法》于1933年（民国22年）在[中华民国大陆时期](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E5%A4%A7%E9%99%B8%E6%99%82%E6%9C%9F "中华民国大陆时期")立法以来，随著[行宪](/wiki/%E8%A1%8C%E6%86%B2 "行宪")、[政府迁台](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E6%94%BF%E5%BA%9C%E9%81%B7%E5%8F%B0 "中华民国政府迁台")、以及[台湾民主化](/wiki/%E8%87%BA%E7%81%A3%E6%B0%91%E4%B8%BB%E5%8C%96 "台湾民主化")等国家重大事件经历多次修正。现行的《兵役法》将兵役分为以下类别：

| 兵役 |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- |
| 军官役 | 士官役 | 士兵役 | 替代役 |  |  |  |
| 常备军官役 | 预备军官役 | 常备士官役 | 预备士官役 | 常备兵役 | 补充兵役 |  |
| 现役 | 后备役 | 现役 | 后备役 | 现役 | 军事训练役 | 后备役 |

在相关法规中，兵役制度由[国防部](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E5%9C%8B%E9%98%B2%E9%83%A8 "中华民国国防部")以及[内政部](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E5%85%A7%E6%94%BF%E9%83%A8 "中华民国内政部")合作办理。其中内政部设立[役政司](/wiki/%E5%85%A7%E6%94%BF%E9%83%A8%E5%BD%B9%E6%94%BF%E5%8F%B8 "内政部役政司")以及[替代役训练及管理中心](/w/index.php?title=%E5%85%A7%E6%94%BF%E9%83%A8%E6%9B%BF%E4%BB%A3%E5%BD%B9%E8%A8%93%E7%B7%B4%E5%8F%8A%E7%AE%A1%E7%90%86%E4%B8%AD%E5%BF%83&action=edit&redlink=1 "内政部替代役训练及管理中心（页面不存在）")专责处理兵役事务，并与户政机关协同处理。

| **补充兵役** | * 补充兵役以适合服常备兵现役，因家庭因素，或经[教育部](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E6%95%99%E8%82%B2%E9%83%A8 "中华民国教育部")、[劳动部](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E5%8B%9E%E5%8B%95%E9%83%A8 "中华民国劳动部")核定之[国家代表队](/wiki/%E5%9C%8B%E5%AE%B6%E9%AB%94%E8%82%B2%E9%9A%8A "国家体育队")者，或替代役体位未服替代役者服之。 * 由[国防部](/wiki/%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B%E5%9C%8B%E9%98%B2%E9%83%A8 "中华民国国防部")依军事需要，施以2个月以内之军事训练，合格后列管、运用。 |  |
| **[替代役](/wiki/%E6%9B%BF%E4%BB%A3%E5%BD%B9_(%E4%B8%AD%E8%8F%AF%E6%B0%91%E5%9C%8B) "替代役 (中华民国)")** | * 役男可因体位判定服替代役，或由家庭因素、宗教因素、专长资格、志工资格、或其他原因申请替代役[[29]](#cite_note-29)[[30]](#cite_note-30)。 * 自2000年8月起征集，替代役役期不得少于常备兵役现役役期或军事训练期间。 * 自2008年起实施“[研发替代役](/wiki/%E7%A0%94%E7%99%BC%E6%9B%BF%E4%BB%A3%E5%BD%B9 "研发替代役")”制度，役期为3年或1年6个月。 * 曾在2015年至2017年间实施“[产业训储替代役](/wiki/%E7%94%A2%E6%A5%AD%E8%A8%93%E5%84%B2%E6%9B%BF%E4%BB%A3%E5%BD%B9 "产业训储替代役")”制度，末梯于2020年底前退役。 |  |

役男在完成兵役义务后，须接受后备管理。其中常备兵役退伍后成为[后备军人](/wiki/%E5%BE%8C%E5%82%99%E8%BB%8D%E4%BA%8B%E5%8B%95%E5%93%A1 "后备军事动员")，至满36岁之年12月31日除役；预备军官与预备士官则依照《[陆海空军军官士官服役条例](/wiki/%E9%99%B8%E6%B5%B7%E7%A9%BA%E8%BB%8D%E8%BB%8D%E5%AE%98%E5%A3%AB%E5%AE%98%E6%9C%8D%E5%BD%B9%E6%A2%9D%E4%BE%8B "陆海空军军官士官服役条例")》，至满50岁除役。
