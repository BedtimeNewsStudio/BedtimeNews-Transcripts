# 建银国际（控股）有限公司

建银国际（控股）有限公司及旗下子公司（“建银国际”）是中国建设银行股份有限公司（“建设银行”）之投行旗舰，以打造匹配建设银行大型商业银行地位的国际一流投行为愿景，依托建设银行全球化网络与综合金融优势，竭诚为个人、企业及机构投资者提供“跨市场、定制化、全周期”的金融解决方案，成功构建起“保荐承销 + 资产与财富管理 + 固定收益 + 证券经纪 + 直接投资 + 环球商品”六位一体的一站式金融服务生态。

作为跨境资本桥梁，建银国际成功协助众多客户完成股权及债务融资项目，融资金额累计逾5万亿港币；资产管理板块构建了多元化、多层次基金产品矩阵，覆盖稳健型至进取型投资策略；直接投资以前瞻性、价值成长型策略见长，专注培育具有行业引领力的创新企业；依托独立深入的研究视角与智能敏捷的交易系统，为机构投资者提供差异化、高附加值的证券服务，持续在市场波动中把握结构性机遇。
