|  | 【2019全球贸易观察】——孟加拉国市场分析 二维码  1. 孟加拉国概览  孟加拉国在1757年沦为英属印度的一个省，1947年印巴分治后，归属巴基斯坦，被称为东巴基斯坦。1971年，脱离巴基斯坦而独立。孟加拉国大部分地区属亚热带季风气候，湿热多雨。  据孟加拉《金融快报》4月30日报道，孟加拉**本财年GDP预计增长8.13%**，实现创纪录增长。2018年第4季度，**出口****收入**达到**204.9亿美元**，同比**增长14.48%**，上年同期为179.2亿美元。**进口支出**为**303.3亿美元**，同比**增长5.73%**。截止2018年12月30日，外汇储备为320.2亿美元。  2. 孟加拉国进出口状况  据孟出口促进局数据，2017—2018财年孟加拉国出口额为424.69亿美元，同比增长6.89%；同时据孟加拉国央行数据，孟2018年进口额为533.7亿美元，同比增长6.86%。  （孟加拉主要进口来源国位置分布 ）  （孟加拉主要进口来源国进口贸易额）  中国作为孟加拉国的主要进口来源国之一，以33.3%进口占比位居第一，而排名第二、三的印度和新加坡的进口占比分别是16.4%和6.4%，可见中国在孟加拉国的进口来源国中作用突出。  （孟加拉前十主要进口产品及贸易额）  根据统计数据显示，孟加拉进口最多的机械设备，总金额到达了453.4亿；其次是棉，进口额442.3亿。  （孟主要出口目的国位置分布）  （孟主要出口目的国及年度出口额）  在孟加拉出口国家中，美国多年来持续占据第一出口目的国地位，孟已成为美全球布局的原料产地和劳动力产地。除美国外，孟主要出口目的国还有欧洲的德国、英国、西班牙和法国。  （孟十大主要出口产品及贸易额）  纺织服装业在孟加拉国经济社会发展中扮演着非常重要的角色，约占孟加拉国工业总产值的38%。孟加拉国拥有2000多家纺织厂，6000多家成衣加工厂，就业人数超过480万，成为仅次于中国的**全球第二大纺织品出口国**。  3. 中孟近年来贸易发展趋势  目前，中国是孟加拉最大的进口来源国，2018年进口额到达了119.5亿，同比增长了17%。  （2018年度中国出口孟加拉主要省份）  中国出口孟加拉的主要地区包括：江苏、浙江、北京、广东、山东、和上海。其中江苏、浙江、北京占据了前三名，出口额占比达到了60%。  （孟从中国主要进口产品）  孟加拉从中国进口的前24中商品中，柴油占据了第一位，进口总额达到了70多个亿，除开柴油商品外，孟加拉从中国进口最多的是棉。占比达到了80%以上。  根据数据显示，孟加拉国布匹产品的产量几乎每年均有两位数的增长幅度。由于市场需求旺盛，但是原料不足，仅能满足50%左右的需求，为缩小供需缺口，孟加拉国在未来将自己投资或吸引外资建立一系列的纺纱织布厂，这无疑给我国的纺纱企业带来巨大的投资机会。  （中孟贸易方式）  从贸易方式来看，采用最多的是一般贸易方式，占比达到了63%；其次是保税监管场所进出境货物和免税外汇商品。  4. 与孟贸易注意事项  孟加拉国经济发展相对落后，在法律法规制度上都不是很完善，尤其是在国际贸易上，所有在和孟加拉客户做生意是一定要注意一下几点问题：  **4.1.收款问题**  **孟加拉国对于外汇管制非常严格，出口孟加拉最大的特点是必须有孟加拉银行开具的信用证，**即L/C Authorization Form（LCA）。而且这些信用证的天数基本上都是120天。所以你要做好货款被押半年的准备。  **4.2审查工作**  开信用证前，一定要先了解一下开立信用证的开证行资信，选择信誉良好的开证行。如果客户选择的开证行资信太差，就直接放弃合作。  另外，确认要开信用证后，应认真审核信用证条款是否可接受，及时向客户提出改证要求，预防因软条款产生的不符点，影响收汇。  分享到： |  |
