# 共谋发展 共话未来！“创新·开放·共享发展”全球对话会乌拉圭专场在蒙得维的亚举行

来源：[央视新闻](http://content-static.cctvnews.cctv.com/snow-book/index.html?item_id=9646145756795165266&channelId=1119&toc_style_id=feeds_default&track_id=160137B3-CE30-476D-B24D-407ED1CF5349_783598099672&share_to=wechat ) | 2025年11月01日 08:48

央视新闻 | 2025年11月01日 08:48

###### 原标题：

正在加载

当地时间10月30日，由中国中央广播电视总台和中国驻乌拉圭大使馆联合主办的“创新·开放·共享发展”全球对话会乌拉圭专场在乌首都蒙得维的亚举行。中宣部副部长、中央广播电视总台台长慎海雄作视频致辞。中国驻乌拉圭大使黄亚中、乌拉圭国防部长桑德拉·拉索、乌拉圭国家视听传播总署署长埃丽卡·霍夫曼、乌拉圭中国商会主席尼克拉斯·波特里出席活动并致辞。乌拉圭劳动与社会保障部长、乌共总书记胡安·卡斯蒂略，乌拉圭总统府新闻局局长马丁·莱斯，乌拉圭外交部文化司总司长、前驻华大使费尔南多·卢格里斯，乌拉圭经济学家丹尼尔·巴里奥斯等来自中乌两国政界、经济界、学界等百余名嘉宾参加活动。

　　慎海雄表示，广受世界关注的中国共产党二十届四中全会在北京胜利闭幕，这是新时代中国的又一重要里程碑。全会再次向世界郑重宣告：中国将扩大高水平对外开放，开创合作共赢新局面。回首即将收官的“十四五”，中国经济社会发展跃上新台阶，对世界经济增长的贡献率保持在30%左右。可以预见，在中国新发展蓝图指引下，中国开放的大门将越开越大，为世界带来更多共赢机遇。中央广播电视总台将与合作伙伴一起，搭建集智共商的全球平台，践行“四大全球倡议”，与世界共享全球治理的“中国方案”，与世界共享中国式现代化的广阔前景，与世界共享新时代中国的创新动能。中国的发展离不开世界，世界的繁荣也需要中国。总台愿与大家携手同行、共赴梦想，推动构建人类命运共同体，共创人类更加美好的未来。

　　△中国驻乌拉圭大使黄亚中

　　黄亚中表示，中国共产党二十届四中全会为未来五年中国发展擘画了宏伟蓝图，是对乘势而上、接续推进中国式现代化的又一次总动员、总部署，将对中国和世界产生深远影响。未来五年，中国将继续推动高质量发展、提高科技自立自强水平、提升人民生活品质、加强美丽中国建设。中乌两国传统友好，是不同意识形态友好相处、不同规模经济体合作共赢、不同文化交流互鉴的典范。近些年来，两国政治互信不断巩固，高层往来频繁，务实合作成果丰硕，人文交流精彩纷呈。展望未来，两国各领域交流合作前景广阔、大有可为。中方期待同乌方共同努力，推动两国全面战略伙伴关系不断取得新的发展，更好造福两国人民。

　　△乌拉圭国防部长桑德拉·拉索

　　桑德拉·拉索表示，此次全球对话会为各国提供了一个深化交流与合作的重要契机。在当今充满挑战的国际环境下，加强对话与国际合作，对维护各国之间的稳定与互信至关重要。乌拉圭高度赞赏中国在“坚持多边主义与和平解决全球问题”方面作出的坚定承诺。乌拉圭与中国建交以来，两国在国际事务中始终相互理解和支持，乌拉圭将继续与中国携手，为和平、创新与人类的可持续发展而努力。

　　△乌拉圭国家视听传播总署署署长埃丽卡·霍夫曼

　　埃丽卡·霍夫曼表示，本次活动充分体现了乌中两国深化友谊、增进理解、加强文化与科技交流的共同意愿，并为两国媒体在专业培训、联合制作与技术交流等方面的合作开启新篇章。乌拉圭正在推进媒体基础设施现代化，希望借鉴中国在科技与传媒创新方面的经验，进一步加强双方在内容管理、视听制作、数字传播及技术转移等领域的务实合作。

　　△乌拉圭中国商会主席尼克拉斯·波特里

　　尼克拉斯·波特里表示，作为连接乌中两国企业的重要桥梁，乌拉圭中国商会在推动双边合作与经贸往来中发挥着重要作用。乌拉圭积极参与中国提出的共建“一带一路”倡议，乌中商会将继续发挥桥梁纽带作用，推动两国在经贸、基础设施、科技和文化等领域加强合作，助力两国关系迈上更高水平。

　　△乌拉圭外交部文化司总司长、前驻华大使费尔南多·卢格里斯和乌拉圭经济学家丹尼尔·巴里奥斯参与现场交流

　　活动上，现场嘉宾围绕中共二十届四中全会的里程碑意义、中国与世界各国共享发展机遇等话题展开深入交流。费尔南多·卢格里斯表示，中国五年规划的制定和实施离不开广泛的社会参与和共识凝聚，我们应该学习中国如何在开放、包容、广泛参与的基础上实现高效的战略设计与实施。丹尼尔·巴里奥斯表示，中国在很多科学技术领域处于全球领先地位，中共二十届四中全会进一步对以科技创新引领发展新质生产力作出了明确部署。未来，中国将不仅在本国范围内引领现代化，也将在全球舞台上扮演越来越重要的角色。

　　活动现场，与会嘉宾共同观看了中央广播电视总台纪录片《中国式现代化之路》，沉浸式感受中国式现代化的万千气象。

　　乌拉圭国家电视台、UCL电视台、《共和国报》《早晨报》等多家乌拉圭主流媒体对活动进行了报道。
