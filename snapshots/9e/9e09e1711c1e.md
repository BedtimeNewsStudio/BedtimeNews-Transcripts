# 安徽怀宁“血铅迷局”追踪: 县环保局局长被撤职(2)

2011年01月14日 07:33　来源：新华网　![](http://www.chinanews.com/fileftp/2010/04/2010-04-23/U76P4T47D13180F981DT20100423110629.jpg)[参与互动(0)](http://comment.chinanews.com/comments/comments.php?newsid=2787292)　　【字体：↑大↓小】

【节目导视】儿童血铅超标集中发生（第一批查了一百多个人，大概有２３例血铅超过２５０微克每升的；以现在看，因为发病病人数比较多，也比较集中，我们考虑还是和当地区域性因素有什么关系）；

两个不同检测结果令人质疑（儿童医院和疾控中心出的结果差得特别多，我们咨询过儿童医院的医生，他们说误差肯定是有的，但是不可能这么多的）。

敬请关注本期节目——《怀宁“儿童血铅超标”事件追踪》。

【演播室主持人】继去年１０月安徽省怀宁县月山镇发生４３名职工血铅含量超标事件之后，　２０１１年新年伊始，怀宁县再次发生血铅超标事件：高河镇新山社区的上百名儿童被检测出血铅超标，其中２４名已经住院治疗。如此短的时间内，一个小小的县城为何会频繁发生血铅超标事件？请看记者的调查。

|     |
| --- |
|  |

【解说】２０１１年元旦这天，远在银川做生意的黄大寨接到了媳妇从老家安徽怀宁打来的电话。电话里，媳妇带来的不是新年祝福，而是一个令他忐忑不安的消息：村里很多小孩被检查出来血铅含量超标，其中自己５岁的儿子被检测出血铅含量３３０．９微克每升，属于中度铅中毒。得知这样的情况后，黄大寨放下手里的活儿，赶紧回到了家。
