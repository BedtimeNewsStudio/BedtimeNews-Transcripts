| 非典时期电子商务激活“非接触经济” | | --- | | * * * | | http://www.sina.com.cn 2003年05月21日 14:42 中国信息产业网-人民邮电报 | | | | 北京的一位中学生在日记里写下了这样的句子：这个季节本来有花香馥郁的灿烂，本来有欢声笑语的浪漫，本来有书声朗朗的盎然，可是，SARS这个“天外杀手”却突从天降，一只看不见的黑手伸向一个个鲜活的生灵，明媚的天空很快布上了一层厚厚的阴霾，骤然间，花香飘散了，笑声窒息了，书声没有了……妈妈与我告别了整整一个春天。 是的，多么美丽的季节却不属于今年的北京，一派欣欣向荣的繁华却疏远了京城…… 北京，中国最大的经济、政治、文化中心，每年不知多少全国乃至全球性商业活动在这里举行，不知有多少商界名流云集于此，不知有多少商业订单在这里签订，但是它陷入了猝不及防的生与死考验之中，一个经济、政治、文化交往频繁的大都市却突然间从经济的“热点”降到了“冰点”。一年一度的各种经济活动不得不被推迟或取消——唇枪舌剑的谈判桌哑然了，人声鼎沸的展览厅寂静了，怦然心跳的交易所冷清了…… 不只是北京呀，从南国到北疆，从沿海到西部，中国大地上正在进行着一场没有硝烟的战争…… 有人这样担心：中国正经受着一次经济上的考验。 不过，也有人这样形容：一半是海水，一半是火焰。当“实体经济”遭受冲击的时候，电子商务却努力弥补着SARS带来的损失。 网上银行理财自如 如果说，SARS把人们从银行的营业厅里“赶”了出来的话，那么，网络银行的大门却永远地敞开着，与SARS进行着针锋相对的斗争。 这里有一条令人振奋的消息：中国工商银行克服非典带来的不利影响，大力发展电子银行业务，4月份电子银行交易额达15648亿元。 面对突如其来的疫情，工商银行充分发挥电子信息化技术的先进优势，及时开放远程和异地工作的技术支持，确保各项业务正常运行，最大限度降低非典疫情带来的负面影响。近一个时期，工商银行的电子银行营销宣传、电子化信息化金融服务、电话银行、手机银行、网上银行等非人员接触方式的营销开展得风风火火。此外，工行牡丹卡中心特别推出了电话办卡、网上办卡等非接触式的办卡新形式。“五一”假期日均接受电话咨询900多个，网上申请办卡人数增加4倍。由于措施得力，前4个月，工商银行电子银行实现交易额45168亿元，其中4月份当月交易额达15648亿元；网上银行交易额达36550亿元，其中4月份当月交易额达12977亿元，比去年同期增长3.65倍，创历史最高；企业网上银行增势旺盛，客户存量达到4.24万户，较年初新增20%。 在北京，不期而遇的非典打乱了人们的正常生活，而“网银生活”却让市民的生活井然有序。在一家外企上班的王女士近些日子虽然深居简出，但是，繁忙的网络生活却使她特别充实。她使用网上银行购物、汇款等等，真是足不出户，却能运筹帷幄。王女士庆幸自己很早就注册了网上银行用户，不然，她将真要在家里“坐吃山空”了。 张先生说，在网上炒股票买保险方便又快捷。他自称已经好几年没有因为办理个人业务去过银行柜台网点了，因为网上银行已经满足了他所有的需要。所以，这闹心的非典还真没有影响他的业务。网上银行几乎所有的功能对他都有用，每月工资一到账，他就要开始进行例行的网上理财：汇款、支付手机费、缴电费、支付住房的按揭等。 专业人士介绍，网上银行是指银行通过因特网向企业客户和个人客户提供的自助金融服务，一般包括账户信息查询、转账支付、在线支付、代理业务等内容。目前，工行、交行、建行、民生银行等均已推出该项业务，非典危机客观上正成为银行的推销良机。近期出现的电子银行红火、刷卡消费看涨等现象，虽说是始于居民减少接触、预防疾病的需要，但非典疫情过后，这种趋势仍会延续。 但是，在大多数人的眼里，对金融电子化的概念一直感到陌生，缺乏亲近感；当SARS把他们推到电子银行的门前的时候，甚至不少企业和普通市民对电子银行的信息安全等方面存有疑虑。 对于许多客户共同关注的安全问题，银行有关专业人士解释道，其实客户对网上银行的安全有很多误解，以为资金就是在互联网上流动，其实并非如此，客户在网上下指令，银行在收到后就按指令操作，操作的过程和柜台完全一样，资金并没有在互联网上流动。工行到目前为止所做的8万亿元的网上银行交易，从来没有发生过一次错误。而且许多银行也正在推出更完善的信息安全方案，这无疑给电子银行用户一个定心丸。 网上展览别开生面 本来如火如荼的会展经济却被突如其来的非典浇了一盆冷水。自从4月以来，会展就成为受影响最大的产业之一。一时间，“提前闭展”、“延期开展”，甚至“撤销展会”的消息纷纷发布。有些重要的会展即使如期开幕，场面也很难续写往日的辉煌。然而，中国的会展经济并没有被一棍子打死，而是以网上会展等形式继续显示其强大的生命力。 今年春季广交会就是一次网上展会的大比拼，它为中外客商提供了一站式的全程贸易服务电子商务交易平台。这次广交会包括交易前、中、后三个阶段的服务：客商可先从商品展示区中查询目标，通过可视系统，双方可以随时进行实时洽谈；利用数字地图的导航，供货厂家位置抬眼可见；平台全程管理贸易双方的合同与订单，物流配送系统将方便中外客商随时跟踪货物到港及交付情况。由于有了如此功能强大的网上会展平台，本届春交会的全部44.2亿美元出口成交中，网上成交就占去了13亿美元。 与传统会展相比，网络会展具有参会者不受地域限制、交易成本低、组织工作简单等优点，日益受到会展主办方的青睐。业内人士认为，作为会展业来讲，网上会展以其低投入、高效益的特点肯定会在今后的会展经济中占有越来越多的份额。非典的出现只是使它的优势被更多的人认识而已，就是没有非典，网上会展也迟早会浮出水面。就连此次受非典影响不大的青岛市也宣布下月举办网上招商会。 一年一度的科技周是每年5月的一大亮点，但是，受非典的影响，2003年全国科技周虽然没有往年的车水马龙、人群潮涌，网上却另有一番景象。随着新浪网以及科技部、中国科学院等多家科普网站的开通，“依靠科学，战胜非典”为鲜明主题的科技周很快被推上高潮。科技周还设有网上论坛，网民可以与众多科学家就SARS问题直接对话，这是历届科技周所没有的优势。 非典时期的汽车市场持续“高烧”，并呈现出许多异于平常的怪现象：从4月中旬开始，北京的北方汽车交易市场将“北方有约，购车有礼”活动在许多网站上公布后，吸引了大量消费者的关注，购车热线咨询量大幅提高，很多消费者在家里咨询有关购车事宜。近半个月以来，“网上车市”的点击率较以前提高了60%。 在浙江，网上技术市场交易出现火爆场面。5月16日上午，中国浙江网上技术市场，仅两个小时内就有多家企业在网上发布了26项技术难题信息。据网上技术市场网管中心统计，4月20日至5月5日半个月内，浙江省企业在网上发布504个技术难题，比此前半个月增加了200个左右；企业提供的研发经费达4.3亿元，并且有84个项目签约，占今年前4个月签约数的45%。 网上贸易照常签单 非典时期，对众多寄望出口业务的企业造成严重打击。据了解，国内企业相当多的传统海外业务联系方式已经被客户告知暂停，然而通过网络实现海外业务的贸易方式则迅速增长。 从长期致力于促进网络国际贸易的美国环球资源公司中国总部获悉，4月份买家发送给环球资源网站供应商的信息查询比去年同期增长了30%，而经独立第三方机构审核的环球资源活跃买家社群成员超过38.5万家，比去年同期增长16%。 “买家和供应商比任何时候都迫切需要其它替代的方法来继续贸易采购。国际贸易不可能因为一些偶然事件而停止。而网上服务、电子沟通方式，恰好可以满足国际贸易买卖双方的需求。”环球资源公司的负责人如是说。 面对非典，投资落户天津经济技术开发区的3616家外资企业没有一家撤资，生产业务一如往常，对外招商引资、网上联络洽谈、增资等各项工作有条不紊地展开。招商部门在继续做好与外资企业、外商办事处沟通联络的同时，积极利用电子商务、电话、传真等现代化通信手段，由专人进行外资项目的跟踪服务，随时掌握项目的进展动向，保持各项主要经济指标实现持续高增长。 在上海，在SARS的威胁下，许多行业纷纷遭受打击，但是网上买卖却陡然火了起来。而一批从事网上创业的4050人员成了其中的最大受益者。据某从事网上商务业务的网站称，近期日平均交易额已经达到230万元，较之三月份日均交易额170万元增长了近30%；如今平均每天在易趣网上完成的交易近4万笔，较之三月份日均交易3万笔，也增长了三成。 首钢近日发布好消息称，在非典疫情给生产生活带来种种困难的情况下，4月份，首钢北京地区预计完成销售收入18.5亿元，比去年同期增加1.5亿元，增长8.8%；1至4月预计实现销售收入76亿元，比去年同期增加9.1亿元，增长13.6%。针对非典疫情给经营生产带来的各种困难，首钢的销售公司则克服了首钢客户与订货量明显减少的困难，着眼于网上办公和电子商务，形成了非典时期的函件传真订货管理办法、客户远程订货与合同查询管理办法、销售服务管理办法，来应对形势变化。通过远程订货和邮寄付款等措施，实现了产销衔接，4月份各项销售指标全面完成。 面对非典疫情造成的各种不确定因素，江苏省政府、企业和中介机构不约而同地迅速改变招式，电子商务普遍成为维护工业经济稳定运行的重要手段之一，电子商务出现前所未有的走强态势。 江苏省决定重点实施电信传输骨干网、光缆接入网和数字多媒体网络建设。加快推进重点行业、重点企业和重点产品的技术升级，包括信息化在内的技术改造投资今年要完成1600亿元。目前，江苏省许多政府部门正在抓紧梳理近年来积累的外商信息，建立招商引资电子数据库。 前不久，江苏一家钢瓶厂向武钢提出订购一种特定型号的气瓶钢卷200吨。该需求经过武钢整体产销资讯系统审核，进行备料、生产、销售时间排程，当即签下合同，并如期交货。这是武钢用信息化改造传统工业、提升企业市场竞争力的一个缩影。投资2亿元的武钢整体产销资讯系统工程，于今年1月正式上线运行。该系统通过计算机网络安排订货、生产、销售，作用日益显现。截至目前，该系统已经接收2003年订货合同66.59万吨。 今年二季度以来，国内钢材市场受非典疫情等影响，发生很大波动，部分钢材产品价格下跌。武钢销售人员利用产销资讯系统上线的快捷、便利优势，采取电话、网上订货的形式，仅在4月份，就接下了钢材和钢坯合同28.73万吨，完成销售收入15.49亿元。武钢销售公司负责人说：“这在以前，我们的销售肯定会受到一定的冲击。但产销资讯系统的启用，使我们在市场竞争中又多了一件利器。”
