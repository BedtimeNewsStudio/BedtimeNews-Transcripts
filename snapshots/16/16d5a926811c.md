# Docker simulation stack

We have created a **Docker container** which contains all of the major components of the [simulation stack](http://docs.openworm.org/projects) we have built so far. It can be used to run a **preliminary model** of the worm in 3D on your computer.

![](https://raw.githubusercontent.com/openworm/OpenWorm/master/img/worm-crawling.gif)

[OpenWorm Docker](https://github.com/openworm/OpenWorm/blob/master/README.md#quickstart)

# For coders

**Geppetto** is a web-based platform for visualizing and simulating data and models. It started in the OpenWorm project and is being used for a number of other projects across neuroscience.

[Geppetto releases](https://github.com/openworm/org.geppetto/releases)

The 3D worm body model in OpenWorm is being developed in **Sibernetic**. you can download this application and run the particle hydrodynamics simulations on your own machine.

[Get Sibernetic](https://github.com/openworm/sibernetic)

We have developed a Python library, **owmeta**, which gives easy programmatic access to a wide range of anatomical and physiological data about _C. elegans_.

[Download owmeta](https://github.com/openworm/owmeta)

The **c302** framework allows network models of the _C. elegans_ nervous system to be generated at various levels of detail to simulate the activity of the brain of the worm.

[Install c302](https://github.com/openworm/c302)

Find out how these and other software packages fit together on our [OpenWorm projects page](http://docs.openworm.org/projects).
